## 1. 系统概述

### 1.1 项目背景
本项目为三段式玻璃输送线自动化控制系统，用于玻璃生产/加工过程中的物料传输。系统包含三条独立控制的输送线：
- **上游输送线**: 接收来自上一工序的玻璃板
- **本站输送线**: 核心工位，负责玻璃定位和工艺处理
- **下游输送线**: 将完成处理的玻璃送至下一工序

### 1.2 设计目标
1. **高可靠性**: 采用成熟的FB_ConveyorControlV4功能块，经过V4.8.1版本验证
2. **安全性**: 完善的联锁逻辑，防止玻璃堆积、碰撞、掉落
3. **灵活性**: 支持手动/自动模式切换，适应不同工况
4. **可维护性**: 模块化设计，三层分离结构(Source/ST结构文本/Docs)

### 1.3 技术规格
| 参数 | 规格 |
|------|------|
| 输送产品 | 浮法玻璃 |
| 产品尺寸 | 1300mm(长) × 700mm(宽) × 10mm(厚) |
| 单片重量 | 约2.3 kg |
| 输送速度 | 可调(0-100 Hz变频控制) |
| 定位精度 | ±5mm (光电传感器检测) |
| PLC扫描周期 | ≤10ms |
| 通讯方式 | 本地I/O + Modbus RTU(预留) |

## 4. 联锁逻辑设计

### 4.1 核心联锁规则

#### 规则1: 正向联锁 (Forward Interlock)
**目的**: 防止向已满载的下游输送产品

```
IF 下游.q_ProductInPlaceDone = TRUE THEN
    禁止上游启动 (或启动后立即暂停)
END_IF
```

**应用场景**:
- 上游 → 本站: 当本站到位标志为TRUE时,禁止上游继续送料
- 本站 → 下游: 当下游到位标志为TRUE时,禁止本站继续送料

#### 规则2: 反向联锁 (Reverse Interlock)
**目的**: 故障向上游传播,防止持续送料导致堆积

```
IF 当前输送线.q_MotorFault = TRUE THEN
    立即停止当前输送线
    向上游发出停止请求
END_IF
```

**故障传播链**:
```
下游故障 → 停止下游 → 通知本站停止 → 停止本站 → 通知上游停止 → 停止上游
```

#### 规则3: 启动顺序约束
**正常启动顺序**: 下游 → 本站 → 上游 (从出口向入口依次启动)
**正常停止顺序**: 上游 → 本站 → 下游 (从入口向出口依次停止)

### 4.2 联锁逻辑流程图
```
┌──────────────────────────────────────────────────────────┐
│                    主循环扫描                               │
├──────────────────────────────────────────────────────────┤
│  Step 1: 读取所有输入信号                                   │
│  Step 2: 计算联锁条件                                       │
│          ├─ bAllowUpstream := NOT Station.ProductInPlaceDone│
│          ├─ bAllowStation := NOT Downstream.ProductInPlaceDone│
│          └─ bSystemFault := ANY(FaultFlags)                │
│  Step 3: 更新FB输入参数(加入联锁)                           │
│  Step 4: 调用3个FB实例                                      │
│  Step 5: 处理故障传播                                       │
│  Step 6: 写入输出                                          │
└──────────────────────────────────────────────────────────┘
```

### 4.3 安全保护机制
| 保护类型 | 触发条件 | 动作 | 恢复条件 |
|---------|---------|------|---------|
| 急停保护 | 急停按钮按下 | 全线立即停止 | 解除急停+人工复位 |
| 驱动报警 | 任一驱动器故障 | 对应线停止+上游联锁停止 | 报警消除+5秒延时+复位 |
| 传感器异常 | 传感器信号超时 | 报警提示 | 信号恢复 |
| 堆积保护 | 下游满位 | 上游禁止启动 | 下游空位 |

前缀规则:
- `X_` / `DI_`: 数字量输入
- `Y_` / `DQ_`: 数字量输出
- `I_` / `AI_`: 模拟量输入
- `Q_` / `AQ_`: 模拟量输出
- `M_` / `Flags_`: 中间标志位
- `D_` / `Data_`: 数据寄存器

示例:
```
X_Start_Upstream        // 上游启动按钮
Y_MotorRun_Station      // 本站电机运行输出
D_SpeedFreq_Downstream  // 下游速度频率设定
```

## 6. 与FB_ConveyorControlV4的接口适配

### 6.1 FB接口回顾 (V4.8.1)
**输入 (9个)**:
- `i_Start`, `i_Stop` - 启动/停止
- `i_Position1Sensor` - 产品到位检测
- `i_MainControlMode` - 运行模式(0停/1手/2自)
- `i_MotorDirection` - 方向(0正转/1反转)
- `i_SlowDelayTime` - 慢速延时(ms)
- `i_Reset` - 复位
- `i_DriveAlarm` - 驱动报警
- `i_Offline` - 离线选择

**INOUT (1个)**:
- `i_SpeedFrequency` - 速度频率(Hz),范围0-100

**输出 (6个)**:
- `q_MotorRunning` - 电机运行状态
- `q_MotorFault` - 故障状态
- `q_MotorDirection` - 方向状态
- `q_ProductInPlaceDone` - 产品到位完成
- `q_SpeedOutput` - 速度输出(Hz)
- `q_StatusWord` - 状态字

### 6.2 三线联锁适配策略
在调用FB前,对输入信号进行联锁处理:

```scl
(* 上游输送线 - 受本站到位信号联锁 *)
fbConveyorUpstream.i_Start := X_Start_Upstream AND bAllowUpstream;
fbConveyorUpstream.i_Stop := X_Stop_Upstream OR (NOT bAllowUpstream);

(* 本站输送线 - 受上下游双重约束 *)
fbConveyorStation.i_Start := X_Start_Station AND bAllowStation;
fbConveyorStation.i_Stop := X_Stop_Station OR (NOT bAllowStation);

(* 下游输送线 - 无下游约束,但受系统急停影响 *)
fbConveyorDownstream.i_Start := X_Start_Downstream AND NOT bEmergencyStop;
fbConveyorDownstream.i_Stop := X_Stop_Downstream OR bEmergencyStop;
```

## 7. 扩展性设计

### 7.1 预留接口
- **HMI接口**: 预留Modbus TCP/IP通讯区,用于ProFace触摸屏监控
- **上位机接口**: 预留Modbus RTU/MES数据采集接口
- **视觉检测**: 预留本站工位的视觉检测触发/反馈信号

### 7.2 未来扩展方向
1. **多规格支持**: 通过HMI设置不同产品的尺寸参数,自动调整速度和延时
2. **MES对接**: 上报生产计数、故障记录、OEE数据
3. **能耗监测**: 采集各驱动器的电流、功率数据,优化能效
