## 3. 概述

### 3.1 项目背景
本项目为三段式玻璃输送线自动化控制系统（DJ-2026-014），用于玻璃生产/加工过程中的物料传输。系统基于成熟的 **FB_ConveyorControlV4 V4.8.1** 功能块进行工程化扩展，将单条输送线控制能力升级为完整的三段式联锁控制系统。

**原始工程来源**:
- 原始功能块: `d:\BaiduSyncdisk\My_Workspace\人工_AI模板\项目2_输送机\AI修改2.0`
- 功能块: FB_ConveyorControlV4 V4.8.1 (515行SCL)
- 开发文档: 需求文档、详细设计说明书、接口文档、开发文档、使用文档、版本变更文档（共6份）

### 3.2 设计目标

#### 功能目标
1. 实现三条独立输送线的协调控制：上游(Line1) → 本站(Line2/核心) → 下游(Line3)
2. 支持手动/自动双模式运行
3. 实现正向联锁（防堆积）和反向联锁（故障传播）
4. 提供完善的安全保护机制（急停、驱动报警、传感器异常）
5. 支持速度频率调节（0-100Hz, 模拟量输出到变频器）

#### 性能目标
| 指标 | 目标值 | 备注 |
|------|--------|------|
| PLC扫描周期 | ≤10ms | 汇川H5U系列 |
| 联锁响应时间 | <30ms (3个扫描周期) | 从故障发生到全线停止 |
| 定位精度 | ±5mm | 光电传感器检测 |
| 系统可用率 | ≥99% | 24小时连续运行 |

### 3.3 适用范围
- **适用设备**: 玻璃生产线输送工位
- **适用产品**: 浮法玻璃板 **1300×700×10mm (约2.3kg/片)**
- **PLC平台**: 汇川AM/H5U系列 (Autoshop V3.x 编程环境)
- **限制条件**: 仅适用于三段式直线输送场景

```
┌──────────────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────────────┤

│   → 设置 bEmergencyStop / nSystemStatus / Y_Alarm_*         │
│                                                              │

│   → bAllowUpstream := NOT Station.ProductInPlaceDone         │
│   → bAllowStation  := NOT Downstream.ProductInPlaceDone      │
│                                                              │
│ Step 3: 计算反向联锁 (故障传播)                               │
│   → bSystemFault := ANY(FaultFlags)                          │
│   → 故障时禁止上游和本站                                     │
│                                                              │
│ Step 4~6: 准备3个FB的输入参数 (加入联锁约束)                  │
│   → i_Start / i_Stop 加入 bAllow* 和 bEmergencyStop 条件     │
│   → i_Position1Sensor 映射到对应传感器                        │

│                                                              │
│ Step 7: 调用3个FB实例                                         │
│   → fbConveyorUpstream()                                    │
│   → fbConveyorStation()                                     │
│   → fbConveyorDownstream()                                  │
│                                                              │
│ Step 8: 映射输出到物理IO                                      │
│   → 电机运行 → Y_MotorRun_*                                 │
│   → 指示灯 → Y_RunInd_*/Y_FaultInd_*/Y_ProductDone_*       │
│   → 速度输出 → Q_SpeedFreq_*                                │
│                                                              │
│ Step 9: 生产计数 (本站到位上升沿)                             │
│   → R_TRIG边沿检测 → nProductCount累加                       │
├──────────────────────────────────────────────────────────────┤
│                    Main Cycle End (~10ms)                    │
└──────────────────────────────────────────────────────────────┘
```

#### 6.2.2 内部状态机

```
         ┌──────────────────────────────────────────────┐
         │              Idle (空闲)                      │
         │  条件: 初始状态 或 复位后                     │
         └──────────────┬───────────────────────────────┘
                        │ i_Start=TRUE AND 无报警 AND
                        │ 无到位完成 AND (手动 OR 自动模式)
                        ▼
         ┌──────────────────────────────────────────────┐
         │         Running_Fast (快速运行)               │
         │  动作: q_SpeedOutput = i_SpeedFrequency       │
         │        q_MotorRunning = TRUE                 │
         └──────────────┬───────────────────────────────┘
                        │ i_Position1Sensor = TRUE
                        │ (检测到产品)
                        ▼
         ┌──────────────────────────────────────────────┐
         │        Running_Slow (慢速运行)                 │
         │  动作: q_SpeedOutput = Speed/3               │
         │        启动慢速定时器(T#_SlowDelayTime)       │
         └──────────────┬───────────────────────────────┘
                        │ 定时器到时
                        ▼
         ┌──────────────────────────────────────────────┐
         │      In_Place (到位停止)                      │
         │  动作: q_MotorRunning = FALSE                │
         │        q_ProductInPlaceDone = TRUE           │
         │        q_SpeedOutput = 0.0                  │
         └──────────────┬───────────────────────────────┘
                        │ 传感器消失 > 3秒
                        ▼
                 (回到Idle, ProductInPlaceDone仍为TRUE,
                  直到外部取走产品后复位)
```

**特殊状态转换**:
- **AlarmState (报警状态)**: 当 `i_DriveAlarm=TRUE` 时从任何状态进入,设置 `q_MotorFault=TRUE`,电机停止
- **FaultState (故障状态)**: 报警未复位的持续状态,需 `i_Reset=TRUE` 且报警消除才能退出
- **停止转换**: 任何时候 `i_Stop=TRUE` 都会触发停止,回到Idle

| 变量名 | 类型 | 初始值 | 用途 |

| `tmp_rSpeedLimit` | REAL | 100.0 | 速度上限限制 |
| `tmp_nLastStatusWord` | INT | 0 | 上一周期状态字(用于变化检测) |

#### 6.2.4 三个FB实例的参数差异

| 参数 | Upstream (Line1) | Station (Line2) | Downstream (Line3) |
|------|------------------|-----------------|-------------------|
| **i_Start** | X_Start_Upstream **AND** bAllowUpstream | X_Start_Station **AND** bAllowStation | X_Start_Downstream (**无下游约束**) |
| **i_Stop** | X_Stop_Upstream **OR NOT** bAllowUpstream | X_Stop_Station **OR NOT** bAllowStation | X_Stop_Downstream **OR** bEmergencyStop |
| **i_Position1Sensor** | X_SensorUpstream_Position1 | X_SensorStation_Position1 | X_SensorDownstream_Position1 |
| **i_SpeedFrequency** | I_SpeedSet_Upstream (默认50Hz) | I_SpeedSet_Station (默认50Hz) | I_SpeedSet_Downstream (默认50Hz) |
| **用途** | 接收上工序来料 | **核心工位定位** | 送至下工序出口 |
| **联锁约束** | 受**本站**到位信号约束 | 受**下游**到位信号约束 | **无下游约束**(末端) |

## 8. 报警设计

### 8.1 报警分类

| 报警等级 | 定义 | 触发条件 | 响应方式 | 恢复条件 |
|---------|------|----------|----------|----------|
| **L0 - 紧急** | 急停 | 急停按钮按下(X1断开) | 全线立即停止(<100ms硬线) | 解除急停 + 人工复位 |
| **L1 - 严重** | 驱动故障 | 任一变频器报警(X20/X21/X22) | 对应线停止 + 联锁停止上游 | 报警消除 + 5秒延时 + 复位 |
| **L2 - 一般** | 联锁停止 | 下游满位/上游故障 | 禁止启动(不急停) | 条件解除自动恢复 |
| **L3 - 提示** | 传感器超时 | 单次循环超过60秒 | 报警提示(不停线) | 人工检查确认 |

### 8.2 报警列表

| 报警ID | 报警名称 | 触发源 | 等级 | 动作 | 输出指示 |
|--------|----------|--------|------|------|----------|
| ALM-001 | 系统急停 | X_EmergencyStop | L0 | 全线立即停止 | 塔灯红灯 + 蜂鸣器 |
| ALM-002 | 上游驱动报警 | X_DriveAlarm_Upstream | L1 | 上游停止 + 禁止本站/上游启动 | Y_FaultInd_Upstream(红) |
| ALM-003 | 本站驱动报警 | X_DriveAlarm_Station | L1 | 本站停止 + 禁止上游启动 | Y_FaultInd_Station(红) |
| ALM-004 | 下游驱动报警 | X_DriveAlarm_Downstream | L1 | 下游停止 + 禁止本站/上游启动 | Y_FaultInd_Downstream(红) |
| ALM-005 | 上游满位联锁 | Station.ProductInPlaceDone | L2 | 禁止上游启动 | (无声光,仅软件联锁) |
| ALM-006 | 本站满位联锁 | Downstream.ProductInPlaceDone | L2 | 禁止本站/上游启动 | (无声光,仅软件联锁) |
| ALM-007 | 传感器异常(上游) | 信号持续>60s | L3 | 报警提示 | (预留HMI显示) |
| ALM-008 | 传感器异常(本站) | 信号持续>60s | L3 | 报警提示 | (预留HMI显示) |
| ALM-009 | 传感器异常(下游) | 信号持续>60s | L3 | 报警提示 | (预留HMI显示) |

### 8.3 报警处理逻辑

```
IF bEmergencyStop THEN
    (* L0: 急停 - 最高优先级 *)
    nSystemStatus := 3;
    Y_Alarm_Buzzer := TRUE;
    Y_Alarm_TowerLight := RED;
ELSIF bSystemFault THEN
    (* L1/L2: 驱动故障或联锁 *)
    nSystemStatus := 2;
    Y_Alarm_TowerLight := RED;  (* L1时亮红灯 *)
    (* 具体哪条线故障由对应的Y_FaultInd_*指示 *)
ELSE
    (* L3: 正常或提示 *)
    Y_Alarm_Buzzer := FALSE;
    Y_Alarm_TowerLight := GREEN or OFF;
END_IF
```

## 10. 安全设计

### 10.1 安全功能矩阵

| 安全功能 | 实现方式 | 安全等级 | 响应时间 | 符合标准 |
|---------|----------|----------|----------|----------|
| **急停保护** | 硬线常闭串联 + 软件检测双重 | SIL 2 / PL d | <100ms | IEC 61508 / ISO 13849-1 |
| **驱动器故障保护** | 变频器故障继电器 + FB报警处理 | SIL 1 / PL c | <20ms | IEC 61508 |
| **联锁防堆积** | 软件正向联锁逻辑 | - | <30ms | 行业最佳实践 |
| **故障传播保护** | 软件反向联锁逻辑 | - | <30ms | 行业最佳实践 |
| **方向互锁** | FB内部方向检查 | - | 即时 | 功能安全 |
| **参数越界保护** | 速度限幅(0-100Hz) | - | 即时 | 编程规范 |

### 10.2 急停回路设计 (硬线)

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│  +24V    │────▶│ 急停按钮  │────▶│ KM1线圈  │────▶│  0V      │
│ (电源)   │     │ (常闭)   │     │ (上游)   │     │ (电源)   │
└──────────┘     └──────────┘     └──────────┘     └──────────┘
                                       │
                    ┌──────────────────┤
                    │                  ▼
               ┌──────────┐     ┌──────────┐
               │ KM2线圈  │     │ KM3线圈  │
               │ (本站)   │     │ (下游)   │
               └──────────┘     └──────────┘
```

**说明**:
- 急停按钮采用**常闭触点**,串联所有接触器(KM1/KM2/KM3)的线圈回路
- 急停按下时,物理断开线圈供电,所有电机**立即停止**(不受PLC扫描周期影响)
- PLC同时通过X_EmergencyStop检测急停状态,执行软件层面的紧急停止逻辑
- 这种**硬线+软件双重保护**符合IEC 61508 SIL 2要求

### 10.3 安全相关变量

| 变量名 | 安全等级 | 说明 |
|--------|----------|------|
| `X_EmergencyStop` | ⭐⭐⭐ Critical | 急停输入(常闭),任何情况下不可屏蔽 |
| `bEmergencyStop` | ⭐⭐⭐ Critical | 急停状态(取反),参与所有启动条件的AND运算 |
| `Y_Alarm_Buzzer` | ⭐⭐ High | 蜂鸣器输出,急停/故障时激活 |
| `Y_Alarm_TowerLight` | ⭐⭐ High | 塔灯输出,红=紧急/黄=警告/绿=正常 |
| `X_SystemReset` | ⭐⭐ High | 复位按钮,仅在有权限时操作 |

## 12. 调试说明

### 12.1 调试前准备

- [ ] 确认PLC型号与程序匹配(H5U/AM600)
- [ ] 确认IO接线与分配表一致(使用万用表逐点测量)
- [ ] 确认变频器参数已设置(加速时间/减速时间/频率范围)
- [ ] 确认传感器安装位置正确且灵敏度已调校
- [ ] 确认急停回路接线正确(常闭串联)
- [ ] 将程序下载到PLC(Autoshop在线连接)

### 12.2 分步调试流程

#### Step 1: IO测试 (不带电机)
```
1. 下载程序到PLC,切换到STOP模式
2. 使用Autoshop的"变量监视表"观察所有DI变量
3. 逐个按下操作按钮,确认DI状态正确变化
4. 逐一遮挡光电传感器,确认传感器信号正确
5. 手动强制输出DO,确认指示灯和继电器动作
```

#### Step 2: 单线调试 (先调下游,再调本站,最后调上游)
```
1. 只启用下游输送线(bSystemOffline=TRUE脱离联锁)
2. 手动模式下测试启停、速度调节
3. 测试产品到位检测(用纸板模拟玻璃)
4. 确认慢速运行和到位停止时序正确
5. 测试驱动器报警模拟(短接X22)
6. 下游OK后,依次调试本站和上游
```

#### Step 3: 联锁调试 (全线联动)
```
1. 切换回在线模式(bSystemOffline=FALSE)
2. 按推荐顺序启动: 下游→本站→上游
3. 测试正向联锁: 让本站到位,尝试启动上游(应被禁止)
4. 测试反向联锁: 模拟下游故障,观察全线停止顺序
5. 测试急停: 按下急停,确认全线<100ms内停止
6. 测试生产计数: 多次送入产品,确认计数准确
```

#### Step 4: 性能验证
```
1. 使用Autoshop的"周期测量"工具监测扫描周期
2. 确认连续运行1小时无故障
3. 记录响应时间数据,与设计目标对比
```

### 12.3 常见问题排查

| 问题现象 | 可能原因 | 排查方法 |
|---------|----------|----------|
| 按下启动但电机不动 | bAllow*为FALSE(联锁禁止) | 监视bAllowUpstream/bAllowStation,检查下游是否到位 |
| 传感器检测不到产品 | 传感器偏移/脏污/电源问题 | 检查传感器LED指示,调整位置,清洁镜头 |
| 电机启动后立即停止 | i_Stop被联锁置TRUE | 检查是否有故障信号或下游满位 |
| 速度输出为0 | i_SpeedFrequency=0或FB不在Running态 | 检查AI输入值和FB状态字 |
| 急停后无法复位 | 未解除急停或仍有报警 | 先旋转释放急停按钮,再按复位 |
| 计数不准确 | 边沿检测抖动 | 检查R_TRIG配置,增加滤波 |
