## 1. 设计原则

### 1.1 核心目标
- **防堆积**: 确保下游有空间时才允许上游送料
- **防碰撞**: 避免两片玻璃在同一位置重叠
- **故障安全**: 任一环节故障时全线有序停止
- **平滑过渡**: 启停顺序合理,避免机械冲击

### 1.2 安全等级
| 保护等级 | 触发条件 | 响应时间 | 恢复方式 |
|---------|---------|---------|---------|
| L0 - 急停 | 急停按钮按下 | <100ms(硬线) | 解除急停+人工确认 |
| L1 - 驱动报警 | 变频器故障 | 1个扫描周期 | 报警消除+5秒延时+复位 |
| L2 - 联锁停止 | 下游满位/上游故障 | 1个扫描周期 | 条件解除自动恢复 |
| L3 - 正常停止 | 操作员停止指令 | 1个扫描周期 | 重新启动 |

## 2. 联锁逻辑详解

### 2.1 正向联锁 (Forward Interlock) - 防堆积

#### 2.1.1 上游→本站联锁
```
条件: 本站.q_ProductInPlaceDone = TRUE (本站已有产品到位)

动作:
  - 禁止上游启动新周期
  - 若上游正在运行,立即暂停(不急停,保留当前位置)
  - 设置 bAllowUpstream := FALSE

恢复: 本站.q_ProductInPlaceDone = FALSE (产品被取走3秒后)
      → bAllowUpstream := TRUE,上游可继续
```

#### 2.1.2 本站→下游联锁
```
条件: 下游.q_ProductInPlaceDone = TRUE (下游已满位)

动作:
  - 禁止本站启动新周期
  - 若本站正在运行,立即暂停
  - 设置 bAllowStation := FALSE

恢复: 下游.q_ProductInPlaceDone = FALSE
      → bAllowStation := TRUE,本站可继续
```

#### 2.1.3 下游无约束
```
下游输送线是最末端,无下游设备约束。
但受系统急停和全局离线信号控制。
```

### 2.2 反向联锁 (Reverse Interlock) - 故障传播

#### 2.2.1 故障传播链
```
场景: 下游驱动器报警 (X_DriveAlarm_Downstream = TRUE)

传播过程:
  T=0ms   : 下游FB检测到报警 → q_MotorFault_Downstream = TRUE
            → 下游电机立即停止
  T=10ms  : 主程序检测到下游故障
            → bSystemFault = TRUE
            → 向本站发出停止请求 (bAllowStation强制FALSE)
  T=20ms  : 本站FB收到停止 → 停止运行
            → 主程序检测到级联需求
            → 向上游发出停止请求 (bAllowUpstream强制FALSE)
  T=30ms  : 上游FB收到停止 → 停止运行
            → 全线停止完成

总响应时间: <3个扫描周期 (<30ms @10ms扫描周期)
```

#### 2.2.2 故障隔离与恢复
```
恢复顺序 (从源头开始):
  Step 1: 排除下游故障原因
  Step 2: 等待 X_DriveAlarm_Downstream = FALSE 持续5秒
  Step 3: 按下复位按钮 X_SystemReset
          → 下游FB清除报警状态
  Step 4: 自动解除 bAllowStation 约束 (如果下游确实空位)
  Step 5: 本站可手动启动
  Step 6: 上游可手动启动 (当本站空位时)
```

### 2.3 启动顺序约束

#### 2.3.1 正常启动流程 (从出口向入口)
```
推荐启动顺序: 下游 → 本站 → 上游

Step 1: 确认全线就绪 (无故障,无急停,无产品残留)
Step 2: 启动下游 (X_Start_Downstream)
        → 下游进入快速运行,等待产品
Step 3: 确认下游运行正常 (q_MotorRunning_Downstream = TRUE)
Step 4: 启动本站 (X_Start_Station)
        → 本站进入快速运行
Step 5: 确认本站运行正常
Step 6: 启动上游 (X_Start_Upstream)
        → 上游进入快速运行,全线投入运行
```

**为什么必须先启 downstream?**
- 如果先启动上游,产品会快速到达本站
- 但本站还没启动,无法接收 → 产品在本站入口处堆积
- 可能导致传感器误判或机械干涉

#### 2.3.2 正常停止流程 (从入口向出口)
```
推荐停止顺序: 上游 → 本站 → 下游

Step 1: 停止上游 (X_Stop_Upstream)
        → 上游停止,不再送新产品到本站
Step 2: 等待本站当前产品处理完毕 (本站ProductInPlaceDone = TRUE)
        → 产品被取走后,本站自动停止或手动停止
Step 3: 停止本站 (X_Stop_Station)
        → 本站停止,不再送新产品到下游
Step 4: 等待下游当前产品处理完毕
Step 5: 停止下游 (X_Stop_Downstream)
        → 全线停止完成
```

**为什么必须先停 upstream?**
- 先停上游可以确保不再有新产品进入系统
- 让系统中已有的产品按顺序流向出口并处理完
- 避免中途停止导致产品卡在中间位置

## 3. 特殊场景处理

### 3.1 场景A: 急停触发
```
触发: X_EmergencyStop = FALSE (常闭触点断开)

动作:
  1. bEmergencyStop := TRUE
  2. 所有FB的 i_Stop 强制为TRUE (覆盖正常停止逻辑)
  3. 所有电机立即停止 (硬线+软件双重保护)
  4. Y_Alarm_Buzzer := TRUE (蜂鸣器响)
  5. Y_Alarm_TowerLight := RED (塔灯红灯)

恢复:
  1. 排除急停原因,旋转释放急停按钮
  2. X_EmergencyStop 恢复为TRUE
  3. bEmergencyStop := FALSE
  4. 按下 X_SystemReset 复位所有错误状态
  5. 按正常启动顺序重新启动
```

### 3.2 场景B: 传感器异常
```
现象: 位置传感器信号持续为TRUE超过超时时间(如30秒)

可能原因:
  - 传感器脏污/偏移
  - 玻璃未成功取走(下游设备故障)
  - 传感器线路短路

处理策略:
  - FB内部: 产品到位后3秒内传感器应变为FALSE,否则保持ProductInPlaceDone
  - 主程序: 可添加超时监控计时器,若单次循环超过60秒则报警提示
  - 不自动复位,需人工检查
```

### 3.3 场景C: 手动模式下的联锁
```
手动模式下,操作员完全控制每条线的启停。

联锁仍然生效:
  - 即使在手动模式,bAllowUpstream/bAllowStation 仍根据到位信号计算
  - 若违反联锁,对应线的启动信号被屏蔽
  - 但可以通过 i_Offline = TRUE 临时脱离联锁(调试用,需谨慎)

建议:
  - 手动模式主要用于调试和检修
  - 正常生产使用自动模式,由主控系统统一协调
```

### 3.4 场景D: 离线调试模式
```
i_Offline 参数说明:
  - i_Offline = TRUE (离线):
    * 忽略外部启动/停止按钮 (i_Start/i_Stop无效)
    * 完全依赖程序内部控制 (如HMI或上位机指令)
    * 联锁逻辑仍生效 (安全性不能绕过)

  - i_Offline = FALSE (在线): 默认值
    * 响应操作台按钮
    * 正常生产模式
```

## 4. 联锁逻辑实现伪代码

```scl
(* ============================================ *)
(* DJ-2026-014 主程序 - 联锁逻辑核心 *)
(* ============================================ *)

PROGRAM PRG_Main_GlassConveyor
VAR
    (* FB实例 *)
    fbConveyorUpstream   : FB_ConveyorControlV4;
    fbConveyorStation    : FB_ConveyorControlV4;
    fbConveyorDownstream : FB_ConveyorControlV4;

    (* 联锁标志 *)
    bAllowUpstream : BOOL := TRUE;
    bAllowStation  : BOOL := TRUE;
    bSystemFault   : BOOL := FALSE;
    bEmergencyStop : BOOL := FALSE;
    bSystemOffline : BOOL := FALSE;

    (* 系统状态 *)
    nSystemStatus   : INT := 0;  (* 0停/1运行/2故障/3急停 *)
    nProductCount   : DINT := 0;
END_VAR


(* ---------- 主逻辑 ---------- *)

(* 1. 读取急停状态 (X1为常闭,断开时为FALSE) *)
bEmergencyStop := NOT X_EmergencyStop;

IF bEmergencyStop THEN
    nSystemStatus := 3;  (* 急停状态 *)
    Y_Alarm_Buzzer := TRUE;
    Y_Alarm_TowerLight := RED;
ELSE
    Y_Alarm_Buzzer := FALSE;
END_IF;


(* 2. 计算正向联锁条件 *)
(* 上游允许运行 = 本站没有产品到位 *)
bAllowUpstream := NOT fbConveyorStation.q_ProductInPlaceDone;

(* 本站允许运行 = 下游没有产品到位 AND 无急停 *)
bAllowStation := NOT fbConveyorDownstream.q_ProductInPlaceDone
                AND NOT bEmergencyStop;


(* 3. 计算反向联锁 (故障传播) *)
bSystemFault := fbConveyorUpstream.q_MotorFault
             OR fbConveyorStation.q_MotorFault
             OR fbConveyorDownstream.q_MotorFault;

IF bSystemFault THEN
    nSystemStatus := 2;  (* 故障状态 *)
    (* 故障时强制禁止上游和本站 *)
    IF fbConveyorDownstream.q_MotorFault THEN
        bAllowStation := FALSE;
        bAllowUpstream := FALSE;
    ELSIF fbConveyorStation.q_MotorFault THEN
        bAllowUpstream := FALSE;
    END_IF;
ELSIF NOT bEmergencyStop AND (
       fbConveyorUpstream.q_MotorRunning
       OR fbConveyorStation.q_MotorRunning
       OR fbConveyorDownstream.q_MotorRunning ) THEN
    nSystemStatus := 1;  (* 运行状态 *)
ELSE
    nSystemStatus := 0;  (* 停止状态 *)
END_IF;


(* 4. 准备FB输入参数 (加入联锁) *)

(* --- 上游输送线 --- *)
fbConveyorUpstream.i_Start := X_Start_Upstream
                          AND bAllowUpstream
                          AND NOT bSystemFault
                          AND NOT bEmergencyStop;
fbConveyorUpstream.i_Stop := X_Stop_Upstream
                         OR NOT bAllowUpstream
                         OR bSystemFault
                         OR bEmergencyStop;
fbConveyorUpstream.i_Position1Sensor := X_SensorUpstream_Position1;
fbConveyorUpstream.i_MainControlMode := D_MainControlMode;
fbConveyorUpstream.i_MotorDirection := D_MotorDirection_Upstream;
fbConveyorUpstream.i_SlowDelayTime := 1000;  (* 默认1秒 *)
fbConveyorUpstream.i_Reset := X_SystemReset;
fbConveyorUpstream.i_DriveAlarm := X_DriveAlarm_Upstream;
fbConveyorUpstream.i_Offline := bSystemOffline;
(* i_SpeedFrequency 由 GVL 提供 *)


(* --- 本站输送线 --- *)
fbConveyorStation.i_Start := X_Start_Station
                        AND bAllowStation
                        AND NOT bSystemFault
                        AND NOT bEmergencyStop;
fbConveyorStation.i_Stop := X_Stop_Station
                       OR NOT bAllowStation
                       OR bSystemFault
                       OR bEmergencyStop;
fbConveyorStation.i_Position1Sensor := X_SensorStation_Position1;
fbConveyorStation.i_MainControlMode := D_MainControlMode;
fbConveyorStation.i_MotorDirection := D_MotorDirection_Station;
fbConveyorStation.i_SlowDelayTime := 1000;
fbConveyorStation.i_Reset := X_SystemReset;
fbConveyorStation.i_DriveAlarm := X_DriveAlarm_Station;
fbConveyorStation.i_Offline := bSystemOffline;


(* --- 下游输送线 --- *)
fbConveyorDownstream.i_Start := X_Start_Downstream
                           AND NOT bSystemFault
                           AND NOT bEmergencyStop;
fbConveyorDownstream.i_Stop := X_Stop_Downstream
                          OR bSystemFault
                          OR bEmergencyStop;
fbConveyorDownstream.i_Position1Sensor := X_SensorDownstream_Position1;
fbConveyorDownstream.i_MainControlMode := D_MainControlMode;
fbConveyorDownstream.i_MotorDirection := D_MotorDirection_Downstream;
fbConveyorDownstream.i_SlowDelayTime := 1000;
fbConveyorDownstream.i_Reset := X_SystemReset;
fbConveyorDownstream.i_DriveAlarm := X_DriveAlarm_Downstream;
fbConveyorDownstream.i_Offline := bSystemOffline;


(* 5. 调用FB实例 *)
fbConveyorUpstream();
fbConveyorStation();
fbConveyorDownstream();


(* 6. 映射输出 *)
Y_MotorRun_Upstream   := fbConveyorUpstream.q_MotorRunning;
Y_MotorRun_Station    := fbConveyorStation.q_MotorRunning;
Y_MotorRun_Downstream := fbConveyorDownstream.q_MotorRunning;

Y_RunInd_Upstream     := fbConveyorUpstream.q_MotorRunning;
Y_RunInd_Station      := fbConveyorStation.q_MotorRunning;
Y_RunInd_Downstream   := fbConveyorDownstream.q_MotorRunning;

Y_FaultInd_Upstream   := fbConveyorUpstream.q_MotorFault;
Y_FaultInd_Station    := fbConveyorStation.q_MotorFault;
Y_FaultInd_Downstream := fbConveyorDownstream.q_MotorFault;

Y_ProductDone_Upstream   := fbConveyorUpstream.q_ProductInPlaceDone;
Y_ProductDone_Station    := fbConveyorStation.q_ProductInPlaceDone;
Y_ProductDone_Downstream := fbConveyorDownstream.q_ProductInPlaceDone;

Q_SpeedFreq_Upstream   := fbConveyorUpstream.q_SpeedOutput;
Q_SpeedFreq_Station    := fbConveyorStation.q_SpeedOutput;
Q_SpeedFreq_Downstream := fbConveyorDownstream.q_SpeedOutput;


(* 7. 生产计数 (上升沿计数) *)
(* 当本站产品到位完成信号的上升沿,累加计数 *)
VAR_TEMP
    bRisingEdge_StationDone : BOOL;
    fbRisingCounter : R_TRIG;
END_VAR

fbRisingCounter(CLK := fbConveyorStation.q_ProductInPlaceDone);
IF fbRisingCounter.Q THEN
    nProductCount := nProductCount + 1;
END_IF;


END_PROGRAM
```
