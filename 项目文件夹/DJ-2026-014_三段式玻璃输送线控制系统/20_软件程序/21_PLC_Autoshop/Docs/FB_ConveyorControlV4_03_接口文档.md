## 接口说明
### 功能概述
FB_ConveyorControlV4是一个高内聚、低耦合的输送线控制功能块，用于实现输送线的自动和手动控制，包括电机启停、速度调节、产品检测等功能。

### 核心控制逻辑
1. **模式控制**：通过`i_MainControlMode`字段控制运行模式，优先级为手动模式 > 自动模式 > 停止模式
2. **启动停止逻辑**：
   - 输入启动和停止不再区分手自动，只在手自动模式下区分具体逻辑
   - 手动模式：通过`i_Start`和`i_Stop`控制，默认快速运行
   - 自动模式：通过`i_Start`和`i_Stop`控制，带产品检测和速度切换
3. **速度控制**：根据运行状态自动切换速度模式（停止/慢速/快速）
4. **产品检测**：通过`i_Position1Sensor`检测产品位置
5. **方向控制**：通过`i_MotorDirection`设定电机运行方向
6. **故障检测**：实时监测电机运行状态，检测故障情况，使用`i_DriveAlarm`信号检测驱动报警
7. **状态反馈**：通过`q_StatusWord`提供详细的状态信息
8. **报警处理**：报警时只响应停止信号，不响应启动信号；运行中报警时电机停止；报警信号为0超过5秒后可复位解除报警

### 业务规则
1. **模式优先级**：手动模式优先级高于自动模式，当同时激活时，以手动模式为准
2. **模式切换**：允许从任何模式直接切换到手动或自动模式，避免先启动后给模式时的错误
3. **停止优先**：任何模式下，停止信号都具有最高优先级
4. **速度切换**：
   - 启动时先快速运行，检测到产品后切换到慢速运行
   - 停止时直接停止，无减速过程
5. **状态字定义**：
   - 位0：模式错误（模式切换失败或停止模式下收到启动信号时置1）
   - 位1：驱动报警状态（当驱动报警信号激活时置1）
   - 位2：方向输入错误（当方向输入值不在有效范围内时置1）
6. **故障处理**：检测到故障时，立即停止电机运行，设置故障标志，所有故障需要人工复位才能清除
7. **报警处理**：
   - 报警时只响应停止信号，不响应启动信号
   - 运行中报警时电机停止运行
   - 报警信号为0时超过5秒，可以按复位按钮解除报警
   - 解除报警后可以继续运行

### 调用示例
```scl
// 实例化FB
VAR
    fbConveyor : FB_ConveyorControlV4;
END_VAR

// 调用FB
fbConveyor(
    // 输入信号
    i_Start := X0,               // 启动信号
    i_Stop := X1,                // 停止信号
    i_Position1Sensor := X4,           // 位置1传感器信号
    i_MainControlMode := D0,           // 主控运行模式(0-停止,1-手动,2-自动)
    i_MotorDirection := D1,            // 电机运行方向(0-正转,1-反转)
    i_SlowDelayTime := D2,             // 慢速延时时间设定(毫秒)
    i_Reset := X5,                     // 复位按钮信号
    i_DriveAlarm := X6,                // 驱动报警信号
    // INOUT信号
    i_SpeedFrequency := D3,            // 速度频率设定(HZ)
    // 输出信号
    q_MotorRunning => Y0,              // 电机运行状态
    q_MotorFault => Y3,                // 电机异常状态
    q_MotorDirection => D4,            // 电机运行方向状态(0-正转,1-反转)
    q_ProductInPlaceDone => Y4,        // 产品到位完成标志
    q_SpeedOutput => D5,               // 速度输出频率(HZ)
    q_StatusWord => D6                 // 状态字(位0:模式错误)
);
```

### 注意事项
1. **输入信号**：所有输入信号应保持稳定，避免频繁波动
2. **模式切换**：模式切换时应确保当前模式已完全停止
3. **速度设置**：慢速延时时间应根据实际设备特性合理设置
4. **故障处理**：检测到故障后，应先排除故障原因，再重新启动
5. **状态监控**：应定期监控`q_StatusWord`，及时发现和处理异常情况
6. **报警复位**：所有报警都需要人工复位才能清除，操作人员必须确认并处理报警原因后，按下复位按钮清除报警状态
7. **报警处理**：报警时只响应停止信号，不响应启动信号；运行中报警时电机停止运行；报警信号为0时超过5秒，可以按复位按钮解除报警；解除报警后可以继续运行

## 输入字段
| 字段 | 类型 | 默认值 | 取值范围 | 描述 | 触发条件 |
|------|------|--------|----------|------|----------|
| `i_Start` | BOOL | OFF | OFF/ON | 启动信号，为ON时启动电机运行 | 需要一直为true以保持电机运行，变为false时电机会停止 |
| `i_Stop` | BOOL | OFF | OFF/ON | 停止信号，为ON时停止电机运行 | 上升沿触发一次即可停止电机 |
| `i_Position1Sensor` | BOOL | OFF | OFF/ON | 位置1传感器信号，检测产品是否到达位置1 | 上升沿触发一次即可检测位置 |
| `i_MainControlMode` | INT | 0 | 0-停止, 1-手动, 2-自动 | 主控运行模式，控制FB的整体运行模式。**生效条件**：仅在停止模式时可以切换到手动或自动模式。**无效结果**：非停止模式下切换会设置模式错误标志。**边界说明**：模式切换时会自动处理当前运行状态，确保平滑切换 | 需要保持为对应值（0-停止,1-手动,2-自动） |
| `i_MotorDirection` | INT | 0 | 0-正转, 1-反转 | 电机运行方向设定。**生效条件**：仅当电机停止运行时，方向修改操作生效。**无效结果**：电机运行时，方向设置不生效，接口无错误返回。**边界说明**：电机运行时所有方向设置均视为无效，仅在电机停止时方向修改才会被执行；输入值不为0或1时，保持当前方向，设置状态字位2为1（方向输入错误） | 只在电机停止时有效，需要保持为对应值（0-正转,1-反转） |
| `i_SlowDelayTime` | INT | 0 | ≥0 | 慢速运行延时时间设定，单位为毫秒 | 需要保持为对应值 |
| `i_Reset` | BOOL | OFF | OFF/ON | 复位按钮信号，为ON时清除所有错误状态并重置模式为停止模式 | 上升沿触发一次即可清除错误状态 |
| `i_DriveAlarm` | BOOL | OFF | OFF/ON | 驱动报警信号，为ON时表示驱动发生报警 | 上升沿触发一次即可设置报警状态 |

## INOUT字段
| 字段 | 类型 | 默认值 | 取值范围 | 描述 | 触发条件 |
|------|------|--------|----------|------|----------|
| `i_SpeedFrequency` | REAL | 50.0 | 0.0-100.0 | 速度频率设定，单位为HZ。**生效条件**：实时响应，立即影响电机速度。**无效结果**：输入值≤0时，自动设置为50.0HZ；输入值>100.0时，使用100.0HZ。**边界说明**：高速时直接使用输入值，低速时使用输入值的1/3 | 需要保持为有效值（0.0-100.0 HZ） |

## 静态变量使用说明
静态变量用于在FB调用之间保持状态，主要用于计时器管理：
- **In_tTimer1**：计时器启动信号，[0]用于无产品检测延时，[1]用于慢速运行延时，[2]用于报警持续时间
- **Q_tTimer1**：计时器完成信号，计时达到预设值时为TRUE
- **R_tTimer1**：计时器复位信号，为TRUE时重置计时器
- **PT_tTimer1**：计时器预设值，单位为毫秒
- **ET_tTimer1**：计时器当前值，反映已计时时间

静态变量在FB实例化后会保持其值，即使FB没有被调用也不会丢失，因此特别适合用于计时器等需要持续状态的场景。

## 接口特性
- **高内聚**：所有控制逻辑封装在FB内部
- **低耦合**：通过明确的输入输出接口与外部交互
- **移植性强**：无硬件依赖，可在不同PLC系统中使用
- **模式优先级**：手动模式优先级高于自动模式

## 触发条件详细说明

### BOOL量触发条件
- **上升沿触发**：只需要信号从FALSE变为TRUE一次即可触发相应操作，适用于：
  - `i_Stop`：停止信号 - 触发后立即停止电机
  - `i_Reset`：复位信号 - 触发后清除所有报警状态
  - `i_Position1Sensor`：位置检测信号 - 触发后确认产品到达位置
- **持续TRUE触发**：需要信号一直保持为TRUE才能维持相应状态，适用于：
  - `i_Start`：启动信号 - 保持TRUE时电机运行，变为FALSE时电机停止
  - `i_DriveAlarm`：驱动报警信号 - 保持TRUE时报警状态持续

### INT量触发条件
- 需要保持为对应值，系统会根据当前值执行相应逻辑，适用于：
  - `i_MainControlMode`：模式信号 - 保持为对应值（0-停止,1-手动,2-自动）
  - `i_MotorDirection`：方向信号 - 只在电机停止时有效，保持为对应值（0-正转,1-反转）
  - `i_SlowDelayTime`：延时信号 - 保持为设定的延时时间(毫秒)

### REAL量触发条件
- 需要保持为有效值，系统会根据当前值执行相应逻辑，适用于：
  - `i_SpeedFrequency`：速度信号 - 保持为设定的频率值(0.0-100.0 Hz)
