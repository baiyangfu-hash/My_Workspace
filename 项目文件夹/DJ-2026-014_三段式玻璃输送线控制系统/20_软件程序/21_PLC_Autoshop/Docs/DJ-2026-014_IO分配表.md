## 5. FB实例与IO映射关系

### 5.1 上游输送线 (fbConveyorUpstream)
```
FB输入                          外部IO映射
i_Start         ←:= X_Start_Upstream AND bAllowUpstream
i_Stop          ←:= X_Stop_Upstream OR NOT bAllowUpstream
i_Position1Sensor←:= X_SensorUpstream_Position1
i_MainControlMode←:= D_MainControlMode
i_MotorDirection ←:= D_MotorDirection_Upstream
i_SlowDelayTime  ←:= D_SlowDelayTime (默认1000ms)
i_Reset          ←:= X_SystemReset
i_DriveAlarm     ←:= X_DriveAlarm_Upstream
i_Offline        ←:= bSystemOffline
i_SpeedFrequency ←:= I_SpeedSet_Upstream (默认50.0)

FB输出                          外部IO映射
q_MotorRunning   => Y_MotorRun_Upstream
q_MotorFault     => Y_FaultInd_Upstream
q_MotorDirection => (内部状态,不映射到DO)
q_ProductInPlaceDone => Y_ProductDone_Upstream
q_SpeedOutput    => Q_SpeedFreq_Upstream
q_StatusWord     => D_StatusWord_Upstream
```

### 5.2 本站输送线 (fbConveyorStation)
```
FB输入                          外部IO映射
i_Start         ←:= X_Start_Station AND bAllowStation
i_Stop          ←:= X_Stop_Station OR NOT bAllowStation
i_Position1Sensor←:= X_SensorStation_Position1
i_MainControlMode←:= D_MainControlMode
i_MotorDirection ←:= D_MotorDirection_Station
i_SlowDelayTime  ←:= D_SlowDelayTime (默认1000ms)
i_Reset          ←:= X_SystemReset
i_DriveAlarm     ←:= X_DriveAlarm_Station
i_Offline        ←:= bSystemOffline
i_SpeedFrequency ←:= I_SpeedSet_Station (默认50.0)

FB输出                          外部IO映射
q_MotorRunning   => Y_MotorRun_Station
q_MotorFault     => Y_FaultInd_Station
q_MotorDirection => (内部状态)
q_ProductInPlaceDone => Y_ProductDone_Station
q_SpeedOutput    => Q_SpeedFreq_Station
q_StatusWord     => D_StatusWord_Station
```

### 5.3 下游输送线 (fbConveyorDownstream)
```
FB输入                          外部IO映射
i_Start         ←:= X_Start_Downstream AND NOT bEmergencyStop
i_Stop          ←:= X_Stop_Downstream OR bEmergencyStop
i_Position1Sensor←:= X_SensorDownstream_Position1

q_MotorFault     => Y_FaultInd_Downstream
```

## 6. 内部中间变量定义

### 6.1 联锁逻辑变量
| 变量名 | 类型 | 初始值 | 说明 |
|--------|------|--------|------|
| `bAllowUpstream` | BOOL | TRUE | 上游允许运行标志(=NOT Station.ProductInPlaceDone) |
| `bAllowStation` | BOOL | TRUE | 本站允许运行标志(=NOT Downstream.ProductInPlaceDone) |
| `bSystemFault` | BOOL | FALSE | 系统总故障标志(任一线故障) |
| `bEmergencyStop` | BOOL | FALSE | 急停状态(取反,X1为常闭) |
| `bSystemOffline` | BOOL | FALSE | 系统离线选择 |

### 6.2 系统状态变量
| 变量名 | 类型 | 初始值 | 说明 |
|--------|------|--------|------|
| `nSystemStatus` | INT | 0 | 系统状态(0停/1运行/2故障/3急停) |
| `nProductCount` | DINT | 0 | 生产计数(本站完成次数累加) |
| `nCycleCount_Total` | DINT | 0 | 总循环次数 |

## 7. 接线注意事项

1. **急停回路**: X1采用常闭触点,硬线串联所有电机接触器的线圈回路,确保急停时物理断电
2. **传感器电源**: 所有光电传感器采用PLC提供的24VDC电源,需做好短路保护
3. **变频器接口**: 驱动报警信号为无源干接点,接入PLC的DI模块
4. **速度给定**: 模拟量输出0-10V对应变频器0-50Hz/0-100Hz(根据变频器参数设置)
5. **屏蔽措施**: 传感器线路和动力线路分开走线,避免干扰
