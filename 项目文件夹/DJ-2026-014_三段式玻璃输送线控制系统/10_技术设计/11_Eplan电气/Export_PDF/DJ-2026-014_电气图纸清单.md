## 3. 设计规范要求

### 3.1 符号标准
- 遵循 **GB/T 4728** 电气简图用图形符号标准
- 遵循 **IEC 60617** 国际电工委员会图形符号标准
- 设备代号遵循 **IEC 61346** 工业系统、装置与设备以及工业产品结构原则与参照代号

### 3.2 导线颜色规范
| 导线类型 | 颜色代码 | 用途 | 截面积(mm²) |
|---------|----------|------|-----------|
| 三相电源L1 | 黄色(U) | A相主电源 | 2.5(主回路)/1.0(控制) |
| 三相电源L2 | 绿色(V) | B相主电源 | 2.5(主回路)/1.0(控制) |
| 三相电源L3 | 红色(W) | C相主电源 | 2.5(主回路)/1.0(控制) |
| 中性线N | 浅蓝色 | 零线 | 2.5(主回路)/1.0(控制) |
| 保护地PE | 黄绿双色 | 安全接地 | ≥2.5 |
| 直流正极L+ | 棕色 | 24VDC正极 | 1.0 |
| 直流负极M | 蓝色 | 24VDC负极 | 1.0 |
| DI信号线 | 黑色 | 数字量输入 | 0.5(屏蔽) |
| DO信号线 | 红色 | 数字量输出 | 0.5(屏蔽) |
| AI信号线 | 蓝色 | 模拟量输入 | 0.5(屏蔽双绞) |
| AO信号线 | 白色 | 模拟量输出 | 0.5(屏蔽双绞) |
| 急停回路 | 红色(专用) | 急停安全回路 | ≥1.0(独立走线) |

### 3.3 线号标注规则
- 格式: `回路编号-线序号` (例如: `DI-01`, `AO-02`)
- 主回路: `PW-01` ~ `PW-XX`
- 控制回路: `CN-01` ~ `CN-XX`
- 急停回路: `EM-01` ~ `EM-XX` (红色专用)

## 4. 关键设计要点

### 4.1 急停安全回路设计要求
```
急停按钮(常闭) → 空开辅助触点(常开) → 主接触器线圈 → 24VDC负极
                    ↓
              PLC输入I0.2(读取急停状态)
```
- 所有急停按钮必须采用**硬线串联**方式接入主接触器回路
- PLC仅作为**第二重检测**, 不作为唯一保护手段
- 急停回路导线使用**红色专用线**, 独立走线槽, 与其他线路物理隔离
- 急停按钮选用**蘑菇头自锁型**, 必须手动旋转解锁

### 4.2 变频器主回路设计要求
```
三相电源(L1/L2/L3) → 断路器(QF) → 交流接触器(KM) → 热继电器(FR) → 变频器(U/V/W) → 电机(M)
```
- 断路器选择: 根据电机额定电流的1.2~1.5倍选型, 带短路保护功能
- 接触器选择: 根据电机功率选型, 线圈电压24VDC(与PLC DO匹配)
- 热继电器设置: 整定电流=电机额定电流×1.05~1.1
- 变频器参数: 需设置加减速时间、转矩提升、过载保护等关键参数

### 4.3 PLC IO接线注意事项
- **DI信号**: 采用源型(Sinking)或漏型(Sourcing)需统一, 推荐汇川PLC默认配置
- **DO信号**: 驱动中间继电器隔离后控制外部设备, 保护PLC输出点
- **AI/AO信号**: 必须使用**屏蔽双绞线**, 屏蔽层单点接地(PLC侧)
- **传感器供电**: 光电传感器等现场设备由独立24V开关电源供电, 不共用PLC电源
