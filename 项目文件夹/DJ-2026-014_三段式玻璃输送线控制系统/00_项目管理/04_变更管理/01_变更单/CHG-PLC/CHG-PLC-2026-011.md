## 4. 变更原因

**变更背景**: 本变更是 **CHG-PLC-2026-006（速度范式改Hz模式）的配套联动变更**。

CHG-PLC-2026-006将速度控制接口从布尔输出(q_MotorSlow/q_MotorFast)重构为REAL型INOUT变量(i_SpeedFrequency, 0~100Hz)。由于i_SpeedFrequency是**INOUT**类型（双向传递），外部程序可以写入该变量来设定速度频率。但如果外部写入了非法值（如负数、零、超范围值），会导致后续速度计算出现异常（如除零、负频率输出等）。

**变更必要性(P2)**: 作为INOUT类型的防御性编程措施：
- 防止外部写入≤0的值导致速度计算异常
- 防止外部写入>100Hz的值超出变频器能力范围
- 提供合理的默认值回退机制(50.0Hz)
- 符合工业控制软件的**防御性编程**最佳实践

**参考依据**: CHG-PLC-2026-006变更单 §6.3传播链；编码规范 DEF-PLC-001 §5.2"输入参数校验"。

```
防呆保护逻辑:
IF i_SpeedFrequency <= 0.0 THEN
    i_SpeedFrequency := 50.0;  (* 默认中速 *)
END_IF;

IF i_SpeedFrequency > 100.0 THEN
    i_SpeedFrequency := 100.0; (* 限幅到最大值 *)
END_IF;
```
