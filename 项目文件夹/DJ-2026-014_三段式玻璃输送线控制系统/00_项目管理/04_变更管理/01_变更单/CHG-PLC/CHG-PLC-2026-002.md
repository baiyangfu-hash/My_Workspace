## 4. 变更原因

**变更背景**: FB_ConveyorControlV4中电机方向输入(i_Direction)的验证逻辑实现与接口文档规范不一致。原实现在**所有运行模式下**都执行方向输入有效性检查，导致电机运行过程中如果方向输入发生变化会触发误报警。

**变更必要性(P0-Bug)**: 这是一个**缺陷修复类Bug**。若不修正，现场实际运行中可能出现以下问题：
- 输送线正常运行时，若方向传感器信号抖动或外部干扰导致i_Direction变化，系统会立即触发方向错误报警
- 误报警会导致不必要的停机，影响生产连续性
- 不符合"电机停止时验证方向，运行时忽略方向输入"的接口设计规范

**根因分析**:
```
【根因】: 原始实现中方向验证条件未区分电机运行状态
  - 错误做法: IF i_Direction <> ExpectedDirection THEN Alarm (无条件触发)
  - 正确做法: IF (NOT q_MotorRunning) AND (i_Direction <> ExpectedDirection) THEN Alarm (仅在停止时验证)

【故障现象】: 运行中方向输入变化 → 触发方向错误报警 → 电机急停
【影响范围】: 所有使用该FB的输送线控制实例
```

**参考依据**: FB_ConveyorControlV4接口设计规范V4.3.0 §3.2节"方向输入验证规则"；现场调试问题记录单 #DBG-014-001。
