## ❓ 为什么没有 02_变更报告/ 目录?

变更报告的功能已合并到:
- **变更单§10验证结论** → 单次变更的完整验证记录
- **台帐§3多维统计 + §5趋势分析** → 多变更的汇总分析

理由: 044变更报告模板与040变更单模板存在约70%内容重叠, 在个人/AI/自动化工具场景下属于过度设计。详见spec文档。


## 🚀 快速开始: 创建新变更单 (AI工具调用步骤)

1. **确定领域**: 主要改哪个专业的交付物? → 选择ELEC/MECH/PLC/HMI/SCPT/DOCU/SAFE之一
2. **复制模板**: 从规范仓库复制 `040_通用变更单模板_CHG-V2.0.0.md`
3. **填写必填项**: §3二维分类(领域+性质+范围), §4原因, §5前后对比, §6影响
4. **检查传播**: 如影响其他领域 → 填写§6.2跨领域影响 + §6.3传播链 → 创建关联变更单
5. **存放到正确目录**: `01_变更单/CHG-[DOMAIN]/CHG-[DOMAIN]-[YYYY]-[XXX].md`
6. **更新台帐**: 在台帐§4中追加一行引用
