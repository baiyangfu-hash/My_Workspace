## 2. 故障诊断流程总览

### 2.1 标准故障排查五步法
```
步骤1: 安全第一 (Safety First)
    ↓
    ● 确认现场安全(无人身危险)
    ● 如有急停/火灾/触电风险 → 先救人/灭火/断电!
    ● 挂警示牌, 禁止他人合闸
    ↓
步骤2: 现象确认 (Symptom Confirmation)
    ↓
    ● 向操作员询问故障发生时的情况(何时/何地/何现象/之前做了什么)
    ● 亲自观察故障现象(指示灯状态/报警代码/HMI显示/异响/异味等)
    ● 尝试复现故障(在安全前提下)
    ↓
步骤3: 原因分析 (Root Cause Analysis)
    ↓
    ● 根据故障现象查阅本手册的"故障代码表"或"常见故障索引"
    ● 从最可能/最容易检查的原因开始排查(奥卡姆剃刀原则)
    ● 使用"是/否"决策树逐步缩小范围
    ↓
步骤4: 定位与修复 (Locate & Fix)
    ↓
    ● 使用万用表/示波器等工具精确定位故障点
    ● 更换损坏部件或修复接线/参数
    ● 记录更换的部件型号/序列号(用于追溯)
    ↓
步骤5: 验证与记录 (Verify & Document)
    ↓
    ● 通电试运行, 确认故障已消除且无新问题产生
    ● 连续运行≥30分钟无复发
    ● 填写《故障维修记录单》(见附录), 详细记录全过程
    ● 若为重复性故障, 触发根本原因分析(RCA)流程
```

| 故障类别 | 典型现象 | 危险等级 | 排查优先级 | 平均修复时间 |
|----------|----------|:--------:|:----------:|-------------|
| 🔴 **紧急故障** | 急停触发/冒烟起火/设备失控/人身伤害风险 | 极高 | 立即处理! | - |

## 3. PLC系统故障

### 3.1 PLC硬件故障

#### 故障F001: PLC不上电/电源指示灯不亮
| 项目 | 内容 |
|------|------|
| **故障现象** | 合上空气开关后, PLC电源指示灯(PWR)不亮, CPU RUN/STOP灯也不亮 |
| **可能原因**(按概率排序) | ①控制柜内PLC电源开关/断路器未合 ②PLC电源线(L+/N)松动或脱落 ③24V开关电源损坏 ④PLC电源模块烧毁 ⑤主电路电压异常(缺相/欠压/过压) |
| **排查步骤** | 1. 用万用表AC档测量PLC电源输入端子L+/N之间电压 → 应为AC220V±15%(187~253V)<br>2. 若电压正常 → 检查PLC电源开关是否ON, 电源线端子是否紧固<br>3. 若电压异常 → 检查上级空开/变压器输出<br>4. 若外部供电正常但PLC仍不亮 → 更换24V开关电源试试<br>5. 若仍无效 → 联系供应商检测PLC主机 |
| **解决方案** | 根据根因采取对应措施: 紧固端子/更换开关电源/更换PLC主机 |
| **预防措施** | 每月二级维护时检查PLC供电电压并记录; 震动环境使用带锁线端子 |

---

#### 故障F002: PLC运行灯不亮/STOP模式无法切换到RUN
| 项目 | 内容 |
|------|------|
| **故障现象** | PLC上电后PWR灯亮, 但RUN灯不亮(或闪烁), 无法切换到RUN模式 |
| **可能原因** | ①程序存在致命错误(编译错误/IO配置错误) ②PLC存储卡损坏或丢失 ③电池电量不足(数据保持区校验失败) ④硬件配置与程序不匹配(如扩展模块缺失) ⑤被远程强制停止(HMI/上位机指令) |
| **排查步骤** | 1. 查看PLC面板ERROR/ERR灯是否点亮及错误代码<br>2. 连接Autoshop编程软件, 上传诊断信息<br>3. 检查"在线→诊断"中的错误详情<br>4. 检查程序编译是否有错误(需重新下载编译通过的程序)<br>5. 检查扩展模块是否全部插好并识别<br>6. 检查PLC电池电压(应在3.0V以上) |
| **解决方案** | 重新下载正确的编译通过程序; 更换电池(CR2032); 插牢扩展模块; 清除远程停止指令 |
| **预防措施** | 每季度检查PLC电池电压; 修改程序前备份原程序; 扩展模块固定螺丝定期紧固 |

### 3.2 IO信号故障

#### 故障F003: DI输入信号全为0或不变化
| 项目 | 内容 |
|------|------|
| **故障现象** | Autoshop监控表中所有DI(I0.0-I2.7)均为FALSE, 或某个DI始终不变 |
| **可能原因** | ①DI公共端COM未接或断开 ②24V传感器电源未输出 ③具体DI点的外部开关/传感器损坏或线路断路 ④PLC输入点硬件损坏 ⑤源型/漏型接法不匹配 |
| **排查步骤** | 1. 测量DI COM端对M(0V)电压 → 应为DC24V(源型接法)<br>2. 测量具体DI点对COM电压 → 开关断开时应≈24V, 闭合时应≈0V<br>3. 若电压正常但不变化 → 检查外部开关/传感器动作是否正常<br>4. 若某DI点始终为0V(无论开关状态) → 该点可能短路到0V或PLC输入光耦损坏<br>5. 若某DI点始终为24V → 外部线路断开或开关常闭触点粘连 |
| **解决方案** | 修复断路/更换传感器/更换损坏的DI点(改用备用DI点或更换CPU模块) |
| **预防措施** | 使用带LED指示的继电器便于观察通断; 重要DI信号并联到HMI显示 |

---

#### 故障F004: DO输出不动作或无法驱动负载
| 项目 | 内容 |
|------|------|
| **故障现象** | PLC程序中DO(Q点)已置位(TRUE), 但外部接触器/继电器/指示灯不动作 |
| **可能原因** | ①DO点输出能力不足(驱动电流过大) ②中间继电器线圈烧毁 ③外部负载回路断路(保险丝熔断/线圈断线) ④DO公共端未接电源 ⑤PLC DO点硬件损坏 |
| **排查步骤** | 1. 在Autoshop中强制该DO点ON, 用万用表测量DO端子对DO-COM电压 → 继电器型应有约24V, 晶体管型应有约0V(拉电流型)<br>2. 若DO端子电压正常但继电器不吸合 → 继电器线圈断路或接线脱落<br>3. 若DO端子无电压输出 → 该DO点损坏, 改用备用DO点<br>4. 检查继电器触点侧回路(主电路)是否通路 |
| **解决方案** | 更换中间继电器(推荐MY2N-J 24VDC 10A); 改用备用DO点; 增加驱动级(小DO驱动小继电器→大继电器→大负载) |
| **预防措施** | DO必须通过中间继电器隔离, 不得直接驱动大于100mA的负载; 继电器选型留50%余量 |

### 3.3 模拟量(AI/AO)故障

#### 故障F005: AI读数异常(恒为0/满量程/跳变)
| 项目 | 内容 |
|------|------|
| **故障现象** | AI通道(IW64/IW66/IW68)读取值异常: 始终为0, 或始终为27648(满量程), 或数值随机跳变 |
| **可能原因** | ①传感器/变频器AO端未输出或损坏 ②AI信号线断路/短路/屏蔽不良受干扰 ③AI通道配置错误(量程类型0-10V/4-20mA不匹配) ④共模干扰(接地环路) ⑤PLC AI模块硬件故障 |
| **排查步骤** | 1. 断开AI输入线, 测量线间电压 → 应有0-10V或4-20mA随速度变化<br>2. 若线间电压正常但PLC读数异常 → 检查Autoshop中AI通道配置(模拟量输入设置: 类型/范围/滤波)<br>3. 若线间电压为0或异常 → 检查传感器/变频器侧AO输出<br>4. 若数值跳变剧烈 → 检查屏蔽层接地(应单点接地于PLC侧),远离动力电缆<br>5. 互换两个AI通道接线判断是否为通道硬件问题 |
| **解决方案** | 修正AI配置参数; 更换屏蔽双绞线; 修复传感器/变频器AO; 加装信号隔离器抗干扰 |
| **预防措施** | AI/AO必须使用屏蔽双绞线, 屏蔽层单点接地; 与动力线分开走线槽(间距>300mm) |

---

#### 故障F006: AO输出异常(电机转速不跟随设定值)
| 项目 | 内容 |
|------|------|
| **故障现象** | AO通道(QW64/QW66/QW68)输出值正确, 但变频器实际转速与设定不符或不变 |
| **可能原因** | ①AO信号线断路/接错端子 ②变频器AI参数设置错误(量程/偏置) ③变频器面板处于本地控制模式(不接受远程AO) ④AO通道损坏(输出电压不准) ⑤变频器本身故障 |
| **排查步骤** | 1. 用万用表测量PLC AO端子输出电压 → 应与设定成比例(如50%速度→约5V)<br>2. 若AO电压正确 → 问题在变频器侧: 检查变频器参数(频率源选择=模拟量输入, 量程0-10V对应0-50Hz)<br>3. 若AO电压异常(0V或恒定) → AO通道损坏或程序未正确写入QW寄存器<br>4. 检查变频器是否被设置为"面板控制"而非"端子控制"<br>5. 短接测试: 用外部可调电源(0-10V)直接给变频器AI输入, 看转速是否跟随 |
| **解决方案** | 修正变频器参数; 切换到远程控制模式; 修复/更换AO通道或变频器 |
| **预防措施** | 变频器调试完成后锁定参数(设密码); 在变频器面板贴注"远程AO控制"标签 |

## 4. 变频器故障

### 4.1 变频器通用故障代码对照表
| 故障代码 | 含义 | 可能原因 | 解决方法 | 预防措施 |
|----------|------|----------|----------|----------|
| **OC/OverCurrent** | 过流 | ①电机短路或接地 ②负载突然增大(卡滞) ③加速时间太短 ④变频器功率过小 | 排除短路/卡滞; 延长加减速时间; 核实功率匹配 | 避免带载直接启动; 设置合适的加减速时间 |
| **OV/OverVoltage** | 过压 | ①减速时间太短(再生能量回馈) ②电网电压过高 ③制动电阻未接或损坏 | 延长减速时间; 安装/更换制动单元+制动电阻; 检查电网 | 重载惯性大的场合必须配制动电阻 |
| **UV/UnderVoltage** | 欠压 | ①电网电压过低或缺相 ②主电路整流桥损坏 ③直流母线电容老化 | 检查供电电压; 测量整流桥; 更换电容组 | 配备稳压器或UPS; 避免在大功率设备启停时运行 |
| **OH/OverHeat** | 过热 | ①散热风扇堵转或损坏 ②环境温度过高(>45°C) ③散热片积尘 ④风道堵塞 | 清洁/更换风扇; 改善通风降温; 吹扫散热片; 清理风道 | 定期清洁除尘; 环境温度控制在40°C以下 |
| **OL/OverLoad** | 过载 | ①长期超过额定电流运行 ②电机功率与变频器不匹配 ③负载机械卡滞 | 减轻负载; 重新核算功率匹配; 排除机械卡滞 | 变频器容量应为电机功率的1.1~1.5倍 |
| **GF/GroundFault** | 接地故障 | ①电机或电缆绝缘破损漏电 ②电机受潮绝缘下降 ③变频器输出侧对地短路 | 摇表测电机/电缆绝缘(>0.5MΩ); 烘干电机; 修复破损点 | 新安装时必须测量绝缘; 潮湿环境选用IP55以上电机 |
| **EF/ExternalFault** | 外部故障(来自PLC) | PLC检测到异常后发送停止命令给变频器 | 查看PLC侧故障记录, 排除根源 | 正确配置PLC与变频器的故障联动逻辑 |

### 4.2 变频器专项故障案例

#### 案例1: 变频器启动几秒后就报OC过流跳闸
```
现场情况: 上游输送线变频器一启动就跳OC, 但手动盘车电机转动灵活
排查过程:
1. 脱开电机电缆, 空载试运行变频器 → 不再跳闸 → 说明变频器本体OK, 问题在电机侧
2. 摇表测电机三相绕组对地绝缘 → A相0.2MΩ(偏低), B/C相>500MΩ → A相可能受潮或匝间短路
3. 用电桥测三相直流电阻 → A相比B/C相大20% → 匝间短路嫌疑
4. 解体电机发现A相端部绑扎线松脱, 线圈振动磨损绝缘对地短路
结论: 电机匝间短路导致单相电流过大→变频器检测到过流保护
解决: 更换电机(或送修重绕线圈)
预防: 新电机安装前做绝缘电阻和直流电阻平衡测试; 定期监测运行电流
```

#### 案例2: 三台变频器同时偶尔报OV过压
```
现场情况: 下班急停时经常报OV, 白天正常运行很少出现
排查过程:
1. 记录故障发生时刻 → 都在17:00-18:00下班集中停机时段
2. 分析: 同时停机时三条线的电机都在发电制动状态 → 再生能量回馈到直流母线 → 电压泵升→过压跳闸
3. 检查: 变频器均未配置制动电阻/制动单元!
4. 计算: 3台0.75kW电机同时制动, 最大回馈功率约1.5kW, 直流母线电容吸收不了
结论: 缺少制动回路导致直流母线过压
解决: 为每台变频器加装制动单元+200W/40Ω制动电阻(或共用制动单元)
预防: 选型阶段就必须考虑制动需求; 惯性负载或频繁启停必须配制动电阻
```

## 5. 机械系统故障

### 5.1 输送带相关故障

#### 故障F007: 输送带跑偏 (皮带偏离滚筒中心)
| 项目 | 内容 |
|------|------|
| **故障现象** | 运行一段时间后, 输送带向一侧偏移, 严重时触碰机架边缘甚至脱落 |
| **可能原因** | ①滚筒轴线不平行(安装误差或地脚沉降) ②托辊轴线与带面不垂直 ③物料偏载(总是靠一侧放料) ④输送带接头不正(切口与带边不垂直) ⑤张紧轮两侧张力不一致 |
| **排查步骤** | 1. 空载运行观察跑偏方向和程度<br>2. 用角尺/激光测距仪检查主动/从动滚筒两端与机架距离是否相等(误差<2mm)<br>3. 检查托辊是否水平(用水平仪)<br>4. 检查张紧螺杆两侧露出长度是否一致<br>5. 检查皮带接头是否垂直(用角尺量) |
| **解决方案** | 微调跑偏侧的张紧螺杆(放松跑偏侧或收紧另一侧); 调整滚筒座位置; 重新粘接皮带接头; 纠正放料位置使其居中 |
| **经验法则**: "跑紧不跑松" → 皮带向哪侧跑, 就将哪侧稍微放松(或将另一侧收紧), 反复微调直至居中 |

---

#### 故障F008: 输送带打滑 (滚筒转但带不动或速度跟不上)
| 项目 | 内容 |
|------|------|
| **故障现象** | 滚筒在转动, 但输送带速度明显慢于滚筒线速度, 或重载时带不走 |
| **可能原因** | ①皮带松弛(张紧力不足) ②滚筒包胶磨损(摩擦系数降低) ③皮带工作面沾油/水/粉(摩擦力下降) ④超载(玻璃堆积过多) ⑤抱闸未完全释放(半摩擦状态) |
| **排查步骤** | 1. 手按压带面, 下沉若>25mm则过松 → 调紧张紧<br>2. 目视检查包胶表面是否有光滑亮点(磨损露底) → 重新滚花或更换滚筒<br>3. 摸带面是否有油腻感 → 清洁带面<br>4. 检查抱闸间隙(应在0.5~1mm) → 调整或更换抱闸弹簧<br>5. 称重当前载荷, 对比设计最大载荷 |
| **解决方案** | 调紧张紧度; 重新包胶或更换滚筒; 清洁带面(禁用溶剂以免损伤PVC/PU); 减轻负载; 调整抱闸 |
| **预防措施** | 每周检查张紧度; 避免油污滴落到皮带上; 抱闸每季度检查调整 |

### 5.2 传感器故障

#### 故障F009: 光电传感器误触发或不触发
| 项目 | 内容 |
|------|------|
| **故障现象** | ①无产品时传感器却显示ON(误触发) → 导致联锁误动作或假计数<br>②有产品时传感器仍OFF(不触发) → 导致不停机送料(堆积)或计数漏计 |
| **可能原因(误触发)** | ①传感器镜头脏污(灰尘/油膜散射光线) ②背景反光强烈(不锈钢/玻璃反射进入接收窗) ③安装角度不对(对到了旁边的反光物) ④外界强光直射(阳光/照明灯光) ⑤灵敏度调得过高 |
| **可能原因(不触发)** | ①发射管或接收管损坏(LED老化) ②电源电压不足(<18VDC) ③检测距离超出规格 ④目标物体颜色/透明度不适合(黑色吸光/全透明) ⑤接线松动或极性接反 |
| **排查步骤(误触发)** | 1. 清洁镜头(镜头纸/麂皮布, 禁用手摸)<br>2. 调整传感器角度, 避开背景反光区域<br>3. 加装遮光罩(纸筒/塑料管套在传感器前端)<br>4. 降低灵敏度旋钮(逆时针旋转)<br>5. 改变安装位置或换用背景抑制型传感器 |
| **排查步骤(不触发)** | 1. 测量传感器供电电压 → 应在DC20-28V范围内<br>2. 用白纸遮挡检测区, 观察指示灯是否动作<br>3. 调高灵敏度旋钮(顺时针旋转)<br>4. 检查接线(棕色=+, 蓝色=-, 黑色=信号)<br>5. 同型号替换法判断是否传感器本体损坏 |
| **解决方案** | 清洁/调整/更换传感器; 加装遮光罩; 调整灵敏度; 修正接线 |
| **预防措施** | 每周清洁传感器镜头; 避免安装在强光直射处; 选用可靠性品牌(欧姆龙E3Z/基恩士PZ/神视EXZERA系列) |

## 6. 联锁与逻辑故障

### 6.1 正向联锁失效 (下游满位时上游未停止)

#### 故障F010: 正向联锁不动作
| 项目 | 内容 |
|------|------|
| **故障现象** | 下游出口传感器持续检测到产品(满位), 但上游输送线仍在继续送料, 造成堆积 |
| **可能原因** | ①下游出口传感器(I1.4)损坏或信号未传入PLC ②PLC程序中正向联锁逻辑被注释或条件不满足 ③联锁功能被HMI参数禁止(如"联锁投退"开关打到"退出") ④通信延迟(如通过总线传输传感器信号) ⑤传感器安装位置不当(检测不到真实满位) |
| **排查步骤** | 1. 在Autoshop监控表中查看I1.4状态 → 满位时应为TRUE, 若始终为FALSE则传感器问题<br>2. 查看程序中正向联锁逻辑(FB_ConveyorControlV4内部或PRG_Main中) → 是否有bDownstreamFull变量参与控制上游使能<br>3. 检查HMI/参数设置中是否有"联锁投退"选项及其当前状态<br>4. 实际测试: 手动遮挡I1.4传感器3秒以上, 观察上游是否停止<br>5. 检查传感器安装位置: 是否在实际满位点(通常距出口滚筒中心1~1.5倍产品长度处) |
| **解决方案** | 修复/更换传感器; 恢复被注释的程序段; 投入联锁功能; 调整传感器位置 |
| **危险等级**: ⚠️ **中等** - 可能造成物料堆积/设备卡滞/产品损坏, 但一般不会立即伤人 |
| **预防措施** | 每月测试联锁功能; 关键传感器冗余配置(双传感器表决); 程序修改必须经过审批和验证 |

---

### 6.2 反向联锁失效 (故障时全线未停止)

#### 故障F011: 反向联锁不动作或延迟过长
| 项目 | 内容 |
|------|------|
| **故障现象** | 某段发生故障(如变频器报警/热继电器动作), 但其他段未及时停止, 故障继续蔓延 |
| **可能原因** | ①故障检测信号未接入PLC或接线错误 ②反向联锁传播逻辑程序bug ③PLC扫描周期过长(程序臃肿) ④故障信号被过滤或延时(防抖时间设置过长) ⑤通信方式传递故障信号时网络拥堵 |
| **排查步骤** | 1. 模拟故障: 断开某变频器就绪信号(I2.0/I2.2/I2.4)或短接故障信号(I2.1/I2.3/I2.5)<br>2. 用秒表测量从故障发生到全线停止的时间 → 应<30ms×段数(3段约90ms内)<br>3. 在Autoshop中查看程序扫描周期(如有此功能)或估算(复杂度/指令执行时间)<br>4. 检查FB_ConveyorControlV4的反向联锁输出是否连接到上下游FB实例的停止输入<br>5. 检查各段故障信号的防抖计时器设置(不应>100ms) |
| **解决方案** | 修复故障信号接线; 优化程序减少扫描周期; 调整防抖参数; 修正联锁逻辑 |
| **危险等级**: 🔴 **高** - 可能导致故障扩大化, 设备二次损坏, 甚至引发安全事故! |
| **预防措施** | 联锁逻辑必须作为最高优先级任务(放在OB1最前面); 定期进行联锁演练测试; 关键故障信号采用硬线+软件双重检测 |

## 7. 安全系统故障

### 7.1 急停回路故障

#### 故障F012: 急停按下后设备未停止 (极度危险!)
| 项目 | 内容 |
|------|------|
| **故障现象** | 拍下急停按钮后, 设备继续运行或延迟很久才停止 |
| **危险等级** | 🔴🔴🔴 **极高风险 - 可能导致重伤或死亡!** |
| **可能原因** | ①急停按钮触点粘连(焊死) ②急停回路被短接(人为破坏或误操作) ③主接触器触点熔焊(分不断) ④急停回路串入了不必要的延时元件 ⑤PLC程序中急停处理逻辑被篡改 |
| **紧急处置** | **立即切断主电源空气开关!(物理断电)** → 远离设备 → 设置警戒线 → 禁止任何人接近 → 通知维修主管和安全负责人 |
| **排查步骤** (必须在断电并挂牌后进行!) | 1. 绘制急停回路完整原理图(从急停按钮→中间继电器→主接触器线圈)<br>2. 逐点断开测试: 分别断开每个急停按钮/门锁/限位, 确认每次断开后主接触器都释放<br>3. 用万用表通断档测量急停按钮NC触点 → 按下时应断开(无穷大), 松开时应导通(近0Ω)<br>4. 检查是否存在非设计要求的跨接线(短接线)! 这是严重安全隐患!<br>5. 检查主接触器触点 → 是否有熔焊粘连痕迹(触点表面凹凸不平或粘连在一起) |
| **解决方案** | 更换急停按钮; 拆除所有非法短接线(追究责任人!); 更换熔焊的主接触器; 恢复原始急停回路设计 |
| **法律后果** | 根据《安全生产法》, 故意短接安全回路属于**违法行为**, 可追究刑事责任! |
| **预防措施** | 急停回路上锁铅封(审计用); 每月测试急停功能; 安全回路变更必须经安全负责人书面批准; 定期安全审计 |
