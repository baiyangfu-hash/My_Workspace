## 项目概述
基于FB_ConveyorControlV4的三段式玻璃输送线PLC控制系统，产品:玻璃1300×700×10mm，包含上游/本站/下游三条输送线，使用汇川Autoshop编程环境

## 环境说明
- **开发工具**:
  - Eplan: 电气设计
  - Autoshop: PLC编程
  - Pro Face: HMI设计
  - VS Code: 上位机和脚本开发
  - Obsidian: 知识库管理
