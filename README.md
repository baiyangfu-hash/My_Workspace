# My_Workspace

## 工作空间入口

- 全局规范入口:
  - `00_Obsidian_Base全局规范文件仓库/`
- PLC 开发入口:
  - `0100_PLC自动化/`
- 上位机与工具项目入口:
  - `01_Project自动化项目管理/`
- 工作区治理入口:
  - `SYS-2026-001_WorkspaceGovernance/`
- 根级临时文档入口:
  - `.trae/documents/`

## 如何使用

### 1. 做具体项目工作

- PLC 项目: 进入 `0100_PLC自动化/` 下对应项目
- 软件/上位机项目: 进入 `01_Project自动化项目管理/` 下对应项目
- 进入项目后优先读取对应 `PM_SESSION_<项目编号>.md`

### 2. 做整个工作空间的治理或重构

- 进入 `SYS-2026-001_WorkspaceGovernance/`
- 先读取 `PM_SESSION_SYS-2026-001.md`
- 再查看 `01_项目文档/` 下的路线图、风险和变更准入规则

### 3. 查看临时分析或草稿

- 进入 `.trae/documents/`
- 该目录只用于临时计划、一次性分析和草稿，不再作为长期治理主入口

## 当前约定

- 工作区级长期事项统一由 `SYS-2026-001` 管理
- 根 `.trae/documents/` 只保留临时和缓冲性质文档
- 现有 PLC / 软件 / 规范三条主线保持稳定，不做顶层重排
