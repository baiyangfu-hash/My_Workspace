## 版本：v4.0.0
- **变更日期**：2026-01-20
- **变更时间**：2026-01-20 16:00:00
- **变更类型**：重大变更
- **变更原因**：
  - 增加主控运行模式接口
  - 增加位置1传感器输入
  - 优化模式切换逻辑
  - 增加电机运行方向接口
  - 增加电机方向和运行模式更改限制
  - 增加产品到位完成标志
  - 修复模式0时内部状态不复位问题
  - 修复产品脱离传感器后到位标志不复位问题
  - 更新计时器格式，符合模板规范
- **变更内容**：
  - **变量表**：添加 `i_MainControlMode` INT 变量，描述为"主控运行模式(0-停止,1-手动,2-自动)"
  - **变量表**：添加 `i_Position1Sensor` BOOL 变量，描述为"位置1传感器信号"
  - **变量表**：添加 `i_MotorDirection` INT 变量，描述为"电机运行方向(0-正转,1-反转)"
  - **变量表**：添加 `q_MotorDirection` INT 变量，描述为"电机运行方向状态(0-正转,1-反转)"
  - **变量表**：添加 `q_ProductInPlaceDone` BOOL 变量，描述为"产品到位完成标志"
  - **变量表**：添加 `tmp_nCurrentMotorDirection` INT 变量，描述为"当前电机方向"
  - **变量表**：添加 `tmp_nCurrentMode` INT 变量，描述为"当前运行模式"
  - **变量表**：添加 `tmp_bProductInPlaceDone` BOOL 变量，描述为"产品到位完成内部标志"
  - **变量表**：添加 `tmp_nNoProductDelay` INT 变量，描述为"无产品检测延时计数器"
  - **变量表**：更新计时器格式，添加 `In_tTimer1`、`Q_tTimer1`、`R_tTimer1`、`PT_tTimer1`、`ET_tTimer1` 数组变量，符合模板规范
  - **变量表**：添加慢速运行延时计时器相关变量（In_tTimer1[1], Q_tTimer1[1], R_tTimer1[1], PT_tTimer1[1], ET_tTimer1[1]）
  - **变量表**：删除未使用的 `tmp_nSlowDelay` INT 变量
  - **变量表**：添加 `i_SlowDelayTime` INT 变量，描述为"慢速延时时间设定(毫秒)"
  - **变量表**：删除 `i_NoProductDelayTime` INT 变量，无产品检测延时固定为3000毫秒
  - **程序文件**：修改模式切换逻辑，使用CASE语句基于主控运行模式变量控制
  - **程序文件**：添加电机运行方向的输出逻辑
  - **程序文件**：添加电机方向更改限制：不允许在电机还在运行时更改
  - **程序文件**：添加运行模式更改限制：只能在运行模式为0（停止）时更改
  - **程序文件**：添加产品到位完成标志的设置逻辑：当产品到达位置1并完成慢速运行停止后设置该标志
  - **程序文件**：添加无产品检测延时逻辑：当产品到位完成标志为TRUE且位置1传感器检测不到产品时，超过3秒后复位标志
  - **程序文件**：修复模式0时内部状态不复位问题：重新设计模式切换逻辑，确保主控给出停止指令时立即进入停止模式并复位所有内部状态
  - **程序文件**：修复产品脱离传感器后到位标志不复位问题：将无产品检测延时逻辑移到主逻辑区域，使用标准TON计时器格式
  - **程序文件**：使用标准TON计时器替换软件计数器，避免数据溢出问题
  - **程序文件**：添加主控设定时间数据逻辑：当主控设定值大于0时使用主控设定值，否则使用默认值
  - **程序文件**：移除无产品检测延时时间设定变量，无产品检测延时固定为3000毫秒
  - **版本更新**：变量表版本更新到 v4.0.0
  - **程序版本**：更新到 v4.0.0
- **问题修复详情**：
  1. **模式0时内部状态不复位问题**：
     - **问题描述**：当主控运行模式从其他模式切换到0（停止）时，内部状态变量未完全复位，导致系统可能保持部分运行状态
     - **根本原因**：模式切换逻辑中缺少对停止模式的完整复位处理
     - **修复方案**：在模式控制逻辑中添加专门的停止模式处理，确保所有内部状态变量都被复位
     - **验证结果**：模式切换到0时，所有内部状态正确复位，系统进入安全停止状态
  2. **产品脱离传感器后到位标志不复位问题**：
     - **问题描述**：当产品脱离位置1传感器后，产品到位完成标志未在规定时间内复位
     - **根本原因**：无产品检测延时逻辑位置不当，且使用了软件计数器而非标准计时器
     - **修复方案**：将无产品检测延时逻辑移到主逻辑区域，使用标准TON计时器格式，并设置3秒延时
     - **验证结果**：产品脱离传感器后，到位标志在3秒后正确复位
  3. **电机方向切换安全问题**：
     - **问题描述**：电机运行过程中允许方向切换，可能导致设备损坏
     - **根本原因**：缺少电机方向切换的安全限制
     - **修复方案**：添加电机方向切换限制，只有在电机停止时才允许更改方向
     - **验证结果**：电机运行时方向信号变化不会立即生效，确保了设备安全
- **变更影响**：
  - 实现了主控运行模式的读取和控制
  - 优化了模式切换逻辑，确保只有一种模式运行
  - 增加了位置1传感器的支持
  - 实现了电机运行方向的控制和状态反馈
  - 增加了电机方向更改限制，防止在电机运行时更改方向导致设备损坏
  - 增加了运行模式更改限制，确保只有在停止状态下才能切换模式
  - 实现了产品到位完成标志的广播功能，方便主控系统了解产品输送状态
  - 增加了无产品检测延时逻辑，提高了系统的稳定性和可靠性
  - 修复了模式0时内部状态不复位问题，确保主控给出停止指令时系统能立即进入安全停止状态
- **变更人员**：系统
- **验证结果**：

  - 电机方向控制和安全限制功能正常
