# 双线圈气缸FB详细设计说明书

## 1. 设计概述

### 1.1 设计目标

本设计基于项目1的单线圈气缸控制逻辑，实现双线圈气缸控制系统。设计目标是为动点和原点各提供一个独立的控制线圈，提高系统的可靠性和控制精度，同时保持与项目1相同的传感器监控、报警系统和状态机管理功能。

### 1.2 设计原则

- **可靠性优先**：确保线圈互斥保护，避免两个线圈同时激活
- **兼容性**：保持与项目1相同的接口和功能，便于系统集成
- **可维护性**：采用模块化设计，便于维护和扩展
- **标准化**：严格按照项目规范命名变量和文件

## 2. 系统架构

### 2.1 整体架构

双线圈气缸控制系统由以下部分组成：

1. **输入层**：接收外部输入信号，包括传感器信号和控制信号
2. **控制层**：实现双线圈控制逻辑、线圈互斥保护、状态机管理
3. **输出层**：输出线圈控制信号和状态信号
4. **监控层**：实现传感器监控、报警系统、故障检测

### 2.2 模块划分

| 模块名称 | 功能描述 | 实现文件 |

## 3. 详细设计

### 3.1 双线圈控制逻辑

#### 3.1.1 核心控制逻辑

```scl
// 网络1：双线圈气缸控制逻辑
// 当i_气缸_S1闭合时，激活动点线圈，禁用原点线圈
IF i_气缸_S1 THEN
    q_气缸动点线圈 := TRUE;
    q_气缸原点线圈 := FALSE;
END_IF;

// 当i_气缸_S0闭合时，激活原点线圈，禁用动点线圈
IF i_气缸_S0 THEN
    q_气缸动点线圈 := FALSE;
    q_气缸原点线圈 := TRUE;
END_IF;

// 线圈互斥保护
// 确保两个线圈不会同时激活
IF q_气缸动点线圈 AND q_气缸原点线圈 THEN
    // 线圈冲突，禁用所有线圈
    q_气缸动点线圈 := FALSE;
    q_气缸原点线圈 := FALSE;
    q_原点异常 := TRUE;
    n_State := 3; // 切换到报警状态
END_IF;

// 控制信号冲突保护
IF i_气缸_S1 AND i_气缸_S0 THEN
    // 控制信号冲突，禁用所有线圈
    q_气缸动点线圈 := FALSE;
    q_气缸原点线圈 := FALSE;
    q_原点异常 := TRUE;
    n_State := 3; // 切换到报警状态
END_IF;
```

#### 3.1.2 线圈互斥保护

实现了三重互斥保护：
1. **控制逻辑互斥**：在控制逻辑中确保只有一个线圈能被激活
2. **线圈状态互斥**：监控线圈状态，确保不会同时激活
3. **控制信号互斥**：监控控制信号，确保不会同时接收相反的控制信号

### 3.3 报警系统设计

#### 3.3.1 原点报警

```scl
// 网络4：原点报警
// 原点报警定时器
T_0[5] := NOT q_气缸动点线圈 AND NOT i_屏蔽原点 AND NOT i_原点传感器;
TONR(IN := T_0[5], 
     PT := 报警延时, 
     R := i_复位 OR NOT (NOT q_气缸动点线圈 AND NOT i_屏蔽原点 AND NOT i_原点传感器), 
     Q => M_0[8], 
     ET => MW_0[8]);

// 原点报警触发与自动恢复
IF M_0[8] THEN
    q_原点异常 := TRUE;
    n_State := 3; // 切换到报警状态
ELSIF NOT (NOT q_气缸动点线圈 AND NOT i_屏蔽原点 AND NOT i_原点传感器) THEN
    // 当报警条件消失时，自动恢复
    q_原点异常 := FALSE;
END_IF;
```

#### 3.3.2 动点报警

```scl
// 网络5：动点报警
// 动点报警定时器
T_0[6] := q_气缸动点线圈 AND NOT i_屏蔽动点 AND NOT i_动点传感器;

     PT := 报警延时, 
     R := i_复位 OR NOT (q_气缸动点线圈 AND NOT i_屏蔽动点 AND NOT i_动点传感器),

    q_动点异常 := FALSE;
END_IF;
```

### 3.4 状态机管理设计

```scl
// 网络7：状态机管理
// 状态初始化
IF i_复位 THEN
    n_State := 0; // 复位到初始化状态
END_IF;

// 状态机逻辑
CASE n_State OF
    // 初始化状态
    0:
        // 检查初始状态
        IF q_气缸原点到位 THEN
            n_State := 1; // 切换到原点状态
        ELSIF q_气缸动点到位 THEN
            n_State := 2; // 切换到动点状态
        ELSE
            // 保持初始化状态
        END_IF;
    
    // 原点状态
    1:
        // 当气缸动点线圈激活时，切换到动点状态
        IF q_气缸动点线圈 THEN
            n_State := 2;
        END_IF;
    
    // 动点状态
    2:
        // 当气缸原点线圈激活且原点到位时，切换到原点状态
        IF q_气缸原点线圈 AND q_气缸原点到位 THEN
            n_State := 1;
        END_IF;
    
    // 报警状态
    3:
        // 当报警清除且回到正常状态时，切换到相应状态
        IF NOT q_动点异常 AND NOT q_原点异常 THEN
            IF q_气缸原点到位 THEN
                n_State := 1;
            ELSIF q_气缸动点到位 THEN
                n_State := 2;
            ELSE
                n_State := 0;
            END_IF;
        END_IF;
END_CASE;
```

## 6. 时序设计

### 6.1 正常工作时序

1. **系统初始化**：
   - 系统上电，进入初始化状态
   - 检查初始位置，根据传感器信号切换到相应状态

2. **原点到动点**：
   - 接收i_气缸_S1信号
   - 激活动点线圈，禁用原点线圈
   - 等待动点传感器信号
   - 检测到动点传感器信号后，确认动点到位

3. **动点到原点**：
   - 接收i_气缸_S0信号
   - 激活原点线圈，禁用动点线圈
   - 等待原点传感器信号
   - 检测到原点传感器信号后，确认原点到位

### 6.2 异常处理时序

1. **传感器故障**：
   - 检测到两个传感器同时触发
   - 触发传感器故障报警
   - 禁用所有线圈
   - 进入报警状态

2. **线圈冲突**：
   - 检测到两个线圈同时激活
   - 触发线圈冲突报警
   - 禁用所有线圈
   - 进入报警状态

3. **控制信号冲突**：
   - 检测到S1和S0同时激活
   - 触发控制信号冲突报警
   - 禁用所有线圈
   - 进入报警状态

## 9. 维护与故障排除

### 9.1 日常维护

- **定期检查**：定期检查传感器状态和线圈工作情况
