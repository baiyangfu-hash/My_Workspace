# 双线圈气缸FB需求文档

## 1. 项目概述

### 1.1 项目背景

本项目基于项目1的单线圈气缸控制逻辑，实现双线圈气缸控制系统。双线圈气缸系统为动点和原点各提供一个独立的控制线圈，提高系统的可靠性和控制精度。

### 1.2 项目目标

- 实现双线圈气缸控制逻辑，动点和原点各一个独立线圈
- 保持与项目1相同的传感器监控、报警系统和状态机管理
- 确保线圈互斥保护，避免两个线圈同时激活
- 提供完整的文档和配置，确保自动化系统能正确识别和管理项目

## 2. 功能需求

### 2.1 核心功能

1. **双线圈控制**：
   - 动点线圈控制：控制气缸向动点方向移动
   - 原点线圈控制：控制气缸向原点方向移动
   - 线圈互斥保护：确保两个线圈不会同时激活

2. **传感器监控**：
   - 动点传感器信号监控
   - 原点传感器信号监控
   - 传感器故障检测

3. **报警系统**：
   - 动点异常报警
   - 原点异常报警
   - 报警延时功能
   - 报警自动恢复

4. **状态机管理**：
   - 初始化状态
   - 原点状态
   - 动点状态
   - 报警状态

### 2.2 输入输出需求

#### 2.2.1 输入信号

| 输入信号 | 类型 | 描述 |
|---------|------|------|
| i_动点传感器 | BOOL | 动点传感器信号输入 |
| i_原点传感器 | BOOL | 原点传感器信号输入 |
| i_气缸_S1 | BOOL | 气缸开始到动点控制信号 |
| i_气缸_S0 | BOOL | 气缸开始到原点控制信号 |
| i_屏蔽动点 | BOOL | 屏蔽动点传感器信号 |
| i_屏蔽原点 | BOOL | 屏蔽原点传感器信号 |
| i_复位 | BOOL | 系统复位信号 |

#### 2.2.2 输出信号

| 输出信号 | 类型 | 描述 |
|---------|------|------|
| q_气缸动点线圈 | BOOL | 气缸动点线圈控制信号 |
| q_气缸原点线圈 | BOOL | 气缸原点线圈控制信号 |
| q_气缸动点到位 | BOOL | 气缸动点到位状态 |
| q_气缸原点到位 | BOOL | 气缸原点到位状态 |
| q_动点异常 | BOOL | 动点异常报警 |
| q_原点异常 | BOOL | 原点异常报警 |

## 3. 非功能需求

### 3.1 性能需求

- 响应时间：传感器信号变化到输出响应的时间不超过10ms
- 报警延时：可配置，默认为3000ms
- 到位延时：可配置，默认值为10ms和100ms

### 3.2 可靠性需求

- 线圈互斥保护：确保两个线圈不会同时激活，避免系统冲突
- 传感器故障检测：当两个传感器同时触发时，识别为传感器故障
- 控制信号冲突保护：当S1和S0同时激活时，禁用所有线圈

### 3.3 可维护性需求

- 模块化设计：采用模块化设计，便于维护和扩展
- 完整文档：提供完整的设计文档、使用文档和变更记录
- 标准化命名：严格按照项目规范命名变量和文件

## 4. 范围限定

- 本项目仅实现双线圈气缸控制逻辑，不包括上位机控制界面
- 本项目基于汇川Autoshop平台开发，仅适用于该平台
- 本项目不涉及硬件设计，仅关注软件控制逻辑
