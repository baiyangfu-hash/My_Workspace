## 1. 概述

### 1.1 功能简介
FB_MainControlStation功能块实现了主控站对各工作站的监控和控制功能，以及与外部系统的通讯对接功能，确保系统稳定运行，包含完整的错误处理和状态监控机制。

### 1.2 应用场景
- 自动化生产线的中央控制系统
- 多工作站协同工作的工业场景
- 需要与外部系统（MES/ERP/HMI）集成的系统
- 具备全面监控和控制需求的工业自动化系统
- 要求高可靠性和故障处理能力的生产环境

### 1.3 工具特点
- **标准化接口**：严格遵循IEC 61131-3标准
- **模块化设计**：采用六大模块结构
- **状态机管理**：使用状态机实现工作站和通讯的有序管理
- **错误处理**：包含完整的超时和报警处理机制
- **测试支持**：提供内置测试模式
- **易于集成**：标准化接口，易于与其他系统集成
- **可扩展性**：支持工作站数量和类型的灵活扩展

## 2. 快速开始

### 2.1 系统要求

| 系统/软件 | 版本/配置 | 用途 |
|-----------|-----------|------|
| 汇川Autoshop | Vx.x.x | PLC编程软件 |
| PLC | 支持IEC 61131-3标准 | 运行环境 |
| 工作站系统 | 支持数字信号交互 | 监控和控制对象 |
| MES系统（可选） | 支持数据交互 | 生产管理系统 |
| ERP系统（可选） | 支持数据同步 | 企业资源计划系统 |
| HMI系统（可选） | 支持数字信号显示 | 监控界面 |

### 2.2 安装步骤

1. **下载文件**：
   - 从项目目录获取以下文件：
     - FB_主控站.scl
     - Test_FB_主控站.scl
     - FB_导入PLC变量_项目名称_autoshop_vX.Y.Z.csv

2. **导入变量表格**：
   - 在Autoshop中选择「导入变量」
   - 选择FB_导入PLC变量_项目名称_autoshop_vX.Y.Z.csv文件
   - 确认导入成功，无乱码

3. **导入FB功能块**：
   - 在Autoshop中选择「导入FB」
   - 选择FB_主控站.scl文件
   - 确认编译通过，无错误

4. **导入测试功能块**（可选）：
   - 在Autoshop中选择「导入FB」
   - 选择Test_FB_主控站.scl文件
   - 确认编译通过，无错误

### 2.3 基本配置

1. **实例化FB**：
   - 在程序中添加FB实例
   - 为实例分配符号名，如FB_MainControlStationInstance

2. **配置工作站参数**：
   - 根据实际工作站数量设置MAX_WORKSTATIONS参数
   - 根据实际系统需求调整计时器预设值

3. **连接输入变量**：
   - 连接工作站信号输入
   - 连接外部通讯输入
   - 连接控制信号输入

4. **连接输出变量**：
   - 连接工作站控制输出
   - 连接外部通讯输出
   - 连接状态监控输出

5. **配置外部通讯**：
   - 根据实际外部系统配置通讯参数
   - 设置适当的通讯超时时间

### 3.4 操作流程

#### 3.4.1 正常操作流程

1. **系统启动**：
   - 主控站系统初始化
   - 检测各工作站状态
   - 检测外部系统连接状态
   - 系统进入准备就绪状态（q_StatusWord.1 = TRUE）

2. **工作站准备**：
   - 主控站检查各工作站准备状态（i_WorkstationReady[]）
   - 当所有工作站就绪时，设置工作站全部就绪状态（q_StatusWord.4 = TRUE）

3. **生产启动**：
   - 接收开始生产信号（i_StartProduction = TRUE）
   - 主控站向各工作站发送启动信号（q_WorkstationStart[] = TRUE）
   - 系统进入生产运行中状态（q_StatusWord.2 = TRUE）

4. **生产监控**：
   - 主控站持续监控各工作站运行状态（i_WorkstationRunning[]）
   - 监控外部系统通讯状态
   - 实时更新状态字和生产计数（q_ProductionCount）

5. **生产完成**：
   - 各工作站发送循环完成信号（i_WorkstationCycleComplete[] = TRUE）
   - 主控站确认生产完成
   - 准备下一轮生产或等待生产停止信号

6. **生产停止**：
   - 接收停止生产信号
   - 主控站向各工作站发送停止信号（q_WorkstationStop[] = TRUE）
   - 系统退出生产运行状态（q_StatusWord.2 = FALSE）

#### 3.4.2 工作站参数更新流程

1. **参数设置**：
   - 通过HMI或外部系统设置工作站参数（i_WorkstationParam[]）
   - 发送参数变更信号（i_WorkstationParamChanged[] = TRUE）

2. **参数更新**：
   - 主控站设置参数更新中状态（q_StatusWord.5 = TRUE）
   - 向工作站发送参数值（q_WorkstationParam[]）
   - 发送参数更新信号（q_WorkstationParamUpdate[] = TRUE）

3. **更新确认**：
   - 工作站确认参数更新完成
   - 主控站清除参数更新中状态（q_StatusWord.5 = FALSE）

#### 3.4.3 错误处理流程

1. **错误检测**：
   - 系统检测到工作站错误（i_WorkstationError[] = TRUE）
   - 检测到外部通讯错误
   - 设置系统错误状态（q_StatusWord.8 = TRUE，q_ErrorFlag = TRUE）
   - 进入错误处理中状态（q_StatusWord.6 = TRUE）

2. **错误处理**：
   - 暂停相关工作站运行
   - 向HMI发送错误信息
   - 触发报警信号
   - 尝试自动恢复或等待人工干预

3. **故障排除**：
   - 检查工作站状态和错误信息
   - 检查外部系统连接状态
   - 排除故障原因

4. **系统复位**：
   - 发送复位信号（i_Reset = TRUE）
   - 主控站向工作站发送复位信号（q_WorkstationReset[] = TRUE）
   - 系统清除错误状态
   - 恢复正常运行

## 4. 测试与调试

### 4.1 测试功能块使用

#### 4.1.1 测试模式说明

| 测试模式 | 功能描述 | 使用建议 |
|----------|----------|----------|
| 0 | 完整流程测试 | 测试整个主控站流程的正确性，包括工作站控制和外部通讯 |
| 1 | 工作站控制测试 | 测试对工作站的启动、停止、复位控制功能 |
| 2 | 外部通讯测试 | 测试与MES/ERP/HMI等外部系统的通讯功能 |
| 3 | 参数更新测试 | 测试工作站参数更新功能 |
| 4 | 错误处理测试 | 测试系统的错误检测和处理功能 |
| 5 | 状态监控测试 | 测试系统状态监控和状态字更新功能 |

#### 4.1.2 测试步骤

1. **实例化测试功能块**：
   - 在程序中添加Test_FB_主控站实例
   - 为实例分配符号名，如Test_FB_MainControlStation

2. **设置测试模式**：
   - 设置i_TestMode为所需的测试模式

3. **启动测试**：
   - 运行程序
   - 测试功能块自动开始测试流程
   - 系统进入测试模式状态（q_StatusWord.7 = TRUE）

4. **监控测试状态**：
   - 通过q_TestStatus监控测试状态
   - 通过q_TestStep监控测试步骤
   - 通过q_TestCompleted和q_TestPassed获取测试结果
   - 通过HMI监控状态字变化

5. **测试完成**：
   - 测试完成后，q_TestCompleted = TRUE
   - 测试通过时，q_TestPassed = TRUE
   - 系统退出测试模式状态（q_StatusWord.7 = FALSE）

### 4.2 常见问题调试

| 问题现象 | 可能原因 | 调试方法 | 解决方案 |
|----------|----------|----------|----------|
| 变量表乱码 | 编码不一致 | 使用check_encoding.py工具检查编码 | 转换为与模板一致的编码 |
| 编译错误 | 变量未定义 | 检查变量表和FB代码 | 确保所有变量都在变量表中定义 |
| 工作站无响应 | 工作站信号未连接 | 检查工作站物理连接和信号状态 | 确保工作站信号正确连接 |
| 外部系统通讯失败 | 通讯参数配置错误 | 检查外部系统通讯参数 | 重新配置通讯参数，确保网络连接正常 |
| 状态字异常 | 内部状态错误 | 检查状态机逻辑和内部变量 | 复位系统，检查状态转换逻辑 |
| 超时错误 | 超时设置过短 | 检查计时器预设值 | 根据实际设备响应时间调整超时时间 |
| 运行不稳定 | 信号冲突或时序问题 | 检查信号顺序和时序 | 确保信号按正确顺序发送，调整信号时序 |
| 参数更新失败 | 参数设置错误或更新信号未连接 | 检查参数值范围和更新信号连接 | 确保参数值在有效范围内，检查更新信号连接 |
| 复位无效 | 复位信号未连接或工作站故障 | 检查复位信号连接和工作站状态 | 确保复位信号正确连接，检查工作站是否存在硬件故障 |
| 生产计数不准确 | 计数信号丢失或重复 | 检查计数信号和计数逻辑 | 确保计数信号稳定，检查计数逻辑是否正确 |

### 4.3 调试技巧

1. **使用状态字监控**：
   - 在HMI上显示状态字的各个位
   - 实时监控系统状态变化

2. **使用测试功能块**：
   - 利用测试功能块的不同测试模式
   - 逐步测试各个功能模块

3. **检查信号顺序**：
   - 确保上游信号按正确顺序发送
   - 使用示波器或逻辑分析仪监控信号时序

4. **调整超时时间**：
   - 根据实际设备响应时间调整计时器预设值
   - 确保有足够的时间处理信号

5. **检查编码一致性**：
   - 使用check_encoding.py工具检查所有文件的编码
   - 确保所有文件使用与模板一致的编码

### 5.3 故障排除

#### 5.3.1 工作站故障

| 故障现象 | 可能原因 | 排除方法 |
|----------|----------|----------|
| 工作站无响应 | 工作站电源故障 | 检查工作站电源供应 |
| 工作站无响应 | 通讯线缆松动 | 检查并紧固通讯线缆 |

## 8. 常见问题解答

### 8.1 基本问题

**Q: 功能块的主要作用是什么？**
A: 功能块实现了主控站对各工作站的监控和控制功能，以及与外部系统的通讯对接功能，确保系统稳定运行，包含完整的错误处理和状态监控机制。

**Q: 功能块支持哪些输入信号？**
A: 功能块支持工作站信号输入（准备就绪、运行状态、错误状态等）、外部通讯输入（MES/ERP/HMI连接状态）和控制信号输入（开始生产、重置生产、复位等）。

**Q: 功能块支持哪些输出信号？**
A: 功能块支持工作站控制输出（启动、停止、复位、参数设置等）、外部通讯输出（MES/ERP数据准备、HMI更新等）和状态监控输出（状态字、错误标志、工作站状态等）。

### 8.2 技术问题

**Q: 变量表乱码怎么办？**
A: 使用check_encoding.py工具检查编码，确保变量表使用与模板一致的编码。如果编码不一致，使用convert_to_gbk_improved.py工具进行转换。

**Q: 编译错误怎么办？**
A: 检查变量表和FB代码，确保所有变量都在变量表中定义，并且变量名和数据类型一致。

**Q: 信号不响应怎么办？**
A: 检查物理连接和信号状态，确保信号正确连接。使用测试功能块测试信号处理功能。

**Q: 状态字异常怎么办？**
A: 检查状态机逻辑和内部变量，复位系统，检查状态转换。使用HMI监控状态字的各个位，定位问题所在。

### 8.3 应用问题

**Q: 如何调整超时时间？**
A: 根据实际设备响应时间调整计时器预设值。在FB代码中修改TON计时器的PT参数。

**Q: 如何在手动模式下控制系统？**
A: 设置i_ManualMode = TRUE，然后通过i_ManualMachineReady、i_ManualComponentIDReceived、i_ManualAllowFeed、i_ManualComponentInPlace手动控制各个状态。

**Q: 如何处理错误状态？**
A: 检查信号连接和设备状态，排除故障原因，然后发送复位信号（i_Reset = TRUE）清除错误状态。

**Q: 如何测试功能块的功能？**
A: 使用Test_FB_上游与本站交互功能块，设置不同的测试模式，测试各个功能模块的功能。
