## 3. 变更详情

### 3.1 v1.0.0 (初始版本)

#### 3.1.1 功能特性

- **运动控制**：实现单线圈气缸的运动和原位控制
- **位置检测**：检测气缸的动点和原点位置
- **故障诊断**：检测和报警气缸故障
- **状态管理**：实现完整的状态机管理

#### 3.1.2 技术实现

- **编程语言**：SCL，符合IEC 61131-3标准
- **状态机**：4个状态（初始化、原点、动点、报警）
- **定时器**：使用TONR定时器实现延时检测
- **变量命名**：采用前缀+驼峰命名规则

### 3.2 v1.0.1 (补丁版本)

#### 3.2.1 性能优化

- **优化到位检测逻辑**：调整定时器参数，提高检测准确性
- **优化传感器信号处理**：添加滤波逻辑，减少误检测

### 3.3 v1.0.2 (补丁版本)

#### 3.3.1 功能增强

- **完善故障诊断机制**：增加多级故障检测，提高诊断准确性
- **添加自动恢复功能**：故障条件消失时自动恢复正常状态

#### 3.3.2 问题修复

- **修复报警信号误触发问题**：调整报警延时参数
- **修复状态切换异常问题**：优化状态切换条件

### 3.4 v1.0.3 (补丁版本)

#### 3.4.1 性能优化

- **优化状态机逻辑**：简化状态切换条件，提高系统稳定性
- **优化代码结构**：重构代码，提高可读性和可维护性

#### 3.4.2 问题修复

- **修复状态机死锁问题**：添加状态超时处理
- **修复复位功能异常问题**：优化复位逻辑

### 3.5 v1.0.4 (补丁版本)

#### 3.5.1 规范统一

## 4. 兼容性说明

### 4.1 向前兼容性

- **v1.0.0到v1.0.4**：所有版本向前兼容，旧版本的FB实例可以直接升级到新版本

## 7. 附录

### 7.1 术语定义

| 术语 | 解释 |
|------|------|
| FB | 功能块（Function Block），IEC 61131-3标准中的功能模块 |
| SCL | 结构化控制语言（Structured Control Language），IEC 61131-3标准中的编程语言 |
| PLC | 可编程逻辑控制器（Programmable Logic Controller） |
| 单线圈气缸 | 只有一个控制线圈的气缸，通过脉冲信号控制运动方向 |
| 状态机 | 用于描述系统状态和状态转换的数学模型 |
| TONR | 带复位的接通延时定时器 |
