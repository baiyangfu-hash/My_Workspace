# 单线圈气缸控制FB需求文档

## 1. 项目概述

### 1.1 项目背景

本项目旨在开发一个基于IEC 61131-3标准的单线圈气缸控制功能块（FB），用于汇川Autoshop PLC编程环境。该功能块将实现单线圈气缸的自动化控制，包括运动控制、位置检测、故障诊断和状态管理等功能。

### 1.2 项目目标

- **功能目标**：实现单线圈气缸的完整控制逻辑，包括运动控制、位置检测、故障诊断和状态管理
- **性能目标**：响应时间≤100ms，支持24/7连续运行
- **质量目标**：代码符合IEC 61131-3标准，无语法错误，变量定义完整
- **兼容性目标**：完全兼容汇川Autoshop编程软件

## 2. 功能需求

### 2.1 核心功能

- **运动控制**：接收外部控制信号，控制气缸的运动和原位
- **位置检测**：通过传感器信号检测气缸的运动位置和原位位置
- **状态管理**：实现完整的状态机，包括初始化、原位、运动、复位等状态
- **故障诊断**：检测和指示运动故障和原位故障
- **复位功能**：支持外部复位信号，恢复初始状态

### 2.2 输入输出需求

#### 2.2.1 输入信号

| 输入信号 | 类型 | 描述 |
|---------|------|------|
| i_运动电磁阀 | BOOL | 气缸运动控制信号 |
| i_原位置电磁阀 | BOOL | 气缸原位置控制信号 |
| i_运动_S1 | BOOL | 气缸运动到位信号 |
| i_运动_S0 | BOOL | 气缸运动原位信号 |
| i_运动检测 | BOOL | 气缸运动位置检测信号 |
| i_原位检测 | BOOL | 气缸原位位置检测信号 |
| i_复位 | BOOL | 系统复位信号 |
| i_运动原位强制读取 | BOOL | 强制读取原位信号 |

#### 2.2.2 输出信号

| 输出信号 | 类型 | 描述 |
|---------|------|------|
| q_运动状态运行中 | BOOL | 气缸运动状态指示 |
| q_运动状态到位 | BOOL | 气缸运动到位状态指示 |
| q_运动原位到位 | BOOL | 气缸原位到位状态指示 |
| q_运动故障 | BOOL | 气缸运动故障指示 |
| q_原位故障 | BOOL | 气缸原位故障指示 |

## 3. 非功能需求

### 3.1 性能需求

- 响应时间：≤100ms
- 运行周期：10ms
- 支持24/7连续运行
- 状态切换时间：≤50ms

### 3.2 可靠性需求

- 故障检测时间：≤100ms
- 故障指示准确率：100%
- 复位成功率：100%
- 抗干扰能力：符合工业环境EMC标准

### 3.3 可维护性需求

- 代码可读性：符合IEC 61131-3标准，结构清晰
- 文档完整性：包含完整的需求文档、设计文档、接口文档和使用文档
- 模块化设计：功能模块清晰，便于维护和扩展
- 变量命名规范：遵循统一的命名规则，便于理解和使用

## 4. 范围限定

- 仅支持单线圈气缸控制
- 仅适用于汇川Autoshop编程环境
- 不支持多气缸联动控制
- 不包含上位机通信功能

### 8.2 术语定义

| 术语 | 解释 |
|------|------|
| FB | 功能块（Function Block），IEC 61131-3标准中的功能模块 |
| SCL | 结构化控制语言（Structured Control Language），IEC 61131-3标准中的编程语言 |
| 单线圈气缸 | 只有一个控制线圈的气缸，通过脉冲信号控制运动方向 |
| 状态机 | 用于描述系统状态和状态转换的数学模型 |
