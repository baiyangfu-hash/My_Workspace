## 产品概述
输送线控制FB（FB_ConveyorControlV4）是一个符合IEC 61131-3标准的功能块，用于控制输送线电机的启动、停止、速度调节和故障检测。该FB采用高内聚、低耦合的设计原则，具有良好的移植性和可维护性。

## 功能特性
- **双模式控制**：支持手动模式和自动模式
- **速度调节**：支持慢速和快速两种速度模式
- **故障检测**：内置故障检测机制
- **高可靠性**：状态管理稳定，避免振荡
- **易于集成**：标准化的输入输出接口

## 技术参数
- **输入信号**：4个BOOL类型输入
- **输出信号**：4个BOOL类型输出
- **内部变量**：5个内部状态变量
- **执行周期**：一个扫描周期内完成所有逻辑运算

## 安装与配置
### 1. 变量表导入
1. 在PLC编程软件中创建新的FB
2. 导入`FB_导入PLC变量_输送线控制_autoshop_v4.0.0.csv`变量表
3. 确保变量表使用GBK编码

### 2. FB实例化
```scl
// 声明FB实例
VAR
    fbConveyor : FB_ConveyorControlV4;
END_VAR

// 调用FB
fbConveyor(
    // 输入信号连接
    i_ManualStart := X0,    // 手动启动按钮
    i_ManualStop := X1,     // 手动停止按钮
    i_AutoStart := X2,      // 自动启动信号
    i_AutoStop := X3,       // 自动停止信号
    
    // 输出信号连接
    q_MotorRunning => Y0,   // 电机运行指示灯
    q_MotorSlow => Y1,      // 电机慢速接触器
    q_MotorFast => Y2,      // 电机快速接触器
    q_MotorFault => Y3      // 故障报警指示灯
);
```

## 操作指南
### 手动模式操作
1. **启动**：按下手动启动按钮（X0）
2. **停止**：按下手动停止按钮（X1）
3. **速度**：手动模式下默认为快速运行

### 自动模式操作
1. **启动**：系统发送自动启动信号（X2）
2. **停止**：系统发送自动停止信号（X3）
3. **速度**：自动模式下初始为快速，产品到位后切换为慢速，1秒后停止

### 故障处理
1. **故障指示**：故障报警指示灯（Y3）亮起
2. **故障原因**：速度模式冲突（运行状态与停止速度模式的冲突）
3. **故障复位**：停止电机后重新启动

## 应用场景示例

### 场景1：包装生产线应用
**应用描述**：在包装生产线上，输送线需要根据产品位置自动调整速度，确保包装精度。

**配置步骤**：
1. **变量表导入**：导入`FB_导入PLC变量_输送线控制_autoshop_v4.0.0.csv`
2. **传感器连接**：将光电传感器连接到X4（i_Position1Sensor）
3. **主控连接**：将主控系统的运行模式信号连接到D0（i_MainControlMode）
4. **参数设置**：设置i_SlowDelayTime为1000（1秒慢速延时）

**运行流程**：
1. 主控系统设置i_MainControlMode为2（自动模式）
2. 发送i_AutoStart信号启动输送线
3. 输送线快速运行，当产品到达位置1时，传感器X4检测到信号
4. 输送线切换为慢速运行1秒
5. 1秒后自动停止，同时q_ProductInPlaceDone置为TRUE
6. 产品被取走后，传感器X4信号消失，3秒后q_ProductInPlaceDone自动复位

### 场景2：装配生产线应用
**应用描述**：在装配生产线上，输送线需要与上下游设备协调，确保装配过程的同步性。

**配置步骤**：
1. **变量表导入**：导入`FB_导入PLC变量_输送线控制_autoshop_v4.0.0.csv`
2. **方向控制**：将电机方向控制信号连接到D1（i_MotorDirection）
3. **状态反馈**：将q_ProductInPlaceDone连接到上游设备的停止信号
4. **参数设置**：设置i_SlowDelayTime为2000（2秒慢速延时）

**运行流程**：
1. 上游设备完成装配后，发送i_AutoStart信号
2. 输送线快速运行将产品送往下游
3. 产品到达位置1后，切换为慢速运行2秒
4. 下游设备取走产品后，传感器信号消失
5. 3秒后q_ProductInPlaceDone复位，通知上游设备可以开始下一个周期

## 故障排查
### 故障排查流程图
```
┌─────────────────────┐
│ 故障现象：电机不运行 │
└─────────────┬───────┘
              ▼
┌─────────────────────┐
│ 检查启动信号是否正常 │
└─────────────┬───────┘
              ▼
┌─────────────────────┐     否     ┌─────────────────────┐
│ 信号正常？          │──────────►│ 检查信号线路和按钮  │
└─────────────┬───────┘           └─────────────────────┘
      是     ▼
┌─────────────────────┐
│ 检查运行模式设置    │
└─────────────┬───────┘
              ▼
┌─────────────────────┐     否     ┌─────────────────────┐
│ 模式设置正确？      │──────────►│ 检查主控模式信号    │
└─────────────┬───────┘           └─────────────────────┘
      是     ▼
┌─────────────────────┐
│ 检查故障标志        │
└─────────────┬───────┘
              ▼
┌─────────────────────┐     是     ┌─────────────────────┐
│ 有故障？            │──────────►│ 检查速度模式冲突    │
└─────────────┬───────┘           └─────────────────────┘
      否     ▼
┌─────────────────────┐
│ 检查电机接触器      │
└─────────────────────┘
```

| 故障现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 电机不运行 | 未输入启动信号 | 检查启动按钮和信号线路 |
| 速度异常 | 模式设置错误 | 检查模式选择和速度设置 |
| 故障报警 | 速度模式冲突 | 停止电机后重新启动 |
| 模式切换失败 | 输入信号冲突 | 确保同一时间只有一个模式的信号有效 |
| 电机方向不切换 | 电机未停止 | 确保电机停止后再切换方向 |
| 产品到位标志不复位 | 传感器信号异常 | 检查传感器安装和信号线路 |
| 计时器不工作 | 计时器变量未初始化 | 检查计时器数组变量设置 |
