## 接口说明
### 功能概述
FB_ConveyorControlV4是一个高内聚、低耦合的输送线控制功能块，用于实现输送线的自动和手动控制，包括电机启停、速度调节、产品检测等功能。

### 核心控制逻辑
1. **模式控制**：通过`i_MainControlMode`字段控制运行模式，优先级为手动模式 > 自动模式 > 停止模式
2. **启动停止逻辑**：
   - 手动模式：通过`i_ManualStart`和`i_ManualStop`控制
   - 自动模式：通过`i_AutoStart`和`i_AutoStop`控制
3. **速度控制**：根据运行状态自动切换速度模式（停止/慢速/快速）
4. **产品检测**：通过`i_Position1Sensor`检测产品位置
5. **方向控制**：通过`i_MotorDirection`设定电机运行方向
6. **故障检测**：实时监测电机运行状态，检测故障情况
7. **状态反馈**：通过`q_StatusWord`提供详细的状态信息

### 业务规则
1. **模式优先级**：手动模式优先级高于自动模式，当同时激活时，以手动模式为准
2. **停止优先**：任何模式下，停止信号都具有最高优先级
3. **速度切换**：
   - 启动时先慢速运行，延时后切换到快速运行
   - 停止时直接停止，无减速过程
4. **状态字定义**：
   - 位0：运行模式冲突（当手动和自动模式同时激活时置1）
   - 位1：速度模式冲突（当速度模式设置不合理时置1）
5. **故障处理**：检测到故障时，立即停止电机运行，设置故障标志

### 调用示例
```scl
// 实例化FB
VAR
    fbConveyor : FB_ConveyorControlV4;
END_VAR

// 调用FB
fbConveyor(
    i_ManualStart := X0,
    i_ManualStop := X1,
    i_AutoStart := X2,
    i_AutoStop := X3,
    i_Position1Sensor := X4,
    i_MainControlMode := D0,
    i_MotorDirection := D1,
    i_SlowDelayTime := D4,
    q_MotorRunning => Y0,
    q_MotorSlow => Y1,
    q_MotorFast => Y2,
    q_MotorFault => Y3,
    q_MotorDirection => D2,
    q_ProductInPlaceDone => Y4,
    q_StatusWord => D3
);
```

### 注意事项
1. **输入信号**：所有输入信号应保持稳定，避免频繁波动
2. **模式切换**：模式切换时应确保当前模式已完全停止
3. **速度设置**：慢速延时时间应根据实际设备特性合理设置
4. **故障处理**：检测到故障后，应先排除故障原因，再重新启动
5. **状态监控**：应定期监控`q_StatusWord`，及时发现和处理异常情况

## 输入字段
| 字段 | 类型 | 默认值 | 取值范围 | 描述 |
|------|------|--------|----------|------|
| `i_ManualStart` | BOOL | OFF | OFF/ON | 手动启动信号，为ON时启动手动模式运行 |
| `i_ManualStop` | BOOL | OFF | OFF/ON | 手动停止信号，为ON时停止手动模式运行 |
| `i_AutoStart` | BOOL | OFF | OFF/ON | 自动启动信号，为ON时启动自动模式运行 |
| `i_AutoStop` | BOOL | OFF | OFF/ON | 自动停止信号，为ON时停止自动模式运行 |
| `i_Position1Sensor` | BOOL | OFF | OFF/ON | 位置1传感器信号，检测产品是否到达位置1 |
| `i_MainControlMode` | INT | 0 | 0-停止, 1-手动, 2-自动 | 主控运行模式，控制FB的整体运行模式。**生效条件**：仅当当前模式为0（停止）时，模式切换操作生效。**无效结果**：当前模式非0时，模式切换不生效，将设置模式错误标志（`q_StatusWord`位0置1）。**边界说明**：所有非0状态均视为锁定，运行模式之间不能直接切换 |
| `i_MotorDirection` | INT | 0 | 0-正转, 1-反转 | 电机运行方向设定。**生效条件**：仅当电机停止运行时，方向修改操作生效。**无效结果**：电机运行时，方向设置不生效，接口无错误返回。**边界说明**：电机运行时所有方向设置均视为无效，仅在电机停止时方向修改才会被执行 |
| `i_SlowDelayTime` | INT | 0 | ≥0 | 慢速运行延时时间设定，单位为毫秒 |

## 输出字段
| 字段 | 类型 | 默认值 | 取值范围 | 描述 |
|------|------|--------|----------|------|
| `q_MotorRunning` | BOOL | OFF | OFF/ON | 电机运行状态，为ON时表示电机正在运行 |
| `q_MotorSlow` | BOOL | OFF | OFF/ON | 电机慢速状态，为ON时表示电机处于慢速运行状态 |
| `q_MotorFast` | BOOL | OFF | OFF/ON | 电机快速状态，为ON时表示电机处于快速运行状态 |
| `q_MotorFault` | BOOL | OFF | OFF/ON | 电机异常状态，为ON时表示电机出现故障 |
| `q_MotorDirection` | INT | 0 | 0-正转, 1-反转 | 电机运行方向状态，反映当前电机实际运行方向 |
| `q_ProductInPlaceDone` | BOOL | OFF | OFF/ON | 产品到位完成标志，为ON时表示产品已成功到达指定位置 |
| `q_StatusWord` | INT | 0 | ≥0 | 状态字，位0:运行模式冲突, 位1:速度模式冲突 |

## 静态变量使用说明
静态变量用于在FB调用之间保持状态，主要用于计时器管理：
- **In_tTimer1**：计时器启动信号，[0]用于无产品检测延时，[1]用于慢速运行延时
- **Q_tTimer1**：计时器完成信号，计时达到预设值时为TRUE
- **R_tTimer1**：计时器复位信号，为TRUE时重置计时器
- **PT_tTimer1**：计时器预设值，单位为毫秒
- **ET_tTimer1**：计时器当前值，反映已计时时间

静态变量在FB实例化后会保持其值，即使FB没有被调用也不会丢失，因此特别适合用于计时器等需要持续状态的场景。

## 接口特性
- **高内聚**：所有控制逻辑封装在FB内部
- **低耦合**：通过明确的输入输出接口与外部交互
- **移植性强**：无硬件依赖，可在不同PLC系统中使用
- **模式优先级**：手动模式优先级高于自动模式
