# 输送线控制FB需求文档

## 1. 项目背景与目标

### 1.1 项目背景

在自动化生产线中，输送线控制是连接各个工位的关键环节。为了实现对输送线的精确控制和管理，需要设计一个符合IEC 61131-3标准的功能块（FB），用于控制输送线的运行状态、气缸动作、与上下游设备的交互，并支持手动和自动两种操作模式。

### 1.2 项目目标

- 设计一个模块化、可扩展的输送线控制FB块
- 支持手动和自动两种操作模式
- 实现双位置检测功能，精确监控产品位置
- 实现气缸伸缩控制，用于产品定位
- 支持与主控系统的完整交互
- 支持与机械手的完整交互
- 提供完善的状态监测和故障检测功能
- 符合IEC 61131-3标准，具有良好的可移植性和兼容性
- 适配三菱GX Works3平台

## 2. 功能需求

### 2.1 基本控制功能

| 功能模块 | 功能描述 | 优先级 |
|----------|----------|--------|
| 双位置检测 | 实现两个位置传感器的检测功能，精确监控产品位置 | 高 |
| 气缸控制 | 实现气缸的伸缩控制，支持手动和自动模式 | 高 |
| 进料禁止控制 | 根据传感器状态控制上游进料禁止 | 高 |
| 状态监测 | 监测工位就绪、有料等状态 | 高 |
| 报警处理 | 检测和报告系统故障等错误 | 高 |

### 2.2 上下游交互功能

| 交互对象 | 功能描述 | 优先级 |
|----------|----------|--------|
| 主控系统 | 发送请求取料/放料信号，接收允许进料/出料信号 | 高 |
| 机械手 | 发送请求取料/放料信号，接收机械手状态和任务完成确认 | 高 |
| 上游输送线 | 发送进料禁止信号，控制上游进料 | 高 |

### 2.3 操作模式需求

| 操作模式 | 功能描述 | 优先级 |
|----------|----------|--------|
| 手动模式 | 直接控制气缸的伸缩动作，支持手动操作 | 中 |
| 自动模式 | 通过状态机实现自动运行，支持与上下游设备交互 | 高 |

## 3. 性能需求

| 性能指标 | 需求描述 | 优先级 |
|----------|----------|--------|
| 响应时间 | 传感器状态变化到输出响应时间≤100ms | 高 |
| 状态切换时间 | 自动模式下状态切换时间≤50ms | 高 |
| 故障检测时间 | 系统故障检测时间≤100ms | 高 |
| 可靠性 | 连续运行时间≥720小时无故障 | 高 |
| 交互响应时间 | 与上下游设备交互响应时间≤100ms | 高 |

## 4. 接口需求

### 4.1 物理接口

| 接口类型 | 数量 | 描述 | 优先级 |
|----------|------|------|--------|
| 输入接口 | ≥14 | 传感器信号、控制命令、状态反馈等 | 高 |
| 输出接口 | ≥12 | 控制信号、状态反馈、交互信号等 | 高 |

### 4.2 软件接口

| 接口类型 | 描述 | 优先级 |
|----------|------|--------|
| FB块调用 | 支持IEC 61131-3标准的FB块调用方式 | 高 |
| 变量映射 | 支持与PLC输入输出点的直接映射 | 高 |
| 状态反馈 | 支持通过变量反馈FB块运行状态 | 高 |
| 主控交互 | 与主控系统通过M30-M32信号交互 | 高 |
| 机械手交互 | 与机械手通过D101、M200-M201信号交互 | 高 |

## 7. 风险分析

| 风险项 | 风险描述 | 应对措施 |
|--------|----------|----------|
| 硬件兼容性问题 | 与特定PLC硬件兼容性不佳 | 进行充分的硬件测试，确保兼容主流PLC |
| 软件版本冲突 | 与GX Works3平台版本不兼容 | 明确支持的GX Works3版本范围 |
| 通信延迟 | 与上下游设备通信延迟影响生产效率 | 优化通信逻辑，减少延迟 |
| 传感器信号干扰 | 传感器信号受到干扰导致误操作 | 实现传感器信号的防抖处理 |
| 状态机逻辑错误 | 状态机逻辑错误导致系统异常 | 充分测试状态机逻辑，确保状态转换正确 |

## 8. 附录

### 8.1 术语定义

| 术语 | 定义 |
|------|------|
| FB | Function Block，功能块，IEC 61131-3标准中的功能模块 |
| IEC 61131-3 | 国际电工委员会制定的工业控制系统编程语言标准 |
| GX Works3 | 三菱电机开发的工业自动化编程软件 |
| PLC | Programmable Logic Controller，可编程逻辑控制器 |
| 双位置检测 | 基于两个位置传感器的产品位置检测方式 |
| 状态机 | 一种数学模型，用于描述对象在不同状态之间的转换 |
| 上下游交互 | 与上游设备和下游设备的数据交换和控制信号传递 |
| 进料禁止 | 控制上游设备停止进料的信号 |
| 机械手 | 自动执行取料、放料等操作的自动化设备 |
| 主控系统 | 控制整个生产线的中央控制系统 |
