# 气缸控制FB使用文档

## 1. 安装与配置

### 1.1 开发环境要求

| 环境类型 | 版本要求 | 备注 |
|----------|----------|------|
| 操作系统 | Windows 10/11 64位 | 推荐使用Windows 11 |
| GX Works3 | V1.0及以上 | 三菱电机工业自动化编程软件 |
| PLC型号 | FX5U, RCPU | 支持的PLC型号 |

### 1.2 安装步骤

1. **打开GX Works3软件**
   - 启动GX Works3编程软件，进入项目管理界面

2. **导入FB块**
   - 选择"导入"功能，浏览到`FB_CylinderControl_work3.st`文件
   - 点击"导入"按钮，将FB块导入到项目中

3. **导入变量表**
   - 选择"导入变量表"功能，浏览到`FB_导出PLC变量_气缸控制_work3.csv`文件
   - 点击"导入"按钮，将变量表导入到项目中

4. **配置变量映射**
   - 在变量表中，为输入输出变量配置实际的PLC地址
   - 参考FB接口文档中的地址映射建议

### 1.3 配置要求

| 配置项 | 要求 | 备注 |
|--------|------|------|
| 输入电源 | 24VDC | 传感器和控制信号电源 |
| 输出电源 | 24VDC | 电磁阀控制电源 |
| 通信速率 | 115200bps | 与其他设备通信速率 |
| 扫描周期 | ≤10ms | PLC扫描周期建议 |

## 2. FB实例化方法

### 2.1 变量声明

在主程序或功能块中声明FB实例变量：

```st
// FB实例化变量声明
VAR
    fbCylinder1 : FB_CylinderControl_work3; // 气缸控制FB实例
END_VAR
```

### 2.2 FB调用

在主程序循环中调用FB块：

```st
// 主程序循环中调用FB块
fbCylinder1(
    // 输入变量配置
    i_OriginSensor := X0,                // 原点传感器信号
    i_EndSensor := X1,                   // 终点传感器信号
    i_ManualMode := X2,                  // 手动模式
    i_AutoMode := X3,                    // 自动模式
    i_ExtendCmd := X4,                   // 手动伸出命令
    i_RetractCmd := X5,                  // 手动缩回命令
    i_Start := X6,                       // 自动运行启动
    i_Stop := X7,                        // 自动运行停止
    i_AlarmReset := X8,                  // 报警复位
    i_ExtendTimeout := T#2S,             // 伸出超时时间
    i_RetractTimeout := T#2S,            // 缩回超时时间
    i_SensorDebounceTime := T#50MS,      // 传感器防抖时间
    i_AlarmDelay := T#100MS,             // 报警延迟时间
    // 输出变量配置
    q_SolenoidOutput => Y0,              // 电磁阀输出控制
    q_OriginPosition => Y1,              // 原点位置状态
    q_EndPosition => Y2,                 // 终点位置状态
    q_Extending => Y3,                   // 正在伸出状态
    q_Retracting => Y4,                  // 正在缩回状态
    q_AutoRunning => Y5,                 // 自动运行状态
    q_ManualRunning => Y6,               // 手动运行状态
    q_Alarm => Y7,                       // 报警状态
    q_StateBits => ARRAY[0..9] OF BOOL   // 气缸状态位数组
);
```

## 3. 运行模式说明

### 3.1 手动模式

**激活条件**：`i_ManualMode = TRUE`

**功能特点**：
- 直接控制气缸的伸缩动作
- 忽略自动状态机逻辑
- 适合调试和维护场景

**操作方法**：
1. 设置`i_ManualMode = TRUE`（手动模式）
2. 使用以下命令控制气缸：
   - `i_ExtendCmd = TRUE`：气缸伸出
   - `i_RetractCmd = TRUE`：气缸缩回

**注意事项**：
- 手动模式下，气缸的伸出和缩回命令是独立的
- 建议不要同时设置伸出和缩回命令，以免造成冲突

### 3.2 自动模式

**激活条件**：`i_AutoMode = TRUE`

**功能特点**：
- 基于状态机实现自动运行
- 支持启动/停止控制
- 适合正常生产场景

**运行流程**：
1. **空闲状态**：系统初始化后进入，等待启动命令
2. **正在伸出状态**：收到启动命令后，气缸开始伸出
3. **伸出到位状态**：终点传感器触发，气缸停止伸出
4. **正在缩回状态**：自动开始缩回动作
5. **缩回到位状态**：原点传感器触发，气缸停止缩回
6. **回到空闲状态**：等待下一次启动命令

**状态转换条件**：
- 启动命令触发
- 传感器信号触发
- 超时检测触发
- 停止命令触发

## 4. 操作流程

### 4.1 开机初始化流程

1. **检查硬件连接**
   - 检查传感器、气缸、电磁阀等硬件连接是否正确
   - 检查电源是否正常

2. **启动PLC**
   - 给PLC上电，等待PLC初始化完成

3. **执行系统复位**
   - 设置`i_AlarmReset = TRUE`，执行系统复位
   - 复位完成后，设置`i_AlarmReset = FALSE`

4. **选择运行模式**
   - 根据需要选择手动模式或自动模式

### 4.2 手动操作流程

1. **切换到手动模式**
   - 设置`i_ManualMode = TRUE`

2. **调试气缸**
   - 操作气缸伸出/缩回命令，检查气缸动作是否正常
   - 观察`q_Extending`和`q_Retracting`状态变化

3. **检查传感器**
   - 触发传感器，检查传感器状态是否正确反馈
   - 观察`q_OriginPosition`和`q_EndPosition`状态变化

4. **返回自动模式**
   - 调试完成后，设置`i_ManualMode = FALSE`
   - 设置`i_AutoMode = TRUE`，切换到自动模式

### 4.3 自动运行流程

1. **准备工作**
   - 确保传感器安装正确，信号正常
   - 设置`i_AutoMode = TRUE`

2. **启动生产**
   - 设置`i_Start = TRUE`，启动自动运行
   - 系统开始自动控制气缸的伸缩动作

3. **监控运行状态**
   - 观察`q_AutoRunning`、`q_Extending`、`q_Retracting`等状态变量
   - 监控气缸运行状态和传感器状态

4. **处理异常情况**
   - 如发生故障，`q_Alarm`会变为TRUE
   - 查看`q_StateBits`获取具体故障信息
   - 根据故障诊断指南处理故障

5. **停止生产**
   - 设置`i_Stop = TRUE`，停止自动运行
   - 气缸停止当前动作，进入空闲状态
   - 可以选择执行系统复位

## 5. 故障诊断与处理

### 5.1 故障指示灯状态

| 指示灯 | 状态 | 含义 |
|--------|------|------|
| 报警状态（Y7） | 亮 | 系统发生故障 |
| 报警状态（Y7） | 灭 | 系统正常运行 |
| 正在伸出（Y3） | 亮 | 气缸正在伸出 |
| 正在缩回（Y4） | 亮 | 气缸正在缩回 |
| 原点位置（Y1） | 亮 | 气缸在原点位置 |
| 终点位置（Y2） | 亮 | 气缸在终点位置 |

### 5.2 常见故障及处理方法

| 故障类型 | 故障原因 | 处理方法 |
|----------|----------|----------|
| 传感器冲突 | 原点和终点传感器同时触发 | 1. 检查传感器安装位置是否正确<br>2. 检查传感器信号是否正常<br>3. 执行系统复位 |
| 伸出超时 | 气缸伸出超时，未到达终点位置 | 1. 检查气缸动作是否顺畅<br>2. 检查终点传感器是否正常<br>3. 调整i_ExtendTimeout参数<br>4. 执行系统复位 |
| 缩回超时 | 气缸缩回超时，未到达原点位置 | 1. 检查气缸动作是否顺畅<br>2. 检查原点传感器是否正常<br>3. 调整i_RetractTimeout参数<br>4. 执行系统复位 |
| 阀门卡死 | 电磁阀状态改变但气缸未动作 | 1. 检查电磁阀是否正常工作<br>2. 检查气缸是否卡死<br>3. 执行系统复位 |

### 5.3 故障诊断流程

1. **观察故障指示灯**
   - 检查报警状态指示灯（Y7）是否点亮

2. **查看状态位数组**
   - 通过HMI或编程软件查看`q_StateBits`的值
   - 根据位状态判断具体故障类型

3. **分析故障原因**
   - 根据故障类型和现场情况，分析可能的故障原因
   - 检查相关硬件设备和线路

4. **排除故障**
   - 根据故障处理方法，排除故障
   - 检查设备是否恢复正常

5. **复位系统**
   - 执行系统复位（`i_AlarmReset = TRUE`）
   - 恢复系统运行

## 6. 维护与注意事项

### 6.1 日常维护

| 维护项目 | 维护周期 | 维护内容 |
|----------|----------|----------|
| 传感器清洁 | 每周 | 清洁传感器表面，确保检测正常 |
| 气缸润滑 | 每月 | 为气缸添加润滑油，确保动作顺畅 |
| 电磁阀检查 | 每月 | 检查电磁阀运行状态，听是否有异常噪音 |
| 线路检查 | 每季度 | 检查所有线路连接是否松动，绝缘是否良好 |
| 程序备份 | 每季度 | 备份PLC程序和变量表 |
| 参数调整 | 每半年 | 根据实际运行情况调整超时时间和防抖时间参数 |

### 6.2 注意事项

1. **安全操作**
   - 操作前确保已经了解设备的安全操作规程
   - 进行手动操作时，确保现场人员安全
   - 发生故障时，及时停机处理

2. **程序修改**
   - 修改程序前，务必备份原程序
   - 程序修改后，必须进行充分测试
   - 确保修改后的程序符合安全规范

3. **硬件更换**
   - 更换传感器或电磁阀时，确保型号一致
   - 更换后，重新调试设备
   - 记录更换的硬件信息和时间

4. **环境要求**
   - 确保PLC和设备工作在干燥、通风的环境中
   - 避免高温、高湿、粉尘等恶劣环境
   - 定期清理设备表面的灰尘

5. **参数设置**
   - 根据实际气缸型号和运行速度调整超时时间参数
   - 根据传感器类型和安装环境调整防抖时间参数

## 7. 常见问题解答

### 7.1 FB块无法正常运行

**问题**：FB块调用后，没有输出信号

**可能原因**：
- 未执行系统复位
- 输入变量配置错误
- 运行模式设置错误
- 变量映射错误

**解决方法**：
1. 执行系统复位（`i_AlarmReset = TRUE`）
2. 检查输入变量配置是否正确
3. 检查运行模式设置
4. 检查变量映射是否正确

### 7.2 气缸不动作

**问题**：设置命令后，气缸不动作

**可能原因**：
- 命令未正确配置
- 电磁阀故障
- 输出电源故障
- 输出线路故障

**解决方法**：
1. 检查命令变量（`i_ExtendCmd`或`i_RetractCmd`）是否为TRUE
2. 检查输出变量（`q_SolenoidOutput`）是否为TRUE
3. 检查输出电源是否正常
4. 检查电磁阀是否故障

### 7.3 自动模式下不工作

**问题**：自动模式下，气缸不动作

**可能原因**：
- 自动模式未正确设置
- 启动命令未设置
- 传感器未触发
- 系统未复位

**解决方法**：
1. 检查`i_AutoMode`是否为TRUE
2. 检查`i_Start`是否为TRUE
3. 检查传感器是否正常工作
4. 执行系统复位，重新初始化系统

### 7.4 传感器信号不稳定

**问题**：传感器信号频繁抖动，导致误操作

**可能原因**：
- 传感器安装不牢固
- 传感器周围有干扰源
- 防抖时间设置过短

**解决方法**：
1. 检查传感器安装是否牢固
2. 移除传感器周围的干扰源
3. 增加`i_SensorDebounceTime`参数值
