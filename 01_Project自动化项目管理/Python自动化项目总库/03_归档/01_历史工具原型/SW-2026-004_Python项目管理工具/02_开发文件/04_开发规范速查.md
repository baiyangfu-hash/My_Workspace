# 开发规范速查

## 1. 编码规范摘要

### 1.1 命名约定
| 类型 | 规范 | 示例 |
|------|------|------|
| 类名 | PascalCase | LibraryService, NewProjectDialog |
| 函数/方法 | snake_case | get_resolved_project_path(), cleanup_root_paths() |
| 变量 | snake_case | base_path, library_id, category_count |
| 常量 | UPPER_SNAKE_CASE | VERSION, SRC_DIR, DEFAULT_CONFIG_PATH |
| 私有属性 | 单下划线前缀 | _session, _logger, _config |
| 文件名 | snake_case | library_service.py, new_project_dialog.py |

### 1.2 文件组织
```
每个 .py 文件应包含:
# -*- coding: utf-8 -*-
"""模块/类简要描述"""

# 导入顺序:
# 1. 标准库
# 2. 第三方库
# 3. 本地模块 (from src.xxx import yyy)
# 4. 相对导入

class ClassName:
    """类的详细docstring"""

    def __init__(self):
        """构造函数说明"""
        ...

    def public_method(self):
        """公开方法"""
        ...

    def _private_method(self):
        """私有方法"""
        ...
```

### 1.3 异常处理模式
```python
# 推荐: 精确捕获 + 日志记录 + 优雅降级
try:
    result = risky_operation()
except SpecificError as e:
    logger.warning(f"操作失败，使用降级方案: {e}")
    result = fallback_operation()
except Exception as e:
    logger.error(f"未预期异常: {e}")
    raise
```

### 1.4 日志规范
```python
import logging
logger = logging.getLogger(__name__)

logger.debug("详细调试信息")   # 开发阶段
logger.info("正常流程信息")     # 关键步骤
logger.warning("警告信息")      # 可恢复的异常
logger.error("错误信息")       # 需关注的错误
```

## 2. Git 提交规范

### 2.1 Commit Message 格式
```
<type>(<scope>): <subject>

<body>

<footer>
```

**type**: feat/fix/docs/refactor/style/test/chore
**scope**: ui/services/models/config/build/docs
**subject**: 中文简述，不超过50字

### 2.2 示例
```
feat(ui): 新建项目对话框增加路径优先级链路

- 实现4级优先级(Config→DB→检测→硬兜底)
- Config导入改为延迟安全ImportError捕获
- 最终兜底改为exe_dir/Projects而非cwd

Closes #V2.5.9-path-fix
```

### 2.3 分支策略
- main: 稳定版（对应正式发布的tag）
- develop: 开发版（日常开发合并到此）
- feature/Vx.y.z-xxx: 功能分支
- fix/Vx.y.z-xxx: Bug修复分支

## 3. 代码审查 Checklist

### 3.1 安全检查
- [ ] 无硬编码密码或密钥
- [ ] 无SQL注入风险（使用参数化查询）
- [ ] 无路径遍历风险（使用Path对象而非字符串拼接）
- [ ] 敏感操作有权限检查

### 3.2 性能检查
- [ ] 无N+1查询问题（批量操作用join或in）
- [ ] 大数据量操作有分页/限制
- [ ] 循环内无重复数据库查询
- [ ] 文件操作使用上下文管理器(with)

### 3.3 规范符合性
- [ ] 命名符合项目规范
- [ ] 有适当的docstring
- [ ] 异常处理不裸捕获(不用 bare except)
- [ ] 日志使用logging模块非print

### 3.4 PyInstaller兼容性
- [ ] 动态import用try/except ImportError包裹
- [ ] 路径处理考虑sys.frozen状态
- [ ] 不依赖CWD作为数据根目录

## 4. 打包前 Checklist

每次执行 `python package.py` 前:

### 4.1 版本一致性
- [ ] version.py VERSION 已更新
- [ ] config/app_config.json (源码) version 已同步
- [ ] config/app_config.json (交付物) version 已同步
- [ ] 三处值完全相同

### 4.2 数据库状态
- [ ] 源码 data/project_manager.db 的 categories >= 5条
- [ ] 源码 DB 的 libraries.root_path 无含盘符值
- [ ] 运行 `python package.py --dry-run` Phase 2 PASS

### 4.3 功能验证
- [ ] `python main.py` 能正常启动GUI
- [ ] 新建项目对话框能弹出且无报错
- [ ] 总库管理页面加载正常

## 5. 常用命令速查

| 操作 | 命令 |
