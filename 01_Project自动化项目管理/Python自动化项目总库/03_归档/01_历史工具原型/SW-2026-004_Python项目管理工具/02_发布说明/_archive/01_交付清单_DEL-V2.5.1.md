## 修复内容

### 1. 总库管理模块
- **问题**: 项目数显示为0
- **原因**: project_dao.py 中 count_by_status 方法的缓存键和查询过滤逻辑问题
- **修复**: 修正缓存键使用枚举的 value 而非对象，确保查询过滤条件被正确应用

### 2. 模板管理
- **问题**: 模板未更新到位
- **原因**: PyInstaller .spec 文件的 pathex 为空，可能导致无法正确找到 src 包
- **修复**: 修正 .spec 文件，添加 pathex=['.'] 配置

### 3. 版本显示
- **问题**: 版本显示异常
- **原因**: 版本号未更新到 V2.5.1
- **修复**: 更新 version.py 中的版本信息到 V2.5.1

### 4. 功能增强
- **新增**: 版本记录功能
- **位置**: 帮助菜单 → 版本记录
- **功能**: 显示当前版本信息和历史版本的更新说明

## 安装与运行

### 安装步骤
1. 解压 `Python自动化项目管理系统_V2.5.1_20260416.zip`
2. 运行 `01_可执行文件/Python项目管理工具.exe`
3. 首次运行会自动初始化默认总库

### 运行环境
- **操作系统**: Windows 10/11 (64位)
- **内存**: 4GB 以上
- **CPU**: Intel i5 或同等性能
- **磁盘空间**: 100MB 以上

## 注意事项

1. **备份**: 首次运行前请备份现有的 `project_manager.db` 文件
2. **权限**: 请以管理员权限运行程序
3. **防火墙**: 如遇到网络访问问题，请检查防火墙设置
4. **兼容性**: 支持 Windows 10/11 64位系统
