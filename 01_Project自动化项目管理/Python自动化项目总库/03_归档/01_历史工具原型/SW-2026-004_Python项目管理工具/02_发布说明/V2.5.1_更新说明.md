## 修复内容

### 1. 总库管理模块 - 项目数显示问题

**问题描述**：总库管理模块中的项目数显示为 0，即使系统中存在多个项目。

**问题原因**：
- `project_dao.py` 中的 `count_by_status` 方法使用了 `ProjectStatus` 枚举对象作为缓存键
- 查询过滤条件未正确应用（缺少 `query =` 赋值）

**修复方案**：
- 修正缓存键使用枚举的 `value` 属性而非对象：`cache_key = f"count:{status.value if status else 'all'}"`
- 确保查询过滤条件被正确应用：`query = query.filter(Project.status == status)`

**影响范围**：总库管理模块的项目统计功能

### 2. 模板管理 - 模板未更新到位

**问题描述**：使用模板生成的项目可能未包含变更管理模块的目录结构。

**问题原因**：
- PyInstaller 的 `.spec` 文件中 `pathex` 为空，可能导致无法正确找到 `src` 包
- 模板定义可能未包含最新的变更管理结构

**修复方案**：
- 更新 `.spec` 文件，添加 `pathex=['.']` 配置
- 验证 `constants.py` 中的模板定义，确保包含正确的变更管理目录结构

**影响范围**：模板生成功能

### 3. 版本显示 - 版本显示异常

**问题描述**：软件界面显示的版本号与实际版本不符。

**问题原因**：
- `version.py` 中的版本号仍为 V2.4.4，未更新到 V2.5.1

**修复方案**：
- 更新 `version.py` 中的版本信息：
  - `VERSION = "2.5.1"`
  - `VERSION_INFO` 中的 `major=2, minor=5, patch=1`
  - 更新 `changelog` 描述

**影响范围**：版本显示、关于对话框

## 功能增强

### 1. 版本记录功能

**功能描述**：新增版本记录查看功能，方便用户了解软件的版本历史和变更内容。

**功能位置**：帮助菜单 → 版本记录

**功能特点**：
- 显示当前版本的详细信息（版本号、构建日期、状态、变更内容）
- 读取 `02_发布说明` 目录中的更新说明文件
- 按版本号降序排列，最新版本在前
- 支持简单的 Markdown 格式显示

**实现方式**：
- 在 `main_window.py` 中添加 `_on_version_history` 方法
- 使用 `QDialog` 和 `QTextBrowser` 构建版本记录对话框
- 从 `src/core/version.py` 读取当前版本信息
- 扫描 `02_发布说明` 目录中的 `.md` 文件

## 安装与升级

### 1. 安装步骤
1. 下载 `Python自动化项目管理系统_V2.5.1_20260416.zip`
2. 解压到任意目录
3. 运行 `01_可执行文件/Python项目管理工具.exe`
4. 首次运行会自动初始化默认总库

### 2. 升级步骤
1. 备份现有的 `project_manager.db` 文件
2. 下载并解压新版本
3. 覆盖原有的可执行文件和配置文件
4. 运行程序，系统会自动检测并迁移数据
