# Python项目管理工具 V2.5.7 更新说明

## 更新信息

| 属性 | 值 |
|------|-----|
| **版本号** | V2.5.7 |
| **更新类型** | 增强 |
| **发布日期** | 2026-04-17 |
| **适用版本** | V2.4.0 及以上 |

## 变更内容

### 主要变更/修复

1. **跨机器路径兼容性增强**
   - 新增 `./Projects` 相对路径支持，解决不同机器间项目路径不一致问题
   - 提升工具在不同开发环境下的可移植性

2. **配置模块扩展 (`app_config.json`)**
   - 新增 `default_project_path` 配置项
   - 支持默认项目路径的统一管理

3. **核心功能增强 (`config.py`)**
   - 新增 `get_resolved_project_path()` 方法
   - 实现项目路径的动态解析与标准化处理

4. **目录结构优化**
   - 新增 `Projects/.gitkeep` 预置文件，确保目录结构完整性
   - 清理数据库中残留的 `root_path` 配置，消除路径冲突隐患

### 影响范围

- **核心模块**: config.py, app_config.json
- **数据库层**: 项目路径相关数据表
- **跨平台兼容性**: Windows/Linux/macOS 路径解析逻辑

## 升级建议

建议所有用户升级，特别是需要在不同开发环境间切换或共享项目的团队。
