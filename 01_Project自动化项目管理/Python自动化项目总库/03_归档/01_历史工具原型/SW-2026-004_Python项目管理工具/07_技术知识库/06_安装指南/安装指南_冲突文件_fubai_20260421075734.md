## 1. 系统要求

### 1.1 硬件要求
- **处理器**: Intel Core i5 或更高
- **内存**: 4GB 或更高
- **磁盘空间**: 1GB 可用空间
- **网络**: 可选，用于更新和远程访问

### 1.2 软件要求
- **操作系统**: Windows 10/11 (64位)
- **Python**: 3.7+ (仅在开发模式下需要)
- **数据库**: SQLite 3 (内置)
- **浏览器**: 现代浏览器 (用于Web界面)

## 2. 安装方式

### 2.1 方式一：使用可执行文件（推荐）

#### 步骤1: 获取安装包
- 从交付物中获取 `Python项目管理工具_1.0.3_交付物.zip`
- 或从官方下载页面获取最新版本

#### 步骤2: 解压安装包
1. 将压缩包解压到目标目录
   - 推荐路径：`D:\Python项目管理工具\`
   - 避免使用包含中文或空格的路径

2. 解压后的目录结构：
   ```
   Python项目管理工具/
   ├── 01_可执行文件/
   │   └── Python项目管理工具.exe
   ├── 02_配置文件/
   │   ├── api_config.json
   │   ├── app_config.json
   │   └── database_config.json
   ├── 03_测试文件/
   │   └── run_full_test_suite.py
   ├── 04_文档/
   │   └── 01_用户手册.md
   └── 05_数据库/
       └── project_manager.db
   ```

#### 步骤3: 运行应用
- 双击 `01_可执行文件\Python项目管理工具.exe`
- 或在命令行中执行：`Python项目管理工具.exe`

### 2.2 方式二：使用Python安装（开发模式）

#### 步骤1: 安装Python
- 下载并安装 Python 3.7+ (https://www.python.org/downloads/)
- 确保勾选 "Add Python to PATH"

#### 步骤2: 克隆项目
```bash
git clone [仓库地址]
cd Python项目管理工具
```

#### 步骤3: 安装依赖
```bash
# 安装依赖
py -m pip install -r requirements.txt

# 或使用setup.py安装
py setup.py install
```

#### 步骤4: 运行应用
```bash
# 启动GUI界面
py main.py

# 或指定模式
py main.py --mode gui
```

### 2.3 方式三：使用pip安装

#### 步骤1: 构建包
```bash
py setup.py sdist bdist_wheel
```

#### 步骤2: 安装包
```bash
pip install dist/python_project_manager-1.0.3-py3-none-any.whl
```

#### 步骤3: 运行命令
```bash
# 使用命令行工具
project-manager

# 查看版本
project-manager version
```

## 3. 配置说明

### 3.1 配置文件

**主配置文件**: `config/app_config.json`
```json
{
  "app_name": "Python项目管理工具",
  "version": "1.0.3",
  "debug": false,
  "log_level": "INFO",
  "data_dir": "data",
  "max_projects": 1000
}
```

**API配置文件**: `config/api_config.json`
```json
{
  "host": "0.0.0.0",
  "port": 8000,
  "api_key": "your-api-key-here",
  "cors_enabled": true
}
```

**数据库配置文件**: `config/database_config.json`
```json
{
  "type": "sqlite",
  "path": "data/project_manager.db",
  "backup_enabled": true,
  "backup_interval": 3600
}
```

### 3.2 环境变量

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| `PM_CONFIG_DIR` | 配置文件目录 | `config` |
| `PM_DATA_DIR` | 数据文件目录 | `data` |
| `PM_LOG_DIR` | 日志文件目录 | `logs` |
| `PM_API_KEY` | API访问密钥 | 随机生成 |

## 6. 数据库管理

### 6.1 数据库备份

#### 自动备份
- 默认每小时自动备份
- 备份文件存储在 `data/backups/` 目录
- 保留最近7天的备份

#### 手动备份
```bash
# 使用命令行备份
py main.py --mode cli --backup
```

### 6.2 数据库恢复

#### 从备份恢复
1. 停止应用
2. 复制备份文件到 `data/project_manager.db`
3. 重新启动应用

### 6.3 数据库迁移

**版本升级时**:
1. 备份当前数据库
2. 运行应用，自动执行迁移
3. 验证数据完整性

## 7. 安全配置

### 7.1 访问控制
- **API密钥**: 修改 `api_config.json` 中的 `api_key`
- **用户权限**: 在系统设置中配置用户权限
- **网络访问**: 配置防火墙允许必要的端口

### 7.2 数据安全
- **密码加密**: 使用bcrypt加密存储
- **敏感数据**: 配置文件中的敏感信息应加密
- **传输安全**: API使用HTTPS（生产环境）

### 7.3 审计日志
- 所有关键操作都有审计日志
- 日志存储在 `logs/audit.log`
- 定期轮换日志文件

## 8. 性能优化

### 8.1 系统调优
- **内存配置**: 根据系统内存调整 `max_memory` 参数
- **缓存设置**: 启用Redis缓存（可选）
- **数据库索引**: 确保关键表有适当的索引

### 8.2 监控指标
- **CPU使用率**: 应低于70%
- **内存使用率**: 应低于80%
- **响应时间**: 应低于2秒

### 8.3 负载测试
```bash
# 运行性能测试
py run_full_test_suite.py --mode performance
```

## 9. 故障排除

### 9.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 应用无法启动 | 缺少依赖或配置错误 | 检查日志文件，重新安装依赖 |
| 数据库连接失败 | 数据库文件损坏或权限问题 | 恢复备份，检查文件权限 |
| API服务无响应 | 端口被占用或配置错误 | 检查端口占用，修改配置 |
| 性能缓慢 | 数据量过大或系统资源不足 | 优化查询，增加系统资源 |

### 9.2 日志文件
- **应用日志**: `logs/app.log`
- **错误日志**: `logs/error.log`
- **审计日志**: `logs/audit.log`
- **API日志**: `logs/api.log`

### 9.3 诊断命令
```bash
# 运行诊断
py main.py --mode cli --diagnose

# 检查系统状态
py main.py --mode cli --status
```

## 10. 版本管理

### 10.1 版本升级

#### 从旧版本升级
1. 备份当前数据和配置
2. 下载新版本安装包
3. 解压到原目录（覆盖）
4. 启动应用，自动执行迁移
5. 验证功能正常

#### 版本兼容性
- **1.0.x**: 完全兼容
- **0.9.x**: 需要手动迁移数据
- **0.8.x及以下**: 建议重新安装

### 10.2 版本回退
1. 停止应用
2. 恢复备份的数据库和配置
3. 安装旧版本
4. 启动应用
