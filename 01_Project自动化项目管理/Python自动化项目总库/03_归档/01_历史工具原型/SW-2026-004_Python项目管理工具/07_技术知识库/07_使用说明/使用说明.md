## 1. 系统概述

### 1.1 产品简介
Python项目管理工具是一个功能强大的项目管理系统，专为Python项目开发团队设计。它提供了项目管理、变更管理、插件管理等核心功能，帮助团队提高开发效率和项目质量。

### 1.2 核心功能
- **项目管理**: 创建、查询、更新、删除项目
- **变更管理**: 变更申请、审批、执行、记录
- **插件管理**: 插件安装、启用、禁用
- **模板管理**: 项目模板创建和应用
- **API服务**: 提供RESTful API接口
- **GUI界面**: 直观的图形化操作界面

### 1.3 适用场景
- **中小型开发团队**：管理多个Python项目
- **敏捷开发环境**：快速响应需求变更
- **DevOps流程**：集成自动化测试和部署
- **个人开发者**：管理个人项目和学习资源

## 3. 项目管理

### 3.1 创建项目

#### 步骤1: 打开新建项目向导
- 点击 **文件 > 新建项目** 或按 **Ctrl+N**
- 或点击左侧面板的 **+ 新建项目** 按钮

#### 步骤2: 填写项目信息
- **项目名称**: 输入项目名称
- **业务线**: 选择所属业务线
- **项目类型**: 选择项目类型
- **模板**: 选择项目模板（可选）
- **描述**: 输入项目描述
- **负责人**: 选择项目负责人

#### 步骤3: 配置项目
- **版本控制**: 配置Git仓库
- **构建工具**: 选择构建工具
- **测试框架**: 选择测试框架
- **部署配置**: 配置部署环境

#### 步骤4: 确认创建
- 点击 **创建** 按钮
- 系统会自动创建项目目录结构和配置文件

### 3.2 项目详情

#### 基本信息
- **项目名称**: 显示项目名称
- **项目ID**: 系统生成的唯一标识符
- **创建时间**: 项目创建时间
- **最后更新**: 项目最后更新时间
- **状态**: 项目当前状态（活跃/暂停/完成）

#### 项目成员
- **负责人**: 项目负责人
- **成员**: 项目团队成员
- **角色**: 成员角色和权限

#### 项目统计
- **变更数量**: 项目相关的变更数量
- **任务数量**: 项目任务数量
- **问题数量**: 项目问题数量
- **文档数量**: 项目文档数量

### 3.3 项目操作

#### 编辑项目
- 点击 **编辑** 按钮修改项目信息
- 修改后点击 **保存** 按钮

#### 暂停项目
- 点击 **暂停** 按钮
- 确认暂停操作

#### 完成项目
- 点击 **完成** 按钮
- 填写完成备注
- 确认完成操作

#### 删除项目
- 点击 **删除** 按钮
- 输入确认密码
- 确认删除操作

## 4. 变更管理

### 4.1 创建变更

#### 步骤1: 打开变更申请向导
- 点击 **变更 > 新建变更** 或按 **Ctrl+Shift+C**
- 或在项目详情页点击 **+ 新建变更** 按钮

#### 步骤2: 填写变更信息
- **变更标题**: 输入变更标题
- **项目**: 选择关联项目
- **变更类型**: 选择变更类型（功能/缺陷/优化/其他）
- **优先级**: 选择变更优先级（高/中/低）
- **描述**: 详细描述变更内容
- **影响范围**: 说明变更影响的范围

#### 步骤3: 附加信息
- **附件**: 上传相关文件
- **相关变更**: 关联其他变更
- **测试计划**: 填写测试计划
- **风险评估**: 评估变更风险

#### 步骤4: 提交审批
- 选择审批人
- 点击 **提交审批** 按钮

### 4.2 变更审批

#### 审批流程
1. **提交申请**: 变更创建者提交变更
2. **审批中**: 审批人审核变更
3. **已批准**: 变更获得批准
4. **已拒绝**: 变更被拒绝
5. **已执行**: 变更执行完成
6. **已关闭**: 变更流程结束

#### 审批操作
- **批准**: 点击 **批准** 按钮，填写审批意见
- **拒绝**: 点击 **拒绝** 按钮，填写拒绝原因
- **退回**: 点击 **退回** 按钮，要求修改
- **转批**: 点击 **转批** 按钮，转给其他审批人

### 4.3 变更执行

#### 执行步骤
1. **准备**: 准备执行环境
2. **执行**: 执行变更内容
3. **测试**: 验证变更效果
4. **部署**: 部署变更到生产环境
5. **验证**: 验证生产环境

#### 执行记录
- **执行时间**: 变更执行时间
- **执行人**: 变更执行人
- **执行结果**: 执行成功/失败
- **测试结果**: 测试通过/失败
- **部署结果**: 部署成功/失败

## 7. API服务

### 7.1 API接口

#### 项目管理接口
- **GET /api/projects**: 获取项目列表
- **POST /api/projects**: 创建项目
- **GET /api/projects/{id}**: 获取项目详情
- **PUT /api/projects/{id}**: 更新项目
- **DELETE /api/projects/{id}**: 删除项目

#### 变更管理接口
- **GET /api/changes**: 获取变更列表
- **POST /api/changes**: 创建变更
- **GET /api/changes/{id}**: 获取变更详情
- **PUT /api/changes/{id}**: 更新变更
- **POST /api/changes/{id}/approve**: 批准变更
- **POST /api/changes/{id}/reject**: 拒绝变更

#### 插件管理接口
- **GET /api/plugins**: 获取插件列表
- **POST /api/plugins**: 安装插件
- **GET /api/plugins/{id}**: 获取插件详情
- **PUT /api/plugins/{id}**: 更新插件
- **DELETE /api/plugins/{id}**: 卸载插件

### 7.2 API认证

#### API密钥
- 在 `api_config.json` 中配置 `api_key`
- 请求时在 headers 中添加 `Authorization: Bearer {api_key}`

#### 权限控制
- **管理员**: 所有API权限
- **开发人员**: 项目和变更管理权限
- **只读用户**: 仅查询权限

### 7.3 API示例

#### 获取项目列表
```bash
curl -X GET "http://localhost:8000/api/projects" \
  -H "Authorization: Bearer your-api-key"
```

#### 创建项目
```bash
curl -X POST "http://localhost:8000/api/projects" \
  -H "Authorization: Bearer your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "新项目",
    "business_line": "DJ",
    "description": "测试项目"
  }'
```

## 12. 故障排除

### 12.1 常见问题

| 问题 | 症状 | 解决方案 |
|------|------|----------|
| 无法创建项目 | 点击创建按钮无响应 | 检查权限设置，确保有创建项目权限 |
| 变更审批失败 | 审批按钮灰色不可用 | 检查审批流程设置，确保审批人权限正确 |
| 插件安装失败 | 安装过程中报错 | 检查网络连接，确保插件包完整 |
| API服务无响应 | API请求返回错误 | 检查API配置，确保服务正常运行 |
| 系统性能缓慢 | 操作响应时间长 | 清理缓存，优化数据库，增加系统资源 |

### 12.2 错误代码

| 错误代码 | 含义 | 解决方案 |
|----------|------|----------|
| 400 | 请求参数错误 | 检查请求参数格式和内容 |
| 401 | 未授权访问 | 检查API密钥或登录状态 |
| 403 | 权限不足 | 检查用户权限设置 |
| 404 | 资源不存在 | 检查请求的资源是否存在 |
| 500 | 服务器内部错误 | 检查系统日志，联系技术支持 |

### 12.3 日志查看

#### 系统日志
- **应用日志**: `logs/app.log` - 应用运行日志
- **错误日志**: `logs/error.log` - 错误信息日志
- **审计日志**: `logs/audit.log` - 操作审计日志
- **API日志**: `logs/api.log` - API访问日志

#### 日志级别
- **DEBUG**: 详细的调试信息
- **INFO**: 一般信息
- **WARNING**: 警告信息
- **ERROR**: 错误信息
- **CRITICAL**: 严重错误信息
