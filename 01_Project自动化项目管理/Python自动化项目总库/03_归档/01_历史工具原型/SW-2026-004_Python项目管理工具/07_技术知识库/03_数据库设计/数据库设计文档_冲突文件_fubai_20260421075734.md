## 1. 数据库概述

### 1.1 数据库类型
- **数据库引擎**：SQLite 3
- **数据库文件**：`data/project_manager.db`
- **字符集**：UTF-8

### 1.2 设计原则
- 遵循第三范式（3NF）
- 使用外键约束保证数据完整性
- 添加索引提高查询性能
- 使用时间戳记录数据变更

## 2. 数据表设计

### 2.1 项目表 (projects)

#### 表结构
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| project_id | VARCHAR(50) | PRIMARY KEY | 项目ID |
| business_line | VARCHAR(10) | NOT NULL | 业务线类型 |
| name | VARCHAR(100) | NOT NULL | 项目名称 |
| template_id | VARCHAR(50) | FOREIGN KEY | 模板ID |
| manager | VARCHAR(50) | NOT NULL | 项目经理 |
| description | TEXT | NULL | 项目描述 |
| status | VARCHAR(20) | DEFAULT 'ACTIVE' | 项目状态 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 更新时间 |

#### 索引
```sql
CREATE INDEX idx_projects_business_line ON projects(business_line);
CREATE INDEX idx_projects_status ON projects(status);
CREATE INDEX idx_projects_manager ON projects(manager);
```

#### 外键约束
```sql
ALTER TABLE projects ADD CONSTRAINT fk_projects_template 
FOREIGN KEY (template_id) REFERENCES templates(template_id);
```

### 2.2 变更表 (changes)

#### 表结构
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| change_id | VARCHAR(50) | PRIMARY KEY | 变更ID |
| project_id | VARCHAR(50) | FOREIGN KEY, NOT NULL | 项目ID |
| title | VARCHAR(200) | NOT NULL | 变更标题 |
| type | VARCHAR(20) | NOT NULL | 变更类型 |
| description | TEXT | NOT NULL | 变更描述 |
| reason | TEXT | NULL | 变更原因 |
| impact | TEXT | NULL | 影响分析 |
| proposer | VARCHAR(50) | NOT NULL | 提出人 |
| status | VARCHAR(20) | DEFAULT 'PENDING' | 变更状态 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 更新时间 |

#### 索引
```sql
CREATE INDEX idx_changes_project_id ON changes(project_id);
CREATE INDEX idx_changes_status ON changes(status);
CREATE INDEX idx_changes_type ON changes(type);
CREATE INDEX idx_changes_created_at ON changes(created_at);
```

#### 外键约束
```sql
ALTER TABLE changes ADD CONSTRAINT fk_changes_project 
FOREIGN KEY (project_id) REFERENCES projects(project_id);
```

#### 索引

### 2.4 插件表 (plugins)

### 2.5 模板表 (templates)

#### 表结构
| 字段名 | 类型 | 约束 | 说明 |

### 2.6 审批表 (approvals)

#### 表结构
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| approval_id | VARCHAR(50) | PRIMARY KEY | 审批ID |
| change_id | VARCHAR(50) | FOREIGN KEY, NOT NULL | 变更ID |
| approver | VARCHAR(50) | NOT NULL | 审批人 |
| decision | VARCHAR(20) | NOT NULL | 审批决定 |
| comment | TEXT | NULL | 审批意见 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 审批时间 |

#### 索引
```sql
CREATE INDEX idx_approvals_change_id ON approvals(change_id);
CREATE INDEX idx_approvals_approver ON approvals(approver);
```

#### 外键约束
```sql
ALTER TABLE approvals ADD CONSTRAINT fk_approvals_change 
FOREIGN KEY (change_id) REFERENCES changes(change_id);
```

### 2.7 项目库关联表 (library_projects)

#### 表结构
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键 |
| project_id | VARCHAR(50) | FOREIGN KEY, NOT NULL | 项目ID |
| library_id | VARCHAR(50) | FOREIGN KEY, NOT NULL | 库ID |

#### 索引
```sql
CREATE INDEX idx_library_projects_project_id ON library_projects(project_id);
CREATE INDEX idx_library_projects_library_id ON library_projects(library_id);
```

#### 外键约束
```sql
ALTER TABLE library_projects ADD CONSTRAINT fk_library_projects_project 
FOREIGN KEY (project_id) REFERENCES projects(project_id);

ALTER TABLE library_projects ADD CONSTRAINT fk_library_projects_library 
FOREIGN KEY (library_id) REFERENCES libraries(library_id);
```

### 3.2 关系说明

| 关系 | 类型 | 说明 |
|-----|------|------|
| Projects → Templates | N:1 | 一个项目使用一个模板 |
| Projects → Changes | 1:N | 一个项目有多个变更 |
| Changes → Approvals | 1:N | 一个变更有多个审批记录 |
| Projects → Libraries | N:N | 项目和库是多对多关系 |

## 6. 性能优化

### 6.1 索引策略

#### 主要索引
- 主键索引：所有表的主键
- 外键索引：所有外键字段
- 查询索引：常用查询字段

#### 索引维护
```sql
-- 重建索引
REINDEX;

-- 分析表
ANALYZE;
```

### 6.2 查询优化

#### 使用索引
```sql
-- 使用索引的查询
SELECT * FROM projects WHERE business_line = 'DJ';

-- 避免全表扫描
SELECT * FROM projects WHERE UPPER(name) LIKE '%TEST%';
```

#### 分页查询
```sql
-- 使用LIMIT和OFFSET
SELECT * FROM projects 
ORDER BY created_at DESC 
LIMIT 20 OFFSET 0;
```

### 6.3 连接池配置

```python
from sqlalchemy import create_engine
from sqlalchemy.pool import QueuePool

# 配置连接池
engine = create_engine(
    'sqlite:///data/project_manager.db',
    poolclass=QueuePool,
    pool_size=10,
    max_overflow=5,
    pool_timeout=30,
    pool_recycle=3600
)
```

## 7. 数据安全

### 7.1 数据备份

#### 自动备份
```python
import shutil
from datetime import datetime

def backup_database():
    backup_path = f"data/project_manager_backup_{datetime.now().strftime('%Y%m%d_%H%M%S')}.db"
    shutil.copy2('data/project_manager.db', backup_path)
    print(f"数据库备份成功: {backup_path}")
```

#### 定期备份
建议每天备份一次数据库，保留最近7天的备份。

### 7.2 数据加密

#### 敏感字段加密
```python
from cryptography.fernet import Fernet

def encrypt_data(data):
    key = Fernet.generate_key()
    fernet = Fernet(key)
    encrypted = fernet.encrypt(data.encode())
    return encrypted
```
