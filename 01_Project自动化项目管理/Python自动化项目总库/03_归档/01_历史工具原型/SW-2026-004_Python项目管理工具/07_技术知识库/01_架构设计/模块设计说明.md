### 2.2 依赖规则

#### 2.2.1 层级依赖
- 表现层 → 服务层
- 服务层 → DAO层
- DAO层 → 核心层

#### 2.2.2 同层依赖
- 服务层之间可以相互调用
- DAO层之间可以相互调用
- 工具层可以被所有层调用

#### 2.2.3 反向依赖禁止
- 下层不能依赖上层
- 核心层不能依赖服务层

## 3. 接口设计

### 3.1 服务层接口

#### 3.1.1 项目服务接口
```python
class IProjectService(ABC):
    """项目服务接口"""
    
    @abstractmethod
    def create_project(self, business_line, name, template_id, manager, description):
        """创建项目"""
        pass
    
    @abstractmethod
    def get_project(self, project_id):
        """获取项目"""
        pass
    
    @abstractmethod
    def update_project(self, project_id, **kwargs):
        """更新项目"""
        pass
    
    @abstractmethod
    def delete_project(self, project_id):
        """删除项目"""
        pass
```

#### 3.1.2 变更服务接口
```python
class IChangeService(ABC):
    """变更服务接口"""
    
    @abstractmethod
    def create_change(self, project_id, title, type, description, reason, impact, proposer):
        """创建变更"""
        pass
    
    @abstractmethod
    def approve_change(self, change_id, approver, comment):
        """审批变更"""
        pass
    
    @abstractmethod
    def execute_change(self, change_id):
        """执行变更"""
        pass
```

## 4. 数据模型

### 4.1 项目模型 (Project)
```python
class Project(Base):
    """项目模型"""
    __tablename__ = 'projects'
    
    project_id = Column(String(50), primary_key=True)
    business_line = Column(String(10), nullable=False)
    name = Column(String(100), nullable=False)
    template_id = Column(String(50), ForeignKey('templates.template_id'))
    manager = Column(String(50), nullable=False)
    description = Column(Text)
    status = Column(String(20), default='ACTIVE')
    created_at = Column(DateTime, default=datetime.now)
    updated_at = Column(DateTime, default=datetime.now, onupdate=datetime.now)
```

### 4.2 变更模型 (Change)
```python
class Change(Base):
    """变更模型"""
    __tablename__ = 'changes'
    
    change_id = Column(String(50), primary_key=True)
    project_id = Column(String(50), ForeignKey('projects.project_id'), nullable=False)
    title = Column(String(200), nullable=False)
    type = Column(String(20), nullable=False)
    description = Column(Text, nullable=False)
    reason = Column(Text)
    impact = Column(Text)
    proposer = Column(String(50), nullable=False)
    status = Column(String(20), default='PENDING')
    created_at = Column(DateTime, default=datetime.now)
    updated_at = Column(DateTime, default=datetime.now, onupdate=datetime.now)
```

## 5. 异常处理

### 5.1 异常分类

#### 5.1.1 业务异常
```python
class BusinessException(Exception):
    """业务异常基类"""
    pass

class ProjectNotFoundException(BusinessException):
    """项目不存在异常"""
    pass

class ChangeNotFoundException(BusinessException):
    """变更不存在异常"""
    pass
```

#### 5.1.2 数据异常
```python
class DataException(Exception):
    """数据异常基类"""
    pass

class DatabaseException(DataException):
    """数据库异常"""
    pass

class FileException(DataException):
    """文件异常"""
    pass
```

### 5.2 异常处理策略

#### 5.2.1 服务层异常处理
```python
try:
    result = ProjectService.create_project(**kwargs)
except BusinessException as e:
    logger.error(f"业务异常: {e}")
    return None, str(e)
except Exception as e:
    logger.exception(f"系统异常: {e}")
    return None, "系统错误"
```

#### 5.2.2 DAO层异常处理
```python
try:
    session.add(project)
    session.commit()
except SQLAlchemyError as e:
    session.rollback()
    logger.exception(f"数据库操作失败: {e}")
    raise DatabaseException(f"数据库操作失败: {e}")
```

## 6. 日志规范

### 6.1 日志级别

| 级别 | 说明 | 使用场景 |
|-----|------|---------|
| DEBUG | 调试信息 | 开发调试 |
| INFO | 一般信息 | 正常操作 |
| WARNING | 警告信息 | 潜在问题 |
| ERROR | 错误信息 | 错误发生 |
| CRITICAL | 严重错误 | 系统崩溃 |

### 6.2 日志格式

```python
# 日志格式
[时间] - [模块] - [级别] - [消息]

# 示例

2026-03-15 10:30:46 - src.dao.project_dao - ERROR - 数据库操作失败: ...
```
