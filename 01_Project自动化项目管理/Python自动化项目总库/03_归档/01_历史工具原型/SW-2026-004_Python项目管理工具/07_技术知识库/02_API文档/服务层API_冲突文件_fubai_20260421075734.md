## 1. 项目管理服务 (ProjectService)

### 1.1 创建项目

#### 接口描述
创建新项目并生成项目文件。

#### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| business_line | String | 是 | 业务线类型 (SW/DJ/ZD/XT/WX) |
| name | String | 是 | 项目名称 |
| template_id | String | 是 | 模板ID |
| manager | String | 是 | 项目经理 |
| description | String | 否 | 项目描述 |

#### 返回结果
```python
# 成功
(project: Project, error: None)

# 失败
(project: None, error: String)
```

#### 示例代码
```python
from src.services.project_service import ProjectService

project, error = ProjectService.create_project(
    business_line='DJ',
    name='电气控制项目',
    template_id='TEMPLATE-DJ-001',
    manager='张三',
    description='电气控制系统开发'
)

if project:
    print(f"项目创建成功: {project.project_id}")
else:
    print(f"项目创建失败: {error}")
```

### 1.5 列出项目

#### 接口描述
获取项目列表，支持分页和筛选。

#### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| business_line | String | 否 | 业务线类型 |
| status | String | 否 | 项目状态 |
| page | Integer | 否 | 页码（默认1） |
| size | Integer | 否 | 每页数量（默认20） |

#### 返回结果
```python
# 成功
(projects: List[Project], total: Integer, error: None)

# 失败
(projects: None, total: None, error: String)
```

#### 示例代码
```python
from src.services.project_service import ProjectService

projects, total, error = ProjectService.list_projects(
    business_line='DJ',
    status='ACTIVE',
    page=1,
    size=10
)

if projects:
    print(f"共 {total} 个项目")
    for project in projects:
        print(f"- {project.project_id}: {project.name}")
else:
    print(f"获取项目列表失败: {error}")
```

## 4. 模板管理服务 (TemplateService)

### 4.1 创建模板

#### 接口描述
创建新模板。

#### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| name | String | 是 | 模板名称 |
| version | String | 是 | 模板版本 |
| structure | List | 是 | 模板结构 |
| templates | List | 否 | 子模板 |

#### 返回结果
```python
# 成功
(template: Template, error: None)

# 失败
(template: None, error: String)
```

#### 示例代码
```python
from src.services.template_service import TemplateService

template_data = {
    'name': '电气项目模板',
    'version': '1.0.0',
    'structure': [
        {'path': '01_项目文档', 'required': True},
        {'path': '02_代码', 'required': True}
    ],
    'templates': []
}

template, error = TemplateService.create_template(template_data)

if template:
    print(f"模板创建成功: {template.template_id}")
else:
    print(f"模板创建失败: {error}")
```

## 5. 统计服务 (StatisticsService)

### 5.1 项目统计

#### 接口描述
获取项目统计数据。

#### 返回结果
```python
{
    'total': Integer,           # 项目总数
    'by_business_line': Dict,   # 按业务线统计
    'by_status': Dict,         # 按状态统计
    'recent': List[Project]     # 最近项目
}
```

#### 示例代码
```python
from src.services.statistics_service import StatisticsService

stats = StatisticsService.get_project_statistics()

print(f"项目总数: {stats['total']}")
print(f"按业务线统计: {stats['by_business_line']}")
print(f"按状态统计: {stats['by_status']}")
```

### 5.2 变更统计

#### 接口描述
获取变更统计数据。

#### 返回结果
```python
{
    'total': Integer,           # 变更总数
    'by_type': Dict,          # 按类型统计
    'by_status': Dict,        # 按状态统计
    'recent': List[Change]     # 最近变更
}
```

#### 示例代码
```python
from src.services.statistics_service import StatisticsService

stats = StatisticsService.get_change_statistics()

print(f"变更总数: {stats['total']}")
print(f"按类型统计: {stats['by_type']}")
print(f"按状态统计: {stats['by_status']}")
```

## 6. 错误码说明

| 错误码 | 说明 | 解决方案 |
|-------|------|---------|
| ERR-001 | 项目不存在 | 检查项目ID是否正确 |
| ERR-002 | 模板不存在 | 检查模板ID是否正确 |
| ERR-003 | 插件不存在 | 检查插件ID是否正确 |
| ERR-004 | 参数错误 | 检查请求参数是否完整 |
| ERR-005 | 数据库错误 | 检查数据库连接 |
| ERR-006 | 文件操作错误 | 检查文件路径和权限 |
| ERR-007 | 权限不足 | 检查用户权限 |
