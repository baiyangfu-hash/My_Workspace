## 3. 部署说明

### 3.1 系统要求
- **操作系统**: Windows 10/11
- **内存**: 4GB+ RAM
- **磁盘空间**: 1GB+ 可用空间
- **Python**: 无需安装（已打包）

### 3.2 部署步骤

#### 步骤1: 解压安装包
- 将交付物zip文件解压到目标目录
- 例如：`D:\Python项目管理工具\`

#### 步骤2: 配置环境
- 打开 `config` 目录下的配置文件
- 根据实际环境修改配置参数

#### 步骤3: 启动应用
- 双击 `Python项目管理工具.exe` 启动应用
- 或使用命令行：`Python项目管理工具.exe`

#### 步骤4: 验证部署
- 运行自动化测试：`py run_full_test_suite.py`
- 检查测试报告是否全部通过

### 3.3 启动参数

| 参数 | 说明 | 默认值 |
|-----|------|--------|
| `--mode` | 运行模式 (quick/ci/full) | full |
| `--notify` | 启用通知功能 | False |
| `--config` | 自定义配置文件路径 | config/app_config.json |
