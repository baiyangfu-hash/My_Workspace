## 设计理念

### 核心目标

本版本的核心设计理念是：**解压即用、零配置、不依赖盘符**

### 解决的问题

在之前的版本中，系统使用硬编码的绝对路径（如 `D:\Projects`），导致以下问题：

1. **跨机器兼容性差** - 不同计算机的盘符分配不同（D盘/C盘/U盘）
2. **部署复杂度高** - 需要手动修改配置文件中的路径
3. **可移植性受限** - 无法直接复制到其他位置使用
4. **团队协作困难** - 每个开发者都需要单独配置路径

### 解决方案

采用**相对路径方案**，将所有硬编码的绝对路径替换为相对于程序根目录的相对路径（`./Projects`），实现真正的"解压即用"体验。

### A2: 配置模块增强

**涉及文件**: `src/core/config.py`

**变更内容**:
1. 默认值改为 `./Projects`
2. 新增 `get_resolved_project_path()` 方法处理相对路径解析

**新增方法功能**:
- 自动将相对路径转换为绝对路径
- 基于当前程序运行位置动态解析
- 兼容开发环境和打包后的交付物环境
- 提供清晰的错误提示信息

**代码示例**:

```python
def get_resolved_project_path() -> Path:
    """
    获取解析后的项目路径（支持相对路径）
    
    Returns:
        Path: 解析后的绝对路径
        
    Raises:
        ValueError: 当路径无法解析时抛出异常
    """
    config = load_config()
    project_path_str = config.get('default_project_path', './Projects')
    
    # 如果已经是绝对路径，直接返回
    if os.path.isabs(project_path_str):
        return Path(project_path_str)
    
    # 相对路径：基于程序根目录解析
    base_dir = get_application_root()  # 获取程序根目录
    resolved_path = base_dir / project_path_str
    
    # 验证路径有效性
    if not resolved_path.exists():
        resolved_path.mkdir(parents=True, exist_ok=True)
        
    return resolved_path
```

### A4: 数据库路径清理

**涉及数据库**: libraries 表

**变更内容**: 清理 root_path 字段中的硬编码绝对路径记录

**处理数据量**: 1条记录

**操作详情**:
- 扫描数据库中所有包含硬编码绝对路径的记录
- 将 `D:\...` 格式的路径更新为相对路径或标记为需用户重新配置
- 提供数据迁移脚本确保历史数据兼容性

**SQL 示例**:

```sql
-- 查询需要更新的记录
SELECT id, name, root_path 
FROM libraries 
WHERE root_path LIKE 'D:\%' OR root_path LIKE 'C:\%';

-- 更新为相对路径（示例）
UPDATE libraries 
SET root_path = './Projects/' || name,
    updated_at = datetime('now')
WHERE root_path LIKE 'D:\%' OR root_path LIKE 'C:\%';
```

#### 技术细节

**路径解析机制**:
```
用户启动程序
    ↓
读取 app_config.json → default_project_path: "./Projects"
    ↓
调用 get_resolved_project_path()
    ↓
检测到相对路径（非以盘符开头）
    ↓
获取程序根目录（os.path.dirname(__file__) 或 sys._MEIPASS）
    ↓
拼接: 程序根目录 + "/Projects"
    ↓
返回绝对路径: "D:\Tools\项目管理工具\06_交付物\Projects"
    ↓
验证/创建目录
    ↓
返回可用的 Path 对象
```

**向后兼容性保障**:
- 如果检测到旧的绝对路径配置，仍会正常使用（兼容模式）
- 新安装默认使用相对路径
- 数据库中的旧路径记录会标记但不会阻止程序运行
- 提供迁移向导帮助用户转换数据

| **绝对路径** | 从根目录开始的完整路径（如 `D:\Projects`），包含完整位置信息 |
| **解压即用** | 无需安装或配置，解压后可直接运行的软件分发方式 |
| **交付物** | 可以直接分发给最终用户的可执行程序包 |
| **源码** | 程序的原始代码，可供开发者查看和修改 |
| **Gitkeep** | Git 版本控制系统中用于保持空目录存在的占位文件 |
