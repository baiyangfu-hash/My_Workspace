### 3.2 问题详情

#### BUG-003: 变更管理流程规范文件未生成（P1 - 中）

**现象**:
```
2026-04-16 15:43:14 - src.services.project_service - WARNING - 生成模板文件失败
00_项目管理/04_变更管理/03_变更管理规范/042_{project_code}_变更管理流程规范_PM-V2.0.0.md: '序号'
```

**原因分析**:
- 模板文件引用了 `{序号}` 占位符
- 项目创建时未提供该变量的值
- 模板引擎抛出 KeyError 导致文件跳过

**实际影响**:
- 可选文档缺失（非必需）
- 核心变更管理功能不受影响
- 用户可手动补充或后续修复后重新生成

**建议修复方案**:
1. 在 `ProjectService.create_project()` 方法中添加默认变量映射
2. 或在模板文件中使用条件渲染 `{序号|default('001')}`
3. 或将该文件标记为可选，失败时不阻塞主流程（当前已是此行为）

### 3.3 非问题项说明

以下为正常运行时出现的 **SAWarning**（SQLAlchemy ORM 警告），**不属于 bug**：

```
SAWarning: relationship 'Project.library' will copy column projects.project_id to column library_projects.project_id,
which conflicts with relationship(s): 'Library.project', 'Project.libraries'
```

**说明**: 这是 SQLAlchemy 的关系映射警告，提示存在外键重叠。不影响功能，但建议后续优化 ORM 模型定义以消除警告。
