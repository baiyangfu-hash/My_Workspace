## 经验教训
1. **规范持久化很重要**：单次 iteration 的产出必须及时提升为组织资产
2. **ID 一致性是常见 bug 源**：硬编码 ID vs 动态生成 ID 的匹配问题需要特别注意
3. **静默失败很危险**：warning 级别的日志可能掩盖严重的数据一致性问题
