## 3. 系统概述

Python项目管理工具是一个本地桌面应用程序，帮助PLC工程师和项目经理管理自动化项目。

**主要功能：**
- 项目管理：新建、导入、编辑、归档、删除项目
- 模板管理：创建和维护项目目录模板
- 变更管理：变更单的创建、审批、执行追踪
- 进度管理：项目里程碑和任务跟踪
- 插件系统：安装和管理功能扩展插件
- 规范管理：查看和同步开发规范
- 报告生成：生成项目各类统计和进度报告
- 总库管理：管理项目总库和分类

**运行环境：**
- 操作系统：Windows 10/11
- 为单用户本地使用设计，无需联网，无需登录

## 4. 安装说明

### 4.1 安装包安装（推荐）

1. 获取安装包 `Python项目管理工具.exe`
2. 双击运行安装包，按提示完成安装
3. 安装完成后，双击桌面快捷方式或安装目录中的 `Python项目管理工具.exe` 启动

### 4.2 源码安装（开发人员）

**环境要求：** Python 3.8+，内存 4GB 以上，硬盘 100MB 以上

**步骤：**

1. 获取项目源码
2. 进入源码目录，安装依赖：
   ```
   pip install -r requirements.txt
   ```
3. 启动程序：
   ```
   python main.py --mode gui
   ```

### 4.3 启动方式

| 方式 | 命令 |
|------|------|
| 启动GUI界面 | `python main.py --mode gui` |
| 启动API服务 | `python main.py --mode api` |
| 启动CLI模式 | `python main.py --mode cli` |
| 查看版本 | `python main.py version` |
| 查看功能 | `python main.py info` |

双击 `Python项目管理工具.exe` 直接进入GUI界面。

## 5. 主界面介绍

程序启动后直接进入主界面，**无需登录**。

### 5.1 界面布局

主窗口为 PyQt5 桌面窗口，最小尺寸 1200×800 像素，标题栏显示"Python项目管理工具 v2.6.0"。

界面分为三个区域：

**顶部-菜单栏：**

| 菜单 | 菜单项 | 快捷键 | 功能 |
|------|--------|--------|------|
| 文件 | 新建项目 | Ctrl+N | 打开新建项目对话框 |
| | 导入项目 | - | 导入已有项目到系统中 |
| | 设置 | Ctrl+, | 打开系统设置对话框 |
| | 退出 | Ctrl+Q | 退出程序 |
| 工具 | 规范检查 | F5 | 对当前选中项目执行规范检查 |
| | 生成报告 | - | 为选中项目生成报告 |
| 帮助 | 关于 | - | 显示版本和版权信息 |

**中部-标签页工作区：**

主工作区采用标签页（Tab）式布局，共9个页签，点击页签标题即可切换功能模块：

1. **项目管理** - 项目列表、新建、编辑、删除、模板变更
2. **模板管理** - 项目模板的增删改查
3. **插件管理** - 插件的安装、启用、禁用
4. **规范中心** - 查看和管理开发规范
5. **变更管理** - 变更单的全生命周期管理
6. **进度管理** - 里程碑和任务管理
7. **报告中心** - 生成各类报告
8. **插件配置** - 已安装插件的参数配置
9. **总库管理** - 总库的新建和分类管理

**底部-状态栏：** 显示"就绪"及操作提示信息。

### 5.2 设置对话框

通过菜单 **文件 → 设置（Ctrl+,）** 打开，包含以下设置页：

| 设置页 | 可配置项 |
|--------|----------|
| 常规设置 | 默认项目路径、自动保存开关、日志级别 |
| 模板设置 | 覆盖已存在模板的开关 |

修改后点击"保存"即可生效。

## 6. 各标签页操作详解

### 6.1 项目管理

**功能：** 查看和管理所有项目。

**界面组成：** 顶部搜索/筛选栏 + 项目列表表格

**操作说明：**

1. **查看项目列表**：切换到"项目管理"标签页，表格显示所有项目，列包括项目编号、名称、业务线、负责人、状态、创建时间。
2. **搜索项目**：在顶部搜索框输入项目名称或编号，列表自动筛选。
3. **按状态筛选**：通过"状态"下拉框筛选（全部/进行中/已完成/已归档等）。
4. **按业务线筛选**：通过"业务线"下拉框筛选。

5. **新建项目**（快捷键 Ctrl+N）：
   - 点击"新建项目"按钮或通过菜单 **文件 → 新建项目**
   - 在弹出的对话框中填写：业务线、项目名称、选择模板、负责人、项目路径
   - 项目编号由系统自动生成
   - 点击"确定"完成创建

6. **导入项目**：
   - 通过菜单 **文件 → 导入项目**
   - 选择业务线、输入项目名称、选择模板、指定项目路径
   - 系统将现有目录注册到管理系统中

7. **右键操作**（选中项目行后右键）：
   - **打开项目目录**：在资源管理器中打开项目文件夹
   - **编辑项目信息**：修改项目名称、负责人、状态、描述
   - **变更模板**：为项目更换目录结构模板（不会删除已有文件）
   - **规范检查**：对该项目执行规范检查
   - **生成报告**：为该生成项目报告
   - **归档项目**：将项目状态改为已归档
   - **删除项目**：可选择"仅删除数据库记录（保留文件）"或"删除数据库记录和本地文件"

8. **双击项目行**：快速打开项目文件夹。

### 6.2 模板管理

**功能：** 管理项目目录模板。模板定义了新建项目时自动创建的目录结构和文件。

**界面组成：** 顶部筛选/操作栏 + 模板列表表格

**操作说明：**

1. **查看模板列表**：表格显示模板ID、名称、版本、编译器、适用场景、业务线、是否内置、描述。
2. **搜索模板**：通过搜索框按名称筛选。
3. **筛选模板**：可按业务线、编译器、场景三个维度组合筛选。
4. **新建模板**：点击"新建模板"打开模板编辑器，定义目录结构和文件。新建模板ID自动生成为`TPL-CUSTOM-{日期}-{随机}`格式。
5. **导入模板**：从配置文件导入模板。
6. **编辑模板**：在表格中双击模板行，打开模板编辑器进行修改。
7. **右键菜单**支持复制、导出等操作。
8. **重置内置模板**：将内置模板恢复到初始状态。
9. **刷新**：重新加载模板列表。

**内置模板类型（V2.8.0 YAML外置）：** 单机设备(PLC+HMI)、自动化整线、单机设备(机器人)、系统升级、上位机项目。

**V2.8.0新增特性：**
- **模板数据外置**：内置模板数据从代码迁移到YAML文件，便于维护
- **模板继承**：自定义模板可继承内置模板，仅覆盖差异部分
- **模板版本管理**：模板包含schema_version字段，项目记录创建时应用的模板版本

### 6.3 插件管理

**功能：** 安装和管理功能扩展插件。

**界面组成：** 顶部搜索/筛选栏 + 插件列表表格

**表格列：** 插件ID、名称、版本、作者、状态、是否内置、操作

**操作说明：**

1. **安装插件**：点击"安装插件"按钮，选择插件包文件进行安装。
2. **启用/禁用插件**：通过右键菜单或表格中的操作按钮启用或禁用已安装的插件。
3. **卸载插件**：通过右键菜单卸载插件（内置插件不可卸载）。
4. **搜索筛选**：按插件名称搜索，或按状态（已启用/已禁用）筛选。
5. **刷新**：重新加载插件列表。

### 6.4 规范中心

**功能：** 查看项目开发规范，管理规范的版本同步。

**界面组成：** 左侧规范树 + 右侧详情面板（含规范详情和速查手册两个子标签）

**操作说明：**

1. **浏览规范**：左侧树形列表按分类展示所有规范，点击规范名称查看详情。
2. **搜索规范**：通过顶部搜索框快速定位规范。
3. **按分类筛选**：通过"全部分类"下拉框筛选规范类别。
4. **查看规范详情**：右侧"规范详情"标签页显示规范的完整内容。
5. **速查手册**：右侧"速查手册"标签页提供规范的快速参考。
6. **规范同步**：点击"规范同步"按钮，检查并更新规范到最新版本。

### 6.5 变更管理

**功能：** 管理项目变更的全生命周期（创建、审批、执行、完成）。

**界面组成：** 项目选择下拉框 + 变更统计栏 + 变更列表 + 底部操作按钮

**变更状态：** 草稿 → 待审批 → 已批准 → 实施中 → 已完成（另有已拒绝、已取消）

**操作说明：**

1. **选择项目**：通过顶部下拉框选择要查看的项目，变更列表自动刷新。
2. **创建变更单**：点击"新建变更"按钮，填写变更内容、变更类型（代码/配置/依赖/文档/结构/模板/插件）、影响范围等。
3. **编辑变更单**：选择草稿状态的变更单，点击"编辑"进行修改。
4. **提交审批**：将草稿状态的变更单提交为"待审批"状态。
5. **审批变更**：对待审批的变更单进行"批准"或"拒绝"操作。
6. **执行变更**：已批准的变更单可进入"实施中"状态，完成后标记为"已完成"。
7. **取消变更**：可取消草稿或待审批的变更单。
8. **查看详情**：双击变更单或在右键菜单选择"查看详情"，查看变更影响分析和审批历史。
9. **删除变更单**：删除草稿状态的变更单。
10. **变更统计**：顶部统计栏实时显示各状态的变更单数量。
11. **右键菜单**：在变更列表上右键可执行审批、编辑、删除、查看详情等操作。

### 6.6 进度管理

**功能：** 跟踪项目里程碑和任务完成情况。

**界面组成：** 项目选择下拉框 + 总体进度条 + 里程碑统计 + 里程碑/任务列表

**操作说明：**

1. **选择项目**：通过顶部下拉框选择要查看的项目。
2. **查看总体进度**：进度条显示项目总体完成百分比。
3. **查看里程碑**：左侧里程碑列表显示项目各阶段里程碑。
4. **管理里程碑**：可新建、编辑、删除里程碑。
5. **管理任务**：选中里程碑后可查看和操作其下的任务。
6. **更新任务状态**：任务支持"待开始""进行中""已完成""已延期"四种状态。
7. **设置任务优先级**：高/中/低三个级别。
8. **右键菜单**：在里程碑或任务上右键，可进行编辑、删除等操作。

### 6.7 报告中心

**功能：** 生成项目各类报告。

**界面组成：** 顶部操作栏 + 报告预览区 + 历史报告列表

**操作说明：**

1. **选择报告类型**：项目报告、统计报告、进度报告、变更报告。
2. **选择项目**：通过下拉框选择目标项目。
3. **选择输出格式**：Markdown、HTML、纯文本。
4. **生成报告**：点击"生成报告"，在预览区查看内容。
5. **导出报告**：点击"导出报告"，选择保存路径。
6. **查看历史**：右侧历史列表可查看之前生成的报告。

此外，还可通过菜单 **工具 → 生成报告** 为当前选中项目快速生成报告。

### 6.8 插件配置

**功能：** 配置已安装插件的参数。

**界面组成：** 左侧插件列表 + 右侧配置面板

**操作说明：**

1. **选择插件**：在左侧列表点击插件名称。
2. **查看插件信息**：右侧显示插件名称、版本、作者、状态、描述。
3. **修改配置**：在配置区域修改插件参数。
4. **保存配置**：点击"保存配置"按钮。
5. **安装/卸载插件**：通过底部按钮操作（与插件管理标签页联动）。
6. **重置配置**：将插件配置恢复为默认值。

### 6.9 总库管理

**功能：** 管理项目总库，将项目按业务线和用途归类。

**界面组成：** 顶部搜索/操作栏 + 左侧总库树 + 右侧详情面板

**操作说明：**

1. **查看总库列表**：左侧树形列表显示所有总库及其项目数量。
2. **搜索总库**：通过顶部搜索框查找指定总库。
3. **新建总库**：点击"新建总库"按钮，填写名称、描述、所属业务线。
4. **查看总库详情**：点击总库名称，右侧显示详细信息。
5. **管理分类**：在详情面板中管理该总库下的项目分类。
6. **刷新**：重新加载总库数据。

## 7. CLI 命令行使用

除GUI界面外，工具还提供命令行模式，适用于脚本和自动化场景。

### 7.1 基础命令

| 命令 | 说明 |
|------|------|
| `python main.py --mode gui` | 启动GUI界面（默认模式） |
| `python main.py --mode api` | 启动API服务（默认监听 127.0.0.1:5000） |
| `python main.py --mode cli` | 进入交互式CLI模式 |
| `python main.py version` | 显示版本号 |
| `python main.py info` | 显示工具信息和功能列表 |

### 7.2 CLI 子命令

进入CLI模式（`python main.py --mode cli`）后支持以下子命令：

| 命令 | 参数 | 说明 |
|------|------|------|
| `gui` | - | 启动GUI界面 |
| `api` | - | 启动API服务 |
| `version` | - | 显示版本 |
| `info` | - | 显示信息 |
| `create-project` | `--business-line` `--name` `--template-id` [`--path`] [`--manager`] | 创建新项目 |
| `check-project` | `<项目ID>` [`--type`] | 检查项目规范 |
| `check-spec` | [`--auto-sync`] | 检查规范更新，添加 `--auto-sync` 自动同步 |
| `sync-spec` | [`--spec-name`] [`--no-backup`] | 同步规范到最新版本 |
| `spec-info` | - | 显示规范信息清单 |

### 7.3 使用示例

```bash
# 查看版本
python main.py version

# 查看工具信息
python main.py info

# 检查规范更新
python main.py check-spec

# 自动同步规范
python main.py check-spec --auto-sync

# 同步所有规范
python main.py sync-spec

# 查看规范清单
python main.py spec-info

# 启动API服务
python main.py --mode api

# 进入CLI创建项目
python main.py --mode cli
> create-project --business-line plc_automation --name "输送机控制系统" --template-id TPL_SINGLE_PLC_HMI
```

### 7.4 API模式

启动API服务后，可通过HTTP接口访问项目管理功能，适用于第三方系统集成。默认地址：`http://127.0.0.1:5000`

## 8. 常见问题

### 8.1 程序无法启动

**现象**：双击exe或运行 `python main.py` 无反应或报错。

**解决**：
- 确认Python版本为3.8或以上
- 确认已安装所有依赖：`pip install -r requirements.txt`
- 检查防火墙是否阻止了程序运行

### 8.2 项目列表为空

**现象**：切换到项目管理标签页后看不到任何项目。

**解决**：
- 首次使用需要先创建项目或导入已有项目
- 检查搜索框和筛选条件是否过滤掉了所有项目

### 8.3 新建项目失败

**现象**：点击"新建项目"后提示失败。

**解决**：
- 确认至少有一个可用模板（检查"模板管理"标签页）
- 确认项目路径有写入权限
- 确认项目名称不与已有项目重复

### 8.4 插件安装失败

**现象**：安装插件时提示失败。

**解决**：
- 确认插件包文件完整、未被损坏
- 检查插件与当前工具版本的兼容性
- 查看日志文件获取详细错误信息

### 8.5 规范检查无结果

**现象**：执行规范检查后无反应。

**解决**：
- 确认已选中一个项目（先点击项目行，再按F5或右键选择规范检查）
- 检查项目目录是否存在

### 8.6 数据存储位置

项目的数据库文件存储在程序目录的 `data/` 文件夹中。如需迁移数据，将该文件夹复制到新环境对应位置即可。
