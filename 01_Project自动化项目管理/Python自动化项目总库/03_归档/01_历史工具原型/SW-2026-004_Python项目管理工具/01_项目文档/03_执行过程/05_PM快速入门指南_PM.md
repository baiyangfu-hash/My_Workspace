## 1. 启动工具

双击 `Python项目管理工具.exe`，或在项目根目录执行：

```bash
python main.py
```

> 工具默认以GUI模式启动。如需CLI：`python main.py --mode cli`

**预期结果**：弹出主窗口，左侧显示导航栏（项目管理、总库管理、模板管理、规范管理、变更管理、报告中心）。

---

## 2. 总库概览

点击左侧导航栏 **"总库管理"** Tab。

**预期结果**：页面展示所有业务线的项目总库，包含项目总数、活跃项目数、各业务线分布饼图。可展开每个总库查看其下的项目列表。

---

## 3. 创建/导入项目

**操作路径**：菜单栏 `文件 → 新建项目`

在弹出的对话框中：

1. **选择模板**：从下拉列表选择项目模板（如 `TPL-SINGLE-PLC-001` 单机PLC项目）
2. **填写名称**：输入项目名称（如 "某生产线PLC项目"）
3. **选择业务线**：从业务线下拉框选择（DJ / ZD / XT / WX）
4. **（可选）指定路径**：自定义项目存放路径，留空则使用默认路径
5. 点击 **"创建"**

**预期结果**：项目创建成功，弹出提示 "项目 DJ-2026-001 创建成功"，左侧项目列表自动刷新显示新项目。

> CLI方式：`python main.py create-project --business-line DJ --name "项目名" --template-id TPL-SINGLE-PLC-001`

---

## 4. 规范检查

**操作路径**：

1. 在项目管理列表中 **选中一个项目**
2. 点击菜单 `工具 → 规范检查`（或按快捷键 **F5**）

**预期结果**：

- 弹出检查进度条，完成后展示检查报告：
  - **通过**（绿色）— 符合规范的检查项
  - **警告**（黄色）— 建议改进项
  - **错误**（红色）— 必须修正项
- 报告底部显示通过率百分比
- 点击 **"导出报告"** 可将检查结果保存为 Markdown 文件

> CLI方式：`python main.py check-project <项目ID>`

---

## 5. 变更管理

**操作路径**：

1. 点击左侧导航 **"变更管理"** Tab
2. 点击 **"新建变更单"** 按钮
3. 填写变更信息：
   - 变更类型（新增/修改/删除）
   - 影响范围
   - 变更描述
4. 点击 **"提交"**

**预期结果**：

- 变更单进入 "待审批" 状态
- 在变更管理台账中可查看所有变更单的状态流转（待审批 → 已审批/已驳回 → 已执行）
- 审批人可通过 `审批` / `驳回` 按钮处理变更单

---

## 6. 统计报告

**操作路径**：点击左侧导航 **"报告中心"** → 点击 **"生成项目统计报告"**

**预期结果**：

- 生成全局项目统计报告，包含：
  - 项目总数及各状态分布
  - 各业务线项目数量
  - 变更统计（本月新增/已审批/已驳回）
  - 缺陷统计（按严重程度/状态分布）
- 报告自动保存至 `data/reports/` 目录，同时弹出预览窗口

## 附录：调试技巧

### 日志查看

日志文件位置：**工具目录下的 `logs/` 文件夹**

- `app.log` — 应用程序主日志
- `api.log` — API请求日志（如启用了API模式）

日志级别可通过 `config/app_config.json` 中的 `logging.level` 调整（DEBUG / INFO / WARNING / ERROR）。

### 数据库位置

数据库文件位置：**工具目录下的 `data/` 文件夹**

- 默认使用 SQLite，文件名为 `project_manager.db`
- 可通过 `config/database_config.json` 查看/修改数据库配置

### 常见问题

| 问题 | 解决方法 |
|------|----------|
| 启动白屏/闪退 | 检查 `logs/app.log` 查看错误堆栈；尝试 `python main.py --mode cli` 确认环境正常 |
| 无法创建项目 | 确认模板存在：`模板管理` Tab 中查看模板列表 |
| F5 规范检查无反应 | 确认已选中项目；检查 `logs/app.log` 是否有权限错误 |
| 变更单无法提交 | 确认必填字段均已填写 |
