## 4. 规范使用指南

### 4.1 人工用户使用流程

1. **确定项目阶段**：根据项目当前所处的阶段选择合适的模板
2. **选择模板类型**：根据需要的文档类型选择对应的模板
3. **查看模板内容**：点击上述链接查看模板详细内容
4. **使用模板**：根据模板结构填写具体内容
5. **质量检查**：使用 [026_AI输出质量检查清单](03_执行过程/01_代码开发/01_代码规范/026_AI输出质量检查清单_CHK.md) 进行质量检查

### 4.2 AI智能体使用指南

#### 4.2.1 快速启动指南（Trae专用）
1. **识别项目阶段**：根据用户需求确定当前项目所处的SOP阶段
2. **定位对应模板**：在 [AI智能体SOP对应关系](#43-ai智能体sop对应关系) 表中查找对应阶段的推荐模板
3. **访问模板文档**：使用文档中的相对路径直接访问模板文件
4. **遵循模板结构**：严格按照模板结构生成内容，确保文档标准化
5. **质量控制**：使用 [026_AI输出质量检查清单](03_执行过程/01_代码开发/01_代码规范/026_AI输出质量检查清单_CHK.md) 进行自我检查

#### 4.2.2 智能体操作提示
- **路径使用**：所有模板路径均为相对路径，可直接用于文件访问
- **版本管理**：遵循语义化版本规范，确保文档版本一致性
- **格式规范**：严格按照Markdown格式和模板结构生成内容
- **变更管理**：使用变更管理模板记录所有文档变更

## 5. 规范维护

### 5.1 维护责任
- **文档专家**：负责规范的日常维护和更新
- **技术负责人**：负责技术规范的审查
- **产品化项目经理**：负责规范的使用监督

### 5.2 维护流程
1. **反馈收集**：收集规范使用中的问题和建议
2. **定期审查**：每季度审查一次规范的有效性
3. **版本更新**：根据需要更新规范版本
4. **培训宣导**：向团队宣导规范的使用

### 5.3 规范更新机制
#### 5.3.1 触发条件
- **反馈累积**：收集到3个以上相关反馈
- **技术变化**：相关技术或工具发生重大变化
- **流程优化**：发现更有效的流程或方法
- **合规要求**：外部合规要求发生变化

#### 5.3.2 审批流程
1. **变更申请**：文档专家提出规范更新申请
2. **技术审查**：技术负责人审查更新内容
3. **管理审批**：项目负责人审批更新方案
4. **发布通知**：发布更新后的规范

#### 5.3.3 通知机制
- **邮件通知**：向所有相关人员发送更新通知
- **文档标注**：在规范文档中明确标注更新内容
- **培训宣导**：组织培训宣导更新内容
- **版本管理**：在版本变更记录中详细记录更新内容
