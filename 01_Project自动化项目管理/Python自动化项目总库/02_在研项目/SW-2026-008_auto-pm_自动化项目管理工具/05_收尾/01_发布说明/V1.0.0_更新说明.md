## 变更内容

### 主要功能

#### 1. 高颜值 Markdown 文档浏览器 (DocBrowserView)
- **结构化原生委托渲染**：摒弃包体积庞大的 WebEngine 依赖，自研 Python 侧 Markdown 结构解析器，配合 QML 原生 Card Delegate 实现高还原度、流畅的玻璃拟物渲染。
- **通用分类筛选系统**：提供 ComboBox 下拉筛选器，自动归纳项目管理、技术文档、规范标准与 PM 日志。
- **双向大纲跳转联动**：提取 H1/H2 级别标题，支持点击大纲快速跳转对应段落，以及滚动正文时大纲高亮自动随动。
- **零依赖本地 PDF 离线保存**：利用 Qt 打印支撑组件，支持直接生成排版优美的 PDF 文档。

#### 2. 点击命令行开发规范 (Click CLI)
- 全面覆盖 `auto-pm` 命令行工具链，打通与项目自愈对账（`ledger reconcile`）及规范检测工具。

## 安装与升级

### 升级步骤
1. 直接运行 `auto-pm.exe` 或通过 Python 环境执行 `pip install .`；
2. 执行 `auto-pm gui` 即可进入工作台体验三栏式 Markdown 浏览器。
