## 3. 文档分类约定

V3.0 起，文档按以下规则分类存放：

| 目录 | 内容类型 | 示例 |
|------|----------|------|
| `02_设计/` | 设计类文档（PRD/INT/DSN/TEC/计划/原型） | 产品需求、架构设计、接口契约 |
| `00_项目基础信息/` | 治理/质量/发布类文档 | 技术债、门禁、试运行 |
| 根目录 | PM_SESSION、CHANGELOG、README | 项目状态真源、变更日志 |

## 4. 废弃标记规范

