## 一、底层逻辑在哪？

在 008 中，界面和 Bridge 不负责真正的计算，真正的业务放在：

- **Modbus 通信计算**：`auto_pm/domain/modbus/modbus_service.py`
- **PLC 规则校验**：`auto_pm/domain/plc/checker.py`
- **项目扫描管理**：`auto_pm/application/core/project_service.py`

这符合工业软件的**分层原则**：逻辑与显示分离（界面换掉，核心计算不用重写）。

## 二、实战：修改 Modbus 32 位浮点数解码算法

打开 `auto_pm/domain/modbus/modbus_service.py`，找到 32 位浮点数解码函数 `_decode_float_cdab`：

```python
def _decode_float_cdab(high: int, low: int) -> str:
    """CDAB（西门子 Word Swap）32位浮点解码。"""
    import struct
    try:
        raw = (high << 16) | low
        swapped = ((raw & 0xFFFF) << 16) | ((raw >> 16) & 0xFFFF)
        result = struct.unpack(">f", swapped.to_bytes(4, "big"))[0]
        if math.isnan(result) or math.isinf(result):
            return "N/A"
        return f"{result:.3f}"  # 💡 试试改成保留 4 位小数: f"{result:.4f}"
    except Exception:
        return "N/A"
```

修改后保存，运行 `python main.py` 或 `auto-pm gui`，点击读取，即可观察到界面浮点解码精度变为了 4 位小数！
