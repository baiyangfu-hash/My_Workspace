## 一、底层逻辑在哪？

在 008 中，界面和 Bridge 不负责真正的计算，真正的业务放在：

- **Modbus 通信计算**：`auto_pm/modbus/modbus_service.py`
- **PLC 规则校验**：`auto_pm/plc/checker.py`
- **项目扫描管理**：`auto_pm/core/project_service.py`

这符合工业软件的**分层原则**：逻辑与显示分离（界面换掉，核心计算不用重写）。

## 二、实战：修改 Modbus 32 位浮点数解码算法

打开 `auto_pm/modbus/modbus_service.py`，找到 32位浮点数解码函数：

```python
def decode_float_32(self, reg1: int, reg2: int, endian: str = "CDAB") -> str:
    """将 2 个 16 位寄存器拼装为 32 位浮点数。"""
    try:
        if endian == "CDAB":
            raw_bytes = struct.pack(">HH", reg2, reg1)
        elif endian == "ABCD":
            raw_bytes = struct.pack(">HH", reg1, reg2)
        else:
            raw_bytes = struct.pack(">HH", reg1, reg2)
            
        val = struct.unpack(">f", raw_bytes)[0]
        return f"{val:.3f}"  # 💡 试试改成保留 4 位小数: f"{val:.4f}"
    except Exception:
        return "解码失败"
```

修改后保存，运行 `python main.py`，点击读取，即可观察到界面浮点解码精度变为了 4 位小数！
