## 一、改完代码后怎么验证有没有把系统改坏？

在 008 中，项目自带了 **1,570+** 项自动化测试用例。

当你修改完任何 Python 或 QML 代码后，在 PowerShell 中运行以下命令：

```powershell
# 运行全量测试套件
.\.venv\Scripts\python.exe -m pytest -v --no-cov
```

- 如果最后显示 **`PASSED`** 且没有红字 `FAILED`，说明你的改动完美兼容原系统，**可以放心使用！**
- 如果出现红字 `FAILED`，查看最后两行的错误信息，提示会精确告诉你是哪一行代码被破坏了。

## 二、遇到改错卡死时的“救命三招”

### 第一招：查看 QML 控制台输出

如果点击界面没有反应，在命令行启动应用：

```powershell
python main.py
```

观察命令行窗口中是否有 `QML WARNING` 或 `TypeError` 报错输出。

### 第二招：检查槽函数装饰器 `@Slot`

如果 QML 报 `TypeError: Property 'xxx' of object is not a function`，检查对应的 Python Bridge 函数上方有没有漏写 `@Slot()` 装饰器：

```python
@Slot(str)
def my_function(self, arg1: str) -> None:
    pass
```

### 第三招：使用 Git 回退代码

如果不小心改乱了文件，想恢复到上一个稳定版本：

```powershell
# 查看修改的文件
git status

# 丢弃某文件的所有未提交修改，恢复原样
git checkout -- auto_pm/ui/qml/views/ModbusDebuggerView.qml
```
