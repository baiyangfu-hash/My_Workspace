# 第 6 天：在 008 中新增一个独立工具子页面（完整接管演练）

> 目标：走通“创建 QML View ➔ 创建 Bridge ➔ 在 Sidebar 注册导航”全流程
> 时间：2.5 小时
> 前置：完成第 1-5 天基础

---

## 一、新增工具页的 3 个步骤

在 008 里加一个新的自定义工具页面（比如“PLC 变量辅助生成器”），只需要 3 步：

```
步骤 1：写 QML 界面视图     auto_pm/ui/qml/views/MyCustomView.qml
步骤 2：写 Python Bridge   auto_pm/domain/plc/my_custom_bridge.py (并在 qml_main_window.py 注入)
步骤 3：在 main.qml 挂载   在 StackLayout 增加视图，并通过 mainWindow.currentPage 切换
```

---

## 二、实战演练

### 步骤 1：创建 QML 视图 `MyCustomView.qml`

在 `auto_pm/ui/qml/views/` 建立 `MyCustomView.qml`：

```qml
import QtQuick
import QtQuick.Layouts
import QtQuick.Controls
import "../theme"
import "../components"

Item {
    id: root

    ColumnLayout {
        anchors.centerIn: parent
        spacing: 20

        Text {
            text: "🛠️ 我的自定义 PLC 辅助工具"
            color: Theme.textPrimary
            font.pixelSize: Theme.fontSizeLg
            font.bold: true
        }

        Button {
            text: "⚡ 触发自定义计算"
            onClicked: {
                if (typeof myBridge !== "undefined" && myBridge !== null) {
                    myBridge.doSomething()
                } else {
                    console.log("自定义按钮被点击")
                }
            }
        }
    }
}
```

### 步骤 2：在 `main.qml` 的 `StackLayout` 中挂载视图

打开 `auto_pm/ui/qml/main.qml`：

1. 找到 `property string currentPage: "projectList"`，支持你的新页面 key（如 `"myCustomTool"`）；
2. 找到 `StackLayout`（约第 805 行），在末尾追加你的视图：

```qml
            // 9. 我的自定义工具页
            MyCustomView {
                id: myCustomView
            }
```

3. 在 `StackLayout` 的 `currentIndex` 映射中增加分支：
```qml
if (mainWindow.currentPage === "myCustomTool") return 9
```

4. 在侧边栏导航按钮的点击事件中执行：
```qml
mainWindow.currentPage = "myCustomTool"
```

重新运行 `python main.py` 或 `auto-pm gui`，你就能打开并使用你亲手添加的新功能页！
