# 第 6 天：在 008 中新增一个独立工具子页面（完整接管演练）

> 目标：走通“创建 QML View ➔ 创建 Bridge ➔ 在 Sidebar 注册导航”全流程
> 时间：2.5 小时
> 前置：完成第 1-5 天基础

---

## 一、新增工具页的 3 个步骤

在 008 里加一个新的自定义工具页面（比如“PLC 变量辅助生成器”），只需要 3 步：

```
步骤 1：写 QML 界面      auto_pm/ui/qml/views/MyCustomView.qml
步骤 2：写 Python Bridge  auto_pm/ui/qml/bridges/my_custom_bridge.py
步骤 3：注册到侧边导航栏  auto_pm/ui/qml/main.qml 中的 sidebarModel
```

---

## 二、实战演练

### 步骤 1：创建 QML 视图 `MyCustomView.qml`

在 `auto_pm/ui/qml/views/` 建立 `MyCustomView.qml`：

```qml
import QtQuick
import QtQuick.Layouts
import QtQuick.Controls
import "../theme"

Rectangle {
    color: "transparent"

    ColumnLayout {
        anchors.centerIn: parent
        spacing: 20

        Text {
            text: "🛠️ 我的自定义 PLC 辅助工具"
            color: Theme.textPrimary
            font.pixelSize: Theme.fontSizeLg
            font.bold: true
        }

        Button {
            text: "⚡ 触发自定义计算"
            onClicked: {
                if (typeof myBridge !== "undefined") {
                    myBridge.doSomething()
                }
            }
        }
    }
}
```

### 步骤 2：在 `main.qml` 侧边栏中注册

打开 `auto_pm/ui/qml/main.qml`，找到 `sidebarModel`，追加一个元素：

```qml
ListElement {
    icon: "🛠️"
    title: "自定义工坊"
    viewPath: "views/MyCustomView.qml"
}
```

重新运行 `python main.py`，你就能在侧边栏看到并打开你亲手添加的新功能页！
