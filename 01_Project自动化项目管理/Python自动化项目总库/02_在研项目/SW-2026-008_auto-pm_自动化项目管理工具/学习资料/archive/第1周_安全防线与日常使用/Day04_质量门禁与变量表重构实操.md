## 🩺 一、SCL 代码质量门禁（LSP-905 硬约束）

现场 PLC 运行时最怕出现三种隐蔽死锁：
1. **使用了原生 `TON` 定时器且写在 `IF` 分支内** $\rightarrow$ 分支不满足时定时器不执行刷新，再次进入时死锁；
2. **`CASE` 状态机漏写 `ELSE`** $\rightarrow$ 遇到异常步号直接卡死在未知状态；
3. **定时器用了 `T#5s` 字面量** $\rightarrow$ 上位机 HMI 无法动态下发参数。

`auto-pm` 内置了 LSP-905 静态 Linter，在代码下发前即可一键扫描全部隐患：

```powershell
# 对 PLC 项目执行合规扫描
python -m auto_pm -w "c:\Users\fubai\Documents\My_Workspace" plc check DJ-2026-005
```

## 📑 二、万行变量点表重构高能编辑器

在电气工程中，修改点表往往是一场噩梦：
* 甲方突然要求：“把所有 `MW100~MW200` 偏移挪到 `MW500`”
* 软件工程师要求：“把全部 `INT` 改为 `DINT`”

在驾驶舱中：
1. 点击左侧导航栏 **“变量点表”**；
2. 支持导入汇川 AutoShop、三菱 GX Works3 和西门子博途导出点表；
3. 使用顶部工具栏：
   * **“批量改类型”**：一键将选中的数百个变量转为指定类型；
   * **“批量偏移地址”**：设定基准偏移量，所有物理地址自动顺延重排，绝不重叠。
