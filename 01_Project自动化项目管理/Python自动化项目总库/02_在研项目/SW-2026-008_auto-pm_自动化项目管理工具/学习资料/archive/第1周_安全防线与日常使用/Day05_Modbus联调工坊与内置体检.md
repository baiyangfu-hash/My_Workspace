## ⚡ 一、Modbus TCP 联调工坊：工位上的数字孪生

在没有真实设备和传感器时，如何验证上位机逻辑？

驾驶舱内置了 **Modbus 联调工坊**：
1. **全功能码支持**：覆盖 FC01~FC06、FC15、FC16、FC23 等；
2. **模拟波形发生器**：支持正弦波、方波、锯齿波、高斯噪声实时注入寄存器；
3. **10x10 并发探测网格**：一键扫描目标 PLC 的 100 个连续寄存器区间，快速摸清设备点表；
4. **多端大小端解码**：CDAB（西门子 Word Swap）、ABCD（标准大端）、BADC（字节翻转）一秒切换。

## 🩺 二、驾驶舱内置健康体检（一键排障）

当你觉得系统运行异常、或者怀疑环境被搞乱了，随时运行这两条命令：

```powershell
# 1. 全量环境与依赖健康诊断
python -m auto_pm doctor

# 2. 一键清扫游离日志与临时垃圾
python -m auto_pm clean
```

* `doctor` 会逐项检查 Python 版本、GUI 依赖、Git 状态和根目录纯净度；
* `clean` 会自动清理临时日志和缓存，保持系统清爽。
