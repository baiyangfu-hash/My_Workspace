## 一、008 的数据表是怎么工作的？

在工控 HMI 里，数据列表（如报警列表、配方表）通常绑定一个变量数组。

在 008 的 `ModbusDebuggerView.qml` 中，监视表由两部分组成：

```
QML 界面 ListView  <───────  ListModel { id: registerModel }  <─────── Python modbus_bridge.py
(负责把数据画出来)             (负责在内存里装数据)                      (负责从 PLC/设备读数据并填入)
```

---

## 二、实战 1：给监视表加一个“报警提示”新字段

打开 `auto_pm/ui/qml/views/ModbusDebuggerView.qml`，找到 `registerModel` 填充位置：

```javascript
// 在 onRegisterDataReceived 函数中，修改填充数据行：
registerModel.append({
    "address": item.address,
    "physical": item.physical,
    "tag": item.tag || "",
    "dec": item.dec,
    "hex": item.hex,
    "float_decoded": item.float_decoded || "",
    "is_alarm": item.dec > 1000  // 💡 新增字段：当数值大于 1000 时标记为报警
})
```

在 ListView 界面上加上报警颜色改变：

```qml
Text {
    text: model.dec !== undefined ? model.dec.toString() : ""
    color: model.is_alarm ? Theme.error : Theme.textPrimary  // 💡 大于 1000 变红！
    font.pixelSize: Theme.fontSizeXs
}
```

## 三、实战 2：调整表格列宽比重（保证网格对齐）

在 008 中，表头与数据行使用 `spacing: 8` 和 `Layout.preferredWidth` 来对齐：

```qml
// 修改物理地址列的宽度
Text {
    text: "物理地址"
    Layout.preferredWidth: 100  // 从 90 改为 100
    color: Theme.textSecondary
}
```

注意：**表头的 `preferredWidth` 必须与 delegate 里的 `preferredWidth` 保持一致**，否则表格列就会错位！

---

## 四、今日小结

1. **ListModel** 是 QML 的内存数据集，通过 `append` / `clear` 管理数据。
2. 界面上的 `model.xxx` 对应 ListModel 里的 key 属性。
3. 表格对齐的诀窍是：**表头与数据行的 `preferredWidth` 必须逐一对齐**。
