## 📋 一、电气工程师日常运维 5 步 CheckList

每次修改或维护驾驶舱前，按顺序检查打勾：

- [ ] **1. 状态检查**：开工前敲 `git status`，确认工作区纯净；
- [ ] **2. 分支隔离**：`git checkout -b feat/xxx`，绝不在主分支盲改；
- [ ] **3. 架构分层**：改画面找 QML，改计算找 Service，改纽带找 Bridge；
- [ ] **4. 门禁体检**：完工后执行 `python -m auto_pm doctor`，确认全绿；
- [ ] **5. 快照归档**：提交清晰说明的 `git commit -m "..."`。
