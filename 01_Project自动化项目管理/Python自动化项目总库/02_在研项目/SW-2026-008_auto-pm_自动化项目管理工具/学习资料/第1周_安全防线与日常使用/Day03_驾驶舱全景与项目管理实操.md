## 🖥️ 一、驾驶舱的三大入口

`auto-pm` 是你作为 PM 与电气总工的“日常中枢系统”，提供三种启动方式：

```
① 免配一键启动 (最常用)         ② 命令行快速调试             ③ 终端 CLI 全量指令
双击根目录 "双击启动驾驶舱.bat"   python main.py              python -m auto_pm <命令>
```

## 🏢 二、项目大厅与 PM 核心工作流

打开驾驶舱后，最核心的界面是 **“业务项目大厅 (ProjectListView)”**：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 🚀 Auto-PM 桌面驾驶舱                                                        │
├────────────┬────────────────────────────────────────────────────────────────┤
│ 📁 项目大厅 │ 📊 项目总览与阶段看板                                           │
│ 🩺 规范体检 │ ┌──────────────────┐  ┌──────────────────┐  ┌────────────────┐ │
│ 📑 变量点表 │ │ DJ-2026-005      │  │ SW-2026-008      │  │ SysLib 公共库  │ │
│ 📝 变更向导 │ │ 边框缓存机 [V9.1]│  │ auto-pm [V1.1.0] │  │ 共享 FB 库     │ │
│ ⚡ Modbus  │ │ 阶段: 开发中     │  │ 阶段: 维护中     │  │ 阶段: 量产     │ │
│            │ └──────────────────┘  └──────────────────┘  └────────────────┘ │
└────────────┴────────────────────────────────────────────────────────────────┘
```

### 1. 项目扫描原理
系统会自动遍历工作空间下的两个核心仓库：
* `0100_PLC自动化/`（PLC 工程，如 `DJ-2026-005`）
* `01_Project自动化项目管理/`（Python 上位机，如 `SW-2026-008`）

### 2. `PM_SESSION_<编号>.md` —— 项目的单一真源
每一个项目内部都有一个 `PM_SESSION` 文件，它记录了该项目的：
* **当前版本号与生命周期阶段**
* **需求清单 (REQ) 与 架构设计 (DSN)**
* **5 大阶段质量门禁通过状态**

## 🧪 三、5 分钟动手实战实验

我们通过 CLI 命令实际体验项目扫描与状态查询：

### 步骤 1：列出当前工作空间的所有在研项目
```powershell
python -m auto_pm -w "c:\Users\fubai\Documents\My_Workspace" project list
```
*预期输出*：输出规整的表格，清晰展示 DJ-2026-000、DJ-2026-005、SW-2026-008 等全部项目的版本、技术栈与阶段。

### 步骤 2：查看特定项目的详细台账
```powershell
python -m auto_pm -w "c:\Users\fubai\Documents\My_Workspace" project show DJ-2026-005
```

### 步骤 3：启动桌面 GUI 驾驶舱
```powershell
python main.py
```
*预期输出*：桌面弹出实底磨砂质感的工业深色驾驶舱，左侧导航栏点击流畅。

---

## 📝 今日打卡小结

1. 驾驶舱会自动汇聚 PLC 与上位机所有项目。
2. 项目的真源状态全部由其内部的 `PM_SESSION_<编号>.md` 驱动。
3. 可以在终端通过 `python -m auto_pm project list` 秒级查询全部项目状态。
