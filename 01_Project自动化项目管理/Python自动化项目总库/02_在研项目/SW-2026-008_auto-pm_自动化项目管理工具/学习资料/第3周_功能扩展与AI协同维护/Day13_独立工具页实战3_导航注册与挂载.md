> 🎯 **今日目标**：在驾驶舱左侧侧边栏（Sidebar）注册新图标，并在主页面 `StackLayout` 中完成视图挂载与跳转。
> ⏱️ **预计耗时**：50 分钟
> 🛠️ **前置准备**：完成 Day 12 学习。

---

## 🛠️ 一、主视图挂载与页面跳转（只需 2 步）

打开 `auto_pm/ui/qml/main.qml`：

### 步骤 1：在 `StackLayout` 中实例化你的视图
找到主窗口中的 `StackLayout` 区域，追加你的页面：

```qml
// 追加你的新页面
MyCustomToolView {
    id: myCustomToolView
}
```

### 步骤 2：在侧边栏导航添加按钮
在左侧导航栏的 `Sidebar` 列表中增加一个导航项：
```qml
NavigationButton {
    text: "🛠️ 自定义工具"
    iconName: "tool"
    isActive: mainWindow.currentPage === "myCustomTool"
    onClicked: {
        mainWindow.currentPage = "myCustomTool"
    }
}
```

重新运行 `python main.py`，点击左侧导航栏的“自定义工具”，即可秒级切入你自己亲手开发的新功能页！

---

## 📝 今日打卡小结

1. 页面切换通过 `mainWindow.currentPage` 属性控制。
2. `StackLayout` 负责存放全部子页面视图，根据当前状态显示对应页面。
