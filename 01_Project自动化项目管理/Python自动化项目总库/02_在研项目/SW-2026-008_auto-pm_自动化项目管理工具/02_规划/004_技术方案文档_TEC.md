# 技术方案文档 (TEC) - auto-pm 自动化项目管理工具

## 1. 技术栈选型

- **核心语言**：Python 3.10+
- **GUI 框架**：PyQt6 + QML (Qt Quick 2.15)
- **数据持久化**：SQLite 3 (WAL 模式) + JSON / YAML / Markdown
- **测试框架**：Pytest (116+ 单元与集成测试用例)
- **代码规范**：PEP 8, Type Hints, LSP-905, STD-820

## 2. 关键技术方案

### 2.1 QML 与 Python 异步通信机制 (QObject Bridges)
- 所有后端重载任务（如全库规范扫描、3000点变量表批量解析、Copier 模板渲染）均运行在 `QThreadPool` / `QThread` 独立工作线程中；
- 通过 Qt Signal/Slot 向 QML 前端抛出进度与结果事件，确保 GUI 界面永不卡顿（60 FPS 流畅度与按压弹性动效）。

### 2.2 AI 上下文契约设计 (V2 Schema)
- 前后端通过 `.auto-pm/ai_context.json` 传递富状态数据；
- 采用不可变 `request_id` 机制，保证 AI 在异步回复时能够精确匹配用户会话与工单。
