# 接口文档（INT）- auto-pm 架构重设计版

## 1. 设计原则

本项目新的接口设计原则只有一句话：

> **把 UI 当成 HMI，把业务系统当成 PLC 逻辑，二者通过稳定的命令、状态、事件接口连接。**

这意味着：

1. UI 不直接访问底层文件系统和仓储
2. UI 不直接拼接领域对象
3. UI 通过 DTO、Command、Event 与应用层交互
4. 未来若替换成 Web，只要接口不变，业务层可复用

## 3. 接口类型

## 3.1 状态接口

用于界面展示，特点是：

- 不改数据
- 尽量返回聚合后的 DTO
- 适合页面首次加载和刷新

典型示例：

- `get_dashboard_snapshot()`
- `list_project_cards()`
- `get_project_workspace(project_id)`
- `get_change_detail(change_id)`
- `get_spec_center_overview()`

## 3.2 命令接口

用于执行动作，特点是：

- 有输入
- 有返回结果
- 可能改变状态

典型示例：

- `create_change_request(command)`
- `transition_change(command)`
- `refresh_project_docs(project_id, dry_run)`
- `run_spec_check()`
- `rebuild_index()`

## 3.3 事件接口

用于通知 UI：

- 数据已更新
- 操作成功
- 操作失败
- 需要确认

典型示例：

- `projects_changed`
- `workspace_changed`
- `change_flow_updated`
- `spec_check_completed`
- `operation_failed`

## 7.4 ModbusBridge 接口定义 (公共调试工坊)

`ModbusBridge` 位于 `auto_pm/modbus/modbus_bridge.py`，向 QML 提供非阻塞的 Modbus TCP 主站交互接口。

### 7.4.1 Slots (QML -> Python)

- **`pingHost(ip: str)`**: 发起 ICMP Ping 探测，结果通过 `pingResultReceived` 信号异步回传。
- **`connectDevice(ip: str, port: int, slave_id: int, sim_mode: bool)`**: 建立连接或启动内置波形仿真发生器。
- **`disconnectDevice()`**: 断开连接并终止定时器。
- **`readRegisters(fc: str, start: int, count: int, endian: str, preset: str)`**: 读取指定寄存器，结果通过 `registerDataReceived` 异步回传。
- **`writeRegister(write_fc: str, addr: int, value_str: str)`**: 写入单个或多个寄存器/线圈。
- **`setPolling(enabled: bool, fc: str, start: int, count: int, endian: str, preset: str)`**: 启动/停止 1000ms 周期轮询。
- **`scanRegisters(start_offset: int, end_offset: int)`**: 启动多线程区间扫描，通过 `scanCellUpdated` 与 `scanFinished` 异步回传。
- **`setTrendRunning(running: bool)`**: 启动/停止趋势图 200ms 数据推送。
- **`exportConfig(path: str) -> bool`**: 导出网口配置为 JSON。
- **`importConfig(path: str) -> dict`**: 导入 JSON 网口配置并返回配置字典。
- **`isConnected() -> bool`**: 同步获取当前连接状态。

### 7.4.2 Signals (Python -> QML)

- **`pingResultReceived(success: bool, message: str)`**: Ping 结果回调。
- **`connectionStateChanged(connected: bool)`**: 连接状态变化事件。
- **`registerDataReceived(data: list[dict])`**: 寄存器读取数据包推送。
- **`consoleLogAppended(type: str, hex_str: str)`**: TX/RX 物理报文或 SYS 诊断日志推送。
- **`scanCellUpdated(offset: int, is_active: bool)`**: 扫描探测器单格扫描状态更新。
- **`scanFinished()`**: 区间扫描完成。
- **`trendDataUpdated(val1: int, val2: int)`**: 趋势图 200ms 定时模拟数据点推送。

## 8. 错误边界

接口层结果统一通过 `auto_pm/ui/contracts/result.py` 中的两个泛型数据类封装（实现状态：已实现）：

```text
QueryResult[T]       # 查询执行结果（供需要明确标识失败的查询使用）
- success: bool
- message: str
- payload: T | None            # 默认 None
- errors: list[str]            # 默认空列表（字符串列表，非 ErrorDTO）

CommandResult[T]     # 命令/操作执行结果
- success: bool
- message: str
- payload: T | None            # 默认 None
- errors: list[str]            # 默认空列表（字符串列表，非 ErrorDTO）
```

> 与 V3.0.0 草案差异：`errors` 字段实际为 `list[str]`，而非 `list[ErrorDTO]`；不存在独立的 `ErrorDTO` 类型。

接口层统一返回以下 4 类错误语义（通过 `success=False` + `message` + `errors` 表达）：

1. `validation_error`
2. `domain_error`
3. `integration_error`
4. `unexpected_error`

对 UI 的要求：

- 页面不能直接展示 traceback
- 页面必须展示可理解的中文错误信息
- 详细技术信息进入日志区或调试抽屉

## 9. 演进策略

## 9.2 第二阶段

2. 真实试用证明多端化有价值
3. 桌面端不再是唯一目标场景
