# auto-pm CLI 命令完整参考 (V1.0 - 2026-09-06)

> **生成基准**：release `1.2.4-6699a5b`（当前 active）；`auto-pm --help` 实测输出。
> 本文档补录 22 个命令组（README 历史仅列 7 个）。

## 全局选项

```bash
auto-pm -w <workspace>   # 指定工作空间根目录（或 AUTO_PM_WORKSPACE 环境变量）
auto-pm --version        # 显示版本
auto-pm -h, --help       # 显示帮助
```

`-w` 必须放在子命令之前。

## 1. project — 项目管理

```bash
auto-pm project list                                    # 列出所有项目
auto-pm project list --business-line SW                 # 按业务线筛选
auto-pm project list --stack plc                        # 按技术栈筛选
auto-pm project create --stack plc --id DJ-2026-010 --name <名称>
auto-pm project show DJ-2026-010 [--json]
auto-pm project edit DJ-2026-010 --phase 调试中
auto-pm project delete DJ-2026-010 --confirm
auto-pm project retrofit DJ-2026-010                    # 补全 .copier-answers.yml
auto-pm project import /path/to/project [--move] [--business-line SW]
auto-pm project archive DJ-2026-010                     # 归档项目（ARC 流水号）
auto-pm project restore DJ-2026-010                     # 逆向恢复归档项目
```

## 2. plc — PLC 项目管理（LSP-907）

```bash
auto-pm plc init DJ-2026-010 --name <名称>
auto-pm plc check DJ-2026-010 [--json] [--substance] [--fix] [--list]
auto-pm plc check --all                                 # 检查全部 PLC 项目（FAIL→Exit 1）
auto-pm plc repair DJ-2026-010 [--rename] [--dry-run]
auto-pm plc standardize DJ-2026-010 [--apply]
auto-pm plc ingest --src <源工程路径> --pid DJ-2026-010 [--stage-only]
```

## 4. change — 变更管理

```bash
auto-pm change list DJ-2026-010 [--status implementing] [--domain PLC] [--full]
auto-pm change show CHG-PLC-2026-001
auto-pm change create --pid DJ-2026-010 --domain PLC --nature REQ --scope PLC \
  --applicant fubai --background "背景" --necessity "必要性"
auto-pm change edit CHG-PLC-2026-001 --background "更新说明"
auto-pm change transition CHG-PLC-2026-001 --to submitted
auto-pm change transition CHG-PLC-2026-001 --to approved --approver fubai
auto-pm change transition CHG-PLC-2026-001 --to completed --approver fubai \
  --verification-conclusion "全量测试通过"
```

## 5. ledger — 版本变更台账对账


> **注意**：SW-2026-008 台账改名前，reconcile 必须从 release f950525 运行；SYS-2026-001 相反必须用 dev 源码。
