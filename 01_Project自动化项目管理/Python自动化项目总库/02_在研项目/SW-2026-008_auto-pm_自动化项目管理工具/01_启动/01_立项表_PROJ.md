## 2. 项目背景与动机

电气自动化工程师在日常工作中需要管理多个 PLC 项目，涉及项目结构、工程文档、变更闭环、调试记录、质量门禁和交付证据。现有工具链分散（specmgr、pm-mgr 等），缺乏统一入口。auto-pm 旨在吸收这些分散工具，提供统一的 CLI + GUI 工作台。

## 3. 项目目标

### 3.1 核心目标

- 统一管理 PLC 项目结构（创建、检查、修复、标准化）
- 工程文档全生命周期管理（PRD/INT/DSN/TEC + PM_SESSION）
- 变更闭环管理（CHG 变更单 + 状态机 + 台账对账）
- 质量门禁自动化（ruff/mypy/pytest + 规范检查）
- 交付物打包与发布

### 3.2 非目标

- 不做在线协作（纯本地工具）
- 不做 PLC 代码生成
- 不做 CI/CD 管理

## 4. 目标用户

- **主要用户**：自动化工程师（兼 PLC+Python 开发）
- **次要用户**：AI 技能（pm-workflow、plc-electrical-engineer、fullstack-engineer）

## 6. 项目结构

项目采用 5 大过程组目录结构（PROJ-016 V1.2.0）：

```
SW-2026-008_auto-pm_自动化项目管理工具/
├── 01_启动/          # 启动过程组
├── 02_规划/          # 规划过程组（PRD/INT/DSN/TEC）
├── 03_执行/          # 执行过程组（迭代计划）
├── 04_监控/          # 监控过程组（变更管理/整改项）
├── 05_收尾/          # 收尾过程组（发布说明/归档）
├── auto_pm/          # 源代码
├── tests/            # 测试代码
├── scripts/          # 辅助脚本
├── templates/        # 项目模板
└── PM_SESSION_SW-2026-008.md  # 项目入口真源
```

## 7. 技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 语言 | Python 3.11 | 团队熟练，生态丰富 |
| GUI | PySide6 + QML | 跨平台原生UI，与PLC HMI概念对齐 |
| CLI | Click + Rich | 命令行框架 + 终端美化 |

| 打包 | PyInstaller | 单文件 exe 分发 |
