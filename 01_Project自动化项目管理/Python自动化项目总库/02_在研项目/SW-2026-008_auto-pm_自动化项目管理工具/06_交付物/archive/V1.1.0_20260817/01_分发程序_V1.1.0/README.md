# auto-pm 分发运行程序包 (V1.1.0)

本目录为 `auto-pm` V1.1.0 的快速分发与运行环境。

## 文件构成

1. **`启动驾驶舱.bat`**：双击即可启动 Python/PySide6 驱动的深色工业级驾驶舱。
2. **`运行GUI测试.bat`**：双击即可一键执行 20 维全景 GUI 交互与弹窗深度矩阵测试，自动生成 20 张高清真机快照。

## 运行前提

- 系统要求：Windows 10 / 11 64位
- Python 环境：已安装 Python >= 3.11 及相关依赖（PySide6, rich, click, pydantic, pyyaml）
