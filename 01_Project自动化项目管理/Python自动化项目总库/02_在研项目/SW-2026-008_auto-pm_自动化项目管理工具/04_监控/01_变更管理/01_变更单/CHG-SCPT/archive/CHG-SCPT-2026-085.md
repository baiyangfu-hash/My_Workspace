| **质量(Quality)** | ☑低 | 提升台账数据完整性 + 闭环门禁严谨性 + DB 缓存一致性，P1 缺陷根源修复 | 全量回归 + ruff/mypy 0 errors 三轨门禁验证无回归 |
| **风险(Risk)** | ☑低 | DB schema ALTER TABLE 在旧 DB 上可能失败；闭环门禁强化导致既有 CHG 流转失败；scanner_version 读取失败 | ① init_schema 用 PRAGMA table_info 检查列存在性后 ALTER；② --allow-partial-verification 显式参数兜底；③ fallback 从 auto_pm.__init__.py 读取 __version__ |

**风险等级**（PMBOK风险评估）：☑低

**缓解措施**（风险应对策略）：
① 全量回归测试（非 GUI + GUI）+ ruff/mypy 0 errors 三轨门禁；② DB schema 升级用 PRAGMA table_info 检查列存在性，避免重复 ALTER 报错；③ `--allow-partial-verification` 显式参数兜底，CHG-085 本身走部分验证闭环（4-6 移至后续）；④ scanner_version 读取失败时 fallback 从 `auto_pm/__init__.py` 读取 `__version__` 常量；⑤ ProjectRecord.scanner_version 默认值 ""，旧 fixture 不传也兼容

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关
