### 5.3 变更详细说明

#### 5.3.1 TD-G01 P0 Bug 修复（实际方案）
- **位置**：`auto_pm/core/project_scanner.py:210-214`（a5e8b3cb commit）
- **根因（运行时验证确认）**：new_project_dialog.py:317-324 `if value:` 守卫导致未选字段被省略 → copier jinja 模板渲染为 null → `.copier-answers.yml` 写入 `equipment_type:` (YAML null) → `yaml.safe_load` 返回 Python None → `read_copier_answers` 无 `or ""` 保底返回 None → `ProjectInfo(equipment_type=None)` Pydantic 校验失败
- **修复**：在 `read_copier_answers` 的字段读取处加 `or ""` 保底，使 None → "" 空字符串，Pydantic 校验通过。**未修改** `new_project_dialog.py` 的 `if value:` 守卫（经诊断验证，移除守卫不能解决 `.copier-answers.yml` null 问题）
- **CHG 流程补充**：a5e8b3cb commit 原未走 CHG 流程且 commit message 存在乱码，本变更单追溯登记
- **验证**：诊断脚本验证 + gui_plc_full_test.py 端到端新建项目 0 bug

#### 5.3.2 V-01~V-03 概览 Tab 内容溢出修复（实际方案：测试误报修正）
- **位置**：`scripts/gui_plc_full_test.py` `_check_widget_bounds` 函数
- **根因（运行时诊断确认）**：V-01~V-03 是**测试脚本误报**。溢出控件完整路径为 `MainWindow > QSplitter > QStackedWidget > ProjectWorkspaceView > QTabWidget > qt_tabwidget_stackedwidget > OverviewTab > QScrollArea > qt_scrollarea_viewport > QWidget`。该 QWidget 是 QScrollArea 的内容 widget，其 minimumSizeHint=505x1246（内容设计上大于 viewport），由滚动条裁剪显示。`_check_widget_bounds` 未排除 QScrollArea 内部内容，误判为 out_of_bounds
- **修复**：在 `_check_widget_bounds` 增加 `_is_inside_scrollarea` 检查，跳过 QScrollArea viewport 内部的 widget（合法溢出由滚动条裁剪）
- **附带防御性修复**：`workspace_view.py` ProjectWorkspaceView 设置 `QSizePolicy(Expanding, Expanding)`（改善 QStackedWidget 中的填充行为，非根因修复）
- **验证**：三视口截图程序化几何检查 0 个 out_of_bounds

#### 5.3.3 V-04~V-12 变量表 Tab 零宽度修复（实际方案）
- **位置**：`auto_pm/ui/vartable/variable_table_editor.py:318-323`（`_build_ui` 方法）
- **根因（运行时诊断确认）**：QTableView 的 verticalHeader（行号列）和 cornerButton（左上角按钮）默认可见，但 horizontalHeader 的 Stretch 模式将其宽度压缩为 0，仍 visible 的 0 宽度控件触发 zero_size 检查
- **修复**：`self._table.verticalHeader().setVisible(False)` + `self._table.setCornerButtonEnabled(False)`。行号（line_number）是解析元数据不作为可编辑列展示
- **验证**：三视口截图程序化几何检查 0 个 zero_size
