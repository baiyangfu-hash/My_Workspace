## 4. 变更原因

**变更背景**：
CHG-133 闭环后发现 ModbusDebuggerView.qml 残留 5 类问题：(1) 5 个 id (ipField/portField/slaveField/connectBtn/simChk) 在两个 GlassPanel 中各定义一次（L233+L467 等），QML 引擎取最后一个导致第一个 GlassPanel 的 connectBtn.onClicked 引用第二个 GlassPanel 的 ipField，跨面板数据流混乱；第一个 GlassPanel connectBtn 调用 4 参数版 connectDevice，第二个 GlassPanel 调用 5 参数版（含 nicCombo.currentIp），行为不一致；(2) 两个 GlassPanel 都渲染连接参数面板，UI 出现重复面板；(3) 文件头注释 L6/L7 功能码列表过时（6 读+4 写 vs 实际 11 读+6 写）；(4) L9 '三标签子视图' + L34 _subTabIndex 注释（0=监测 1=趋势 2=扫描）与实际 TabBar 2 个标签不符；(5) L201 与 L420 重复注释行 '顶部连接与 Ping 诊断大面板'。

**变更必要性**：
重复 id 导致 JavaScript 引用指向错误对象（旧版 connectBtn 跨面板引用新版 ipField），数据流混乱且 UI 重复渲染；失真注释误导后续维护。修复后第一个 GlassPanel 成为纯 Ping 诊断面板，连接参数统一由第二个 GlassPanel（带 nicCombo 升级版）承担，所有重复 id 消除。

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关
