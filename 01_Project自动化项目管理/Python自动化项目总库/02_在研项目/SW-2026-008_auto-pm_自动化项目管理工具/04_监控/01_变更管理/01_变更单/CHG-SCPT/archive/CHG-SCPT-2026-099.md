## 4. 变更原因

**变更背景**:
CHG-098 M5 QML UI 落地期间系统性发现 79 处 QML view 文件中文编码损坏, 根因是中文字符被损坏成 ASCII ? (U+003F) 导致字符串未闭合, QML 解析失败. 深度扫描后确认实际损坏约 250 处, 分布在 7 个 view 文件中, 含 3 类损坏: 引号未闭合 81 处 + U+FFFD 字节级损坏 30 处 + 中文上下文 ? 损坏 112 处 + 非中文 ? 损坏 20 处 + 双逗号 8 处.

**变更必要性**:
QML view 文件编码损坏导致 GUI 无法正常加载, 电气工程师试用受阻. 需系统性修复所有损坏, 恢复 QML 语法正确性, 确保 GUI 可见模式冒烟测试通过.

**参考依据**:
- CHG-SCPT-2026-098 §5.2 既有 QML 编码损坏系统性发现登记
- Claude 诊断报告 09_整改项/Claude-result #9 根目录散落临时文件清理建议

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物, 就选哪个领域
- 如果同时涉及多个专业, 选**最主要**的那个作为主领域, 其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气, PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关
