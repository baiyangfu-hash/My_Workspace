# 变更单：CHG-SCPT-2026-163

## 1. 变更动因与背景 (Background & Motivation)

在已完成 P0 级生产 Bug 根治（CHG-SCPT-2026-162）的基础上，为了彻底消除严苛审计中识别的 **P1 级架构安全隐患** 与 **工控可审计性断层**，启动本轮 P1 专项深化实施：

1. **工控异常可审计性断层 (IEC 62443-2-1)**：
   - 现有 7 个 QML Bridge 文件中，存在 120+ 处异常直接返回 `{"success": False}` 而无日志记录；
   - 必须统一接入 `logger.warning(..., exc_info=True)`，确保工控现场丢帧、文件 IO 阻塞、桥接参数错误具备毫秒级现场可追溯性。
2. **PLC 项目检查器核心矩阵单测缺失 (`PlcChecker`)**：
   - `domain/plc/checker.py` 是控制项目结构合法性（LSP-907、.plc.json 依赖、PM_SESSION 行数阈值、文档结构实质化）的核心防线，需建立专门的矩阵单测集；
3. **Modbus QML 桥接与多网卡异步通信单测补齐 (`ModbusBridge`)**：
   - `domain/modbus/modbus_bridge.py` 承担 `QThreadPool` 异步 Ping、网格扫描、多网卡绑定的 QML 通信桥接，需补充完整的 PySide6 信号槽与多线程回归测试。

---

## 2. 实施方案与任务拆解 (Implementation Plan)

### 任务 1：全量 Bridge 层异常治理与审计规范化（已完成）
- 针对 7 大 Bridge 文件，建立统一的 `logger = logging.getLogger(__name__)` 规范；
- 改造全部 `@Slot` 异常捕获块，记录方法名、参数摘要与完整堆栈；
- 保障 QML 依然能稳定接收错误报文（不造成界面崩溃）。

### 任务 2：新建 `tests/plc/test_plc_checker_matrix.py` 单测集（已完成）
- 测试 `.plc.json` 存在性、必填字段（name/description/version）、非法 JSON 解析容错；
- 测试 `PM_SESSION` 文件名与项目 ID 匹配、行数阈值检查（>150 行警告）；
- 测试 PRD 目录兼容性（标准 02_规划/ 与历史遗留路径识别）；
- 测试 SCL 代码规则集成拦截。

### 任务 3：新建 `tests/modbus/test_modbus_bridge.py` 单测集（已完成）
- 测试 `getNetworkInterfaces()` 本地 IPv4 网卡枚举能力；
- 测试 `connectDevice()` 与 `disconnectDevice()` 状态流转与 `connectionStateChanged` 信号；
- 测试 `readRegisters()` 与 `writeRegister()` 报文日志触发；
- 测试 `exportConfig()` 与 `importConfig()` JSON 配置持久化流转。

### 任务 4：全量覆盖率测量与健康门禁验收（已完成）
- 执行带全量回归，出具真实的包级测试报告；
- 运行 `auto-pm doctor` 确保工作空间 100% 纯净。
