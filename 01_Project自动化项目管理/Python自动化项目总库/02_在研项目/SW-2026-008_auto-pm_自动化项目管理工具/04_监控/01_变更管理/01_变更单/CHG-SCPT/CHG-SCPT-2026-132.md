## 11. 版本详细变更说明

<a name="v100"></a>
### V1.0.0 版本详细变更
1. **[NEW]** `auto_pm/modbus/` 模块下新增服务逻辑：
   - `__init__.py`
   - `modbus_service.py`：实现 Modbus TCP 寄存器读取 (FC01/FC02/FC03/FC04/FC17/FC23) 和写入 (FC05/FC06/FC15/FC16)、物理地址转换、内置仿真波形信号发生器、并发扫描探测活跃寄存器区间，并支持 JSON 配置文件的导入与导出。
   - `modbus_bridge.py`：PySide6 Bridge 层，利用多线程 `QThreadPool` 与 `QRunnable` 异步处理网络联调与扫描逻辑，防止 UI 界面卡死。
2. **[NEW]** `auto_pm/ui/qml/` 下新增 Modbus 原生 QML 视图及组件：
   - `components/ModbusBitExpander.qml`：显示寄存器 16 位位状态展开的卡片。
   - `components/ModbusScannerGrid.qml`：网格化显示寄存器活跃/非活跃扫描结果。
   - `components/ModbusTrendCanvas.qml`：实时渲染正弦/余弦或真实模拟信号的趋势波形监测图。
   - `views/ModbusDebuggerView.qml`：主界面包含连接面板、监测表、写入面板、扫描面板与实时波形趋势监测大盘。
3. **[MODIFY]** `main.qml` 导航集成：
   - 在侧边栏新增 "⚡ Modbus 联调工坊" 轨道。
   - 在 StackLayout 中将 `ModbusDebuggerView` 挂载在第 9 页 (currentIndex 8)。
4. **[MODIFY]** `qml_main_window.py` 挂载：
   - 实例化 `ModbusBridge` 并注入到 QML 上下文属性 `"modbusBridge"` 中。
5. **[NEW]** `tests/modbus/` 目录新增完整的单元测试 `test_modbus_service.py` 覆盖 25 个测试用例。
6. **[NEW]** `02_设计/Html原型预览/` 新增 V11-V13 架构原型 HTML。

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关
