## 4. 变更原因

**变更背景**：
V0.8.0 已完成 QML 完整覆盖 + CLI 默认入口翻转 + A 类激进清理（CHG-090/091/092 三连闭环），QML UI 已成为默认入口（200/200 QML 测试通过），旧 QWidget GUI 已被标记为 deprecated（`--qwidget` 标志）。

但 tests/ui/（22 文件）和 tests/gui/（21 文件）仍测试旧 QWidget GUI，总计 433 个旧 QWidget 测试。这些测试：
1. 依赖已被标记 deprecated 的 `auto_pm.ui.main_window.MainWindow`
2. 测试的 QWidget 页面（ReportPage/SettingsPage/SpecCenterView/TemplatePage）已在 V0.8.0 删除（main_window.py 用 try/except 占位回退）
3. QML 等价覆盖已通过 tests/qml/ 200 测试验证

**变更必要性**：
1. 删除旧 QWidget 测试可消除 59 个 DeprecationWarning 噪音
2. 降低维护成本：避免维护双份测试（QWidget + QML）
3. 为 CHG-094（删除 main_window.py + 旧 QWidget 模块）扫清障碍

**约束**：
- tests/qml/ 200 测试已等价覆盖 tests/ui/ + tests/gui/ 的功能场景
- tests/conftest.py（qapp fixture）保留不动
- 后端测试（tests/{change,cli,core,db,models,plc,utils,logging,config}/）保留不动
