## 4. 变更原因

**变更背景**：
V0.3.0 M0 基座清理：技术债偿还（批次1-5 + mypy清理）。消除测试债（TD-T01~T04）、代码质量债（TD-C01）、类型标注债（TD-TA01/TA02），恢复测试套件全绿（1019 passed）、ruff 0 errors、mypy 0 errors、元测试 0 violations。

**变更必要性**：
M0 验收标准要求 1019 测试全部通过 + ruff 0 errors + mypy <50 errors + 元测试 0 violations。本次偿还后实际达成 mypy 0 errors，超额完成。dogfooding 验证 auto-pm 自身变更单流程可用性。

**参考依据**：
