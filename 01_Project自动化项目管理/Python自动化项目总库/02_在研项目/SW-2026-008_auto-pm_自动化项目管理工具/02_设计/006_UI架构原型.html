数据流示意

1. QML / HTML 画面
  • 只关心展示和交互
  • 不直接碰 Service
2. Bridge
  • WorkBench / Change / Spec
  • 接收页面命令
3. Facade
  • 聚合业务动作
  • 输出 DTO / Result
4. 现有 Service
  • Project / Change / Spec
  • 复用既有核心逻辑
5. 数据层
  • SQLite
  • 文件系统
  • PM_SESSION / CHG
