## 3. 设计概述

### 3.1 设计目标

- **统一入口**: 一个 CLI/GUI 工具管理 PLC/Python 多技术栈项目，全量吸收 5 个源工具
- **PySide6 原生桌面**: 弃用 pywebview，采用 PySide6 QMainWindow + 侧边栏 + StackedWidget + 项目工作区 Tab 容器
- **项目中心式导航**: 首页项目列表 ↔ 项目工作区 ↔ 全局功能页 三态切换
- **多角色适配**: 4 类角色（PM/PLC/Python/SpecEditor）通过角色-Tab 映射机制按需激活工作区
- **数据真源**: 三源并存（.copier-answers.yml / PM_SESSION / index.db），互不冲突
- **增量扫描**: 基于 file_mtime 判据，避免全量扫描开销
- **可扩展性**: Click 子命令组 + 技术栈插件 + PySide6 视图插件，新增技术栈只需新增 cli/<stack>/ 与 ui/ 对应子模块（V2.0.1 核对：实际 UI 层为 8 个子模块，非 views/<stack>/ 结构）

### 3.2 设计原则

1. **单一职责**: 每个 Service 类只负责一个领域（项目/模板/变更/检查/修复/同步）；每个 QWidget 只负责一个视图
2. **依赖注入**: Service 通过构造函数注入 workspace_root 和可选的 DatabaseManager；View 通过构造函数注入 Service
3. **延迟导入**: 避免循环依赖（如 ChangeService 延迟导入 Generator/LedgerUpdater；UI 延迟导入 Service）
4. **信号槽解耦**: PySide6 视图通过 Signal/Slot 与 Service 通信，View 不直接持有其他 View 引用
5. **破坏性操作显式确认**: delete/repair --rename 需 --confirm/--rename 标志；GUI 弹窗二次确认
6. **路径安全**: path_resolver 防止目录遍历攻击
7. **不复用资产**: 严格遵循 PRD §7「不复用资产清单」，死代码/空壳/未实现/不安全实现严禁复用

### 4.3 数据流（V2.0 PySide6 信号槽）

```

  │
  ▼
PySide6 Widget (View)
  │
  ├── emit Signal (clicked/changed/filterApplied)
  │
  ▼
Slot 处理函数 (View 内部)
  │
  ├── 调用 Service 层方法
  │     │
  │     ▼
  │   Service (ProjectService/ChangeService/...)
  │     │
  │     ├── 文件系统读写 (.copier-answers.yml / PM_SESSION / CHG-*.md)
  │     ├── DB 缓存读写 (SQLite)
  │     └── Copier 模板调度
  │     │
  │     ▼
  │   返回 Model 对象 (Project/ChangeRequest/CheckResult/...)
  │
  ▼
Slot 接收返回值
  │
  ├── 更新 QAbstractListModel / QAbstractTableModel
  │
  ▼
View 刷新显示 (QTableView/QListView/QWidget)
  │
  ▼
用户看到结果
```

### 5.1 主窗口架构（QMainWindow）

**文件**: `auto_pm/ui/main_window.py`

```python
from PySide6.QtWidgets import QMainWindow, QWidget, QHBoxLayout, QStackedWidget
from PySide6.QtCore import Qt

class MainWindow(QMainWindow):
    """auto-pm 主窗口（项目中心式导航）"""

    def __init__(self, workspace_root: str) -> None:
        super().__init__()
        self.workspace_root = workspace_root
        self.current_role: Role = Role.PM  # 默认项目经理
        self._setup_ui()
        self._connect_signals()

    def _setup_ui(self) -> None:
        self.setWindowTitle("auto-pm - 自动化项目管理工具")
        self.resize(1400, 900)

        # 中央容器：侧边栏 + StackedWidget
        central = QWidget()
        layout = QHBoxLayout(central)
        layout.setContentsMargins(0, 0, 0, 0)

        # 侧边栏（导航）
        self.sidebar = Sidebar()
        # 角色切换器（顶部）
        self.role_switcher = RoleSwitcher()

        # StackedWidget 承载三种页面
        self.stacked = QStackedWidget()
        self.project_list_page = ProjectListPage(self.workspace_root)
        self.project_workspace = ProjectWorkspace(self.workspace_root)
        self.global_page = GlobalPage(self.workspace_root)
        self.stacked.addWidget(self.project_list_page)    # index 0
        self.stacked.addWidget(self.project_workspace)    # index 1
        self.stacked.addWidget(self.global_page)          # index 2

        layout.addWidget(self.sidebar)
        layout.addWidget(self.stacked, 1)
        self.setCentralWidget(central)

    def _connect_signals(self) -> None:
        self.sidebar.home_clicked.connect(self.show_project_list)
        self.sidebar.global_clicked.connect(self.show_global_page)
        self.project_list_page.project_selected.connect(self.open_project)
        self.project_workspace.back_clicked.connect(self.show_project_list)
        self.role_switcher.role_changed.connect(self.on_role_changed)

    def show_project_list(self) -> None:
        self.stacked.setCurrentIndex(0)

    def open_project(self, project_id: str) -> None:
        self.project_workspace.load_project(project_id, self.current_role)
        self.stacked.setCurrentIndex(1)

    def show_global_page(self, page_name: str = "spec_center") -> None:
        self.global_page.show_page(page_name)
        self.stacked.setCurrentIndex(2)

    def on_role_changed(self, role: Role) -> None:
        self.current_role = role
        self.project_workspace.apply_role(role)
```

### 5.3 项目工作区 Tab 容器（V2.0.1 核对修正）

**文件**: `auto_pm/ui/workspace/workspace_view.py` + 4 Tab 文件

> **V2.0.1 核对修正**: V2.0.0 原设计为 `ui/views/project_workspace.py` 单文件 + `views/tabs/` 子目录，实际为 `workspace/workspace_view.py` + 4 Tab 文件直接放在 `workspace/` 目录下。V2.0.0 原设计的 `var_table_tab.py`（变量表 Tab）**实际未实现**。

```python
from PySide6.QtWidgets import QWidget, QVBoxLayout, QTabWidget, QLabel

class ProjectWorkspace(QWidget):
    """项目工作区：Tab 导航容器"""

    def __init__(self, workspace_root: str) -> None:
        super().__init__()
        self.workspace_root = workspace_root
        self.current_project_id: str | None = None
        self.current_role: Role = Role.PM
        self._setup_ui()

    def _setup_ui(self) -> None:
        layout = QVBoxLayout(self)
        # 项目标题栏
        self.title_label = QLabel()
        layout.addWidget(self.title_label)

        # Tab 容器（实际 4 个 Tab，无变量表 Tab）
        self.tab_widget = QTabWidget()
        self.overview_tab = OverviewTab()
        self.change_tab = ChangeTab()
        self.doc_tab = DocTab()
        self.check_tab = CheckTab()
        self.tab_widget.addTab(self.overview_tab, "概览")
        self.tab_widget.addTab(self.change_tab, "变更")
        self.tab_widget.addTab(self.doc_tab, "文档")
        self.tab_widget.addTab(self.check_tab, "检查")
        layout.addWidget(self.tab_widget)

    def load_project(self, project_id: str, role: Role) -> None:
        self.current_project_id = project_id
        self.title_label.setText(f"项目: {project_id}")
        self.apply_role(role)
        self.overview_tab.load(project_id)
        self.change_tab.load(project_id)

    def apply_role(self, role: Role) -> None:
        """按角色-Tab 映射表激活/隐藏 Tab"""
        self.current_role = role
        active_tabs = ROLE_TAB_MAP[role]
        for i, tab_name in enumerate(["overview", "change", "doc", "check"]):
            tab_widget = [self.overview_tab, self.change_tab,
                          self.doc_tab, self.check_tab][i]
            self.tab_widget.setTabVisible(i, tab_name in active_tabs)
```

#### 6.5.1 PlcService - PLC 统一服务入口

**文件**: `auto_pm/plc/service.py`

**职责**: 封装 PlcChecker/PlcRepairer/SubstanceChecker，提供统一的 PLC 项目检查/修复/标准化入口。CLI/UI 层通过本服务操作 PLC 项目，遵循分层架构（P0 架构合规修复 C-2/C-3）。

**设计动机**:
- **C-2 修复**: CLI 层直接访问 PlcChecker/PlcRepairer 违反分层架构，统一通过 PlcService 入口
- **C-3 修复**: `project retrofit` 命令直接调用 PlcRepairer，改为通过 PlcService.repair()
- 消除 CLI 层与底层检查器/修复器的直接耦合，便于后续扩展（如新增检查器无需修改 CLI）

**类设计**:

```python
class PlcService:
    """PLC 项目服务 - 封装 PlcChecker/PlcRepairer/SubstanceChecker"""

    def __init__(self, workspace_root: str) -> None:
        self.workspace_root = os.path.abspath(workspace_root)
        self._checker = PlcChecker(self.workspace_root)
        self._repairer = PlcRepairer(self.workspace_root)
        self._substance_checker = SubstanceChecker(self.workspace_root)

    def check(self, project_path: str, fix: bool = False) -> CheckResult: ...
    def repair(self, project_path: str, dry_run: bool = False, rename_confirm: bool = False) -> RepairResult: ...
    def standardize(self, project_path: str, dry_run: bool = False) -> StandardizeResult: ...
    def check_substance(self, project_path: str) -> CheckResult: ...
    def check_workspace(self) -> list[CheckResult]: ...
```

**方法委托关系**:

| PlcService 方法 | 委托对象 | 委托方法 |
|----------------|---------|---------|
| `check(project_path, fix=False)` | PlcChecker + PlcRepairer | `check_project()`；`fix=True` 时额外调用 `repair_project()` 后重新检查 |
| `repair(project_path, dry_run, rename_confirm)` | PlcRepairer | `repair_project()` |
| `standardize(project_path, dry_run)` | PlcRepairer | `standardize_docs(apply=not dry_run)` |
| `check_substance(project_path)` | SubstanceChecker | `check_project()` |
| `check_workspace()` | PlcChecker | `check_workspace()` |

**调用方**:
- `auto_pm/cli/plc/__init__.py`（plc check/repair/standardize 命令）
- `auto_pm/cli/project.py::cmd_retrofit`（retrofit 命令对 PLC 项目补全标志文件）
- UI 层 CheckTab（V2.0.1 已通过 PlcChecker，V2.0.2 后改用 PlcService）

#### 6.5.2 SubstanceChecker - 文档实质化检查器

**文件**: `auto_pm/plc/substance_checker.py`

**职责**: 检查 PRD/DSN/INT/TEC 文档是否为"占位文档"（仅有标题无实质内容），识别字数不足、章节缺失、占位符密度过高的问题。

**修复说明**（P1 SubstanceChecker 修复，C-4/H-6/H-7）:

| 问题编号 | 修复内容 | 修复前 | 修复后 |
|---------|---------|--------|--------|
| C-4 | 字数统计语义 | 中英文混合统计，阈值不合理 | 中文按字符数 ≥ 800，英文按词数 ≥ 1000，任一达标即 PASS |
| H-6 | 章节正则 | `^##\s*` 误匹配 `###` 三级标题 | `^##(?!\s*#)\s*`（负向前瞻，排除 ### 及以上） |
| H-7 | 占位符密度检查 | 仅计数无严重程度分级 | 密度 > 70% → FAIL；30% < 密度 ≤ 70% → WARN；≤ 30% → PASS |

**检查项**:

| 检查项 | 阈值 | 失败状态 | 说明 |
|--------|------|---------|------|
| 文档存在 | - | FAIL | PRD/DSN/INT/TEC 文件不存在 |
| 字数（中文） | ≥ 800 字符 | WARN | `re.findall(r"[\u4e00-\u9fff]", content)` |
| 字数（英文） | ≥ 1000 词 | WARN | `re.findall(r"[a-zA-Z]+", content)` |
| 章节数 | ≥ 3 | WARN | `^##(?!\s*#)\s*` 匹配 ## 标题（排除 ### 及以上） |
| 占位符密度 | ≤ 30% | >70% FAIL，30-70% WARN | 占位符出现次数 / 非空行数 |

**占位符关键词**: `TODO`、`TBD`、`待补充`、`待填写`、`XXX`、`xxx`、`占位`、`placeholder` 等。

def on_role_changed(self, role: Role) -> None:
    """角色切换处理"""
    self.current_role = role
    self.project_workspace.apply_role(role)
    self.global_page.apply_role(role)

# ui/views/project_workspace.py
def apply_role(self, role: Role) -> None:
    """按角色-Tab 映射激活/隐藏 Tab"""
    self.current_role = role
    active_tabs = ROLE_TAB_MAP[role]
    tab_widgets = [
        ("overview", self.overview_tab),
        ("change", self.change_tab),
        ("var_table", self.var_table_tab),
        ("doc", self.doc_tab),
        ("check", self.check_tab),
    ]
    for i, (tab_name, tab_widget) in enumerate(tab_widgets):
        self.tab_widget.setTabVisible(i, tab_name in active_tabs)
    # 若当前激活的 Tab 被隐藏，切换到第一个可见 Tab
    if not self.tab_widget.isTabVisible(self.tab_widget.currentIndex()):
        for i in range(self.tab_widget.count()):
            if self.tab_widget.isTabVisible(i):
                self.tab_widget.setCurrentIndex(i)
                break

# ui/views/global_page.py
def apply_role(self, role: Role) -> None:
    """按角色-全局功能页映射激活/隐藏侧边栏全局功能项"""
    active_globals = ROLE_GLOBAL_MAP[role]
    for page_name, action in self.sidebar_actions.items():
        action.setVisible(page_name in active_globals)

## 13. 路径安全设计（保留 V1.0.0）

### 13.1 path_resolver 设计

**文件**: `auto_pm/change/path_resolver.py`

**功能**: 解析变更单文件路径，防止目录遍历攻击

**安全校验规则**:

1. **路径必须在 workspace_root 下**:
   ```python
   def resolve_change_path(workspace_root: str, project_id: str, change_number: str) -> Path:
       workspace = Path(workspace_root).resolve()
       target = (workspace / "00_项目管理" / "04_变更管理" / "01_变更单" / f"{change_number}.md").resolve()
       if not str(target).startswith(str(workspace)):
           raise ValueError("路径越界: 不允许访问工作空间外的文件")
       return target
   ```

2. **项目编号格式校验**:
   - 必须匹配 `^[A-Z]{2,4}-\d{4}-\d{3}$`
   - 防止 `../` 注入

3. **变更单编号格式校验**:
   - 必须匹配 `^CHG-[A-Z]{2,4}-\d{4}-\d{3}$`
   - 防止 `../` 注入

4. **文件名安全**:
   - 禁止包含 `..`、`/`、`\` 等路径分隔符
   - 禁止以 `.` 开头（隐藏文件）

### 13.2 攻击防护

| 攻击类型 | 防护措施 |
|---------|---------|
| 目录遍历 | Path.resolve() + startswith 校验 |
| 路径注入 | 正则校验 project_id/change_number 格式 |
| 符号链接攻击 | Path.resolve() 解析符号链接 |
| 文件名注入 | 禁止路径分隔符 |
