## 0. 文档说明

### 0.1 目标读者

- 开发者（执行自动化测试、补齐测试用例）
- 使用者（按计划执行侧自动测试，验证功能可用性）

### 0.2 计划原则

1. **全覆盖**：覆盖 README 和 PRD 声明的所有功能命令与 GUI 交互
2. **分层测试**：单元测试 → 集成测试 → 端到端测试 → 侧自动测试
3. **双视角**：开发者视角（pytest 自动化）+ 使用者视角（CLI/GUI 侧自动验证）
4. **可执行**：每个测试项明确前置条件、步骤、预期结果
5. **可回归**：所有测试用例可重复执行，支持 CI 流水线

### 0.3 测试套件建议

> 用户问及"是否需要测试套件"——**需要**，建议如下：

| 套件类别 | 推荐工具 | 用途 | 当前状态 |
|---------|---------|------|---------|
| 单元测试 | pytest + pytest-cov | Service/Repository/Model 层 | ✅ 已有部分 |
| CLI 测试 | click.testing.CliRunner | CLI 命令行测试 | ✅ 已有部分 |
| GUI 单元测试 | pytest-qt | PySide6 组件实例化与信号 | ⚠️ 仅冒烟 |
| GUI 交互测试 | pytest-qt + QTest | 模拟点击/输入/键盘 | ❌ 缺失 |
| 端到端测试 | pytest + tmp_path | 完整工作流 | ❌ 缺失 |
| 性能测试 | pytest-benchmark | 大型工作空间扫描 | ❌ 缺失 |
| 侧自动测试 | PowerShell 脚本 + 截图对比 | 真实环境验证 | ❌ 缺失 |
| 覆盖率 | pytest-cov + coverage.py | 覆盖率统计 | ✅ 已配置 |

**建议新增依赖**（写入 pyproject.toml dev 组）：
- `pytest-qt>=4.4.0` — PySide6 GUI 测试
- `pytest-benchmark>=4.0.0` — 性能基准测试（可选）

## 2. 测试分层架构

```
┌─────────────────────────────────────────────────────┐
│ L4 侧自动测试（使用者视角，真实环境）              │
│   - PowerShell 脚本驱动 CLI 命令                    │
│   - GUI 启动 + 截图对比 + 手动验证清单              │
├─────────────────────────────────────────────────────┤
│ L3 端到端测试（pytest + tmp_path）                  │
│   - 完整工作流：创建→扫描→列表→编辑→删除           │
│   - 三源数据一致性：.copier-answers.yml/PM_SESSION/DB│

├─────────────────────────────────────────────────────┤
│ L2 集成测试（pytest + 真实文件系统）                │
│   - CLI 命令全量测试（CliRunner）                   │
│   - GUI 交互测试（pytest-qt + QTest）               │
│   - Service 层跨模块调用                            │
├─────────────────────────────────────────────────────┤
│ L1 单元测试（pytest + mock）                        │
│   - Service/Repository/Model 隔离测试               │
│   - GUI 组件实例化与信号测试                        │
│   - 纯函数/工具方法测试                             │
└─────────────────────────────────────────────────────┘
```

### 10.1 测试依赖

| 依赖 | 用途 | 当前状态 |
|------|------|---------|
| pytest | 测试框架 | ✅ 已安装 |

### 10.2 测试风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| PySide6 GUI 测试在 CI 不稳定 | GUI 测试失败 | 使用 QT_QPA_PLATFORM=offscreen |
| Copier 模板调用慢 | E2E 测试慢 | 使用 tmp_path 隔离 + 缓存 |
| 文件系统扫描深度影响测试 | 测试用例不稳定 | 固定 scan_depth 参数 |
| DB 锁冲突 | 并发测试失败 | 使用独立 tmp_path |
| 中文路径编码问题 | Windows 下失败 | 统一使用 utf-8 编码 |
