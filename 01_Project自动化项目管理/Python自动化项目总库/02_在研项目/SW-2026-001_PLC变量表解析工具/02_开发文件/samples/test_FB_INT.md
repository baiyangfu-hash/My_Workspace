# FB_Test 接口文档

## 1. 概述

测试用功能块接口文档

## 2. 变量定义

### 2.1 VAR_INPUT

| 名称 | 数据类型 | 默认值 | 有效值域 | 说明 |
|------|----------|--------|----------|------|
| bEnable | BOOL | FALSE | TRUE/FALSE | 使能信号 |
| nMode | INT | 0 | 0-3 | 运行模式 |

### 2.2 VAR_OUTPUT

| 名称 | 数据类型 | 默认值 | 有效值域 | 说明 |
|------|----------|--------|----------|------|
| bDone | BOOL | FALSE | TRUE/FALSE | 完成标志 |
| nStatus | INT | 0 | 0-99 | 状态码 |

### 2.3 VAR

| 名称 | 数据类型 | 默认值 | 有效值域 | 说明 |
|------|----------|--------|----------|------|
| nCounter | INT | 0 | 0-65535 | 内部计数器 |

## 3. 结构体定义

**ST_Cmd 字段定义**

| 字段 | 数据类型 | 默认值 | 有效值域 | 说明 |
|------|----------|--------|----------|------|
| bExecute | BOOL | FALSE | TRUE/FALSE | 执行触发 |
| nCmdId | INT | 0 | 0-1000 | 命令ID |
