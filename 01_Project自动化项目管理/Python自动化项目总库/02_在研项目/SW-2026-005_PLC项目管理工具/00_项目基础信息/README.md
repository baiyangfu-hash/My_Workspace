## 1. 目录定位

本目录负责回答两类问题：
- 为什么要做 `SW-2026-005`
- 当前产品目标、约束和验收背景是什么

当前产品定位已更新为：
- Trae 负责 PLC 主开发
- SW-2026-005 负责工作空间治理、项目树、共享库识别、规范检查与汇总
- **V4.x架构**: PyWebView(Chromium)前端 + IPCBridge后端桥接，PyQt5为回退路径
