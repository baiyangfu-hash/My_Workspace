# PLC项目管理工具 (SW-2026-005)

## 项目概述

### 产品定位

PLC项目管理工具是一款**面向IEC 61131-3标准的桌面集成化管理工具**，为PLC自动化项目提供从创建到交付的全生命周期管理能力。

### 核心价值

| 痛点 | 解决方案 |
|------|----------|
| 项目结构不统一 | M001/S001标准模板一键生成 |
| SCL代码规范性差 | 六维自动检查 + 实时反馈 |
| 文档编写耗时 | 10种标准模板自动填充 |
| 项目健康度不可见 | 七维度深度诊断评分 |
| HMI变量管理混乱 | 映射表可视化编辑 |

## 功能概览

本工具包含 **10个核心功能模块**：

### 1. 仪表盘 (Dashboard)
- 项目统计卡片（FB数/变量数/文档数/测试数）
- 健康度环形图（综合评分 0-100）
- 最近项目快速访问列表
- 一键快捷操作按钮组

### 2. 项目管理
- 新建项目向导（支持M001完整版/S001精简版模板）
- 打开/关闭已有项目
- 项目属性配置（业务线、负责人、描述等）

### 3. ST代码编辑器 (ST Editor)
- IEC 61131-3 ST/SCL语法高亮显示
- 代码片段库（IF/FOR/CASE/MOVE/TON/FB等常用模式）
- 基于QScintilla的富文本编辑体验

### 4. HMI变量映射 (HMI Mapper)
- PLC变量到HMI标签的映射关系管理
- 可视化表格编辑界面
- 支持Excel导入导出

### 5. 规范检查面板 (Spec Check Panel)
- **六维度自动检查**：
  - 命名规范检查
  - 语法规范检查
  - 注释规范检查
  - 配置合规性检查
  - 定时器使用检查
  - 变量定义检查
- 实时反馈与修复建议

### 6. 诊断面板 (Diagnostic Panel)
- **七维度深度诊断**：
  - 结构完整性（15%权重）
  - 命名规范率（15%权重）
  - 文档覆盖率（15%权重）
  - 代码质量分（20%权重）
  - 配置合规性（10%权重）
  - LSP兼容性（15%权重）
  - 测试覆盖度（10%权重）
- Siemens LSP兼容性专项检查
- 问题分级与修复建议

### 7. 测试运行器 (Test Runner)
- SCLTest测试脚本解析与执行
- 测试用例管理（创建/编辑/删除）
- 测试结果可视化展示（PASS/FAIL/ERROR）
- 测试报告生成

### 8. 文档生成 (Document Generator)
- **10种标准文档模板**：
  - 需求规格说明书 (REQ)
  - 架构设计文档 (ARCH)
  - 详细设计文档 (DES)
  - 接口说明文档 (IFC)
  - IO分配表 (IO)
  - 变量清单 (VAR)
  - 用户操作手册 (UM)
  - 报警定义 (ALM)
  - 变更记录 (CHG)
  - 验收报告 (ARC)
- 自动填充项目数据
- Markdown格式输出

### 9. 变量检查器 (Variable Checker)
- PLC变量命名规范性校验
- 变量地址冲突检测
- 数据类型一致性验证
- 批量分析与报告生成

### 10. 路径解析器 (Path Resolver)
- 策略模式实现路径转换
- 相对路径存储（保证可移植性）
- 绝对路径读取（供UI层使用）
- 支持跨平台路径处理

| **编程语言** | Python | 3.9+ |
| **GUI框架** | PyQt5 | 5.15+ |

| **数据处理** | openpyxl / json | 最新稳定版 |
| **UI风格** | Material Design | 自定义QSS主题 |

### 架构特点

```
分层架构: 表现层(UI) → 业务层(Services) → 核心层(Core) → 数据层(Models) → 基础设施层(Parsers/Checkers/Diagnostics/Utils)

设计模式:
├── EventBus事件驱动机制（模块间松耦合通信）
├── PathResolver策略模式（路径可移植处理）
└── RuleRegistry注册表模式（检查器扩展管理）
```

## 快速开始

### 环境准备

```bash
# 1. 克隆或下载项目
cd SW-2026-005_PLC项目管理工具/03_主程序/01_主程序核心代码

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动应用
python main.py
```

### 系统要求

- **操作系统**: Windows 10/11 (64位)
- **Python**: 3.9 或更高版本
- **内存**: 建议 4GB 以上
- **磁盘空间**: 约 200MB（含依赖包）
