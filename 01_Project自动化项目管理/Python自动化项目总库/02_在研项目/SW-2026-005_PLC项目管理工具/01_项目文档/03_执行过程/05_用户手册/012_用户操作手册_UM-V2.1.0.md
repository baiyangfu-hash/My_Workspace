## 1. 产品概述

PLC项目管理工具是一款面向 IEC 61131-3 标准的桌面工具，提供从项目创建到检查、诊断与文档交付的基本闭环。

核心能力：
- 项目结构模板化（M001/S001）
- 规范检查（命名/语法/注释/配置/定时器/变量）
- 健康度诊断（多维评分 + 问题列表）
- 文档生成（标准模板）
- 变更管理Sync: 版本检查/CHG/IFC文档自动生成
- 主题切换: 浅色/深色主题一键切换

## 2. 快速开始

### 2.1 安装依赖

在 `03_主程序/01_主程序核心代码/` 下执行：

```powershell
python -m pip install -r requirements.txt
```

可选增强（不装也能用，STEditor 会回退并提示）：

```powershell
python -m pip install QScintilla
```

### 2.2 启动应用

```powershell
cd "03_主程序/01_主程序核心代码"
python main.py
```

## 3. 常用工作流

### 3.1 新建项目（推荐从模板开始）

- 入口：菜单"文件→新建项目"或工具栏"新建"
- 选择模板：M001（中大型）/S001（小型）
- 完成后：左侧项目树自动加载项目结构

### 3.2 打开项目

- 入口：菜单"文件→打开项目"或"最近项目"
- 打开后：状态栏显示项目名称/路径，项目树刷新

### 3.3 运行规范检查

- 入口：规范检查面板（Dock）
- 操作：选择规则集→执行→查看结果列表

### 3.4 变更管理（版本检查/CHG/IFC）

- 入口：左侧侧边栏"规范中心"→"🔄 版本检查"/"📝 生成CHG文档"/"📄 生成IFC文档"
- 版本检查：自动扫描项目文件版本号，生成差距矩阵
- 生成CHG：从.scl changelog和PM_SESSION提取变更记录，生成CHG变更文档
- 生成IFC：从GlobalVars.db解析接口变量，生成IFC接口文档
- 结果：生成的文档保存在项目目录下

### 3.5 深度诊断

- 入口：左侧侧边栏"规范中心"→"🔬 深度诊断 (F6)" 或 菜单"工具→深度诊断"
- 功能：七维度健康度评估(命名/语法/注释/配置/定时器/变量/LSP兼容性)
- 结果：底部诊断面板显示评分、问题列表、修复建议
- 仪表盘：圆环图显示综合健康度得分，柱状图显示四维评分

### 3.6 主题切换

- 入口：左侧侧边栏"系统设置"→"🎨 主题切换" 或 菜单"视图→主题"
- 支持浅色(light)和深色(dark)两种主题
- 切换即时生效，无需重启

### 3.7 规范检查Dock面板

- 入口：菜单"视图→底部面板→规范检查面板"
- 独立Dock面板，可拖拽、显示/隐藏
- 与Tab中的规范检查面板功能相同，独立运行

## 4. 已知限制（V2.0-R2）

| 限制 | 说明 | 计划 |
|------|------|------|
| HMI变量映射 | 显示"开发中"占位符，不可操作 | V2.1+ |
| IO分配表 | 显示"开发中"占位符，不可操作 | V2.1+ |
| 测试运行器 | Dock面板不创建 | V2.1+ |
| ST编辑器增强 | 基础语法高亮可用，代码片段/高级高亮暂不可用 | V2.1+ |
| 变更管理工作流 | CHG/IFC可生成，但缺审核→回写闭环 | V2.1+ |

## 5. 常见问题

| 现象 | 处理建议 |
|---|---|
| STEditor 提示"功能受限/回退模式" | 安装 QScintilla 后重启 |
| `No module named pytest` | `python -m pip install pytest` 或重装 requirements |
| `No module named PyQt5` | `python -m pip install PyQt5` 或重装 requirements |
