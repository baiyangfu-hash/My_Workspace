## 1. 产品概述

PLC项目管理工具是一款面向 IEC 61131-3 标准的桌面工具，提供从项目创建到检查、诊断与文档交付的基本闭环。

核心能力：
- 项目结构模板化（M001/S001）
- 规范检查（命名/语法/注释/配置/定时器/变量）
- 健康度诊断（多维评分 + 问题列表）
- 文档生成（标准模板）
- 可选 ST 编辑增强（安装 QScintilla 后获得语法高亮等能力）

## 2. 快速开始

### 2.1 安装依赖

在 `03_主程序/01_主程序核心代码/` 下执行：

```powershell
python -m pip install -r requirements.txt
```

可选增强（不装也能用，STEditor 会回退并提示）：

```powershell
python -m pip install QScintilla
```

### 2.2 启动应用

```powershell
cd "03_主程序/01_主程序核心代码"
python main.py
```

## 3. 常用工作流

### 3.1 新建项目（推荐从模板开始）

- 入口：菜单“文件→新建项目”或工具栏“新建”
- 选择模板：M001（中大型）/S001（小型）
- 完成后：左侧项目树自动加载项目结构

### 3.2 打开项目

- 入口：菜单“文件→打开项目”或“最近项目”
- 打开后：状态栏显示项目名称/路径，项目树刷新

### 3.3 运行规范检查

- 入口：规范检查面板（Dock）
- 操作：选择规则集→执行→查看结果列表

### 3.4 运行诊断分析

- 入口：深度诊断面板（Dock）
- 结果：综合评分 + 分项维度 + 问题清单与建议

### 3.5 生成项目文档

- 入口：文档相关页面/入口（以 UI 菜单为准）
- 建议：每个 Sprint 结束后生成一次并提交到项目文档目录

## 4. 常见问题

| 现象 | 处理建议 |
|---|---|
| STEditor 提示“功能受限/回退模式” | 安装 QScintilla 后重启 |
| `No module named pytest` | `python -m pip install pytest` 或重装 requirements |
| `No module named PyQt5` | `python -m pip install PyQt5` 或重装 requirements |
