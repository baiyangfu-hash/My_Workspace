## 1. Bug 描述与根因分析

### 1.1 问题描述

GUI 无法正常启动运行。设置环境变量 `PLC_WORKSPACE_ROOT=C:\Users\fubai\Desktop\My_Workspace\0100_PLC自动化` 后运行 `python main.py`，程序抛出异常：

```
TypeError: Window.__init__() got an unexpected keyword argument 'loaded'
```

### 1.2 根因分析

| 项目 | 详情 |
|------|------|
| **根因** | `main.py` 第53行 `webview.create_window()` 使用了 `loaded=on_loaded` 参数 |
| **版本变更** | pywebview 6.x 移除了 `create_window()` 的 `loaded` 参数 |
| **正确API** | pywebview 6.x 使用 `window.events.loaded += handler` 事件绑定方式 |
| **影响范围** | 所有使用 pywebview 6.x 的环境均无法启动 GUI |

### 1.3 修复方案

```python
# 修复前 (pywebview 5.x API — 已废弃)
window = webview.create_window(
    ...,
    loaded=on_loaded,  # ← 6.x 不支持
)

# 修复后 (pywebview 6.x API)
window = webview.create_window(...)
window.events.loaded += on_loaded  # ← 事件绑定
```

### 1.4 修改文件清单

| 文件 | 变更说明 |
|------|---------|
| `03_主程序/01_主程序核心代码/main.py` | `loaded=on_loaded` 参数 → `window.events.loaded += on_loaded` 事件绑定 |
