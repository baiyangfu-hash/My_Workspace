## 1. 设计目标

### 1.1 核心目标
消除 HTML 原型 (`ui_prototype/index.html`) 与 Qt/PySide5 实现之间的**视觉与交互差距**，使实际运行效果与原型一致度达到 **90%+**。

### 1.2 设计原则
- **沿用IDE深色工业风**：保持 `#1E1E1E` 主背景 + `#E86100` 橙色强调色体系
- **上下文感知Sidebar**：Sidebar内容随Activity Bar切换而动态变化（原型核心交互）
- **视觉精致度提升**：引入微阴影、圆角、过渡动画（QSSPropertyAnimation可模拟）
- **信息架构对齐**：Dashboard指标/布局与原型完全一致
