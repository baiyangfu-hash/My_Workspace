### Epic 2: 变更管理工作流闭环 ✅已完成

**目标**: CHG/IFC 生成后可审核、可回写项目目录，形成"生成→审核→回写"闭环。

#### Story 2.1: 生成结果对话框 ✅已完成

**实际实现**:
- 创建 `src/ui/dialogs/sync_result_dialog.py` (140行)
- SyncResultDialog 显示: 文件路径 + 内容只读预览 + 打开目录/回写/仅保存 三个按钮
- `get_action() -> str` 返回用户选择
- `get_doc_type() -> str` 返回文档类型

#### Story 2.2: 回写服务 ✅已完成

**实际实现**:
- SyncEngine 新增 `writeback_to_project(source_path, project_path, doc_type) -> List[str]`
- WRITEBACK_DIRS 类属性定义回写路径映射:
  - CHG → `00_项目管理/04_变更管理/01_变更单/`
  - IFC → `00_项目管理/03_接口文档/`
- 同名文件自动备份(.bak)，自动创建目标目录

#### Story 2.3: SyncController 集成 ✅已完成

**实际实现**:
- SyncController 完整重写，集成 SyncResultDialog + 回写逻辑
- on_sync_generate_chg/ifc → 生成 → 弹出SyncResultDialog → 根据选择回写/保存
- 回写后通过 _notify_project_tree_refresh() 刷新项目树
- 版本检查改为异步 QThread 执行 (Story 4.1 合并实现)

#### Story 2.4: 变更单审核状态流转 ✅已完成

**实际实现**:
- ChangeStatus 枚举扩展: DRAFT → REVIEW → APPROVED → ANALYZING → IN_PROGRESS → IMPLEMENTED → VERIFYING → COMPLETED → CANCELLED
- 新增 `ChangeStatus.valid_transitions(current)` 类方法，定义合法状态转换
- ChangeService 新增:
  - `update_status(project_path, change_id, new_status) -> bool` — 校验转换合法性
  - `approve_change_request(project_path, change_id, approver) -> bool` — 审核通过并记录审核人
- 新增辅助方法: `_find_change_file`, `_read_status`, `_write_status`, `_status_from_value`
