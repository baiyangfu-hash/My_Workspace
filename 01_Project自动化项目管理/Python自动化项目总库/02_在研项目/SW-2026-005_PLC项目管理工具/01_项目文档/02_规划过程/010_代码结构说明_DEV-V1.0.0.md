# 代码结构说明 DEV-V1.0.0

> **版本**: V1.0.0 | **日期**: 2026-05-10

## 1. 顶层目录职责

| 目录 | 职责 |
|---|---|
| `00_项目基础信息/` | 立项表、PRD 等基础信息与验收依据 |
| `01_项目文档/` | 全生命周期工程文档（启动/规划/执行）唯一权威源 |
| `03_主程序/01_主程序核心代码/` | Python 主程序与测试（可运行与交付主体） |
| `.trae/specs/` | 规范/计划/阶段性分析文档（辅助研发，不作为交付文档） |

---

## 2. 主程序目录结构（核心）

路径：`03_主程序/01_主程序核心代码/`

| 路径 | 说明 |
|---|---|
| `main.py` | 程序入口（创建 Application 并启动 GUI） |
| `requirements.txt` | Python 依赖（PyQt5 / QScintilla / pytest 等） |
| `src/` | 源码根目录（分层架构） |
| `tests/` | 单元/集成测试用例 |
| `resources/` | 图标、QSS 样式、字体等静态资源 |

---

## 3. src/ 分层架构速查

| 层 | 目录 | 职责 |
|---|---|---|
| 核心层 | `src/core/` | 应用生命周期、配置、事件总线、核心模型封装 |
| 表现层 | `src/ui/` | MainWindow、Dashboard、Dialogs、Widgets |
| 服务层 | `src/services/` | 项目/模板/文档/检查/诊断/测试等业务服务 |
| 数据层 | `src/models/` | Project/Document/TestCase/Report 等数据模型 |
| 解析层 | `src/parsers/` | ST/变量/规范文档/测试文件解析 |
| 规则层 | `src/checkers/` | 规则引擎与各类检查器实现 |
| 诊断层 | `src/diagnostics/` | 健康度与 LSP 兼容性诊断 |
| 工具层 | `src/utils/` | 日志、文件工具、路径策略、校验器 |

---
