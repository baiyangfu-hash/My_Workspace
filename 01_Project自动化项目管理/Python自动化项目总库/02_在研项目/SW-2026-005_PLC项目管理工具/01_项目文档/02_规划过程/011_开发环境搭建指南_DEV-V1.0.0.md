# 开发环境搭建指南 DEV-V1.0.0

> **项目**: SW-2026-005 PLC项目管理工具  
> **适用**: Windows 10/11 + Python 3.11+  
> **版本**: V1.0.0 | **日期**: 2026-05-10  
> **说明**: 本指南以“能跑起来 + 能跑测试 + 能复现问题”为目标；依赖以 `requirements.txt` 为准

---

## 1. 环境要求

| 组件 | 建议 |
|---|---|
| Python | 3.11（当前已验证） |
| GUI 依赖 | PyQt5 |
| 可选编辑增强 | QScintilla（ST 编辑器语法高亮/补全相关） |
| 测试 | pytest（建议同时安装 pytest-cov） |

---

## 2. 安装步骤（推荐最短路径）

在目录 `03_主程序/01_主程序核心代码/` 下执行：

```powershell
python -m pip install -r requirements.txt
```

可选安装（如果不装也能运行，但 STEditor 会回退到基础模式并提示）：

```powershell
python -m pip install QScintilla
```

---

## 3. 启动应用

```powershell
cd "03_主程序/01_主程序核心代码"
python main.py
```

---

## 4. 运行测试

```powershell
cd "03_主程序/01_主程序核心代码"
python -m pytest -q
```

如果仅验证 STEditor 的“缺依赖回退”路径：

```powershell
python -m pytest tests\test_st_editor_dependency.py -q
```

---

## 5. 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `No module named pytest` | pytest 未安装 | `python -m pip install pytest` 或重新安装 requirements |
| `No module named PyQt5` | PyQt5 未安装 | `python -m pip install PyQt5` 或重新安装 requirements |
| STEditor 功能受限提示 | 未安装 QScintilla | 安装 QScintilla 后重启 |
