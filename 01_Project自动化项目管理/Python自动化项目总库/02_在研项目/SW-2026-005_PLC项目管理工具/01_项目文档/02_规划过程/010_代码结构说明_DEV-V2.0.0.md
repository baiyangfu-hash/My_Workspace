## 2. 主程序目录结构（核心）

路径：`03_主程序/01_主程序核心代码/`

| 路径 | 说明 |
|---|---|

---

## 3. src/ 分层架构速查

| 层 | 目录 | 职责 |
|---|---|---|
| 核心层 | `src/core/` | 应用生命周期、配置、事件总线、核心模型封装 |
| 表现层 | `src/ui/` | MainWindow(薄壳)、Dashboard、Dialogs、Widgets |
| 控制层 | `src/ui/controllers/` | ProjectController/SyncController/DashboardController |
| 管理层 | `src/ui/managers/` | MenuManager/ToolbarManager |
| 服务层 | `src/services/` | 项目/模板/文档/检查/诊断/规范/变更/工作流(9个业务服务) |
| 同步层 | `src/sync/` | 版本检查/CHG生成/IFC生成/同步报告/fb_registry(8个模块) |
| 数据层 | `src/models/` | Project/Document/TestCase/Report等数据模型 |
| 解析层 | `src/parsers/` | ST/变量/规范文档/测试文件解析 |
| 规则层 | `src/checkers/` | 规则引擎与6种检查器实现 |
| 诊断层 | `src/diagnostics/` | 健康度与LSP兼容性诊断 |
| 工具层 | `src/utils/` | 日志、文件工具、路径策略、校验器 |
