## 1. 文档定位

本目录是 `SW-2026-005` 的规划阶段权威源，用于回答以下问题：
- 这个产品现在到底要做成什么
- 当前版本为什么要从"单项目工具"演进到"工作空间治理工具"
- V4.x架构如何从PyQt5迁移到PyWebView
- 哪些文档是历史资料，哪些文档只是未来储备

本轮主线定位已经统一为：
- **Trae负责主开发**: PLC代码、文档正文、AI协同开发主要在 Trae 中完成
- **SW-2026-005负责治理**: 提供工作空间挂载、项目树、共享库识别、规范检查、文档生成、全库汇总等能力
- **V4.x架构**: PyWebView(Chromium)前端 + IPCBridge(38 API)后端桥接 + HTML/CSS/JS前端
- **非目标**: 不把产品继续扩张成脱离 Trae 的"大而全"独立主开发平台

## 5. 维护规则

- 主线文档只保留当前权威版本，不再继续引用已归档的失效路径
- 历史规划和未来储备必须在索引中显式降级，避免被误当作当前开发入口
- 文档与实现必须同步更新，任何结构性改动都要同步更新 `006~013` 中受影响部分
- 若后续新增工作空间相关实现，以 `011_工作空间支持开发规划_DEV-PLAN-V1.0.0.md` 为直接执行主入口，`006~010` 为权威支撑文档
- PyWebView前端代码变更需同步更新 `013_UI重设计规范` 和 `009_API接口文档` 的IPCBridge章节
