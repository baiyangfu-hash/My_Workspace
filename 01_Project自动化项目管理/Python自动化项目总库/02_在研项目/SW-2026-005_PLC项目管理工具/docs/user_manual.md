# SW-2026-005 PLC项目管理工具 - 用户操作手册

> 版本: V1.0.0 | 状态: 开发中

## 1. 产品概述

### 1.1 简介
SW-2026-005 PLC项目管理工具是一款面向IEC 61131-3标准的PLC工程项目管理桌面应用。
集成文档管理、ST代码编辑、变量检查、IO分配表和HMI映射等核心功能，
为自动化工程师提供一站式的PLC项目开发辅助环境。

### 1.2 技术栈
- **运行环境**: Python 3.8+
- **GUI框架**: PyQt5
- **代码编辑**: QScintilla (可选)
- **数据存储**: SQLite
- **文档格式**: Markdown

### 1.3 适用场景
- 单机设备PLC项目 (DJ业务线)
- 自动化整线PLC项目 (ZD业务线)
- 多品牌PLC开发 (Siemens/Beckhoff/Omron/Codesys)

## 2. 快速开始

### 2.1 环境准备
```bash
# 创建虚拟环境 (推荐)
python -m venv venv
venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

### 2.2 启动应用
```bash
cd 03_主程序/01_主程序核心代码
python main.py
```

### 2.3 首次使用
1. 启动后显示仪表盘首页
2. 点击 "新建项目" 或 Ctrl+N 创建第一个项目
3. 选择业务线和模板类型
4. 项目创建后可在左侧树状视图中浏览结构

## 3. 功能模块说明

### 3.1 仪表盘 (Dashboard)
- 显示项目统计信息 (总数/进行中/已完成)
- 快捷操作入口
- 最近打开的项目列表

### 3.2 项目管理
- 新建/打开/删除项目
- 项目目录树浏览
- 右键快捷菜单操作

### 3.3 文档管理
- 基于模板的标准化文档创建
- Markdown编辑器 (支持语法高亮)
- 实时预览功能
- 文档版本管理

### 3.4 PLC工具 (开发中)
- ST代码编辑器 (需安装QScintilla)
- 代码片段快速插入
- 语法高亮与补全

### 3.5 HMI映射 (开发中)
- PLC变量到HMI控件的绑定管理
- IO地址冲突检测
- 多品牌HMI格式导出

### 3.6 规范检查 (开发中)
- 801文档命名规范校验
- 变量命名匈牙利法验证
- IO地址重复检测

## 5. 常见问题

**Q: 安装PyQt5报错?**
A: 推荐使用 `pip install PyQt5==5.15.10` 指定版本。

**Q: ST代码编辑器没有语法高亮?**
A: 需要额外安装 `pip install QScintilla`。

**Q: 如何切换深色主题?**
A: 视图 -> 主题 -> 深色主题。
