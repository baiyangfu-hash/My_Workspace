## 2. 文件命名约定

| 模式 | 示例 | 说明 |
|------|------|------|
| **模块__init__.py** | `core/__init__.py` | 包初始化，可为空 |
| **主类小写** | `main_window.py`, `dashboard.py` | 主要类名=文件名 |
| **服务_xxx.py** | `project_service.py` | 服务以功能命名 |
| **模型_xxx.py** | `project.py`, `variable.py` | 数据实体 |
| **xxx_checker.py** | `naming_checker.py` | 检查器后缀 |
| **xxx_parser.py** | `st_parser.py` | 解析器后缀 |
| **xxx_manager.py** | `menu_manager.py` | 管理器后缀 |

## 3. 导入路径规范

```python
# 同层导入
from src.core.settings import SettingsManager
from src.ui.widgets import DiagnosticPanel

# 跨层导入 (避免循环依赖)
# services → models: 允许
# ui → services: 通过EventBus间接调用
# core → 所有层: 作为基础设施被引用
```
