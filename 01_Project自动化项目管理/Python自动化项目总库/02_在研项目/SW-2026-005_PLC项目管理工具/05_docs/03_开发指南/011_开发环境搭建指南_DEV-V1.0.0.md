## 2. 安装步骤

### 2.1 安装 Python

**方式A: 从官网下载 (推荐新手)**

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.9+ Windows installer (64-bit)
3. 运行安装程序
4. ⚠️ **务必勾选 "Add Python to PATH"**
5. 点击 Install Now

**方式二: 使用 winget (推荐有经验的开发者)**

```powershell
winget install Python.Python.3.11
```

### 2.2 验证安装

```bash
python --version
# 应输出: Python 3.x.x

pip --version
# 应输出: pip xx.x.x from python x.x.x
```

## 3. 创建虚拟环境（推荐）

```bash
# 1. 进入项目目录
cd SW-2026-005_PLC项目管理工具/03_主程序/01_主程序核心代码

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 4. 验证激活成功 (命令行前缀显示 (venv))
```

> **为什么使用虚拟环境?**
> - 隔离项目依赖，避免全局环境污染
> - 方便切换不同项目的Python版本
> - 删除 venv 目录即可完全清理

## 4. 安装依赖

### 4.1 基础依赖（必须）

```bash
# 确保在虚拟环境中
pip install -r requirements.txt
```

**关键依赖说明**:

| 包名 | 版本 | 用途 | 是否必须 |
|------|------|------|----------|
| PyQt5 | ≥5.15 | GUI框架 | ✅ 必须 |
| PyQt5-sip | ≥12.8 | PyQt5底层绑定 | ✅ 必须 |
| loguru | ≥0.7 | 日志系统 | ✅ 必须 |
| openpyxl | ≥3.0 | Excel IO操作 | ✅ 必须 |
| Markdown | ≥3.4 | Markdown渲染 | ✅ 必须 |
| pydantic | ≥2.0 | 数据校验 | ✅ 必须 |

### 4.2 可选依赖（增强功能）

```bash
# ST语法高亮编辑器 (推荐安装)
pip install QScintilla>=2.13.0

# 开发测试依赖
pip install pytest>=7.0 pytest-cov>=4.0 pytest-qt>=4.2.0
```

### 4.3 验证安装

```bash
# 检查关键包是否安装成功
python -c "
import PyQt5; print('PyQt5:', PyQt5.__version__)
import loguru; print('Loguru: OK')
import openpyxl; print('OpenPyXL: OK')
try:
    import QScintilla; print('QScintilla: OK')

    print('QScintilla: 未安装 (ST高亮不可用)')
"
```

## 5. 首次启动

```bash
# 1. 确保虚拟环境已激活
# 2. 运行主程序
python main.py
```

**预期结果**:
- 控制台输出日志信息
- GUI窗口弹出（约2-3秒）
- 显示仪表盘首页
- 无报错信息

### 5.1 常见启动问题

| 现象 | 原因 | 解决方法 |
|------|------|----------|
| `ModuleNotFoundError: No module named 'PyQt5'` | 未安装依赖或未激活venv | `pip install PyQt5` 并确认venv已激活 |
| `ImportError: DLL load failed` | 缺少Visual C++运行时 | 安装 [VC Redistributable](https://aka.ms/vs/17/release/vc_redist.exe) |
| 窗口一闪而过 | 程序异常退出 | 在终端手动运行查看错误堆栈 |
| 中文界面乱码 | 字体缺失 | 等待首次运行自动下载字体 |

## 6. IDE 配置建议

### 6.1 VS Code 推荐

**推荐扩展**:
- Python (Microsoft) — 语法检查/调试
- Pylance — 智能补全
- material-icon-theme — 图标主题

**settings.json 配置**:
```json
{
    "python.defaultInterpreterPath": "${workspaceFolder}/03_主程序/01_主程序核心代码/venv/Scripts/python.exe",
    "python.terminal.activateEnvironment": true
}
```

### 6.2 PyCharm 配置

1. File → Open → 选择项目根目录
2. Settings → Project → Interpreter → 选择 venv/python.exe
3. Run → Edit Configurations → Script path 设为 `main.py`
4. Working directory 设为 `03_主程序/01_主程序核心代码`

## 7. 调试模式

### 7.1 启用调试日志

修改 `main.py` 中的启动参数:

```python
# 将此行:
app = Application(mode="gui", debug=False)
# 改为:
app = Application(mode="gui", debug=True)  # 开启DEBUG级别日志
```

### 7.2 日志级别说明

| 级别 | 输出场景 | 用途 |
|------|----------|------|
| DEBUG | 详细函数调用链 | 开发调试 |
| INFO | 正常操作记录 | 运行监控 |
| WARNING | 可恢复的问题 | 注意事项 |
| ERROR | 操作失败 | 问题排查 |

日志输出到控制台，可通过 `loguru` 配置同时输出到文件。
