# SW-2026-005 PLC项目管理工具

> **状态**: 活跃规划与开发中  
> **当前主线**: PLC项目库/工作空间支持  
> **产品形态**: Trae伴生工具  
> **技术栈**: Python 3.9+ / PyQt5 / pytest

---

## 项目定位

`SW-2026-005` 当前不再按“独立主开发桌面工具”定位推进，而是按 **Trae伴生式 PLC 工作空间治理工具** 规划与实现：
- Trae 负责 PLC代码、文档正文与 AI 协同开发
- SW-2026-005 负责工作空间挂载、项目树、共享库识别、规范检查、文档生成与全库汇总
- 当前重点是补齐 `Workspace` 层，而不是继续堆叠单项目补丁

## 当前代码现状

目前代码已经具备：
- 单项目创建/打开/导入能力
- DJ 单机项目识别能力
- 规范检查、诊断、文档生成、变更同步等基础能力

当前缺口集中在：
- 缺少 `PLC_WORKSPACE` / `PLC_LIBRARY` 模型
- 只能按单项目打开目录
- 无法把共享库和规范目录纳入工作空间治理

---

## 开发原则

- 高内聚、低耦合
- 文档与实现同步更新
- 工作空间能力优先沉到 Service 层
- 不把产品重新做成与 Trae 竞争的编辑器
