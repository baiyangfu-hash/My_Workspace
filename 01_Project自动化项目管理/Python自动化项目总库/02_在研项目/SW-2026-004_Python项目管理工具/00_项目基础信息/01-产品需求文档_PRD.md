# 自动化项目管理工具产品需求文档(PRD)

## 1. 产品概述

自动化项目管理工具是一个专为自动化领域设计的**项目总库管理与变更管控平台**，支持多种技术栈（PLC、Python、上位机等）和多种业务线（软件开发、单机设备、自动化整线、系统升级、维保项目），聚焦解决项目管理标准化、变更可控化、规范检查自动化的核心痛点。

**核心价值**：
- 标准化项目管理流程，确保项目规范执行
- 变更全流程管控（V2.1.0三维分类+分级审批+传播链追踪）
- 规范自动检查（目录完整性+命名规范+代码风格）
- 模板驱动项目初始化，确保结构一致性
- 插件系统，支持功能扩展和定制

**目标用户**：
- 企业内部自动化开发团队
- PLC自动化工程师
- Python软件开发团队
- 自动化项目管理人员

**产品类型**：本地桌面应用（PyQt5） + CLI命令行工具

## 2. 核心功能

### 2.1 总库管理 ✅

| 功能模块 | 功能描述 | 用户价值 |
|---------|---------|----------|
| 总库创建与配置 | 创建和配置项目总库，设置总库基本信息和参数 | 统一管理自动化项目，建立标准化的项目集合 |
| 项目导入与管理 | 将现有项目导入总库，支持项目的添加、删除、更新、批量导入 | 方便项目管理，实现项目的集中化管理 |
| 项目分类管理 | 对总库中的项目进行分类管理，支持自定义分类 | 项目组织清晰，便于查找和管理 |
| 项目搜索与过滤 | 支持根据项目名称、类型、状态、业务线等条件搜索和过滤 | 快速定位项目，提高工作效率 |

### 2.2 模板管理 ✅

| 功能模块 | 功能描述 | 用户价值 |
|---------|---------|----------|
| 模板创建与编辑 | 创建和编辑项目模板，定义目录结构和文件模板 | 标准化项目初始化，确保项目结构一致性 |
| 模板分类管理 | 按业务线、编译器、适用场景对模板进行分类 | 快速找到合适的模板，提高项目创建效率 |
| 模板版本管理 | 管理模板版本，支持版本更新和回滚 | 确保模板的一致性和可追溯性 |
| 模板应用 | 根据模板创建新项目，自动生成目录结构和文件 | 快速启动项目，减少重复配置工作 |
| 多技术栈支持 | 支持PLC（Step7/TIA Portal）、Python（Web/GUI/数据分析）、上位机等多种技术栈 | 统一管理不同技术平台的项目 |

**支持的业务线和技术栈**：
- 软件开发（SW）：Python Web(Flask/Django)、Python GUI(PySide6)、Python数据分析
- 单机设备（DJ）：单机设备项目、PLC标准项目
- 自动化整线（ZD）：PLC整线项目、PLC+HMI上位机项目
- 系统升级（XT）：系统升级项目
- 维保项目（WX）：维保项目

### 2.3 项目监控与统计分析

| 功能模块 | 功能描述 | 用户价值 | 实现状态 |
|---------|---------|----------|----------|
| 项目状态监控 | 基础统计信息查询（项目数量/状态分布/业务线分布） | 了解项目整体概况 | ⚠️ 部分实现（缺实时监控/告警） |
| 依赖关系分析 | 分析项目间依赖关系 | 评估变更影响范围 | ⚠️ 部分实现（缺图谱可视化） |
| 健康状态评估 | 自动评估项目健康度（目录完整性+文档完整性+命名规范+代码风格） | 快速发现项目风险 | ✅ 已实现 |
| 统计报告 | 生成多维度统计报告（项目分布、进度统计、质量评估） | 为决策提供数据支持 | ⚠️ 部分实现（缺图表可视化） |

### 2.4 变更管理与版本控制 ✅

| 功能模块 | 功能描述 | 用户价值 |
|---------|---------|----------|
| 项目变更跟踪 | 创建和管理变更单，V2.1.0三维分类（Domain×Nature×Scope），记录变更原因、内容和影响范围 | 变更过程可追溯，分类清晰 |
| 变更审批流程 | 完整审批链：草稿→提交→审批→实施→完成，含驳回/取消，按Scope自动匹配审批层级 | 变更审批规范化 |
| 传播链追踪 | 追踪变更在项目内的传播路径，记录影响范围 | 评估变更影响，避免遗漏 |
| 版本变更台账 | 自动记录项目版本变更历史，支持台账查询 | 了解项目配置演变历史 |
| 影响分析 | 分析变更对相关项目的影响，生成影响报告 | 评估变更风险，提前准备 |

## 3. 非功能需求

### 3.1 性能要求
- 支持同时管理100+项目的总库
- 项目列表加载时间 < 2秒
- 代码检查速度：1000行代码 < 5秒

### 3.2 可用性要求
- 5分钟快速上手（有快速入门指南）
- 界面符合Windows桌面应用操作习惯
- 提供中文本地化界面
- 关键操作提供确认提示

### 3.3 安全要求
- 支持API模式Token认证
- 敏感信息不硬编码
- 数据文件受操作系统文件权限保护

### 3.4 兼容性要求
- 操作系统：Windows 10+
- Python版本：3.10+
- 支持独立exe运行（无需安装Python）

## 4. 不做的事项（Non-Goals）
- 在线协作/多用户协同编辑
- 云部署/SaaS服务
- CI/CD流水线集成
- 移动端（平板/手机）支持
- 代码托管（Git集成）
