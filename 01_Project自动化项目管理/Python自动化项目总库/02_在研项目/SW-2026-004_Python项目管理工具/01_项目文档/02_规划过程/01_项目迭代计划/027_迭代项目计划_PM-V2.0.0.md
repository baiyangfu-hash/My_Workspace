## 5. 迭代方法论

### 5.1 单模块迭代原则
- 每次只聚焦**一个功能模块**
- 按 Spec → Tasks → Implementation → Verification 流程执行
- 每个模块迭代包含: Bug修复 + 功能完善 + GUI优化
- 完成后运行全套回归测试确保无破坏性变更

### 5.2 文档同步原则
- 每次迭代完成后更新本文档（迭代计划）
- 更新里程碑清单
- Spec 文件保留在 `.trae/specs/<change-id>/` 中作为永久记录
