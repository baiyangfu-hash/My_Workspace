### 3.2 V1.1.1 Bug修复详情

#### BUG-013: 模板ID格式验证过于严格
- **问题描述**：模板ID格式验证只允许`TPL-XXX`格式，不支持`TPL-PLC-STD-001`等格式
- **修复方案**：放宽验证规则，允许`TPL-`开头的任意格式
- **修复代码**：
```python
# 修复前
if not re.match(r'^TPL-\d{3}$', template_id):
    return False, "模板ID格式不正确，应为: TPL-XXX"

# 修复后
if not re.match(r'^TPL-[A-Z0-9-]+$', template_id):
    return False, "模板ID格式不正确，应以TPL-开头"
```

#### BUG-016: 模板筛选信号未连接
- **问题描述**：编译器和场景筛选下拉框未连接信号，筛选不生效
- **修复方案**：添加信号连接，并使用blockSignals防止重复触发
- **修复代码**：
```python
# 添加信号连接
self.compiler_filter.currentIndexChanged.connect(self._filter_templates)
self.scene_filter.currentIndexChanged.connect(self._filter_templates)

# 更新选项时阻止信号
self.compiler_filter.blockSignals(True)
# ... 更新选项 ...
self.compiler_filter.blockSignals(False)
```
