## 3. 系统概述

SW-2026-004 Python项目管理工具是一个功能全面的Python项目管理系统，旨在提供总库管理、项目管理、变更管理、插件系统等核心功能。系统采用分层架构设计，结合PyQt5 GUI界面和Flask API接口，为用户提供直观的操作体验。

## 4. 系统安装

### 4.1 系统要求

- **操作系统**：Windows 10/11
- **Python版本**：Python 3.8+
- **内存**：至少4GB
- **硬盘空间**：至少100MB

### 4.2 安装步骤

#### 4.2.1 安装包安装

1. 下载系统安装包 `Python项目管理工具.exe`
2. 双击运行安装包
3. 按照安装向导的提示完成安装
4. 安装完成后，在桌面会生成快捷方式

#### 4.2.2 源码安装

1. 克隆项目源码到本地
2. 安装依赖包：`pip install -r requirements.txt`
3. 运行主程序：`python main.py`

## 3. 系统登录

1. 双击桌面快捷方式或运行主程序
2. 系统启动后，会显示登录界面
3. 输入用户名和密码（默认用户名：admin，密码：admin）
4. 点击"登录"按钮进入系统主界面

## 4. 主界面介绍

系统主界面主要包含以下部分：

- **菜单栏**：位于顶部，包含文件、编辑、视图、工具、帮助等菜单
- **工具栏**：位于菜单栏下方，包含常用功能的快捷按钮
- **左侧导航栏**：包含总库管理、项目管理、变更管理、插件管理等功能模块
- **主工作区**：显示当前功能模块的详细内容
- **状态栏**：位于底部，显示系统状态和操作提示

## 5. 总库管理

### 5.1 项目总库

1. 在左侧导航栏点击"总库管理" -> "项目总库"
2. 主工作区会显示所有项目的列表
3. 可以通过搜索框搜索项目
4. 可以通过筛选条件筛选项目
5. 可以点击项目名称查看项目详情

### 5.2 项目分类

1. 在左侧导航栏点击"总库管理" -> "项目分类"
2. 主工作区会显示项目分类列表
3. 点击"添加分类"按钮添加新分类
4. 选择分类后点击"编辑分类"按钮修改分类信息
5. 选择分类后点击"删除分类"按钮删除分类

### 5.3 统计分析

1. 在左侧导航栏点击"总库管理" -> "统计分析"
2. 主工作区会显示项目统计图表
3. 可以选择不同的统计维度查看数据
4. 点击"导出报告"按钮导出统计报告

## 6. 项目管理

### 6.1 项目列表

1. 在左侧导航栏点击"项目管理" -> "项目列表"
2. 主工作区会显示所有项目的列表
3. 点击"创建项目"按钮创建新项目
4. 选择项目后点击"编辑项目"按钮修改项目信息
5. 选择项目后点击"删除项目"按钮删除项目
6. 选择项目后点击"查看详情"按钮查看项目详细信息

### 6.2 项目模板

1. 在左侧导航栏点击"项目管理" -> "项目模板"
2. 主工作区会显示项目模板列表
3. 点击"创建模板"按钮创建新项目模板
4. 选择模板后点击"编辑模板"按钮修改模板信息
5. 选择模板后点击"删除模板"按钮删除模板
6. 选择模板后点击"使用模板"按钮基于模板创建项目

**当前模板列表**：
- **整线项目模板**：适用于整线集成项目，包含所有内容
- **单机设备-机器人版**：适用于机器人单机设备项目，包含eplan、机械、通讯设计
- **单机设备-PLC-HMI版**：适用于PLC-HMI单机设备项目，包含eplan、机械、通讯设计
- **系统升级模板**：适用于系统升级项目
- **上位机项目模板**：适用于上位机软件项目，只有软件python

### 6.3 模板变更

1. 在左侧导航栏点击"项目管理" -> "项目列表"
2. 在项目列表中找到需要变更模板的项目
3. 右键点击项目行，在弹出的菜单中选择"变更模板"
4. 在弹出的对话框中，从下拉列表中选择新的模板
5. 点击"确定"按钮执行模板变更
6. 系统会根据新模板更新项目的目录结构和文件
7. 变更完成后，系统会显示成功提示

**注意**：模板变更会根据新模板的定义更新项目结构，可能会添加新的目录和文件，但不会删除现有的文件。

### 6.4 项目进度

1. 在左侧导航栏点击"项目管理" -> "项目进度"
2. 主工作区会显示项目进度列表
3. 选择项目后点击"更新进度"按钮更新项目进度
4. 可以查看项目的进度图表和时间线

## 11. 常见问题与解决方案

### 11.1 登录失败

- **问题**：输入用户名和密码后登录失败
- **解决方案**：检查用户名和密码是否正确，默认用户名：admin，密码：admin

### 11.2 插件安装失败

- **问题**：安装插件时失败
- **解决方案**：检查插件文件是否完整，是否符合系统要求

### 11.3 数据库连接失败

- **问题**：系统无法连接数据库
- **解决方案**：检查数据库连接参数是否正确，数据库服务是否运行

### 11.4 系统运行缓慢

- **问题**：系统运行缓慢
- **解决方案**：检查系统资源使用情况，关闭不必要的程序
