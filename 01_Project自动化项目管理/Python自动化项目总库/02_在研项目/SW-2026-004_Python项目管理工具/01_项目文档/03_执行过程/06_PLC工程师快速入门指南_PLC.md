## 1. 启动工具

双击 `Python项目管理工具.exe`，或在项目根目录执行：

```bash
python main.py
```

**预期结果**：弹出主窗口，显示项目管理界面。

---

## 2. 创建PLC项目

**操作路径**：菜单栏 `文件 → 新建项目`

在弹出的对话框中：

1. **选择模板**：选择 **TPL-SINGLE-PLC-001**（单机PLC项目模板）
2. **填写业务线**：选择 `DJ`（或其他业务线代码）
3. **填写项目名称**：输入项目名称，如 "输送机PLC控制系统"
4. 点击 **"创建"**

**预期结果**：项目创建成功，弹出提示 "项目 DJ-2026-XXX 创建成功"。

> CLI方式：`python main.py create-project --business-line DJ --name "输送机PLC控制系统" --template-id TPL-SINGLE-PLC-001`

---

## 3. 检查生成目录

项目创建后，打开项目目录确认结构完整。

**预期目录结构**（以单机PLC模板为例）：

```
DJ-2026-XXX_输送机PLC控制系统/
├── 00_项目基础信息/        # 项目章程、PRD等
├── 01_项目文档/            # 技术文档
├── 02_PLC程序/             # PLC源代码目录
├── 03_HMI设计/             # HMI界面设计
├── 04_变更管理/            # 变更单与审批记录
├── 05_测试验收/            # 测试计划与报告
└── 06_交付物/              # 交付打包
```

**预期结果**：上述目录均已自动创建，可直接在 `02_PLC程序/` 下开始编写SCL代码。

---

## 4. 规范同步

项目管理工具内置PLC领域规范，可通过CLI检查并同步最新版本。

### 4.1 检查规范版本

```bash
python main.py check-spec
```

**预期结果**：列出所有引用的PLC规范及版本状态：

```
可更新规范:
  • 905_SCL编程规范: V1.0.0 → V1.1.0 (次版本号)
  • 904_SCL注释规范: V1.0.0 (已最新)
  • 903_定时器使用规范: V1.0.0 (已最新)
```

### 4.2 同步最新规范

```bash
python main.py sync-spec
```

**预期结果**：自动下载并更新所有可更新的规范文件，旧版本自动备份到 `backup/specs/`。

> 也可以同步单个规范：`python main.py sync-spec --spec-name "905_SCL编程规范"`
> 查看全部规范信息：`python main.py spec-info`

---

## 5. 代码规范检查

**操作路径**：

1. 在项目管理列表中 **选中PLC项目**
2. 点击菜单 `工具 → 规范检查`（或按快捷键 **F5**）

**预期结果**：

- 系统自动扫描项目中的SCL代码文件
- 展示检查结果：
  - **通过** — 命名、代码风格、注释符合905/904规范
  - **警告** — 建议优化项（如缺少注释、变量命名可读性）
  - **错误** — 必须修正项（如FB命名不符合规范）
- 点击 **"导出报告"** 保存检查结果

> CLI方式：`python main.py check-project <项目ID>`

---

## 6. 变更管理

### 6.1 创建PLC领域变更单

1. 点击左侧导航 **"变更管理"** Tab
2. 点击 **"新建变更单"**
3. **领域选择**：选择 `PLC`
4. 系统自动建议关联领域 — **建议同时设置 `HMI` / `DOCU`** 等受影响领域
5. 填写变更描述（如 "修改输送机启停联锁逻辑"）
6. 提交变更单

### 6.2 审批与台账

- 审批人审核变更单 → 审批通过/驳回
- 变更执行后，台账自动更新状态为 "已执行"
- 变更台账支持按领域、状态、时间筛选

**预期结果**：PLC领域变更可追溯、可审计，关联领域自动联动通知。

## 附录B：调试技巧

### 日志

- 位置：工具目录 `logs/app.log`
- 出现问题时优先检查日志中的 ERROR 级别记录

### 数据库

- 位置：工具目录 `data/project_manager.db`（SQLite）
- 可使用 SQLite 客户端直接查询项目管理数据

### 常见问题

| 问题 | 解决方法 |
|------|----------|
| 找不到 `TPL-SINGLE-PLC-001` 模板 | 检查 `模板管理` Tab → 确认模板列表中是否存在；如不存在，联系管理员导入 |
| 规范同步失败 | 检查网络连接；确认全局规范目录 `00_Obsidian_Base全局规范文件仓库/` 可访问 |
| SCL代码检查无结果 | 确认项目目录下存在 `02_PLC程序/` 文件夹且包含 `.scl` 文件 |
| 变更单无法提交 | 确认"领域"字段已选择、变更描述已填写 |
