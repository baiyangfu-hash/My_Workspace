## 四、V2.5.9 修复详情 (2026-04-17)

**类型**: BugFix Release（修复 V2.5.8 遗留问题 + 增强稳定性）

### V2.5.9 (2026-04-17)

**修复问题**:
1. **路径一致性修复**: 修复新建项目路径在跨机器部署时仍显示旧绝对路径的问题
   - new_project_dialog.py: 实现 Config 延迟安全导入（避免 PyImporter 冻结环境闪退）
   - 调整路径优先级链路：Config → 跳过不可信DB路径 → 自动检测 → exe_dir/Projects 硬兜底

   - 统一 version.py、app_config.json(源码)、app_config.json(交付物) 三处版本号为 2.5.9
   - 确认 GUI 标题栏从 app_config.json 读取版本号

3. **数据库自愈能力**: 增加启动时自动清理旧绝对路径功能
   - LibraryService.initialize_default_library() 启动时自动检测并清空含盘符的 root_path
   - 防止总库管理界面显示旧机器的绝对路径

4. **数据库预清理**: 打包前清空交付物 project_manager.db 中的旧 root_path 记录

**技术改进**:
- PyInstaller 冻结环境兼容性增强
- 路径解析优先级重构（4层优先级 + 最终降级）
- 数据库零污染策略（root_path 自动清空）

**文件变更**:
- src/ui/dialogs/new_project_dialog.py (路径优先级重构)
- src/services/library_service.py (策略0 + 自动清理方法)
- src/core/version.py (版本号更新)
