## 2. 测试执行方式

### 2.1 手动执行测试

#### 全量测试（推荐）
```bash
py run_full_test_suite.py
```

#### 快速模式（仅核心测试）
```bash
py run_full_test_suite.py --mode quick
```

#### CI模式（核心+服务测试）
```bash
py run_full_test_suite.py --mode ci
```

#### 启用通知功能
```bash
py run_full_test_suite.py --notify
```

### 2.2 测试模式对比

| 模式 | 执行时间 | 测试范围 | 适用场景 |
|-----|---------|---------|---------|
| quick | ~0.2s | 核心模块测试 | 快速验证基础功能 |
| ci | ~0.4s | 核心+服务测试 | CI/CD集成 |
| full | ~0.7s | 全量测试（含性能） | 完整验证 |

### 2.3 命令行参数说明

| 参数 | 说明 | 默认值 |
|-----|------|-------|
| `--mode` | 测试模式 (quick/ci/full) | full |
| `--notify` | 启用通知功能 | False |

## 3. 测试报告查看

### 3.1 报告类型

#### 1. 详细测试报告
- **路径**：`data\test_reports\detailed\详细测试报告_YYYYMMDD_HHMMSS.md`
- **内容**：
  - 每个测试用例的详细信息
  - 执行时间统计
  - 测试结果（通过/失败）
  - 错误信息（如有）

#### 2. 汇总测试报告
- **路径**：`data\test_reports\测试报告_YYYYMMDD_HHMMSS.md`
- **内容**：
  - 测试结果汇总统计
  - 通过率分析
  - 失败用例列表
  - 执行时间总览

#### 3. 趋势分析报告
- **路径**：`data\test_reports\trends\趋势报告_YYYYMMDD_HHMMSS.md`
- **内容**：
  - 测试历史数据趋势
  - 性能指标变化
  - 问题追踪分析

### 3.2 报告查看方式

#### 方式1：直接打开
双击Markdown文件，使用Markdown编辑器或文本编辑器查看。

#### 方式2：命令行查看
```bash

type data\test_reports\测试报告_*.md | more

# 查看最新详细报告
type data\test_reports\detailed\详细测试报告_*.md | more
```

## 4. 定时任务管理

### 4.1 查看定时任务

#### 查看任务状态
```bash
schtasks /query /tn "Python项目管理工具自动化测试"
```

#### 查看任务详细信息
```bash
schtasks /query /tn "Python项目管理工具自动化测试" /fo LIST /v
```

### 4.2 手动触发测试

#### 立即执行测试
```bash
schtasks /run /tn "Python项目管理工具自动化测试"
```

#### 查看任务历史
```bash
schtasks /query /tn "Python项目管理工具自动化测试" /fo LIST /v
```

### 4.3 修改定时任务

#### 修改执行时间
```bash
# 删除旧任务
schtasks /delete /tn "Python项目管理工具自动化测试" /f

# 创建新任务（修改时间）
schtasks /create /tn "Python项目管理工具自动化测试" /tr "py D:\BaiduSyncdisk\Trae_AI编程测试\自动化项目管理\Python自动化项目总库\02_在研项目\SW-2026-004_Python项目管理工具\03_主程序\01_主程序核心代码\run_full_test_suite.py" /sc daily /st 04:00 /f
```

#### 常用执行时间设置
```bash
# 每天凌晨3点执行
/sc daily /st 03:00

# 每周一上午9点执行
/sc weekly /d MON /st 09:00

# 每小时执行一次
/sc hourly

# 每天执行多次（如9:00和18:00）
/sc daily /st 09:00
schtasks /create /tn "Python项目管理工具自动化测试_2" /tr "py ..." /sc daily /st 18:00 /f
```

### 4.4 删除定时任务

```bash
schtasks /delete /tn "Python项目管理工具自动化测试" /f
```

### 4.5 重新创建定时任务

```bash
schtasks /create /tn "Python项目管理工具自动化测试" /tr "py D:\BaiduSyncdisk\Trae_AI编程测试\自动化项目管理\Python自动化项目总库\02_在研项目\SW-2026-004_Python项目管理工具\03_主程序\01_主程序核心代码\run_full_test_suite.py" /sc daily /st 03:00 /f
```

## 6. 常见问题处理

### 6.1 测试执行问题

#### 问题1：Python命令无法识别
**现象**：执行 `py run_full_test_suite.py` 时提示找不到命令

**解决方案**：
```bash
# 使用完整Python路径
python run_full_test_suite.py

# 或使用Python启动器
py run_full_test_suite.py
```

#### 问题2：数据库连接失败
**现象**：测试输出数据库连接错误

**解决方案**：
1. 检查数据库文件路径是否正确
2. 确认数据库文件权限
3. 查看日志文件：`data\logs\app.log`

#### 问题3：测试报告生成失败
**现象**：测试完成但报告未生成

**解决方案**：
1. 检查 `data\test_reports` 目录是否存在
2. 确认目录写入权限
3. 查看控制台错误信息

### 6.2 定时任务问题

#### 问题1：定时任务未执行
**现象**：定时任务创建成功但未按时执行

**解决方案**：
```bash
# 检查任务计划程序服务
sc query Schedule

# 查看任务历史
schtasks /query /tn "Python项目管理工具自动化测试" /fo LIST /v

# 手动触发测试
schtasks /run /tn "Python项目管理工具自动化测试"
```

#### 问题2：任务创建失败
**现象**：创建定时任务时提示权限不足

**解决方案**：
1. 以管理员身份运行命令提示符
2. 检查任务计划程序服务是否运行
3. 确认命令语法正确

### 6.3 性能问题

#### 问题1：测试执行时间过长
**现象**：测试执行时间超过预期

**解决方案**：
1. 使用快速模式：`--mode quick`
2. 检查系统资源占用
3. 清理测试数据

#### 问题2：内存占用过高
**现象**：测试过程中内存占用过高

**解决方案**：
1. 关闭其他应用程序
2. 重启测试环境
3. 检查内存泄漏问题
