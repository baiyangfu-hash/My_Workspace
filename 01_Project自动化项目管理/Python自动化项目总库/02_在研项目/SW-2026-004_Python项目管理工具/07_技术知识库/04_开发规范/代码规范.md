## 1. 命名规范

### 1.1 文件命名

#### Python文件
- 使用小写字母和下划线
- 使用描述性名称
- 示例：
  ```
  ✅ project_service.py
  ✅ change_dao.py
  ✅ file_utils.py
  
  ❌ ProjectService.py
  ❌ ChangeDAO.py
  ❌ file-utils.py
  ```

#### 配置文件
- 使用小写字母和下划线
- 示例：
  ```
  ✅ app_config.json
  ✅ logging_config.ini
  
  ❌ AppConfig.json
  ❌ logging-config.ini
  ```

### 1.2 变量命名

#### 普通变量
- 使用小写字母和下划线
- 使用描述性名称
- 示例：
  ```python
  ✅ project_id = 'DJ-2026-001'
  ✅ user_name = '张三'
  ✅ is_active = True
  
  ❌ projectId = 'DJ-2026-001'
  ❌ userName = '张三'
  ❌ active = True
  ```

#### 常量
- 使用大写字母和下划线
- 示例：
  ```python
  ✅ MAX_RETRY_COUNT = 3
  ✅ DEFAULT_TIMEOUT = 30
  ✅ DATABASE_PATH = 'data/project_manager.db'
  
  ❌ max_retry_count = 3
  ❌ default_timeout = 30
  ❌ database_path = 'data/project_manager.db'
  ```

### 1.3 函数命名

#### 普通函数
- 使用小写字母和下划线
- 使用动词开头
- 示例：
  ```python
  ✅ def create_project():
  ✅ def get_user_info():
  ✅ def calculate_total():
  
  ❌ def CreateProject():
  ❌ def getUserInfo():
  ❌ def total():
  ```

#### 私有函数
- 使用单下划线前缀
- 示例：
  ```python
  ✅ def _validate_input():
  ✅ def _process_data():
  
  ❌ def validate_input():
  ❌ def __process_data():
  ```

### 1.4 类命名

#### 普通类
- 使用大驼峰命名法（PascalCase）
- 使用名词
- 示例：
  ```python
  ✅ class ProjectService:
  ✅ class ChangeDAO:
  ✅ class FileUtil:
  
  ❌ class projectService:
  ❌ class change_dao:
  ❌ class file_util:
  ```

#### 抽象类
- 使用大驼峰命名法
- 以Abstract开头或使用ABC
- 示例：
  ```python
  ✅ class AbstractProjectService:
  ✅ class IProjectService(ABC):
  
  ❌ class ProjectServiceBase:
  ❌ class project_service_abstract:
  ```

### 1.5 数据库表和字段

#### 表名
- 使用复数形式
- 使用小写字母和下划线
- 示例：
  ```sql
  ✅ CREATE TABLE projects (...)
  ✅ CREATE TABLE changes (...)
  ✅ CREATE TABLE library_projects (...)
  
  ❌ CREATE TABLE project (...)
  ❌ CREATE TABLE Changes (...)
  ❌ CREATE TABLE LibraryProjects (...)
  ```

#### 字段名
- 使用小写字母和下划线
- 示例：
  ```sql
  ✅ project_id VARCHAR(50),
  ✅ created_at DATETIME,
  ✅ is_active BOOLEAN
  
  ❌ projectId VARCHAR(50),
  ❌ CreatedAt DATETIME,
  ❌ IsActive BOOLEAN
  ```

## 2. 代码格式

### 2.1 缩进

#### 使用4个空格缩进
```python
✅ 正确示例
def create_project(project_id, name):
    if project_id:
        project = Project(
            project_id=project_id,
            name=name
        )
        return project
    return None

❌ 错误示例
def create_project(project_id, name):
  if project_id:
    project = Project(
      project_id=project_id,
      name=name
    )
    return project
  return None
```

### 2.2 行长度

#### 每行不超过100个字符
```python
✅ 正确示例
result = ProjectService.create_project(
    business_line='DJ',
    name='电气控制项目',
    manager='张三'
)

❌ 错误示例
result = ProjectService.create_project(business_line='DJ', name='电气控制项目', manager='张三', description='这是一个非常长的描述文本，超过了100个字符的限制')
```

#### 长行换行
```python
✅ 正确示例
long_variable_name = some_function(
    parameter_one,
    parameter_two,
    parameter_three
)

❌ 错误示例
long_variable_name = some_function(parameter_one, parameter_two, parameter_three)
```

### 2.3 空行

#### 函数之间空2行
```python
✅ 正确示例
def create_project():
    pass


def get_project():
    pass

❌ 错误示例
def create_project():
    pass
def get_project():
    pass
```

#### 类之间空3行
```python
✅ 正确示例
class ProjectService:
    pass


class ChangeService:
    pass

❌ 错误示例
class ProjectService:
    pass
class ChangeService:
    pass
```

## 3. 注释规范

### 3.1 文件注释

#### 模块文档字符串
```python
"""
项目管理服务模块

本模块提供项目管理的业务逻辑，包括项目的创建、查询、更新和删除等功能。

主要功能：
- 项目创建
- 项目查询
- 项目更新
- 项目删除
"""

from typing import List, Optional
from src.models.project import Project
```

### 3.2 类注释

#### 类文档字符串
```python
class ProjectService:
    """
    项目管理服务类
    
    提供项目管理的业务逻辑处理，包括项目的创建、查询、更新和删除。
    
    Attributes:
        None
        
    Methods:
        create_project: 创建新项目
        get_project: 获取项目信息
        update_project: 更新项目信息
        delete_project: 删除项目
    """
```

### 3.3 函数注释

#### 函数文档字符串
```python
def create_project(business_line: str, name: str, template_id: str, 
                manager: str, description: str = None) -> tuple:
    """
    创建新项目
    
    Args:
        business_line (str): 业务线类型 (SW/DJ/ZD/XT/WX)
        name (str): 项目名称
        template_id (str): 模板ID
        manager (str): 项目经理
        description (str, optional): 项目描述. Defaults to None.
        
    Returns:
        tuple: (project: Project, error: str)
            project: 创建的项目对象，失败时为None
            error: 错误信息，成功时为None
            
    Example:
        >>> project, error = ProjectService.create_project(
        ...     business_line='DJ',
        ...     name='电气控制项目',
        ...     template_id='TEMPLATE-DJ-001',
        ...     manager='张三'
        ... )
        >>> print(project.project_id)
        'DJ-2026-001'
    """
```

### 3.4 行内注释

#### 使用#号注释
```python
✅ 正确示例
# 检查项目ID是否有效
if project_id and len(project_id) > 0:
    return True

❌ 错误示例
if project_id and len(project_id) > 0:  # 检查项目ID是否有效
    return True
```

#### 注释与代码同行
```python
✅ 正确示例
result = calculate_total()  # 计算总数

❌ 错误示例
# 计算总数
result = calculate_total()
```

## 5. 错误处理

### 5.1 异常捕获

#### 捕获特定异常
```python
✅ 正确示例
try:
    project = ProjectService.get_project(project_id)
except ProjectNotFoundException as e:
    logger.error(f"项目不存在: {e}")
    return None, str(e)
except DatabaseException as e:
    logger.exception(f"数据库错误: {e}")
    return None, "数据库错误"

❌ 错误示例
try:
    project = ProjectService.get_project(project_id)
except Exception as e:
    logger.error(f"错误: {e}")
    return None, str(e)
```

### 5.2 异常抛出

#### 使用自定义异常
```python
✅ 正确示例
if not project_id:
    raise ProjectNotFoundException(f"项目ID不能为空")

if not project:
    raise ProjectNotFoundException(f"项目不存在: {project_id}")

❌ 错误示例
if not project_id:
    raise Exception("项目ID不能为空")

if not project:
    raise Exception(f"项目不存在: {project_id}")
```

### 5.3 错误日志

#### 记录错误信息
```python
✅ 正确示例
try:
    result = Database.query(sql)
except DatabaseException as e:
    logger.exception(f"数据库查询失败: {e}")
    logger.error(f"SQL语句: {sql}")
    logger.error(f"参数: {params}")
    raise

❌ 错误示例
try:
    result = Database.query(sql)
except DatabaseException as e:
    print(f"错误: {e}")
    raise
```

## 8. 最佳实践

### 8.1 避免全局变量

#### 使用类属性或函数参数
```python
✅ 正确示例
class Config:
    _config = {}
    
    @classmethod
    def get(cls, key):
        return cls._config.get(key)

❌ 错误示例
config = {}

def get_config(key):
    return config.get(key)
```

### 8.2 使用上下文管理器

#### 资源管理
```python
✅ 正确示例
with open('file.txt', 'r') as f:
    content = f.read()

with Database.session() as session:
    session.add(project)
    session.commit()

❌ 错误示例
f = open('file.txt', 'r')
content = f.read()
f.close()

session = Database.session()
session.add(project)
session.commit()
session.close()
```

### 8.3 使用列表推导式

#### 简洁代码
```python
✅ 正确示例
active_projects = [p for p in projects if p.status == 'ACTIVE']

❌ 错误示例
active_projects = []
for p in projects:
    if p.status == 'ACTIVE':
        active_projects.append(p)
```
