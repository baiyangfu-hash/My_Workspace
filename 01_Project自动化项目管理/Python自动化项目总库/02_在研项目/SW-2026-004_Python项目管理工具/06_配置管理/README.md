# 配置管理

## 目录用途
本目录用于统一管理项目的全局配置文件、环境配置基线、配置变更记录等，确保多环境（开发/测试/交付）间配置的一致性和可追溯性。

## 当前状态
**占位中** — 配置文件当前分散在以下位置：

| 位置 | 文件 | 用途 |
|------|------|------|
| `03_主程序/01_主程序核心代码/config/` | app_config.json | 应用主配置（版本号/窗口设置等） |
| `03_主程序/01_主程序核心代码/config/` | database_config.json | 数据库连接配置 |
| `03_主程序/01_主程序核心代码/config/` | api_config.json | Flask API服务配置 |
| `03_主程序/01_主程序核心代码/config/` | spec_version_config.json | 规范版本映射配置 |
| `06_交付物/01_可执行文件/config/` | 同上4个JSON | 交付物运行时配置副本 |

## 配置一致性机制
- **版本同步**: `package.py` Phase 1 强制校验 version.py / 源码app_config.json / 交付物app_config.json 三方一致
- **打包复制**: `package.py` Phase 4 将源码 config/ 整体复制到交付物目录
- **运行时读取**: EXE模式优先读取自身目录下的 config/

## 后续规划
如需建立集中式配置管理中心（如多环境切换、配置加密、热更新等），可将配置文件统一迁移至此目录：

```
06_配置管理/
├── 01_开发环境/           # 开发环境专用配置
├── 02_测试环境/           # 测试环境专用配置
├── 03_交付环境/           # 交付物运行时配置
├── 04_配置基线/           # 各版本配置快照归档
└── 05_配置变更记录.md      # 配置修改审计日志
```
