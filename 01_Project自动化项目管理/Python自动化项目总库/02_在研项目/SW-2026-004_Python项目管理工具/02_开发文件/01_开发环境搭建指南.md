## 2. 快速开始（5分钟体验）

本节提供最简路径，让新开发者能在 5 分钟内看到程序运行效果。

### 2.1 获取代码

```bash
# 方式一：从仓库克隆（如果有远程仓库）
git clone <仓库地址>
cd SW-2026-004_Python项目管理工具

# 方式二：直接复制项目文件夹到本地工作目录
# 将项目文件夹复制到: D:\BaiduSyncdisk\My_Workspace\01_Project自动化项目管理\Python自动化项目总库\02_在研项目\
```

### 2.2 创建虚拟环境

```bash
# 进入主程序核心代码目录（这是项目的实际工作根目录）
cd 03_主程序/01_主程序核心代码

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate          # Windows PowerShell/CMD
# source venv/bin/activate      # Linux/macOS / WSL2
```

> **提示**: 激活成功后，终端提示符前会显示 `(venv)` 前缀。

### 2.3 安装依赖

项目已提供 `requirements.txt` 文件，包含所有必需的第三方依赖：

```bash
pip install -r requirements.txt
```

如果上述命令因网络问题失败，可使用国内镜像源：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**若 requirements.txt 不存在或需要手动安装核心依赖**:

```bash
pip install PyQt5 Flask SQLAlchemy PyInstaller openpyxl python-docx \
    Click pytest python-dotenv requests python-dateutil markdown networkx \
    bcrypt pydantic pydantic-settings dependency-injector alembic
```

### 2.4 配置环境变量

复制环境变量模板文件：

```bash
# Windows (PowerShell)
Copy-Item .env.example .env

# Windows (CMD)
copy .env.example .env

# Linux/macOS
cp .env.example .env
```

> **重要**: 生产环境部署前，务必修改 `.env` 文件中的 `API_SECRET_KEY` 为随机生成的安全密钥。

### 2.5 首次运行

```bash
# 确保虚拟环境已激活，且当前目录为 03_主程序/01_主程序核心代码
python main.py
```

**预期结果**:
- GUI 窗口弹出
- 标题栏显示 "Python项目管理工具" （具体版本号以实际为准）
- 主界面正常展示各功能模块

**如果启动成功，恭喜！开发环境已就绪。** 可以跳至 [第5节](#5-下一步) 继续了解项目。如果遇到问题，请继续阅读以下详细步骤和排查指南。

## 3. 详细安装步骤

### 3.1 Python 安装

#### 下载与安装

1. 访问 Python 官网: https://www.python.org/downloads/
2. 下载 **Python 3.14**（或 3.8+ 的任意稳定版本）
3. 运行安装程序，**务必勾选以下选项**:
   - [x] **Add Python to PATH** （将 Python 添加到系统环境变量）
   - [x] Install pip （通常默认勾选）
4. 选择 "Customize installation"，确保勾选:
   - pip
   - tcl/tk and IDLE
   - Python test suite
   - py launcher
   - for all users (requires admin privileges) -- 可选

#### 验证安装

打开新的终端窗口（PowerShell 或 CMD），执行：

```bash
python --version
# 预期输出: Python 3.14.x (或你安装的版本)

pip --version
# 预期输出: pip x.x.x from ...
```

> **注意**: 如果提示 `python` 不是内部命令，请尝试使用 `py` 命令（Windows Python Launcher），或重新安装 Python 并确保勾选 "Add Python to PATH"。

#### 多版本管理（可选）

如需在同一机器上管理多个 Python 版本，可考虑：
- **pyenv-win** (Windows): https://github.com/pyenv-win/pyenv-win
- **conda** (跨平台): https://docs.conda.io/

### 3.4 Windows 特殊配置

#### PyQt5 显示问题

如果 GUI 窗口无法正常显示或出现白屏：

```powershell
# 方法一：临时设置（当前终端有效）
$env:QT_QPA_PLATFORM="windows"

# 方法二：永久设置（系统环境变量）
# 右键"此电脑" -> 属性 -> 高级系统设置 -> 环境变量 -> 新建
# 变量名: QT_QPA_PLATFORM
# 变量值: windows
```

#### 中文显示乱码

如果终端或GUI中出现中文乱码：

```powershell
# 切换终端编码为 UTF-8
chcp 65001

# 在PowerShell中设置输出编码
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::InputEncoding = [System.Text.Encoding]::UTF8
```

或在 Python 代码执行前设置环境变量：

```powershell
$env:PYTHONIOENCODING="utf-8"
```

#### PyInstaller 打包权限

打包 EXE 时可能需要管理员权限：

```powershell
# 以管理员身份运行终端，然后执行
python build.py
# 或
pyinstaller Python项目管理工具.spec
```

#### 杀毒软件误报

PyInstaller 打包的程序可能被 Windows Defender 误报：
- 将 `dist/` 目录添加到杀毒软件排除列表
- 或将打包产物提交给 Microsoft 进行白名单审核

## 4. 常见问题排查

### 4.1 问题速查表

| 问题现象 | 可能原因 | 解决方案 |
|----------|---------|----------|
| `ModuleNotFoundError: No module named 'PyQt5'` | 未安装PyQt5或未激活虚拟环境 | 1. 确认虚拟环境已激活 (`venv\Scripts\activate`) <br> 2. 执行 `pip install PyQt5==5.15.10` |
| `sqlite3.OperationalError: unable to open database file` | data目录不存在或权限不足 | 首次运行程序会自动创建 `data/` 目录和数据库文件；如仍报错，手动创建 `data` 目录 |
| `ImportError: DLL load failed` | PyQt5与Python版本不匹配 | 重装PyQt5: `pip uninstall PyQt5 && pip install PyQt5==5.15.10` |
| 中文路径/文件名报错 | 编码问题 | 1. 终端执行 `chcp 65001` <br> 2. 设置 `$env:PYTHONIOENCODING="utf-8"` <br> 3. 避免项目路径中含中文和空格 |
| `PermissionError` | 文件被占用或权限不足 | 1. 关闭正在运行的程序实例 <br> 2. 以管理员身份运行终端 <br> 3. 检查文件是否被其他程序锁定 |
| PyInstaller hidden import警告 | 正常现象 | 可忽略；如需消除，编辑 `.spec` 文件添加到 `hiddenimports` 列表 |
| `pip install` 速度极慢或超时 | 网络问题 | 使用国内镜像: `pip install xxx -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `virtualenv` 创建失败 | Python安装不完整 | 重新运行Python安装程序，确保勾选 "pip" 和 "python launcher" |
| 启动后GUI无响应/卡死 | 数据库锁定或资源冲突 | 1. 检查是否有另一实例在运行 <br> 2. 删除 `data/project_manager.db-journal` 文件 <br> 3. 重启程序 |
| Flask API无法访问 | 端口被占用或防火墙拦截 | 1. 检查端口5000是否被占用: `netstat -ano \| findstr 5000` <br> 2. 防火墙放行该端口 |

### 4.2 诊断步骤

当遇到无法定位的问题时，按以下顺序排查：

```bash
# 第一步：检查Python版本
python --version

# 第二步：检查虚拟环境是否激活
where python
# 应显示: ...venv\Scripts\python.exe

# 第三步：检查关键依赖是否安装
pip list | findstr -i "pyqt5 flask sqlalchemy"

# 第四步：检查工作目录
cd
# 应显示: ...\03_主程序\01_主程序核心代码

# 第五步：查看详细错误信息
python main.py 2>&1
# 注意终端输出的完整 Traceback 信息

# 第六步：检查日志文件
type data\logs\app.log
```

### 4.3 完全重置环境

如果上述方法均无效，可尝试完全重置：

```bash
# 1. 删除旧虚拟环境
Remove-Item -Recurse -Force venv

# 2. 重新创建虚拟环境
python -m venv venv
venv\Scripts\activate

# 3. 升级pip
python -m pip install --upgrade pip

# 4. 清理pip缓存
pip cache purge

# 5. 重新安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 6. 尝试运行
python main.py
```
