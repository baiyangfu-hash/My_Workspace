# 代码结构说明

## 1. 项目总览

### 1.1 一句话描述
Python自动化项目管理工具 — 一个基于 PyQt5 + Flask + SQLAlchemy 的桌面应用，支持自动化项目的全生命周期管理。

### 1.2 技术栈
| 层次 | 技术 | 说明 |
|------|------|------|
| GUI前端 | PyQt5 | 桌面窗口、对话框、表格 |
| 后端API | Flask | RESTful接口（预留） |
| ORM | SQLAlchemy | 数据库操作 |
| 数据库 | SQLite | 轻量级嵌入式 |
| 打包 | PyInstaller | 单EXE分发 |
| 自动化 | package.py | 一键打包脚本 |

## 11. 开发指南快速参考

### 11.1 新增功能的标准流程
1. 在 `.trae/specs/` 创建新spec目录（spec.md + tasks.md + checklist.md）
2. 在对应层添加代码：
   - Model: `src/models/xxx.py` (如果需要新表)
   - DAO: `src/dao/xxx_dao.py` (数据访问)
   - Service: `src/services/xxx_service.py` (业务逻辑)
   - UI Widget: `src/ui/widgets/xxx.py` (界面组件)
3. 在 `MainWindow` 中注册新的Tab页
4. 更新 `config/app_config.json` (如需要)
5. 执行测试: `python -m pytest tests/`
6. 打包: `python package.py`

### 11.2 常用命令
```bash
# 启动GUI
cd 03_主程序/01_主程序核心代码
python main.py

# 启动API服务
python app.py

# 运行测试套件
python -m pytest tests/ -v

# 一键打包
python package.py

# 数据库迁移
alembic upgrade head
```
