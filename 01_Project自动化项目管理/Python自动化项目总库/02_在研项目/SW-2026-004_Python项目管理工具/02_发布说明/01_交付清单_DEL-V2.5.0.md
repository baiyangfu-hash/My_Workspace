## 二、本版本变更概述

### 2.1 核心功能增强

#### ✅ 变更管理目录结构标准化（对齐 06_项目模板规范）

- **问题**: 旧版本使用 `CHG-{DOMAIN}/` 领域子目录存放变更单，不符合规范
- **改进**: 统一改为扁平结构，变更单直接存放在 `01_变更单/` 目录下
- **影响范围**:
  - [constants.py](file:///d:/BaiduSyncdisk/My_Workspace/01_Project自动化项目管理/Python自动化项目总库/02_在研项目/SW-2026-004_Python项目管理工具/03_主程序/01_主程序核心代码/src/core/constants.py) (DEFAULT_TEMPLATES 全量重构)
  - [change_service.py](file:///d:/BaiduSyncdisk/My_Workspace/01_Project自动化项目管理/Python自动化项目总库/02_在研项目/SW-2026-004_Python项目管理工具/03_主程序/01_主程序核心代码/src/services/change_service.py) (export_change, generate_ledger)
  - [project_service.py](file:///d:/BaiduSyncdisk/My_Workspace/01_Project自动化项目管理/Python自动化项目总库/02_在研项目/SW-2026-004_Python项目管理工具/03_主程序/01_主程序核心代码/src/services/project_service.py) (新增初始化逻辑)

#### ✅ 新建项目自动初始化变更管理

- **新增功能**: 使用任意模板创建新项目时，自动生成：
  - 完整的变更管理目录结构（01+03+04）
  - 空白台帐文件（符合 CHG-V2.1.0 规范）
  - README 说明文档
  - .gitkeep 占位文件
- **智能识别**: 根据模板类型自动判断是否创建 `03_变更管理规范/` 目录

#### ✅ 内置模板定义全量对齐

- **TPL-FULLLINE-AUTO-001**: 升级至 V3.0.0，移除7个CHG-*子目录，采用扁平结构
- **TPL-SINGLE-ROBOT-001**: 同上
- **TPL-SINGLE-PLC-001**: 确定为 S001 精简版（无03_变更管理规范/）
- **TPL-UPGRADE-STD-001**: 路径标准化
- **TPL-UPPER-STD-001**: 升级至 V3.0.0，支持双重变更管理（标准+软件专用）

### 2.2 技术改进细节

| 改进项 | 修改前 | 修改后 | 规范依据 |
|--------|--------|--------|----------|
| 变更单存储路径 | `.../CHG-PLC/{id}.md` | `.../040_{code}_变更单{seq}_CHG-V2.0.0.md` | 06规范 §2.1 |
| 台帐存储路径 | `.../{name}_版本变更台帐.md` | `.../04_变更记录/041_{code}_版本变更台帐_CHG-V2.1.0.md` | TPL-UPPER-STD-001 |
| 变更单命名 | `{change_id}.md` | `040_{code}_变更单 XXX_CHG-V2.0.0.md` | 变更管理映射文档 |
| 台帐超链接 | `./CHG-{domain}/{id}.md` | `../01_变更单/040_xxx.md` | 相对路径修正 |
| 初始化时机 | 首次创建变更单时 | 项目创建时立即初始化 | 最佳实践 |

### 2.3 Breaking Changes

⚠️ **重要提示**: 本次更新包含以下不兼容变更（仅影响新建项目）：

| 变更项 | 影响 | 兼容性方案 |
|--------|------|-----------|
| 变更单路径格式 | 仅影响**新建项目**；已有项目的旧结构不受影响 | 已有项目可继续使用旧路径，或手动迁移 |
| 台帐路径迁移 | 同上 | 同上 |

**向后兼容性**: ✅ 完全向后兼容（运行时不强制迁移旧项目）
