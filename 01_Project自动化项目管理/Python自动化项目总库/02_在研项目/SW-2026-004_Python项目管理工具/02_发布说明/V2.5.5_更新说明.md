#### [BugFix] 2. 总库管理多项 Bug 修复（数据显示 + 状态同步）

**问题描述 A：总库项目列表数据显示异常**

**现象描述**：
- 总库管理界面的项目列表在某些操作后出现数据重复或丢失
- 项目状态图标与实际状态不一致
- 列表滚动后部分行数据错位

**根因分析**：
1. 数据模型层（DAO）的查询结果缓存未在数据变更时及时失效
2. GUI 层的列表模型（QAbstractTableModel）未正确实现 `dataChanged` 信号通知
3. 多线程环境下存在竞态条件（后台统计线程与UI刷新线程冲突）

**修复方案**：

```python
# 1. 缓存失效策略优化 (library_dao.py)
def invalidate_cache(self, library_id: int = None):
    """精确失效指定总库或全部缓存"""
    if library_id:
        self._cache.pop(f"projects_{library_id}", None)
    else:
        self._cache.clear()

# 2. GUI 数据同步强化 (library_dashboard.py)
def on_project_data_changed(self):
    """数据变更时强制刷新列表"""
    self.model.beginResetModel()
    self._load_projects()
    self.model.endResetModel()
    # 显式触发排序和过滤重新计算
    self.proxy_model.invalidate()

# 3. 线程安全保护
self._data_lock = QReadWriteLock()  # 读写锁保护共享数据
```

**验证结果**：✅ 数据显示一致性问题已解决

---

**问题描述 B：总库状态同步延迟**

**现象描述**：
- 项目状态变更后，总库概览面板的统计数据延迟更新（需手动刷新）
- 新建/删除项目后，项目总数计数器不准确
- 在多窗口场景下，各窗口显示的状态不同步

**修复方案**：
1. 引入观察者模式（Observer Pattern）：状态变更时自动通知所有订阅者
2. 统计数据计算改为事件驱动（而非定时轮询）
3. 新增跨窗口信号广播机制（基于 Qt 的信号槽机制）

```python
# 观察者模式实现示例
class LibraryStateNotifier(QObject):
    """总库状态变更通知中心"""
    project_added = Signal(int)       # 参数: project_id
    project_updated = Signal(int)     # 参数: project_id
    project_deleted = Signal(int)     # 参数: project_id
    stats_changed = Signal()          # 无参数，触发全量统计刷新
```

**验证结果**：✅ 状态同步实时性显著提升
