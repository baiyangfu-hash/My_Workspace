#### 4. 版本号首次统一至三处一致

**背景与问题描述**：

在之前的版本迭代中，版本号散布在多个位置，且存在不一致的情况：
- `src/core/version.py` 中的 `__version__` 变量
- `config/app_config.json` 中的 `version` 字段
- GUI 窗口标题栏读取的版本号
- 交付物中 `app_config.json` 的 `version` 字段

这导致用户在 GUI 上看到的版本号可能与实际打包版本不符，造成困惑。

**本版本解决方案**：

建立"三处一致性"原则，确保以下三个位置的版本号 **必须完全一致**：

| 优先级 | 位置 | 文件路径 | 说明 |
|--------|------|----------|------|
| P0 (权威源) | version.py | `src/core/version.py` | 版本号的唯一权威来源 |
| P1 (同步目标) | app_config.json (源码) | `config/app_config.json` | 从 version.py 同步 |
| P2 (同步目标) | app_config.json (交付物) | `06_交付物/01_可执行文件/config/app_config.json` | 打包前同步 |

**同步流程**：

```
开发阶段:
  修改 version.py → __version__ = "2.5.6"
      ↓ (自动或手动)
  同步 config/app_config.json → "version": "2.5.6"

打包阶段:
  执行 build.py / PyInstaller 打包
      ↓ (自动复制)
  同步到 06_交付物/.../app_config.json → "version": "2.5.6"
      ↓ (GUI读取)
  标题栏显示: "Python项目管理工具 v2.5.6"  ← 三处一致 ✅
```

**验证方法**：
```powershell
# 一致性快速验证命令
$pyVer = Select-String -Path "src\core\version.py" -Pattern '__version__' | ForEach { $_.Line.Trim() }
$jsonVer = Get-Content "config\app_config.json" | ConvertFrom-Json | Select -ExpandProperty version
Write-Host "version.py: $pyVer"
Write-Host "app_config.json: $jsonVer"
# 两者应输出相同版本号
```
