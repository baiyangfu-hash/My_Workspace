## 🎯 主要更新内容

### 1. 🔄 变更管理目录结构标准化 (核心变更)

#### 背景
旧版本的变更单管理使用按领域分类的子目录结构（如 `CHG-PLC/`, `CHG-ELEC/` 等），但根据最新的 Obsidian 项目模板规范（06_项目模板规范），应采用**扁平化存放方式**。

#### 变更对比

**❌ 旧结构 (V2.4.x)**:
```
00_项目管理/04_变更管理/
└── 01_变更单/
    ├── CHG-PLC/
    │   ├── CHG-001.md
    │   └── CHG-002.md
    ├── CHG-ELEC/
    │   └── CHG-003.md
    └── ... (其他7个领域子目录)
```

**✅ 新结构 (V2.5.0)**:
```
00_项目管理/04_变更管理/
├── 01_变更单/                    # 扁平结构！
│   ├── 040_SW-2026-001_变更单 001_CHG-V2.0.0.md
│   ├── 040_SW-2026-001_变更单 002_CHG-V2.0.0.md
│   └── .gitkeep
├── 03_变更管理规范/              # 可选（完整版模板）
│   └── 042_xxx_变更管理流程规范_PM-V2.0.0.md
└── 04_变更记录/                  # 必须存在
    └── 041_SW-2026-001_版本变更台帐_CHG-V2.1.0.md
```

#### 好处

- ✅ 符合最新 Obsidian 规范标准
- ✅ 文件查找更直观（按序号排列）
- ✅ 避免领域分类的歧义和复杂性
- ✅ 与其他项目管理工具的输出格式一致

---

### 2. ✨ 新建项目自动初始化变更管理

#### 新功能描述
在 V2.5.0 中，当您使用任意内置模板创建新项目时，系统会**自动**完成以下初始化工作：

**自动生成的文件清单**:

| 文件 | 用途 | 是否必需 |
|------|------|:-------:|
| `01_变更单/.gitkeep` | 保持目录结构（Git提交空目录用） | ✅ 必须 |
| `04_变更记录/041_{code}_版本变更台帐_CHG-V2.1.0.md` | 空白台帐（含V1.0.0初始行） | ✅ 必须 |
| `README.md` | 变更管理目录使用说明 | ✅ 推荐 |
| `03_变更管理规范/` 目录 | 存放流程规范文件 | ⚠️ 可选（完整版模板） |

**智能区分模板类型**:
- **完整版模板** (FULLLINE, ROBOT, UPGRADE, UPPER): 自动创建 `03_变更管理规范/` 目录
- **精简版模板** (SINGLE-PLC-S001): 不创建该目录（简化结构）

### 4. 🔧 文件命名规则统一

新的标准化命名规则：

| 文件类型 | 格式 | 示例 |
|---------|------|------|
| 变更单 | `040_{code}_变更单 {seq:03d}_CHG-V2.0.0.md` | `040_SW-2026-001_变更单 001_CHG-V2.0.0.md` |
| 台帐 | `041_{code}_版本变更台帐_CHG-V2.1.0.md` | `041_SW-2026-001_版本变更台帐_CHG-V2.1.0.md` |
| 流程规范 | `042_{code}_变更管理流程规范_PM-V2.0.0.md` | `042_SW-2026-001_变更管理流程规范_PM-V2.0.0.md` |

**编号前缀含义**:
- `040-`: 变更单据（Order）
- `041-`: 变更记录/台帐（Record）
- `042-`: 流程规范（Specification）

## 📋 使用指南

### 场景1: 使用新模板创建项目

1. 启动 Python项目管理工具
2. 点击「新建项目」
3. 选择任意内置模板（建议选择 TPL-UPPER-STD-001 体验最完整的功能）
4. 填写项目信息并确认创建
5. 打开项目目录 → `00_项目管理/04_变更管理/` → 您将看到完整的初始结构！

### 场景2: 在新项目中创建变更单

1. 进入项目详情页
2. 点击「变更管理」→「新建变更单」
3. 填写变更信息并保存
4. 系统自动导出变更单到 `01_变更单/` 目录
5. 文件名示例：`040_您的项目代码_变更单 001_CHG-V2.0.0.md`

### 场景3: 查看和更新台帐

1. 在变更管理页面点击「更新台帐」
2. 台帐文件自动生成/刷新到 `04_变更记录/` 目录
3. 打开台帐文件查看变更历史统计
4. 台帐中的超链接可直接跳转到对应的变更单文件

## 🔄 迁移指南（可选）

> **注意**: 此步骤仅适用于希望将**已有项目**迁移到新结构的用户。如果不迁移，旧项目可以继续正常使用。

### 手动迁移步骤

如果您有一个使用旧结构（V2.4.x及之前）创建的项目，想要迁移到新的扁平结构：

1. **备份原项目**（重要！）
2. 进入 `00_项目管理/04_变更管理/01_变更单/` 目录
3. 将各 `CHG-*/` 子目录下的 `.md` 文件移动到 `01_变更单/` 根目录
4. （可选）按新规则重命名文件：`040_{code}_变更单{seq}_CHG-V2.0.0.md`
5. 删除空的 `CHG-*/` 子目录
6. 在 `04_变更管理/` 下创建 `04_变更记录/` 目录
7. 将原有的台帐文件移动到该目录并重命名
8. 验证超链接是否有效

**或者**: 直接使用新模板创建一个新项目，然后将业务数据迁移过去（推荐）。
