### CHK-P0-001: _resolve_template_path() 函数存在性

**测试方法**: 代码静态分析

**预期结果**: `project_service.py` 中存在 `_resolve_template_path()` 静态方法

**实际结果**: ✅ 通过

**证据**:
- 文件: [`src/services/project_service.py`](../03_主程序/01_主程序核心代码/src/services/project_service.py)
- 位置: 第27-47行
- 实现: 使用 `@staticmethod` 装饰器，参数为 `(file_def: dict, template_vars: dict)`
- 返回值: `Path` 对象

**代码片段**:
```python
@staticmethod
def _resolve_template_path(file_def: dict, template_vars: dict) -> Path:
    """解析模板文件路径，替换其中的占位符"""
    raw_path = file_def.get("path", "")
    resolved_path = raw_path
    for var_name, var_value in template_vars.items():
        placeholder = f"{{{var_name}}}"
        if placeholder in resolved_path:
            resolved_path = resolved_path.replace(placeholder, str(var_value))
    return Path(resolved_path)
```

### CHK-P0-004: 占位符替换算法正确性

**测试方法**: 算法逻辑审查

**预期结果**: 能正确处理所有标准模板变量（project_code, project_name, business_line, current_date 等）

**实际结果**: ✅ 通过

**算法分析**:
```python
# 算法流程:
1. 获取原始路径: raw_path = file_def.get("path", "")
2. 遍历所有模板变量:
   for var_name, var_value in template_vars.items():
       placeholder = f"{{{var_name}}}"  # 构造 {var_name} 格式
       if placeholder in resolved_path:  # 检查是否存在
           resolved_path = resolved_path.replace(placeholder, str(var_value))  # 替换
3. 返回 Path 对象
```

**边界条件覆盖**:
- ✅ 路径含单个占位符: `{project_code}/docs/README.md`
- ✅ 路径含多个占位符: `{project_code}_{current_date}.md`
- ✅ 路径不含占位符: `.gitignore`, `README.md` (无副作用)
- ✅ 空路径处理: `file_def.get("path", "")` 默认空字符串
