## 发现的问题和修复

### 1. 项目创建失败 - `name 'func' is not defined` 错误
- **问题原因**: `project_dao.py` 文件中使用了 `func.max()` 函数但没有导入 `func`
- **修复方案**: 在 `project_dao.py` 文件中添加 `from sqlalchemy import func` 导入语句
- **修复结果**: ✅ 已修复，项目创建功能恢复正常

### 2. 版本更新
- **更新内容**: 将版本从 1.0.5 更新到 1.0.6
- **更新原因**: 包含了对 `func` 导入问题的修复
- **更新结果**: ✅ 版本更新成功
