### 根因 #1: 模板定义不完整 ⭐⭐⭐⭐⭐ (主要)

**位置**: [constants.py#L364-L489](src/core/constants.py#L364-L489) - `TPL-PLC-STD-001`

**问题描述**:
DJ项目使用的是 `TPL-PLC-STD-001` (PLC标准版) 模板，该模板存在严重的**结构-内容不匹配**问题:

```python

    "id": "TPL-PLC-STD-001",
    "business_lines": ["DJ", "ZD"],  # ✅ 支持DJ业务线
    
    "structure": [  # 定义了 38 个目录
        "00_项目概述",
        "01_电气设计/...",
        "02_PLC程序/...",
        ... (共38个)
    ],
    
    "templates": [  # 只定义了 15 个文件模板！
        "00_项目概述/00_项目立项表.md",
        "00_项目概述/01_需求分析文档.md",
        ... (共15个)
    ]
}
```

**数学计算**:
- 目录总数: 38个
- 文件模板数: 15个
- **覆盖率**: 15/38 = **39.5%**
- **空壳率预期**: 60.5%

**实际空壳率**: 77.6% (高于预期，因为DJ项目还手动扩展了11个目录)

### 方案B: 自动生成README机制 ⭐⭐⭐⭐

**实现思路**:
在 [project_service.py#L168](src/services/project_service.py#L168) 之后增加:

```python
# 为没有文件的目录自动生成README
for dir_def in template.structure:
    dir_path = project_path / dir_def["path"]
    
    # 检查目录是否为空（排除.gitignore等配置文件）
    existing_files = [f for f in dir_path.iterdir() 
                     if f.is_file() and f.name != '.gitignore']
    
    if not existing_files and dir_path.exists():
        readme_path = dir_path / "README.md"
        readme_content = f"""# {dir_def['description']}

## 目录说明
- 用途: {dir_def['description']}
- 状态: 待填充

## 文件清单
(暂无文件)

---
**生成时间**: {datetime.now().strftime('%Y-%m-%d %H:%M')}
**所属项目**: {project_code}
"""
        with open(readme_path, 'w', encoding='utf-8') as f:
            f.write(readme_content)
        logger.info(f"自动生成README: {readme_path}")
```

**优点**:
- 立即解决所有空壳问题
- 不需要大量编写模板内容
- 用户可以基于README快速开始工作

**缺点**:
- README内容较简单，不如专业模板有价值
- 需要用户后续手动完善

### 方案C: 分层模板策略 ⭐⭐⭐

**思路**: 将模板分为三层:

1. **必填层 (Core)** - 项目必须的核心文档 (~10个)
   - 立项表、需求文档、变更台帐、验收报告

2. **推荐层 (Recommended)** - 推荐使用的文档 (~25个)
   - IO分配表、程序说明、操作手册、维护手册

3. **可选层 (Optional)** - 按需生成的文档 (~20个)
   - 调试笔记、最佳实践、避坑指南

**实现方式**:
在创建项目时提供选项:
```python
def create_project(..., template_level="recommended"):
    """
    template_level:
    - "core": 只生成必填层 (10个文件)
    - "recommended": 必填+推荐 (35个文件) ← 默认
    - "full": 全部生成 (55个文件)
    """
```
