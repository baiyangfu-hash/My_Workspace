## 背景与上下文
Python项目管理工具是一个用于创建和管理项目的工具，通过提供不同类型的模板来快速搭建项目结构。用户在创建新项目时可以选择不同的模板，这些模板定义了项目的目录结构和初始文件。

### 模板管理机制
1. 模板定义在 `DEFAULT_TEMPLATES` 常量中
2. 程序启动时通过 `TemplateService.initialize_builtin_templates()` 方法初始化到数据库
3. 模板包含ID、名称、版本、编译器、场景、目录结构和文件模板等信息

### 可用模板类型
1. **TPL-001**: Python标准版（精简）- 10个核心目录，适合<3个月项目
2. **TPL-002**: Python标准版（完整）- 40+目录，适合>3个月项目
3. **TPL-003**: Python+PyQt5 GUI版 - 包含UI目录结构、资源文件目录
4. **TPL-PLC-STD-001**: PLC标准版 - 符合PLC项目结构模板规范
5. **TPL-PLC-AUTO-001**: 自动化整线版 - 包含多PLC程序、HMI、上位机完整结构
6. **TPL-PLC-HMI-001**: PLC+上位机版 - 包含PLC程序和Python上位机程序
7. **TPL-DJ-STD-001**: 单机设备标准版 - 包含机械设计、电气设计、控制程序完整结构
8. **TPL-XT-STD-001**: 系统升级版 - 包含现状分析、升级方案、回滚方案完整结构
9. **TPL-WX-STD-001**: 维保项目版 - 包含维保计划、维保记录、备件管理完整结构
10. **TPL-PY-WEB-001**: Python Web版 - 包含前后端目录结构、API接口定义

### 模板文件结构
每个模板包含以下信息：
- `id`: 模板唯一标识
- `name`: 模板名称
- `version`: 模板版本
- `compiler`: 适用编译器（可选）
- `scene`: 适用场景
- `description`: 模板描述
- `is_builtin`: 是否为内置模板
- `structure`: 项目目录结构
- `templates`: 模板文件列表
- `business_lines`: 适用业务线（可选）

### 模板文件类型
模板文件包括：
- Markdown文档（.md）
- Python代码文件（.py）
- 配置文件（.txt, .json）
- 数据文件（.csv）

## 结论
Python项目管理工具的模板文件存储在 `src/core/constants.py` 文件中，通过 `DEFAULT_TEMPLATES` 常量定义。这些模板在程序启动时初始化到数据库中，供用户创建项目时选择使用。模板涵盖了多种项目类型，包括Python开发、PLC自动化、设备管理、系统升级和维保项目等。

## 建议
1. 如需修改模板内容，可直接编辑 `constants.py` 文件中的 `DEFAULT_TEMPLATES` 常量
2. 如需添加新模板，可在 `DEFAULT_TEMPLATES` 列表中添加新的模板定义
3. 模板修改后需要重新启动程序以初始化到数据库

## 注意事项
- 内置模板不可通过界面修改，只能通过修改代码进行更改
- 模板文件中的变量（如 `{project_name}`, `{project_code}` 等）会在创建项目时被实际值替换
- 模板的目录结构和文件会根据业务线和项目类型进行调整
