# V2.5.1 交付物问题修复与功能增强 Spec

## Overview
- **Summary**: 修复 V2.5.0 交付物的三个关键问题（项目数显示异常、模板未更新、版本显示问题），并增强版本管理功能
- **Purpose**: 确保交付物在所有环境中正常运行，提升用户体验
- **Target Users**: Python项目管理工具的使用者

## Goals
- 修复总库管理模块项目数显示为0的问题
- 确保模板定义在交付物中正确更新到位
- 修复版本显示异常问题
- 增强版本记录功能，添加软件更新记录查看

## Non-Goals (Out of Scope)
- 不修改项目核心业务逻辑
- 不重新设计整体架构
- 不添加新的业务功能

## Background & Context
用户在 `管理工具测试/问题点.md` 中反馈了以下问题：
1. 总库管理模块：新建的测试项目存在，但是总览项目数位0
2. 模板管理：版本2.5.0的模板未更新到位，至少交付物在其他电脑上运行时没有
3. 交付物版本显示：2.5.0的交付物显示有问题，需要增加版本的记录的功能

## Functional Requirements
- **FR-1**: 修复总库管理模块项目数显示为0的问题
- **FR-2**: 确保模板定义在交付物中正确更新
- **FR-3**: 修复版本显示异常问题
- **FR-4**: 增加版本记录功能，允许用户查看软件更新记录

## Non-Functional Requirements
- **NFR-1**: 交付物必须在不同电脑上正常运行
- **NFR-2**: 修复后版本必须正确显示为 V2.5.1
- **NFR-3**: 版本记录功能必须简洁明了

## Constraints
- **Technical**: 基于现有的 PyInstaller 打包流程
- **Business**: 保持与现有版本的兼容性
- **Dependencies**: 依赖现有的项目结构和配置

## Assumptions
- 项目数显示问题可能是数据库连接或查询逻辑问题
- 模板未更新问题可能是打包时文件未正确包含
- 版本显示问题可能是配置文件或显示逻辑问题

## Acceptance Criteria

### AC-1: 项目数显示修复
- **Given**: 用户打开总库管理模块
- **When**: 系统加载项目列表
- **Then**: 显示正确的项目数量（大于0）
- **Verification**: `programmatic`

### AC-2: 模板更新验证
- **Given**: 用户在其他电脑上运行 V2.5.1 交付物
- **When**: 创建新项目时选择模板
- **Then**: 显示最新的模板定义（包含变更管理目录结构）
- **Verification**: `programmatic`

### AC-3: 版本显示修复
- **Given**: 用户查看软件版本信息
- **When**: 系统显示版本号
- **Then**: 正确显示为 "V2.5.1"
- **Verification**: `programmatic`

### AC-4: 版本记录功能
- **Given**: 用户打开版本记录功能
- **When**: 系统加载更新记录
- **Then**: 显示完整的版本更新历史
- **Verification**: `human-judgment`
