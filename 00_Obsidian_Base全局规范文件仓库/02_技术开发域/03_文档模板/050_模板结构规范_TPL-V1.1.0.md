## 3. 模板结构统一标准

### 3.1 基本结构

所有模板必须包含以下基本结构：

1. **文档基础信息**：包含文档标题、版本、编制日期、编制人、审核人
2. **版本变更记录**：记录版本变更历史
3. **核心内容**：根据模板类型确定的具体内容
4. **附录**：参考资料、术语定义等

#### 3.1.1 文档基础信息标准格式

文档基础信息 SHALL 使用以下标准 Markdown 表格格式：

```markdown
## 文档基础信息

| 属性 | 值 |
|------|-----|
| **文档标题** | [文档完整名称] |
| **文档版本** | Vx.y.z |
| **编制日期** | YYYY-MM-DD |
| **编制人** | [姓名] |
| **审核人** | [待审核/姓名] |
| **遵循规范** | [引用的相关规范编号和版本] |
```

**字段说明**：
| 字段 | 必填 | 说明 |
|------|------|------|
| 文档标题 | ✅ | 文档的完整名称 |
| 文档版本 | ✅ | 遵循语义化版本号（V MAJOR.MINOR.PATCH） |
| 编制日期 | ✅ | 文档创建或最后修订日期（YYYY-MM-DD 格式） |
| 编制人 | ✅ | 文档主要编写者 |
| 审核人 | ✅ | 文档审核者（未审核时可填 `[待审核]`） |
| 遵循规范 | 推荐 | 本文档遵循的全局规范编号列表 |

### 3.2 标题层级

统一使用以下标题层级：

- `#`：一级标题（文档标题）
- `##`：二级标题（主要章节）
- `###`：三级标题（子章节）
- `####`：四级标题（详细子章节）

### 3.3 编号规范

统一使用阿拉伯数字编号：

- 一级章节：1. 2. 3. ...
- 二级章节：1.1 1.2 1.3 ...
- 三级章节：1.1.1 1.1.2 1.1.3 ...
- 四级章节：1.1.1.1 1.1.1.2 1.1.1.3 ...

### 3.4 表格格式

统一表格格式：

- 使用Markdown表格语法
- 表头居中对齐
- 内容左对齐
- 表格边框样式统一

### 3.5 代码块格式

统一代码块格式：

- 使用```语言```标记代码块
- 代码缩进统一
- 代码注释规范

### 3.6 链接格式

统一链接格式：

- 相对路径使用一致的格式
- 超链接文本简洁明了
- 版本号链接指向具体版本

### 3.7 版本号格式

统一版本号格式：

- 格式：V1.0.0
- 遵循语义化版本规范
- 主版本号：重大变更
- 次版本号：功能添加
- 补丁版本号：错误修复

### 4.4 PLC 项目文档模板

**适用场景**：IEC 61131-3 标准 PLC 程序开发项目（含西门子/三菱/欧姆龙等平台）

#### 4.4.1 必选文档清单（6种）

| 序号 | 文档类型 | 前缀码 | 模板来源 | 核心章节 |
|------|----------|--------|----------|----------|
| 1 | PLC变量定义文档 | VAR | 自定义模板 | IO分配表(DI/DO/M/D区)、功能块接口说明、工站间协调信号 |
| 2 | 程序架构文档 | ARC | 基于4.1技术文档 | 系统架构图(Mermaid)、组件清单、数据流说明、调用关系 |
| 3 | 详细设计说明书 | DSN | 基于021详细设计说明书 | 功能需求→设计映射、各工站状态机设计、接口定义 |
| 4 | 报警码定义 | ALM | 自定义模板 | 报警码列表、触发条件、处理建议、数据流(D400/D402/D404) |
| 5 | FBD使用说明 | FBD | 自定义模板 | FB接口ASCII图、针脚说明表、调用示例、关联文档索引 |
| 6 | IO分配表 | IO | 可并入VAR文档 | 物理地址→逻辑变量映射（X/Y/M/D区完整分配） |

#### 4.4.2 PLC文档通用结构要求

所有PLC项目文档除满足 §3.1 基本结构外，还应遵循以下约定：

1. **变量命名一致性**：文档中所有变量名必须与ST代码中的声明完全一致（遵循 801_PLC变量命名与功能块命名规范）
2. **FB名称一致性**：文档中所有功能块名必须与ST代码中的声明完全一致（遵循 `FB_编号_英文功能描述_设备对象` 格式）
3. **物理地址标注**：IO相关文档中必须标注物理地址（如 `%IX0`、`%QX0`、`M0.0`、`D400`）
4. **交叉引用有效性**：文档间的超链接必须指向正确的文件路径（含版本号后缀）
5. **架构同步**：程序架构文档中的组件清单必须与实际代码文件一一对应

#### 4.5 PLC ST程序模板结构强制要求 (DEV-V1.1.0 新增)

**适用范围**：所有基于IEC 61131-3标准的ST语言PLC程序文件(.st/.scl/.txt)

##### 4.5.1 FB标准化文件头必填项

每个功能块(FB)或程序(PRG)文件必须包含以下8个必填字段：

| 序号 | 字段名 | 必填 | 格式要求 | 示例 |
|:---:|--------|:---:|---------|------|
| 1 | 功能块名称 | ✅ | `FB_编号_英文功能描述_设备对象` | FB_1001_Conveyor4Layer_BufferFraming |
| 2 | 功能描述 | ✅ | 简洁说明核心功能(≤30字) | 四层输送机边框缓存控制 |
| 3 | 版本号 | ✅ | V主版本.次版本.修订号 | V4.1.0 |
| 4 | 创建人/修改人 | ✅ | 姓名 | Trae |
| 5 | 遵循规范 | ✅ | 规范编号+版本 | 801_V1.0.5 / 810_V1.0.4 |
| 6 | 工艺对象 | ✅ | 设备/工位名称 | 边框缓存机·四层输送机 |
| 7 | 架构特点 | 推荐 | 关键设计决策 | 三层解耦/纯逻辑FB/Region标记 |
| 8 | 变更记录 | ✅ | 版本-日期-变更内容-变更人 | 见下方示例 |

**标准文件头格式示例**：
```pascal
(* ================================================================= *)
(*  功能块名称：FB_1001_Conveyor4Layer_BufferFraming                *)
(*  功能描述：四层输送机边框缓存控制                                 *)
(*  版本号：V4.1.0                                                  *)
(*  创建人：Trae                                                    *)
(*  遵循规范：801_V1.0.5 / 810_V1.0.4                               *)
(*  工艺对象：边框缓存机·四层输送机                                   *)
(*  架构特点：三层解耦架构 / Region标记体系 / 定时器简化命名         *)
(*  变更记录：                                                        *)
(*    - V4.1.0 (2026-04-25) Trae: 初始创建,基于023模板V2.0          *)
(* ================================================================= *)
```

##### 4.5.2 Region标记编号体系强制要求

所有ST程序文件必须使用以下 standardized Region 编号体系：

| 编号段 | 区域名称 | 用途说明 | 适用位置 | 典型内容 |
|:-----:|---------|---------|---------|----------|
| **100** | VAR_INPUT | 输入变量声明 | PRG/FB顶部 | 系统控制、工艺参数、传感器输入 |
| **200** | VAR_OUTPUT | 输出变量声明 | PRG/FB顶部 | 执行器请求、下游信号、状态显示 |
| **300** | VAR | 内部变量/静态变量 | PRG/FB内部 | 状态机核心、定时器、系统变量 |
| **400** | VAR_CONSTANT | 常量定义 | PRG/FB顶部 | 步序常量、报警码常量、定时参数 |
| **500** | 主程序逻辑 | 调度与主流程 | PRG_Main | 使能处理、初始化、模式分发、状态汇总 |
| **600** | 自动状态机 | CASE自动运行逻辑 | 业务FB内部 | 各步骤的状态转换与动作输出 |
| **700** | 手动控制 | JOG/手动操作逻辑 | 业务FB内部 | 伺服点动、气缸手动操作 |
| **800** | 输入分发 | IO→FB映射 | PRG_Main | 公共信号、手动操作、传感器信号分发 |
| **900** | 输出收集 | FB→IO映射 | PRG_Main | 执行器输出、下游信号、步序收集 |

**使用语法**（支持IEC 61131-3和三菱扩展）：
```pascal
//#region 100_VAR_INPUT 输入变量声明
    (* 系统控制信号 *)
    i_bSystemEnable     : BOOL;   (* 系统使能信号 *)
    i_bEmgStop          : BOOL;   (* 急停信号 *)
//#endregion

//#region 600_自动状态机 AutoStateMachine
CASE nAutoStep OF
    0:
        (* 步骤0: 等待启动 *)
        IF bStartCondition THEN
            nAutoStep := 10;
        END_IF;
    10:
        (* 步骤10: 执行动作 *)
        ...
END_CASE;
//#endregion
```

##### 4.5.3 变量声明区顺序要求

**强制顺序**（从上到下）：

```
┌─────────────────────────────────────┐
│  1. VAR_INPUT      (输入参数)       │  ← 必须第一
│  2. VAR_OUTPUT     (输出参数)       │  ← 第二
│  3. VAR            (内部静态变量)   │  ← 第三
│   3.1 VAR_STATIC   (静态保持变量)   │  ← 状态机/定时器
│   3.2 VAR_TEMP      (临时变量)       │  ← 计算中间值
│  4. VAR_CONSTANT   (常量定义)       │  ← 必须最后
└─────────────────────────────────────┘
```

**命名前缀约束**：

| 变量类型 | 前缀 | 示例 | 说明 |
|---------|------|------|------|
| VAR_INPUT | `i_` | `i_bStartBtn`, `i_rSpeedSet` | 输入参数 |
| VAR_OUTPUT | `q_` | `q_bMotorRun`, `q_nCurrentValue` | 输出参数 |
| VAR (内部) | `s_` | `s_nAutoStep`, `s_tActionDelay` | 静态变量(Static) |
| VAR_TEMP | `tmp_` | `tmp_nIndex`, `tmp_bFlag` | 临时变量(禁止用于状态保持) |
| VAR_CONSTANT | 前缀`c_`或全大写 | `c_nMaxSteps`, `TIMEOUT_3S` | 常量 |

**违规示例**（禁止）：
```pascal
VAR
    bStartBtn    : BOOL;   ❌ 缺少i_前缀
    q_MotorRun   : BOOL;   ❌ 输出变量混在VAR区
    nAutoStep    : INT;    ❌ 缺少s_前缀(状态机变量)
END_VAR
```

**正确示例**（推荐）：
```pascal
VAR_INPUT
    i_bStartBtn  : BOOL;   ✅ 输入参数带i_前缀
END_VAR

VAR_OUTPUT
    q_bMotorRun  : BOOL;   ✅ 输出参数带q_前缀
END_VAR

VAR
    s_nAutoStep  : INT;    ✅ 内部状态变量带s_前缀
    s_tActionDelay : TON;  ✅ 定时器实例带s_前缀
END_VAR
```
