# SCL 注释规范 (Siemens LSP Go-Gen 兼容版)

> 版本：V1.0.0  
> 状态：已验证  
> 更新日期：2026-05-02  
> 适用环境：Siemens LSP (VS Code)、TIA Portal、CODESYS、GX Works

---

## 1. 核心规则总结

| 规则 | 状态 | 说明 |
|------|------|------|
| `//` 单行注释 | ✅ **推荐** | 安全可靠，所有平台兼容 |
| `(* *)` 多行注释 | ✅ **允许** | 完全支持，适合大段注释或头部说明 |
| 嵌套注释 | ❌ **严格禁止** | `(* 外 (* 内 *) *)` 或任何形式的嵌套都会导致LSP解析错误 |
| 中文标点 | ❌ **禁止** | 必须使用英文标点符号（`,` `:` `.` `;`） |
| 中文内容 | ✅ **允许** | 注释文字可用中文，但标点必须英文 |

## 2. 注释格式规范

### 2.1 推荐格式：单行注释 `//`

```scl
(*
 ============================================================================
功能块名称: FB_TON
描述: 接通延时定时器 - 当IN为TRUE时，经过PT时间后Q变为TRUE
============================================================================
*)
FUNCTION_BLOCK FB_TON
VAR_INPUT
    IN  : BOOL;
    PT  : DINT;   // 预设时间(扫描周期)
END_VAR
VAR_OUTPUT
    Q   : BOOL;
    ET  : DINT;   // 已用时间(扫描周期)
END_VAR
VAR
    Counter   : DINT := 0;
    Running   : BOOL := FALSE;
END_VAR

BEGIN
    // IN为TRUE时启动定时器
    IF #IN THEN
        IF NOT #Running THEN
            #Running := TRUE;
            #Counter := 0;  // 复位计数器
        END_IF;

        // 计时逻辑
        IF #Running THEN
            #Counter := #Counter + 1;

            // 判断是否达到预设值
            IF #Counter >= #PT THEN
                #Q := TRUE;
                #ET := #PT;
                #Counter := #PT;  // 保持最大值
            ELSE
                #ET := #Counter;  // 输出当前值
            END_IF;
        END_IF;
    ELSE
        // IN为FALSE时复位
        #Q := FALSE;
        #ET := 0;
        #Counter := 0;
        #Running := FALSE;
    END_IF;

END_FUNCTION_BLOCK
```

### 2.2 允许格式：多行注释 `(* *)`

**✅ 完全支持，推荐用于功能块头部或大段说明**

```scl
(*
 ============================================================================
 功能块名称: FB_TON
 描述: 接通延时定时器 - 当IN为TRUE时，经过PT时间后Q变为TRUE
 版本: V2.0.0 (多平台兼容优化版)
 ============================================================================

 ----- 多平台兼容性说明 -----

 此功能块使用纯DINT计数方式, 避免TIME类型转换,
 确保与Siemens LSP (Go后端)、TIA Portal、GX Works、
 CODESYS以及所有其他平台的兼容性.
*)
```

**⚠️ 严格禁止嵌套（任何形式）**

```scl
(* ✅ 正确 - 单层多行注释
   内容...
*)

(* ❌ 错误1 - 嵌套多行注释
   (* 内层注释 *)
   外层内容...
*)

(* ❌ 错误2 - 其他嵌套形式
   // 注释内包含 (* ... *)
   或 (* 内含 (* *) *)
*)

// ❌ 错误3 - 混合嵌套
(* 多行注释开始
   // 单行注释中不能包含 (* *)
   多行注释结束 *)
```

## 3. 标点符号规范（关键）

### 3.1 禁止使用的中文标点

| 中文标点 | Unicode编码 | 问题 | 替换为 |
|----------|-------------|------|--------|
| `，` (逗号) | U+FF0C | LSP识别为非法token | `,` |
| `：` (冒号) | U+FF1A | LSP识别为非法token | `:` |
| `。` (句号) | U+3002 | LSP识别为非法token | `.` 或省略 |
| `；` (分号) | U+FF1B | LSP识别为非法token | `;` |
| `（）` (括号) | U+FF08/U+FF09 | 可能导致解析问题 | `()` |

### 3.2 正确示例对比

```scl
// ❌ 错误 - 使用中文标点
// 描述: 接通延时定时器，当IN为TRUE时，经过PT时间后Q变为TRUE。

// ✅ 正确 - 使用英文标点
// 描述: 接通延时定时器, 当IN为TRUE时, 经过PT时间后Q变为TRUE
// 或者: 接通延时定时器 - 当IN为TRUE时经过PT时间后Q变为TRUE
```

## 4. 注释密度建议

### 4.1 推荐密度

| 代码位置 | 注释频率 | 示例 |
|----------|----------|------|
| 文件头部 | 必须 | 功能块名称、描述、版本 |
| 变量声明 | 每个重要变量 | `PT : DINT; // 预设时间(扫描周期)` |
| 函数/功能块开始 | 必须 | 简要说明功能 |
| 关键逻辑分支 | 每个IF/CASE块 | `// IN为TRUE时启动定时器` |
| 复杂计算 | 计算前后 | `// 判断是否达到预设值` |
| 复位/初始化 | 每次 | `// 复位计数器` |

### 4.2 密度参考标准

- **每5-10行代码**至少1条注释
- **每个函数/功能块**必须有头部注释（3-5行）
- **每个变量**建议有简短说明（尤其I/O参数）
- **避免过度注释**：显而易见的代码不需要注释

## 5. 常见错误及解决方法

### 5.1 LSP编译错误

| 错误信息 | 原因 | 解决方法 |
|----------|------|----------|
| `unexpected token ，(LX003)` | 使用了中文逗号 `，` | 改为英文逗号 `,` |
| `unexpected token *(LX003)` | 块注释格式错误或嵌套 | 使用 `//` 单行注释或检查 `(* *)` 配对 |
| `字符 U+ff0c 与 ASCII 字符 U+002c 混淆` | 中文全角标点 | 全部替换为英文半角标点 |
| 注释未生效（显示为代码） | 缺少关闭符号 `*)` 或嵌套 | 改用 `//` 格式 |

### 5.2 实际案例

#### 案例1：FB_CTD.scl 注释错误（已修复）

**❌ 错误代码：**
```scl
(* 先加载10，然后每脉冲减1，到达0时Q变为TRUE   
    ----- 架构特性 -----
    
    - 纯逻辑实现: 无系统函数依赖，完全兼容go-gen仿真
    ...
*)
```

**问题分析：**
1. 第1行缺少关闭符号 `*）`
2. 第2行的 `----- 架构特性 -----` 被当成代码执行
3. 包含中文标点 `，`

**✅ 修复后：**
```scl
// FB_CTD: 减计数器
// 描述: CD上升沿时CV减1, 当CV<=0时Q变为TRUE

FUNCTION_BLOCK FB_CTD
VAR_INPUT
    CD   : BOOL;   // 减计数脉冲输入 (上升沿有效)
    LOAD : BOOL;   // 加载预设值 (TRUE时设置CV=PV)
    PV   : INT;    // 预设计数值 (初始加载值)
END_VAR
...
```

## 6. 多平台兼容性矩阵

| 注释特性 | Siemens LSP | TIA Portal | CODESYS | GX Works |
|----------|-------------|------------|---------|----------|
| `//` 单行注释 | ✅ 完全支持 | ✅ 完全支持 | ✅ 完全支持 | ✅ 完全支持 |
| `(* *)` 多行注释（不嵌套）| ✅ 完全支持 | ✅ 完全支持 | ✅ 完全支持 | ✅ 完全支持 |
| 嵌套注释 `(* (* *) *)` | ❌ **严格禁止** | ⚠️ 未定义行为 | ⚠️ 可能报错 | ❌ 编译错误 |
| 中文内容 | ✅ 支持 | ✅ 支持 | ✅ 支持 | ✅ 支持 |
| 中文标点 `，：。` | ❌ **不支持** | ⚠️ 部分支持 | ⚠️ 部分支持 | ⚠️ 部分支持 |

**结论：使用 `//` 或单层 `(* *)` + 英文标点 = 最大兼容性**

## 7. 注释模板库

### 7.1 功能块头部模板

```scl
// ============================================================================
// [功能块名称]: [简要描述]
// 描述: [详细功能说明]
// 版本: V[版本号] ([日期])
// ============================================================================
```

### 7.2 函数头部模板

```scl
// [函数名称]: [功能描述]
// 输入: [参数说明]
// 输出: [返回值说明]
// 注意: [特殊情况说明]
```

### 7.3 行内注释模板

```scl
变量名 : 类型;   // [用途说明]
#Variable := Value;  // [赋值原因]
IF Condition THEN    // [条件说明]
```

## 8. 代码审查检查清单

在提交代码前，请确认以下项目：

- [ ] 所有注释使用 `//` 或**单层** `(* *)` 格式
- [ ] **严格禁止任何形式的嵌套注释**（包括 `(* (* *) *)`、混合嵌套等）
- [ ] `(* *)` 注释必须正确配对（每个 `(*` 有对应的 `*)`）
- [ ] 所有标点符号为英文半角（`,` `:` `.` `;`）
- [ ] 每个公开的函数/功能块有头部注释
- [ ] 重要变量有行内注释说明
- [ ] 关键逻辑分支有注释解释意图
- [ ] 注释内容准确，与代码保持同步
- [ ] 无过时或冗余的注释
