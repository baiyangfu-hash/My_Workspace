## 二、按项目阶段查找指南

### 新手入门：我应该从哪些规范开始？

#### 开始一个新 PLC 项目时：

```
第一步: 基础规则
  [001] 通用项目名称命名规范     --> 了解项目/文档命名基础规则
  [004] 版本管理与变更核心规范   --> 掌握版本号格式和前缀码体系
  [801] PLC变量命名与功能块命名  --> 学习 i_b/q_b 前缀、FB编号格式
  [802] PLC工作流命名规范        --> 学习 WF 编号和步序命名

第二步: 架构与编程
  [810] PLC编程规范             --> 了解纯逻辑FB模式、推荐架构

第三步: 文档编写
  [050] 模板结构规范            --> 所有文档的标准格式要求
  [023] PLC程序设计文档模板      --> 编写程序设计文档
  [815] PLC接口文档模板          --> 编写接口文档

第四步: 测试与交付
  [031] 通用测试规范            --> 制定测试策略
  [030] 通用项目交付规范         --> 准备交付物
```

#### 开始一个新 Python 项目时：

```
第一步: 基础规则
  [001] 通用项目名称命名规范     --> 了解命名基础规则
  [004] 版本管理与变更核心规范   --> 掌握版本号格式和前缀码体系

第二步: 编码与审查
  [210] Python编程规范          --> 学习编码标准和最佳实践
  [211] Python代码审查规范      --> 了解 Code Review 流程和检查项
  [026] AI输出质量检查清单       --> AI生成内容的自检标准

第三步: 文档编写
  [215] Python接口文档模板      --> 编写 API 文档
  [050] 模板结构规范            --> 所有文档的标准格式要求

第四步: 打包与交付
  [220] Python项目打包规范      --> exe打包 + 两阶段交付流程
  [030] 通用项目交付规范         --> 交付物要求和AI风险控制
```

#### 开始一个产品化项目时（含立项/规划/执行/收尾）：

```
启动阶段:
  [000] 项目立项表模板          --> 提交立项申请
  [001] PRD模板                 --> 编写产品需求文档
  [006] 项目章程模板            --> 制定项目章程
  [007] 产品路线图模板          --> 规划产品路线图

规划阶段:
  [010] 项目管理规范            --> 建立项目管理流程
  [020] 需求分析文档模板        --> 详细需求分析
  [014] 技术方案文档模板        --> 技术选型和方案设计
  [021] 详细设计说明书模板      --> 系统详细设计
  [027] 迭代项目计划模板        --> 制定迭代计划

执行阶段:
  [033] 功能模块迭代流程标准    --> 按模块迭代开发
```

### 3.2 版本前缀码含义

| 前缀码 | 含义 | 适用场景 |
|--------|------|---------|
| **DEV** | 开发规范 (Development Standard) | 编码规范/命名规范/编程规范 |
| **PM** | 项目管理 (Project Management) | 管理/计划/流程/模板类文档 |
| **TPL** | 模板规范 (Template Standard) | 文档结构/格式标准 |
| **REQ** | 需求文档 (Requirement) | 需求分析/规格说明书 |
| **TECH** | 技术文档 (Technical) | 技术方案/设计文档 |
| **DES** | 设计文档 (Design) | 详细设计说明书 |
| **INT** | 接口文档 (Interface) | API/接口说明文档 |
| **TEST** | 测试文档 (Test) | 测试报告/测试方案 |
| **BUG** | 缺陷跟踪 (Bug Tracking) | 缺陷跟踪表 |
| **CHK** | 检查清单 (Checklist) | 质量/合规检查清单 |
| **CHG** | 变更文档 (Change) | 变更单/变更记录/变更台帐 |
| **SUM** | 总结文档 (Summary) | 项目总结报告 |
| **PLC** | PLC专用 | PLC程序设计文档 |
| **PROJ** | 项目结构 (Project Structure) | 项目目录结构模板 |
| **USE** | 使用文档 (User Manual) | 用户手册/操作指南 |
| **TASK** | 任务分配 (Task) | 任务分解与分配 |
| **REV** | 复盘文档 (Review) | 迭代复盘报告 |
| **PRD** | 产品需求 (Product Requirement) | 产品需求文档 |

### 3.3 版本号格式

```
{前缀码}-V{主版本}.{次版本}
```

示例：
- `DEV-V1.0.3` = 开发规范，主版本1，次版本0，补丁3
- `PM-V2.0.0` = 项目管理规范，主版本2（重大更新）
- `TPL-V1.0.1` = 模板规范，小版本迭代

版本晋升规则详见 [004_通用项目文档版本管理与变更核心规范](01_启动过程/02_基础规范/02_版本规范/004_通用项目文档版本管理与变更核心规范_DEV-V1.1.1.md)。
