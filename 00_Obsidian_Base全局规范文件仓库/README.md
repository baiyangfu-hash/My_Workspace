## V1.0 → V2.0 变更摘要

| 变更项 | 说明 |
|--------|------|
| **双域分离** | 项目管理(01) vs 技术开发(02) 不再混在一起 |
| **工作流驱动** | PLC规范按 Phase1→4 开发顺序组织，不再按编号堆砌 |

## 权威来源

**当冲突时，以 `0100_项目/00_通用规范` 为最终权威基准**

本仓库PLC技术栈规范均基于 Siemens LSP 插件生态，已在以下项目验证：
- DJ-2026-005 (边框缓存机) — 实战bug总结来源
- SW-2026-005 (PLC项目管理工具) — 自动化检查支持

## 快速开始

**你是PM？** → 进入 `01_项目管理域/` 查看立项/规划/变更模板

**你是PLC工程师？** → 按4步走：
1. 新建项目 → [LSP-907](02_技术开发域/01_PLC开发工作流/Phase1_项目初始化/) 配置.plc.json
2. 写代码 → [LSP-905](02_技术开发域/01_PLC开发工作流/Phase2_编码规范/LSP-905_SCL编程规范_V1.0.1.md) 查命名/语法
3. 出bug？ → [LSP-906](02_技术开发域/01_PLC开发工作流/Phase3_错误预防/) 对照预防清单
4. 写文档 → [Phase4](02_技术开发域/01_PLC开发工作流/Phase4_文档与接口/) 用标准模板
