## 5. 接口详细信息

### 5.1 接口1

**接口URL**：`/api/endpoint1`

**请求方法**：GET

**功能描述**：功能描述1

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| param1 | string | 是 | 参数1描述 | 无 |
| param2 | int | 否 | 参数2描述 | 0 |

**请求示例**：

```python
import requests

url = "http://example.com/api/endpoint1"
params = {
    "param1": "value1",
    "param2": 123
}

response = requests.get(url, params=params)
print(response.json())
```

**响应格式**：

| 字段名 | 类型 | 描述 |
|--------|------|------|
| code | int | 响应码 |
| message | string | 响应消息 |
| data | object | 响应数据 |

**成功响应示例**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "field1": "value1",
    "field2": "value2"
  }
}
```

**失败响应示例**：

```json
{
  "code": 400,
  "message": "参数错误",
  "data": null
}
```

### 5.2 接口2

**接口URL**：`/api/endpoint2`

**请求方法**：POST

**功能描述**：功能描述2

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| param1 | string | 是 | 参数1描述 | 无 |
| param2 | array | 否 | 参数2描述 | [] |

**请求示例**：

```python
import requests

url = "http://example.com/api/endpoint2"
headers = {
    "Content-Type": "application/json"
}
data = {
    "param1": "value1",
    "param2": [1, 2, 3]
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
```

**响应格式**：

| 字段名 | 类型 | 描述 |
|--------|------|------|
| code | int | 响应码 |
| message | string | 响应消息 |
| data | object | 响应数据 |

**成功响应示例**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 123,
    "status": "created"
  }
}
```
