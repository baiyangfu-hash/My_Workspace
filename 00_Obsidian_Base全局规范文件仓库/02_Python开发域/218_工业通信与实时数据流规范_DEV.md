## 1. 架构总览：三层数据解耦

为防止工业总线高频通信阻塞 UI 画面渲染（保证 60 FPS），系统必须实施 **“采集驱动层 ── 内存缓冲层 ── 表现推送层”** 的物理三层解耦：

```
┌─────────────────────────────────────────────────────────┐
│ 🖥️ 【表现层 (QML / UI Views)】                          │
│    • 10x10 网格渲染、波形画布 (ModbusTrendCanvas)       │
└───────────────────────────▲─────────────────────────────┘
                            │ Qt Signal 批量推送 (50ms 节流 Batching)
┌───────────────────────────┴─────────────────────────────┐
│ 🧠 【内存缓冲层 (Double-Buffered VarTable Cache)】       │
│    • 线程安全无锁双缓冲、点位值/质量戳/时间戳快照       │
└───────────────────────────▲─────────────────────────────┘
                            │ 后台原子更新
┌───────────────────────────┴─────────────────────────────┐
│ ⚙️ 【采集驱动层 (Industrial Comm Worker Thread)】        │
│    • 独立后台线程运行、Modbus TCP / S7 Client 轮询       │
│    • 指数退避断线重连状态机、心跳保活机制                │
└─────────────────────────────────────────────────────────┘
```

## 2. 核心规约与工程模式

### 2.1 通信线程隔离（独立 Worker 线程）
- **隔离原则**：所有通信驱动（如 `pymodbus` / `snap7`）必须运行在独立的后台 Worker 线程中，严禁在 Qt UI 主线程执行任何网络 Socket 阻塞读写。
- **生命周期**：通信 Worker 具备清晰的 `start()`, `stop()`, `pause()` 控制接口，支持系统优雅退出。

### 2.2 点表内存双缓冲机制（Double Buffering）
- **前后台缓冲**：采集线程写入后台缓冲区（Back Buffer），UI 线程定时原子读取前台缓冲区（Front Buffer）生成视图快照，避免多线程读写点表锁竞争；
- **点位元数据契约**：每个采集点位必须包含：
  - `tag_name`: 点位标识符（如 `CONVEYOR_RUN`）
  - `value`: 当前值（BOOL / INT / REAL）
  - `quality`: 质量戳（`GOOD` / `BAD` / `COMM_LOST`）
  - `timestamp`: 毫秒级采集时间戳

### 2.3 故障自愈与断线重连状态机
- 通信链路必须遵循标准 5 态状态机：
  `DISCONNECTED -> CONNECTING -> CONNECTED -> COMM_ERROR -> RECONNECTING`；
- **重连退避算法**：发生网络断线或超时（Socket Timeout）时，必须实施**指数退避重试（Exponential Backoff）**（如 1s → 2s → 4s → 最大 10s），严禁高频死循环重连打崩工控机网络栈。

### 2.4 表现层批量节流推送 (Batching & Throttling)
- **推送频率**：上位机向 QML 画面推送数据流时，必须采用 **50ms ~ 100ms 批量节流（Throttling）**；
- **网格与波形**：对于 10x10 并发探测网格（`ModbusScannerGrid`）与趋势波形，单次 Signal 打包全部最新数据切片，避免每更新一个点位触发一次 UI Repaint。

### 2.5 工业功能码与异常处理标准化
- 标准化支持工业功能码：
  - `FC01` (读线圈), `FC02` (读离散输入), `FC03` (读保持寄存器), `FC04` (读输入寄存器)
  - `FC05` (写单个线圈), `FC06` (写单个寄存器), `FC15` (写多个线圈), `FC16` (写多个寄存器)
- 通信异常返回必须携带标准 Modbus 异常码（如 `01: Illegal Function`, `02: Illegal Data Address`, `04: Server Device Failure`），并映射为用户友好的中文诊断提示。

## 3. 反模式（严禁使用）

1. ❌ **严禁在 UI 界面点击事件中直接同步调用 PLC 读写 Socket**；
2. ❌ **严禁高频点位更新每毫秒 emit 一次 Qt Signal**；
3. ❌ **严禁通信断线后无延时无限死循环重连**；
4. ❌ **严禁向 UI 暴露未捕获的 Socket 裸异常导致客户端崩溃**。
