## 7. 变更管理流程

### 7.1 变更流程图

```
变更提出 → 变更评估 → 变更审批 → 变更实施 → 变更验证 → 变更关闭
    │          │          │          │          │          │
    ▼          ▼          ▼          ▼          ▼          ▼
  记录变更   影响分析   用户确认   文档更新   测试验证   归档记录
```

### 7.2 变更状态说明

| 状态 | 说明 |
|------|------|
| 待审批 | 变更已提出，等待审批 |
| 已批准 | 变更已通过审批，等待实施 |
| 已拒绝 | 变更未通过审批 |
| 实施中 | 变更正在实施 |
| 已实施 | 变更已完成实施 |
| 已关闭 | 变更已完成验证并关闭 |
