## 4. 目录说明

### 4.1 01_变更单（按技术领域分子目录）⭐

每个变更对应**一份且仅一份**独立的变更单文件(`CHG-[DOMAIN]-[YYYY]-XXX.md`), 该文件是此变更的**权威数据源(Single Source of Truth)**。

**领域分子目录的优势**:
- 快速统计各领域的变更数量和频率
- 领域工程师只关注自己领域的变更单
- 安全相关变更(SAFE)有独立的存放位置,便于安全审计
- AI工具可按领域批量解析和处理

**命名规则**: `CHG-[领域代码]-[YYYY]-[序号].md`
- 例: `CHG-PLC-2026-001.md` (PLC程序类第1号变更单)
- 例: `CHG-SAFE-2026-001.md` (安全功能类第1号变更单, 特殊标记)

**领域代码速查**:

| 代码 | 领域 | 典型交付物 |
|:---:|:-----|:----------|
| ELEC | 电气设计 | Eplan原理图/接线图/IO分配表/BOM |
| MECH | 机械结构 | SolidWorks 3D/装配图/加工图 |
| PLC | PLC程序 | IEC 61131-3 SCL/ST/LD/GVL/功能块 |
| HMI | HMI程序 | 触摸屏画面/变量映射/报警配置 |
| SCPT | Python脚本 | 数据采集/MES接口/上位机应用 |
| DOCU | 工程文档 | 设计说明书/操作手册/验收报告 |
| SAFE | 安全功能 | 急停回路/安全矩阵/SIL评估 |
| SPEC | 规范法典 | Obsidian 规范库治理变更单(frontmatter/registry/INDEX/链接) |

### 4.2 版本变更台帐（引用模式）

台帐是项目的**变更索引和统计中心**, 采用**引用模式**而非内嵌模式:

```
台帐(索引/统计) ──超链接──▶ 变更单(完整档案)
     ↑                           │
  §4 一行摘要               §1~§10 全部细节
  §3 多维统计               §6 影响评估
  §5 趋势分析               §8 审批记录
                           §10 验证结论
```

**台帐§4记录格式示例**:
```markdown
| 编号 | 变更单链接 | 领域 | 性质 | 范围 | 标题 | 优先级 | 状态 |
|------|-----------|:----:|:----:|:----:|:-----|:------:|:----:|
| FB-V2-001 | [→ CHG-PLC-2026-001](./01_变更单/CHG-PLC/CHG-PLC-2026-001.md) | PLC | REQ | MOD | 新增状态字输出 | P1 | ✅完成 |
```

**关键原则**:
- 台帐只存放**一行摘要 + 超链接**, 不内嵌完整变更细节
- 详细信息(原因/前后对比/影响分析/审批/验证)全部在变更单文件中
- 其他文档如需提及变更, 应引用变更单编号而非复制内容

### 4.3 README.md（推荐）

每个项目的`01_变更管理/`目录下建议放置README.md, 包含:
- 当前目录树及各子目录使用状态(有文件✓ / 空预留○)
- 为何采用精简结构(无02_变更报告/)的理由说明
- 变更单快速创建指南(适合AI自动化工具的最小步骤)
- 当前统计摘要(变更单数/SYSTEM级数/P0级数/传播链数)

## 5. 三文件职责分工（避免重叠）

| 功能点 | 变更单(040模板) | 台帐(041模板) | 备注 |
|:------|:--------------:|:------------:|:-----|
| 基本信息(编号/日期/类型) | ✅ §3 | ✅ §4(摘要) | 台帐只保留一行 |
| 二维分类(领域×性质×范围) | ✅ §3(完整) | ✅ §3(统计汇总) | 各司其职 |
| 变更原因/背景 | ✅ §4 | - | 仅变更单有 |
| 变更前后对比 | ✅ §5 | - | 仅变更单有 |
| 影响分析(三维) | ✅ §6(完整) | ✅ §5(摘要矩阵) | 变更单更详细 |
| 审批记录 | ✅ §8 | - | 仅变更单有 |
| 实施记录 | ✅ §9 | - | 仅变更单有 |
| 验证结论 | ✅ §10 | - | 仅变更单有 |
| **多维统计(4D)** | - | ✅ **§3(唯一)** | **仅台帐有** |
| **趋势分析** | - | ✅ **§5(唯一)** | **仅台帐有** |
| **传播链可视化** | ✅ §6.3(单链) | ✅ §5.3(全局) | 两者视角不同 |

## 6. 快速开始指南（AI工具调用步骤）

```
Step 1: 确定领域 → 选择ELEC/MECH/PLC/HMI/SCPT/DOCU/SAFE之一
Step 2: 复制模板 → 从规范仓库复制 040_通用变更单模板_CHG.md
Step 3: 填写必填 → §3二维分类 + §4原因 + §5前后对比 + §6影响
Step 4: 检查传播 → 如跨领域 → §6.2填受影响领域 + §6.3画传播链
Step 5: 存放文件 → 01_变更单/CHG-[DOMAIN]/CHG-[DOMAIN]-[YYYY]-[XXX].md
Step 6: 更新台帐 → 在台帐§4追加一行引用
```
