### 适用场景
**小型单机版适用**：
- IO 点数 < 100 点
- 单 PLC 控制
- 简单 HMI 操作界面
- 无复杂运动控制
- 无机器人集成
- 项目周期 < 3 个月
- 项目团队 < 5 人

**中大型版适用**：
- IO 点数 >= 100 点
- 多 PLC 协同
- 复杂 HMI/SCADA 系统
- 复杂运动控制（伺服、步进）
- 机器人集成
- 项目周期 >= 3 个月
- 项目团队 >= 5 人

## 变更管理功能映射

### 变更管理流程
```
1. 创建变更单 → 00_项目管理/04_变更管理/01_变更单/040_{code}_变更单号_CHG-V2.0.0.md
2. 审批变更 → 更新变更单状态 + 记录审批意见
3. 实施变更 → 更新受影响文件 + 记录实施结果
4. 记录台帐 → 00_项目管理/04_变更管理/04_变更记录/041_{code}_版本变更台帐_CHG-V2.1.0.md
```

### 变更单类型（小型单机）
- **CHG-PLC**: PLC 程序类变更
- **CHG-ELEC**: 电气设计类变更
- **CHG-HMI**: HMI 程序类变更
- **CHG-DOCU**: 文档类变更

## 工具集成说明

### 项目管理工具需要知道的映射关系
1. **变更单生成**: 工具根据变更类型和目标文件，自动生成变更单文件
2. **变更单编号**: 工具自动分配变更单编号（001, 002, 003...）
3. **变更台帐更新**: 工具在变更单创建/审批/实施后自动更新台帐
4. **文件版本控制**: 工具追踪受变更影响的文件版本变化

### 文档编号规则
- **格式**: `{sequence}_{project_code}_{document_name}_V{version}.md`
- **sequence**: 3 位数字编号（003, 005, 006...）
- **project_code**: 项目代码（如 DJ-2026-001）
- **document_name**: 文档名称
- **version**: 版本号（V1.0.0, V2.0.0...）

## 使用建议

### 何时选择小型单机版？
1. **项目规模小**: IO 点数少于 100 点
2. **技术难度低**: 标准功能块即可满足
3. **项目周期短**: 1-3 个月内完成
4. **团队规模小**: 1-3 人开发团队
5. **客户文档要求低**: 不需要完整的技术文档

### 何时升级到中大型版？
1. 项目规模扩大，IO 点数超过 100 点
2. 技术复杂度增加，需要详细设计文档
3. 项目周期延长，需要完整的进度管理
4. 团队规模扩大，需要沟通管理计划
5. 客户要求完整的交付文档
