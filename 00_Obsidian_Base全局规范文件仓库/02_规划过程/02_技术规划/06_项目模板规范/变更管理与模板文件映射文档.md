# 变更管理与模板文件映射文档

## 1. 文档目的

本文档定义项目管理工具的变更管理功能与项目模板文件之间的映射关系，确保工具能够正确生成、更新和追踪变更管理相关文档。

## 5. 变更类型定义

### 5.1 变更类型分类
| 变更类型代码 | 变更类型名称 | 适用场景 | 影响范围 |
|------------|------------|---------|---------|
| **CHG-PLC** | PLC 程序类变更 | PLC 程序修改、FB 修改、变量表修改 | PLC 程序、HMI 变量、测试用例 |
| **CHG-ELEC** | 电气设计类变更 | Eplan 图纸修改、IO 分配修改 | 电气图纸、IO 表、接线图 |
| **CHG-MECH** | 机械结构类变更 | 3D 模型修改、2D 图纸修改 | 机械图纸、BOM 清单 |
| **CHG-HMI** | HMI 程序类变更 | HMI 画面修改、变量绑定修改 | HMI 工程、操作手册 |
| **CHG-ROBOT** | 机器人程序类变更 | 机器人程序修改、轨迹修改 | 机器人程序、仿真文件 |
| **CHG-SCPT** | 脚本工具类变更 | Python 脚本修改、工具修改 | 脚本文件、工具配置 |
| **CHG-DOCU** | 文档类变更 | 文档内容修改、版本更新 | 技术文档、操作手册 |
| **CHG-SAFE** | 安全功能类变更 | 安全回路修改、安全配置修改 | 安全图纸、安全程序 |

## 6. 变更管理流程

### 6.1 变更管理流程图
```
申请变更 → 创建变更单 → 审批变更 → 实施变更 → 验证变更 → 关闭变更单
    ↓           ↓           ↓          ↓          ↓          ↓
记录台帐 →  更新台帐 →  更新台帐 →  更新台帐 →  更新台帐 →  归档
```

### 6.2 变更管理流程说明
1. **申请变更**: 项目成员提出变更需求
2. **创建变更单**: 工具自动生成变更单文件
3. **审批变更**: 项目经理审批变更申请
4. **实施变更**: 工程师实施变更并记录
5. **验证变更**: 测试工程师验证变更结果
6. **关闭变更单**: 项目经理关闭变更单
7. **记录台帐**: 工具自动更新变更台帐

### 6.3 工具自动化功能
| 流程节点 | 工具自动化功能 | 文件操作 |
|---------|--------------|---------|
| 创建变更单 | 自动生成变更单编号、填充模板 | 创建变更单文件 |
| 审批变更 | 发送审批通知、记录审批意见 | 更新变更单文件 |
| 实施变更 | 追踪受影响文件、记录实施结果 | 更新变更单文件 + 更新台帐 |
| 验证变更 | 生成测试任务、记录验证结果 | 更新变更单文件 |
| 关闭变更单 | 检查完整性、归档变更单 | 更新变更单状态 |
| 记录台帐 | 自动统计变更数据、生成报表 | 更新变更台帐文件 |

## 7. 模板文件版本控制

### 7.1 版本号规则
- **格式**: `V{MAJOR}.{MINOR}.{PATCH}`
- **MAJOR**: 重大变更（不兼容的变更）
- **MINOR**: 功能添加（向后兼容）
- **PATCH**: Bug 修复（向后兼容）

### 7.2 版本变更触发条件
| 变更类型 | 版本号变更 | 示例 |
|---------|-----------|------|
| 重大功能修改 | MAJOR 版本 +1 | V1.0.0 → V2.0.0 |
| 功能添加 | MINOR 版本 +1 | V1.0.0 → V1.1.0 |
| Bug 修复 | PATCH 版本 +1 | V1.0.0 → V1.0.1 |

### 7.3 工具版本追踪
工具需要追踪每个文件的版本变化：
```json
{
  "file_path": "02_PLC 程序/程序文档/015_DJ-2026-001_IO 分配表_IO-V1.0.0.md",
  "current_version": "V1.0.0",
  "change_history": [
    {
      "version": "V1.0.0",
      "date": "2026-04-15",
      "change_no": "001",
      "change_type": "CHG-PLC",
      "description": "初始版本"
    }
  ]
}
```
