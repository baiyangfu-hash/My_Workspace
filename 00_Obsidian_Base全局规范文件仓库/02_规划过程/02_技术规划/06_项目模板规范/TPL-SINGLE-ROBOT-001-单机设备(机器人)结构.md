## 变更管理功能映射

### 变更管理流程
```
1. 创建变更单 → 00_项目管理/04_变更管理/01_变更单/040_{code}_变更单号_CHG-V2.0.0.md
2. 审批变更 → 更新变更单状态 + 记录审批意见
3. 实施变更 → 更新受影响文件 + 记录实施结果
4. 记录台帐 → 00_项目管理/04_变更管理/04_变更记录/041_{code}_版本变更台帐_CHG-V2.1.0.md
```

### 变更单类型（机器人专用）
- **CHG-PLC**: PLC 程序类变更
- **CHG-ELEC**: 电气设计类变更
- **CHG-MECH**: 机械结构类变更
- **CHG-HMI**: HMI 程序类变更
- **CHG-ROBOT**: **机器人程序类变更**（核心）
- **CHG-SCPT**: 脚本工具类变更
- **CHG-DOCU**: 文档类变更
- **CHG-SAFE**: **安全功能类变更**（核心）

### 机器人专用变更影响
| 变更类型 | 影响范围 | 验证要求 |
|---------|---------|---------|
| CHG-ROBOT | 机器人程序、轨迹规划、IO 配置、安全区域 | 必须仿真验证 + 现场测试 |
| CHG-SAFE | 安全回路、安全 IO、急停逻辑 | 必须安全认证 + 功能测试 |

## 工具集成说明

### 项目管理工具需要知道的映射关系
1. **变更单生成**: 工具根据变更类型和目标文件，自动生成变更单文件
2. **变更单编号**: 工具自动分配变更单编号（001, 002, 003...）
3. **变更台帐更新**: 工具在变更单创建/审批/实施后自动更新台帐
4. **文件版本控制**: 工具追踪受变更影响的文件版本变化

### 文档编号规则
- **格式**: `{sequence}_{project_code}_{document_name}_V{version}.md`
- **sequence**: 3 位数字编号（000, 001, 002...）
- **project_code**: 项目代码（如 DJ-2026-001）
- **document_name**: 文档名称
- **version**: 版本号（V1.0.0, V2.0.0...）
