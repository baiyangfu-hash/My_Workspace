## 🎯 模板推荐矩阵

### [DJ] 单机设备类

#### TPL-SINGLE-PLC-S001 - 小型单机设备 (PLC+HMI)
**文件**: `TPL-SINGLE-PLC-S001-小型单机设备(PLC+HMI)结构.md`

**适用条件**：
- ✅ IO 点数 < 100 点
- ✅ 单 PLC 控制
- ✅ 简单 HMI 操作界面（<=7 寸）
- ✅ 无复杂运动控制（仅变频/气缸）
- ✅ 无机器人集成
- ✅ 项目周期 < 3 个月
- ✅ 团队规模 <= 3 人

**包含模块**：
```
00_项目管理/          # 精简版（立项表 + 需求分析 + 变更管理）
01_需求与设计/        # Eplan 电气 + 软件方案
02_PLC 程序/          # 主程序 + 变量表 + IO 表
03_HMI 设计/          # 变量绑定 + 操作手册
04_驱动器与设备/       # 驱动器参数
05_测试与验证/         # 测试报告 + 验收记录
06_文档与交付/         # 操作手册 + 验收清单
07_工具与配置/         # .gitignore
```

**变更类型支持**: CHG-PLC / CHG-ELEC / CHG-HMI / CHG-DOCU

## 🚀 使用建议

### 新手快速选择流程
1. **问自己**: 这是纯软件项目吗？
   - 是 → 使用 **TPL-UPPER-STD-001**
   - 否 → 继续

2. **问自己**: 这是新项目还是升级改造？
   - 升级 → 使用 **TPL-UPGRADE-STD-001**
   - 新建 → 继续

3. **问自己**: 有机器人吗？
   - 有 → 使用 **TPL-SINGLE-ROBOT-001**
   - 没有 → 继续

4. **问自己**: 是单机还是整线？
   - 整线（>=2 PLC）→ 使用 **TPL-FULLLINE-AUTO-001**
   - 单机 → 继续

5. **问自己**: 项目规模多大？
   - 小型（<100 IO）→ 使用 **TPL-SINGLE-PLC-S001**
   - 中大型（>=100 IO）→ 使用 **TPL-SINGLE-PLC-M001**

### 进阶使用建议
1. **首次使用**: 先阅读模板的"总览"部分，了解完整结构
2. **定制调整**: 根据项目实际情况，适当裁剪不需要的模块
3. **工具集成**: 配合项目管理工具使用，自动生成标准文档
4. **持续改进**: 将项目经验反馈到技术知识库，优化模板

## ❓ 常见问题

### Q1: 可以混合使用多个模板吗？
**A**: 不建议。每个模板都是完整的体系，混合使用会导致结构混乱。如果项目确实复杂，建议基于最接近的模板进行定制。

### Q2: 小型项目可以升级到中大型模板吗？
**A**: 可以。当项目范围扩大时，可以从中大型模板补充缺失的模块。

### Q3: 这些模板与 016_Python软件项目结构规范冲突吗？
**A**: 不冲突。两者适用于不同场景：
- 本模板：电气工程自动化项目（PLC/HMI/机器人）
- 016 规范：纯 Python 软件项目

### Q4: 如何将模板集成到项目管理工具？
**A**: 查看 `变更管理与模板文件映射文档.md`，其中详细说明了工具接口和文件路径映射。
