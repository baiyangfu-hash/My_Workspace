# STD-850: 步进链时序控制与防卡死设计规范

> **规范定位**：参考汽车制造行业（SICAR / VASS Schrittkette）标准，规范自动化工艺步序控制的架构模型。
> **核心铁律**：步进链每一步必须严格采用三段式结构，且关键动作步必须配备独立的超周期看门狗（Step Timeout Watchdog）。

---

## 1. 标准三段式 Schrittkette 步序架构

所有工位步进链必须严格分离 **“转移条件判断”**、**“步号流转”** 与 **“动作使能输出”**：

```pascal
CASE s_iStep OF
    10: // 【第 10 步: 取料伺服下降】
        // [段 1: 动作使能输出 (由当前步唯一驱动)]
        q_bAxisZ_MoveAbs := TRUE;
        q_diAxisZ_TargetPos := 15000;

        // [段 2: 转移条件判断 (前步到位 + 传感器反馈)]
        IF i_bAxisZ_Done THEN
            // [段 3: 步号推进与计时器清零]
            q_bAxisZ_MoveAbs := FALSE;
            s_diStepTimerMs := 0;
            s_iStep := 20;
        ELSIF s_diStepTimerMs > 10000 THEN
            // [步序超时看门狗]
            q_bStepTimeoutAlarm := TRUE;
            s_iStep := 99; // 切入故障停机步
        END_IF;

    ELSE
        s_iStep := 0; // 防死锁复位 (LSP-905 强制要求)
END_CASE;
```

---

## 2. 步序安全与防死锁设计准则

1. **CASE ELSE 防死锁**：所有 `CASE s_iStep OF` 语句必须显式声明 `ELSE s_iStep := 0;` 分支，防止意外越界导致程序挂起。
2. **动作使能无锁存**：动作输出信号必须在转移离开当前步时由程序显式复位（或自然失电），严禁使用全局置位（`SET`）导致跨步飞车。
3. **使能切断瞬时停机**：当工位自动模式使能（`i_bAutoEnable = FALSE`）被切断时，步进链必须立即关闭所有电机与阀门输出，并将步号安全复位。
