## 产品概述
输送线控制FB（FB_ConveyorControlV4）是一个符合IEC 61131-3标准的功能块，用于控制输送线电机的启动、停止、速度调节和故障检测。该FB采用高内聚、低耦合的设计原则，具有良好的移植性和可维护性。

## 功能特性
- **双模式控制**：支持手动模式和自动模式
- **速度调节**：支持慢速和快速两种速度模式
- **故障检测**：内置故障检测机制
- **高可靠性**：状态管理稳定，避免振荡
- **易于集成**：标准化的输入输出接口

## 技术参数
- **输入信号**：9个输入变量（5个BOOL类型，3个INT类型，1个REAL类型）
- **输出信号**：6个输出变量（3个BOOL类型，2个INT类型，1个REAL类型）
- **内部变量**：20个内部状态变量（含计时器数组和报警相关变量）
- **执行周期**：一个扫描周期内完成所有逻辑运算

## 操作指南
### 1. 手动模式操作
1. **准备**：确保`i_MainControlMode`设置为1（手动模式）
2. **启动**：按下启动按钮（X0）并保持，电机开始运行
3. **运行**：保持启动按钮为true，电机持续运行
4. **停止**：松开启动按钮（X0变为false）或按下停止按钮（X1），电机会停止
5. **速度**：手动模式下使用设定的速度频率（`i_SpeedFrequency`）运行

### 2. 自动模式操作
1. **准备**：确保`i_MainControlMode`设置为2（自动模式）
2. **启动**：按下启动按钮（X0）并保持，电机开始运行
3. **运行**：保持启动按钮为true，电机持续运行
4. **速度切换**：当产品到达位置1传感器（X4）时，电机会自动切换为慢速运行（速度的1/3）
5. **自动停止**：慢速运行一段时间（`i_SlowDelayTime`）后，电机会自动停止
6. **停止**：松开启动按钮（X0变为false）或按下停止按钮（X1），电机会立即停止

### 3. 模式切换操作
1. **从停止模式切换**：
   - 确保电机已停止
   - 将`i_MainControlMode`设置为1（手动）或2（自动）
   - 系统会自动进入相应模式
2. **模式切换限制**：
   - 只能从停止模式（0）切换到手动（1）或自动（2）模式
   - 从运行模式切换到其他运行模式会触发模式错误

### 4. 方向控制操作
1. **方向设置**：
   - 确保电机已停止
   - 将`i_MotorDirection`设置为0（正转）或1（反转）
   - 系统会在电机启动时使用设定的方向
2. **方向切换限制**：
   - 电机运行时方向设置无效
   - 必须在电机停止后才能更改方向

### 5. 故障处理
1. **故障指示**：故障报警指示灯（Y3）亮起，`q_MotorFault`置为TRUE
2. **故障类型**：
   - 驱动报警：驱动器发送报警信号
   - 其他故障：系统内部检测到的异常
3. **故障处理**：
   - 当驱动器报警时，电机立即停止运行
   - 报警期间只响应停止信号，不响应任何启动信号
4. **故障复位**：
   - 确认并处理故障原因
   - 等待驱动报警信号（i_DriveAlarm）变为0并保持超过5秒
   - 按下复位按钮（X5），上升沿触发一次
   - 系统会清除错误状态，准备重新启动

### 6. 速度设置操作
1. **速度调整**：
   - 将`i_SpeedFrequency`设置为所需的频率值（0.0-100.0 HZ）
   - 系统会实时响应速度变化
2. **速度范围**：
   - 最小值：0.0 HZ（停止）
   - 最大值：100.0 HZ
   - 当设置≤0时，系统会自动设置为50.0 HZ

## 触发条件详解

### 1. BOOL量触发条件
| 接口名称 | 触发条件 | 说明 |
|---------|---------|------|
| `i_Start` | 持续TRUE | 需要一直为true以保持电机运行，变为false时电机会停止 |
| `i_Stop` | 上升沿触发 | 只需要为true一次，就会触发停止操作 |
| `i_Reset` | 上升沿触发 | 只需要为true一次，就会触发复位操作 |
| `i_Position1Sensor` | 上升沿触发 | 只需要为true一次，就会触发位置检测和速度切换 |

### 2. INT量触发条件
| 接口名称 | 触发条件 | 说明 |
|---------|---------|------|
| `i_MainControlMode` | 持续保持 | 需要保持为对应的值（0-停止,1-手动,2-自动） |
| `i_MotorDirection` | 持续保持 | 只在电机停止时有效，需要保持为对应的值（0-正转,1-反转） |
| `i_SlowDelayTime` | 持续保持 | 需要保持为对应的值（单位：毫秒） |

### 3. REAL量触发条件
| 接口名称 | 触发条件 | 说明 |
|---------|---------|------|
| `i_SpeedFrequency` | 持续保持 | 需要保持为有效值（0.0-100.0 HZ） |

### 4. 触发条件使用示例

#### 示例1：启动/停止操作
```
// 启动电机
i_Start := TRUE;  // 保持为TRUE
// 电机运行中...
i_Start := FALSE; // 变为FALSE，电机停止
```

#### 示例2：停止按钮操作
```
// 停止电机（只需要触发一次）
i_Stop := TRUE;   // 触发停止
i_Stop := FALSE;  // 可以立即恢复为FALSE
```

#### 示例3：复位操作
```
// 清除错误状态（只需要触发一次）
i_Reset := TRUE;  // 触发复位
i_Reset := FALSE; // 可以立即恢复为FALSE
```

#### 示例4：模式切换操作
```
// 切换到手动模式
i_MainControlMode := 1; // 保持为1
// 手动模式运行中...
// 切换到停止模式
i_MainControlMode := 0; // 保持为0
```

#### 示例5：速度设置操作
```
// 设置速度为60HZ
i_SpeedFrequency := 60.0; // 保持为60.0
// 电机以60HZ运行...
// 调整速度为30HZ
i_SpeedFrequency := 30.0; // 保持为30.0
```

## 应用场景示例

### 场景1：包装生产线应用
**应用描述**：在包装生产线上，输送线需要根据产品位置自动调整速度，确保包装精度。

**配置步骤**：
1. **变量表导入**：导入`FB_导入变量_输送线控制_20260122_0600_v4.6.0.csv`
2. **传感器连接**：将光电传感器连接到X4（i_Position1Sensor）
3. **主控连接**：将主控系统的运行模式信号连接到D0（i_MainControlMode）
4. **参数设置**：设置i_SlowDelayTime为1000（1秒慢速延时），i_SpeedFrequency为50.0（50HZ）
5. **复位按钮**：将复位按钮连接到X5（i_Reset），用于清除错误状态

**运行流程**：
1. 主控系统设置i_MainControlMode为2（自动模式）
2. 发送i_Start信号启动输送线（保持为TRUE）
3. 输送线快速运行（50HZ），当产品到达位置1时，传感器X4检测到信号
4. 输送线切换为慢速运行（50/3 ≈ 16.7HZ）1秒
5. 1秒后自动停止，同时q_ProductInPlaceDone置为TRUE
6. 产品被取走后，传感器X4信号消失，3秒后q_ProductInPlaceDone自动复位
7. 若遇到错误状态，按下复位按钮X5清除错误

### 场景2：装配生产线应用
**应用描述**：在装配生产线上，输送线需要与上下游设备协调，确保装配过程的同步性。

**配置步骤**：
1. **变量表导入**：导入`FB_导入变量_输送线控制_20260122_0600_v4.6.0.csv`
2. **方向控制**：将电机方向控制信号连接到D1（i_MotorDirection）
3. **状态反馈**：将q_ProductInPlaceDone连接到上游设备的停止信号
4. **参数设置**：设置i_SlowDelayTime为2000（2秒慢速延时），i_SpeedFrequency为40.0（40HZ）
5. **复位按钮**：将复位按钮连接到X5（i_Reset）

**运行流程**：
1. 上游设备完成装配后，发送i_Start信号（保持为TRUE）
2. 输送线快速运行（40HZ）将产品送往下游
3. 产品到达位置1后，切换为慢速运行（40/3 ≈ 13.3HZ）2秒
4. 下游设备取走产品后，传感器信号消失
5. 3秒后q_ProductInPlaceDone复位，通知上游设备可以开始下一个周期
6. 若需要切换电机方向，确保电机停止后修改i_MotorDirection值

## 故障排查
### 故障排查流程图
```
┌─────────────────────┐
│ 故障现象：电机不运行 │
└─────────────┬───────┘
              ▼
┌─────────────────────┐
│ 检查启动信号是否正常 │
└─────────────┬───────┘
              ▼
┌─────────────────────┐     否     ┌─────────────────────┐
│ 信号正常？          │──────────►│ 检查信号线路和按钮  │
└─────────────┬───────┘           └─────────────────────┘
      是     ▼
┌─────────────────────┐
│ 检查运行模式设置    │
└─────────────┬───────┘
              ▼
┌─────────────────────┐     否     ┌─────────────────────┐
│ 模式设置正确？      │──────────►│ 检查主控模式信号    │
└─────────────┬───────┘           └─────────────────────┘
      是     ▼
┌─────────────────────┐
│ 检查故障标志        │
└─────────────┬───────┘
              ▼
┌─────────────────────┐     是     ┌─────────────────────┐
│ 有故障？            │──────────►│ 检查速度模式冲突    │
└─────────────┬───────┘           └─────────────────────┘
      否     ▼
┌─────────────────────┐
│ 检查电机接触器      │
└─────────────────────┘
```

| 故障现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 电机不运行 | 未输入启动信号 | 检查启动按钮和信号线路 |
| 速度异常 | 模式设置错误 | 检查模式选择和速度设置 |
| 故障报警 | 速度模式冲突 | 按下复位按钮清除错误状态后重新启动 |
| 模式切换失败 | 输入信号冲突 | 确保同一时间只有一个模式的信号有效 |
| 电机方向不切换 | 电机未停止 | 确保电机停止后再切换方向 |
| 产品到位标志不复位 | 传感器信号异常 | 检查传感器安装和信号线路 |
| 计时器不工作 | 计时器变量未初始化 | 检查计时器数组变量设置 |
| 方向输入错误 | 输入值不在有效范围 | 确保输入值为0或1，按下复位按钮清除错误 |
| 模式不匹配 | 启动信号与当前模式不匹配 | 确保在正确的模式下使用对应的启动信号，按下复位按钮清除错误 |

## 注意事项
1. **安全操作**：操作前确保熟悉设备安全规程
2. **信号隔离**：确保输入信号的隔离和保护
3. **负载匹配**：确保电机接触器容量与电机匹配
4. **定期维护**：定期检查电气连接和机械部件
5. **复位按钮使用**：遇到错误状态时，应按下复位按钮清除错误后再重新启动
6. **方向控制**：电机运行时禁止切换方向，应确保电机停止后再修改方向设置
7. **模式切换**：模式切换时系统会自动处理当前状态，无需手动停止
8. **方向输入范围**：电机方向输入值应在0-1范围内，超出范围会触发错误
