## 3. 系统概述

### 3.1 系统简介

自动撕胶带机HMI系统用于监控和控制自动撕胶带机的运行状态，包括系统启动/停止、参数设置、状态监控、报警处理等功能。

### 3.2 HMI硬件信息

| 项目 | 规格 |
|------|------|
| HMI型号 | Pro-face GP系列 |
| 屏幕尺寸 | 10.4英寸 |
| 分辨率 | 800×600 |
| 通信接口 | 以太网、RS-485 |
| 电源 | 24VDC |

### 3.3 系统功能

- 系统状态监控
- 设备状态监控
- 手动/自动模式切换
- 参数设置
- 报警处理
- 历史数据查询

## 4. 画面导航

### 4.1 主画面

主画面是系统的入口，显示系统的整体状态和主要操作按钮。

**功能**：
- 显示系统运行状态
- 提供手动/自动模式切换
- 提供系统启动/停止按钮
- 提供画面导航菜单

### 4.2 状态监控画面

状态监控画面显示系统和设备的详细状态信息。

**功能**：
- 显示系统状态（运行、停止、错误等）
- 显示设备状态（电机、电磁阀、传感器等）
- 显示报警信息
- 显示计数器数据

### 4.3 参数设置画面

参数设置画面用于设置系统运行参数。

**功能**：
- 设置胶带长度
- 设置胶带速度
- 设置循环时间
- 设置延迟时间

### 4.4 手动操作画面

手动操作画面用于手动控制设备。

**功能**：
- 手动控制电机
- 手动控制电磁阀
- 手动测试传感器

### 4.5 报警画面

报警画面显示系统的报警信息。

**功能**：
- 显示当前报警
- 显示历史报警
- 提供报警确认功能

### 4.6 历史数据画面

历史数据画面显示系统的历史运行数据。

**功能**：
- 显示循环计数
- 显示错误计数
- 显示胶带计数
- 提供数据查询功能

## 5. 操作流程

### 5.1 系统启动流程

1. 检查系统状态，确保系统处于就绪状态
2. 选择运行模式（自动/手动）
3. 点击启动按钮
4. 系统开始运行

### 5.2 自动模式操作流程

1. 在主画面选择自动模式
2. 设置运行参数（胶带长度、速度等）
3. 点击启动按钮
4. 系统自动运行，完成撕胶带任务
5. 系统自动停止或等待下一个任务

### 5.3 手动模式操作流程

1. 在主画面选择手动模式
2. 进入手动操作画面
3. 手动控制设备（电机、电磁阀等）
4. 测试传感器状态
5. 完成后返回主画面

### 5.4 参数设置流程

1. 进入参数设置画面
2. 修改相应参数（胶带长度、速度等）
3. 点击保存按钮
4. 系统应用新参数

### 5.5 报警处理流程

1. 系统出现报警时，报警画面会自动弹出
2. 查看报警信息，确定报警原因
3. 处理报警原因
4. 点击确认按钮，消除报警
5. 系统恢复正常运行

## 6. 操作说明

### 6.1 按钮操作

| 按钮名称 | 功能 | 操作方法 |
|----------|------|----------|
| 启动按钮 | 启动系统 | 点击按钮，系统开始运行 |
| 停止按钮 | 停止系统 | 点击按钮，系统停止运行 |
| 复位按钮 | 复位系统 | 点击按钮，系统复位 |
| 急停按钮 | 紧急停止 | 点击按钮，系统紧急停止 |
| 自动模式 | 切换到自动模式 | 点击按钮，系统切换到自动模式 |
| 手动模式 | 切换到手动模式 | 点击按钮，系统切换到手动模式 |
| 保存按钮 | 保存参数 | 点击按钮，保存当前参数设置 |
| 确认按钮 | 确认操作 | 点击按钮，确认当前操作 |

| 操作 | 方法 | 说明 |

## 7. 故障排除

### 7.1 常见故障及处理方法

| 故障现象 | 可能原因 | 处理方法 |
|----------|----------|----------|
| 系统无法启动 | 系统未就绪 | 检查系统状态，确保所有设备正常 |
| 设备无响应 | 通信故障 | 检查通信连接，确保PLC与HMI通信正常 |
| 参数设置无效 | 参数未保存 | 确保修改参数后点击保存按钮 |
| 报警无法消除 | 报警原因未处理 | 处理报警原因后再确认报警 |
| 画面切换异常 | HMI程序错误 | 重启HMI设备 |

### 7.2 维护建议

1. 定期检查HMI设备的电源和通信连接
2. 定期备份HMI项目文件
3. 定期更新HMI固件
4. 定期清理HMI屏幕，保持屏幕清洁
5. 避免在HMI屏幕上使用尖锐物体

## 8. 安全注意事项

1. 操作HMI时，应遵循安全操作规程
2. 系统运行时，不要随意修改参数
3. 紧急情况下，应使用急停按钮停止系统
4. 维护HMI设备时，应先切断电源
5. 不要在HMI设备上放置重物或液体
