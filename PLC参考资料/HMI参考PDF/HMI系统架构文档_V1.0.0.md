## 3. 系统架构概览

### 3.1 架构层次

自动撕胶带机HMI系统采用分层架构，从上到下依次为：

1. **画面层**：用户界面，包括主画面、状态监控画面、参数设置画面等
2. **逻辑层**：HMI内部逻辑，处理用户操作和数据转换
3. **通信层**：负责与PLC的通信，包括数据采集和命令下发
4. **设备层**：PLC和现场设备，执行实际的控制任务

### 3.2 系统组件

| 组件 | 功能 | 说明 |
|------|------|------|
| HMI设备 | 用户界面和操作控制 | Pro-face GP系列，10.4英寸触摸屏 |
| PLC | 逻辑控制和设备管理 | Siemens S7-1200 |
| 通信网络 | 数据传输 | 以太网，Modbus TCP协议 |
| 现场设备 | 执行机构 | 电机、电磁阀、传感器等 |

## 5. 数据流分析

### 5.1 数据流向

1. **从现场设备到HMI**：
   - 传感器检测信号 → PLC → 通信层 → 逻辑层 → 画面层（状态显示）

2. **从HMI到现场设备**：
   - 用户操作 → 画面层 → 逻辑层 → 通信层 → PLC → 现场设备（控制执行）

### 5.2 数据类型

| 数据类型 | 流向 | 说明 |
|----------|------|------|
| 状态数据 | 设备→HMI | 系统和设备的运行状态 |
| 控制数据 | HMI→设备 | 用户操作和控制命令 |
| 参数数据 | HMI↔设备 | 系统运行参数，可双向传输 |
| 报警数据 | 设备→HMI | 系统和设备的报警信息 |
| 历史数据 | 设备→HMI | 系统运行的历史记录 |

## 6. 系统功能模块

### 6.1 监控模块

**功能**：实时监控系统和设备的运行状态

**组件**：
- 状态显示画面
- 数据采集逻辑
- 实时数据更新

**流程**：
1. PLC采集现场设备状态
2. HMI通过通信层获取PLC数据
3. 逻辑层处理数据
4. 画面层显示状态信息

### 6.2 控制模块

**功能**：控制设备的运行

**组件**：
- 控制按钮
- 控制逻辑
- 命令下发

**流程**：
1. 用户操作控制按钮
2. 画面层传递操作信息
3. 逻辑层处理控制命令
4. 通信层下发命令到PLC
5. PLC执行控制操作

### 6.3 参数设置模块

**功能**：设置系统运行参数

**组件**：
- 参数设置画面
- 参数验证逻辑
- 参数保存

**流程**：
1. 用户进入参数设置画面
2. 修改参数值
3. 逻辑层验证参数有效性
4. 通信层下发参数到PLC
5. PLC更新参数设置

### 6.4 报警模块

**功能**：处理系统报警

**组件**：
- 报警画面
- 报警检测逻辑
- 报警确认

**流程**：
1. 现场设备产生报警
2. PLC检测到报警信号
3. HMI通过通信层获取报警信息
4. 逻辑层处理报警信息
5. 画面层显示报警画面
6. 用户确认报警
7. 逻辑层发送确认信号
8. PLC复位报警

### 6.5 历史数据模块

**功能**：记录和查询系统运行历史数据

**组件**：
- 历史数据画面
- 数据存储
- 数据查询逻辑

**流程**：
1. PLC采集运行数据
2. HMI通过通信层获取数据
3. 逻辑层处理和存储数据
4. 用户进入历史数据画面
5. 逻辑层查询历史数据
6. 画面层显示历史数据

## 7. 通信架构

### 7.1 通信协议

| 协议 | 用途 | 配置 |
|------|------|------|
| Modbus TCP | PLC与HMI通信 | 端口502，IP地址192.168.1.100 |
| Ethernet | 网络通信 | 100Mbps，全双工 |

### 7.2 通信流程

1. **数据采集**：
   - HMI定时发送读取请求到PLC
   - PLC响应请求，返回数据
   - HMI接收数据并更新画面

2. **命令下发**：
   - 用户操作HMI界面
   - HMI发送控制命令到PLC
   - PLC执行命令并返回执行结果
   - HMI更新界面状态

## 8. 系统安全

### 8.1 安全架构

| 安全层级 | 措施 | 说明 |
|----------|------|------|
| 物理安全 | 设备防护 | 防止物理损坏和未授权访问 |
| 网络安全 | 网络隔离 | 限制网络访问范围 |
| 系统安全 | 权限管理 | 设置不同用户权限 |
| 数据安全 | 数据加密 | 保护敏感数据 |

### 8.2 安全措施

1. **物理安全**：
   - HMI设备安装在安全位置
   - 防止灰尘、液体和机械损坏

2. **网络安全**：
   - 使用专用网络
   - 限制网络访问权限
   - 定期检查网络连接

3. **系统安全**：
   - 设置用户密码
   - 分配不同权限级别
   - 记录操作日志

4. **数据安全**：
   - 备份重要数据
   - 加密敏感数据
   - 定期清理数据
