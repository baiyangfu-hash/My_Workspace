## 目的
为了统一PLC项目全层级命名规范，提高项目管理效率和可追溯性，特制定本规范。本规范适配工业自动化行业标准，适用于多平台、多工作流、多生命周期的PLC项目管理。

## 核心原则（适配工业自动化行业标准）
- **唯一性**：项目号全局唯一，工作流/组件编号在所属层级内唯一，避免跨项目冲突；
- **可读性**：名称含「核心功能+设备类型+控制方式」，无需额外说明即可识别项目用途；
- **可追溯性**：关联「项目号+层级标识」，支持从文件反向定位至总项目/工作流/组件；
- **兼容性**：适配多平台（Work3/Autoshop）、多工作流（输送/搬运/通讯）、多生命周期（在研/交付/维护）；
- **扩展性**：规范应能适应未来技术发展和新的开发工具。

## 一、总项目命名规范（行业主流格式）

### 1. 项目号规则（全局唯一）
```plaintext
[业务线前缀]-[年份]-[3位序号]
```

**说明**：
- **业务线前缀（可选）**：按行业常见业务分类，统一缩写（避免冗余）：
  - ZD：自动化整线（如汽车零部件装配线、电子厂总装线）
  - DJ：单机设备（如独立测试台、专用控制柜）
  - XT：系统升级（如既有产线PLC程序升级、功能扩展）
  - WX：维保项目（如设备故障修复、程序优化）
- **年份**：4位数字（如2025、2026），对应项目立项年份；
- **3位序号**：001-999，按立项顺序编排，同一业务线+年份内不重复。

### 2. 项目名称规则（含核心功能）
```plaintext
项目号_客户简称（可选）_核心设备_控制类型_核心功能
```

**行业通用示例**：
- ZD-2025-001_XX汽车_发动机装配线_PLC_全流程自动化控制
- DJ-2025-002_XX电子_芯片测试台_PLC+变频_精准温控与数据采集
- XT-2025-003_XX机械_旧产线_PLC程序_多工作流协同升级
- WX-2025-004_XX化工_反应釜控制柜_PLC_故障修复与功能优化

### 3. 简写规则（用于目录/文件名缩写）
```plaintext
项目号_核心功能简写（2-4字）
```

**示例**：
- ZD-2025-001_发动机装配自动化
- DJ-2025-002_芯片测试温控采集
