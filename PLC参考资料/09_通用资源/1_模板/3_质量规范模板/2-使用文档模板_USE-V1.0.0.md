## 安装与配置
### 1. 变量表导入
1. 在PLC编程软件中创建新的FB
2. 导入`FB_导入PLC变量_[功能块名称]_autoshop_v1.0.0.csv`变量表
3. 确保变量表使用GBK编码

### 2. FB实例化
```scl
// 声明FB实例
VAR
    fb[功能块名称] : [功能块名称];
END_VAR

// 调用FB
fb[功能块名称](
    // 输入信号连接
    i_ManualStart := [手动启动信号],    // 手动启动按钮
    i_ManualStop := [手动停止信号],     // 手动停止按钮
    i_AutoStart := [自动启动信号],      // 自动启动信号
    i_AutoStop := [自动停止信号],       // 自动停止信号
    
    // 输出信号连接
    q_[执行机构]Running => [运行状态输出],   // [执行机构]运行指示灯
    q_[执行机构][Mode1] => [模式1输出],      // [执行机构][模式1]接触器
    q_[执行机构][Mode2] => [模式2输出],      // [执行机构][模式2]接触器
    q_[执行机构]Fault => [故障状态输出]      // 故障报警指示灯
);
```

## 操作指南
### 手动模式操作
1. **启动**：按下手动启动按钮（[手动启动信号]）
2. **停止**：按下手动停止按钮（[手动停止信号]）
3. **[功能1]**：手动模式下默认为[模式2]运行

### 自动模式操作
1. **启动**：系统发送自动启动信号（[自动启动信号]）
2. **停止**：系统发送自动停止信号（[自动停止信号]）
3. **[功能1]**：自动模式下初始为[模式2]，[检测对象]到位后切换为[模式1]，[延时时间]后停止

### 故障处理
1. **故障指示**：故障报警指示灯（[故障状态输出]）亮起
2. **故障原因**：[功能1]模式冲突（运行状态与停止[功能1]模式的冲突）
3. **故障复位**：停止[执行机构]后重新启动

## 应用场景示例

### 场景1：[场景1名称]应用
**应用描述**：在[场景1名称]中，[设备类型]需要根据[检测对象]位置自动调整[功能1]，确保[场景1目标]。

**配置步骤**：
1. **变量表导入**：导入`FB_导入PLC变量_[功能块名称]_autoshop_v1.0.0.csv`
2. **传感器连接**：将[传感器类型]连接到[传感器信号]（i_[SensorName]）
3. **主控连接**：将主控系统的运行模式信号连接到[模式信号]（i_MainControlMode）
4. **参数设置**：设置i_[DelayTime]为[延时时间]（[延时描述]）

**运行流程**：
1. 主控系统设置i_MainControlMode为2（自动模式）
2. 发送i_AutoStart信号启动[设备类型]
3. [设备类型][模式2]运行，当[检测对象]到达[检测位置]时，传感器[传感器信号]检测到信号
4. [设备类型]切换为[模式1]运行[延时时间]
5. [延时时间]后自动停止，同时q_[Detection]Done置为TRUE
6. [检测对象]被[处理动作]后，传感器[传感器信号]信号消失，[复位延时]后q_[Detection]Done自动复位

### 场景2：[场景2名称]应用
**应用描述**：在[场景2名称]中，[设备类型]需要与上下游设备协调，确保[场景2目标]。

**配置步骤**：
1. **变量表导入**：导入`FB_导入PLC变量_[功能块名称]_autoshop_v1.0.0.csv`
2. **[控制参数]控制**：将[控制参数]控制信号连接到[控制信号]（i_[ControlName]）
3. **状态反馈**：将q_[Detection]Done连接到上游设备的[反馈信号]
4. **参数设置**：设置i_[DelayTime]为[延时时间]（[延时描述]）

**运行流程**：
1. 上游设备完成[上游操作]后，发送i_AutoStart信号
2. [设备类型][模式2]运行将[检测对象]送往下游
3. [检测对象]到达[检测位置]后，切换为[模式1]运行[延时时间]
4. 下游设备[下游操作][检测对象]后，传感器信号消失
5. [复位延时]后q_[Detection]Done复位，通知上游设备可以开始下一个周期

│ 故障现象：[执行机构]不运行 │

              ▼

      是     ▼
┌─────────────────────┐
│ 检查运行模式设置    │

              ▼
┌─────────────────────┐     否     ┌─────────────────────┐

              ▼

| 故障现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| [执行机构]不运行 | 未输入启动信号 | 检查启动按钮和信号线路 |
| [功能1]异常 | 模式设置错误 | 检查模式选择和[功能1]设置 |
| 故障报警 | [功能1]模式冲突 | 停止[执行机构]后重新启动 |
| 模式切换失败 | 输入信号冲突 | 确保同一时间只有一个模式的信号有效 |
| [执行机构][控制参数]不切换 | [执行机构]未停止 | 确保[执行机构]停止后再切换[控制参数] |
| [检测对象]到位标志不复位 | 传感器信号异常 | 检查传感器安装和信号线路 |
| 计时器不工作 | 计时器变量未初始化 | 检查计时器数组变量设置 |
