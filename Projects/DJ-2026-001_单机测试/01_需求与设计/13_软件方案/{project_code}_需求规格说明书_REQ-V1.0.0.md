## 1. 引言

### 1.1 编写目的
本文档定义单机测试项目的软件需求，作为PLC程序开发和HMI设计的依据。

### 1.2 项目背景
- 设备类型: 单机自动化设备
- 控制系统: PLC + HMI
- 参考项目: DJ-2026-005 边框缓存机

### 1.3 术语定义
| 术语 | 定义 |
|------|------|
| FB | Function Block 功能块 |
| OB | Organization Block 组织块 |
| HMI | Human Machine Interface 人机界面 |
| ST | Structured Text 结构化文本 |

### 1.4 参考文献
- IEC 61131-3 编程规范
- 公司PLC编程规范
- DJ-2026-005 边框缓存机项目文档

## 2. 总体描述

### 2.1 产品概述
侧耳

### 2.2 用户特征
| 用户类型 | 操作内容 | 技能要求 |
|----------|----------|----------|
| 操作工 | 生产操作、异常处理 | 基础培训 |
| 维修工 | 故障排查、参数调整 | 中级培训 |
| 工程师 | 程序修改、系统调试 | 高级资质 |

### 2.3 运行环境
- **硬件环境**: CPU型号、IO模块、HMI型号
- **软件环境**: 编程软件版本、HMI开发软件
- **网络环境**: 通讯协议、波特率

### 2.4 设计约束
- 必须符合IEC 61131-3规范
- 采用Device-Logic-Main三层架构
- 遵循公司命名规范

## 3. 具体需求

### 3.1 功能需求

#### 3.1.1 系统控制功能
| ID | 功能描述 | 优先级 | 验收标准 |
|:--:|----------|:------:|----------|
| F001 | 自动/手动模式切换 | 必须 | 切换响应<100ms |
| F002 | 启停控制 | 必须 | 符合安全规范 |
| F003 | 回原点功能 | 必须 | 定位精度±0.1mm |
| F004 | 急停保护 | 必须 | 响应时间<30ms |

#### 3.1.2 设备层功能
- IO映射管理
- 单轴定位控制
- 执行器驱动

#### 3.1.3 逻辑层功能
- 工艺流程控制
- 顺序状态机
- 步进逻辑

#### 3.1.4 主控层功能
- 系统模式管理
- 启停调度
- 故障处理

### 3.2 性能需求
| 指标 | 要求 | 测试方法 |
|------|------|----------|
| PLC扫描周期 | <10ms | 诊断缓冲区 |
| 急停响应时间 | <30ms | 示波器测量 |
| 定位精度 | ±0.1mm | 千分表检测 |
| HMI刷新周期 | <500ms | 秒表测量 |

### 3.3 安全需求
- 急停回路独立于PLC
- 安全门联锁
- 光幕保护(如有)
- 故障安全原则

### 3.4 接口需求

#### 3.4.1 HMI接口
- 通讯协议: Modbus RTU/Ethernet
- 变量映射清单
- 报警显示规则

#### 3.4.2 上位机接口(预留)
- 通讯协议: OPC UA / Modbus TCP
- 数据交换格式
