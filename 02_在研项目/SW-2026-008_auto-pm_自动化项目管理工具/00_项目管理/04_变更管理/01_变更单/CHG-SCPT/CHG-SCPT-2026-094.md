## 4. 变更原因

**变更背景**：
V0.9.0 Phase 1（CHG-093）已删除 tests/ui/ + tests/gui/ 43 个旧 QWidget 测试文件（dogfooding #24 闭环），旧 QWidget GUI 的测试依赖已清除。main_window.py 及其依赖的 7 个旧 QWidget 模块目录不再有测试覆盖，也无生产引用（V0.8.0 CLI 默认入口已翻转为 QML）。

**变更必要性**：
1. 删除已废弃的 QWidget 代码，消除维护负担（~21,300 行旧代码）
2. 消除 main_window.py 的 try/except 占位 QWidget 类（V0.8.0 临时兼容）
3. 删除 auto_pm/gui/ 兼容包（仅做 MainWindow 重导出）
4. 删除 scripts/gui_plc_full_test.py 旧版全功能测试脚本

**约束**：
- 保留 `auto_pm/ui/global_pages/spec_center_dto.py` — QmlBridge.py 仍通过 SpecCenterAdapter 使用
- 保留 `auto_pm/ui/global_pages/global_view.py` — 待确认是否有非 main_window 引用
- 保留 `auto_pm/ui/__init__.py` — 移除 MainWindow 导入，改为空模块 docstring
- 保留 `auto_pm/ui/qml/` 整个目录 — QML 是当前默认 UI
- 保留 `auto_pm/ui/qml_main_window.py` — QML 入口
- 保留 `auto_pm/ui/models/` — QML 和 QWidget 共用
