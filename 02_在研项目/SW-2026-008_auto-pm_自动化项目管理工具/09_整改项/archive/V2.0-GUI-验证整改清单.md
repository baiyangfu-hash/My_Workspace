## UI-001 [高] 项目列表页搜索框布局异常

**现象**：截图1 显示搜索框位置偏左上，与侧边栏视觉关系不协调。
搜索框似乎位于侧边栏右侧边缘与内容区之间，而非完全在内容区内，
导致整体视觉层次混乱。

**预期行为**：搜索框应完整位于内容区域顶部，与统计栏对齐，
形成清晰的内容区头部区域。

**复现步骤**：
1. 启动 `python main.py gui`
2. 观察「项目列表」页面顶部的搜索框位置

**涉及文件**：
- `auto_pm/ui/views/project_list_view.py` — 搜索栏布局代码

## UI-002 [中] 统计栏数据全为0 + 工作空间默认值不合理

**现象**：截图1 显示所有统计数据为 0（项目 0、开发中 0、PLC 0、SW 0 等）。
这是因为启动时工作空间根目录默认指向了项目自身目录，
导致扫描不到任何子项目。

**日志证据**：
```
扫描完成: 发现 0 个项目
```

**预期行为**：
- 方案A：启动时自动向上探测到 `02_在研项目` 或 `Python自动化项目总库` 目录
- 方案B：在 GUI 首次启动时弹出「选择工作空间」对话框
- 方案C（最低限度）：在空状态时显示引导提示文案，如「请通过菜单设置工作空间根目录」

**涉及文件**：
- `auto_pm/ui/main_window.py` — 启动逻辑
- `auto_pm/app_context.py` — 工作空间默认值

## UI-003 [中] 占位页面视觉一致性差

**现象**：截图2~5 显示四个未实现功能的占位页面：

| 页面 | 提示文字 | 计划版本 |
|------|----------|----------|
| 规范中心 | "规范中心 功能将在 V2.2 交付" | V2.2 |
| 模板管理 | "模板管理 功能将在 V2.4 交付" | V2.4 |
| 报告中心 | "报告中心 功能将在 V2.4 交付" | V2.4 |
| 系统设置 | "系统设置 功能将在 V2.5 交付" | V2.5 |

**问题**：
1. 占位页面背景色为深灰色 (#2b2b2b 或类似)，与项目列表页的浅色风格不一致
2. 文字居中显示但缺少图标或装饰，显得过于简陋
3. 「规范中心」页面的 Tab 标签显示为浅色（截图2），与其他页面的深色 Tab 不一致？

**预期行为**：统一占位页面风格，使用与主页面一致的配色方案，
添加功能图标和更友好的提示文案。

**涉及文件**：
- `auto_pm/ui/views/` 下各占位视图文件

## UI-004 [低] 状态栏信息不完整

**现象**：截图5 右下角状态栏显示：
```
项目: 0    变更: 0    D8 已连接    上次扫描: —
```

**问题**：
1. "D8 已连接" 含义不明——可能是指 SQLite 数据库连接状态？
   如果是应改为更清晰的文案，如 "DB 已连接"
2. "上次扫描: —" 在首次启动时合理，但扫描后应更新为相对时间
3. 缺少当前工作空间路径的显示

**涉及文件**：
- `auto_pm/ui/main_window.py` — 状态栏初始化
