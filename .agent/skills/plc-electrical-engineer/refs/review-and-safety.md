# 评审、证据与安全边界

## 证据标签与等级

输出任何结论时必须区分：观测事实 / 推断假设 / 建议检查 / 拟议修正。

### 响应标签

- Known（已知）
- Assumed（假设）
- Open point（待确认）
- Must confirm on site（必须现场确认）

### 证据等级（复杂任务建议显式输出）

- E1 已确认：源码、文档、规范三方一致或源码直接可证实
- E2 代码推断：源码可推断，但缺少外部文档/硬件信息
- E3 文档推断：文档有描述，但源码或现场资料不足
- E4 证据不足：只能做保守推断，禁止包装成确定结论

## 高风险反模式清单（必须警惕）

以下反模式一旦出现，必须主动指出：

1. 接口宣称能力已支持，但逻辑未实现
   - 模式参数写进接口但没有分支逻辑
   - 速度、控制模式、预留功能只有注释，没有实现
   - 文档写“支持”，源码实际只是保留字段
2. 用文档假设代替代码互锁
   - 注释写“调用方保证互锁”
   - 文档写“外部保证先决条件”
   - 代码里没有任何保护
3. 关键动作步无超时 / 无退路
   - 状态迁移只等到位
   - 子步骤无超时
   - 通信等待无超时
4. 手动 / 自动切换无状态收敛
   - 手动输出直接接管，但不清理自动状态
   - 从手动回自动时保留旧步号、旧锁存、旧定时器
5. 把 PLC 必须执行的逻辑交给 HMI / 上位机
   - 总量、顺控、互锁、报警条件依赖上位轮询
   - HMI 中断后设备进入不确定状态
6. 模板抽象过度
   - 为通用而丢失现场语义
   - 结构体看似共享，实际没有稳定对象边界
   - 不同设备被强行塞进同一对象模型

## 成熟度目标（技能自检）

- M1 可读：工艺对象明确；命名清晰；注释可追踪
- M2 可维护：FB 分层清楚；结构体边界合理；模板和规范有锚点
- M3 可验证：有编译检查点；有逻辑验证点；有现场验证点
- M4 可迭代：规范变更后知道哪里要改；模板更新不会失控扩散；专用与共享边界明确
- M5 可交付：源码、接口、设计、验证口径一致；结论带证据等级；风险和人工复核点明确

## 编程前必要文档机制

在真正编码前，至少输出：

1. 设计摘要：控制对象、适用场景、模式边界、风险边界
2. 接口摘要：FB 接口草案、结构体草案、关键参数及单位
3. FB / 结构体决策记录：为什么 FB/FC、为什么专用/共享、为什么放置位置
4. 验证清单：编译项、逻辑项、场景项、现场项

复杂任务追加：程序设计文档段落、接口文档段落、风险与兼容性说明。

## 规范驱动模板机制（必须执行）

### 模板主来源

所有模板输出至少对齐以下来源：

- `023_PLC程序设计文档模板_PLC.md`
- `815_PLC接口文档模板_INT.md`
- `903_定时器使用规范_LSP.md`
- `904_SCL注释规范_LSP.md`
- `905_SCL编程规范_LSP.md`
- `906_错误预防规则_LSP.md`
- `907_项目配置规范_LSP.md`

### 模板使用前必须核对

- 文件存在性
- `spec_id` / `version` / `lifecycle` / `canonical_path`
- 当前项目实现是否有更近约束

### 冲突处理方式

若规范与当前项目实现冲突，必须明确输出：

- 本地规范要求
- 当前项目实现
- 建议采用版本
- 需人工确认项

### 模板迭代规则

- 版本敏感：引用规范时必须关注 frontmatter 的版本和状态
- 冲突优先级：项目真实已落地实现与现场约束 > 当前有效项目级文档 > 本地 LSP 规范与标准模板 > 技能内部默认模板
- 更新动作：指出受影响段落、说明旧模板为何失效、给出新骨架、提醒同步检查源码/IFC/DSN/PM_SESSION
- 正确性要求：缺少必要规范/文档/实现依据时必须说明“当前模板为保守版本”

## 统一输出骨架（复杂任务优先）

1. 工艺视角：控制对象、执行器/传感器、模式边界、互锁与安全态
2. TIA 实现视角：FB/FC/DB/状态机/定时器实现、扫描周期影响、实例化与保持态
3. 本地规范视角：是否违反 023/815/903/904/905/906/907 或 `plc-rules.md`；平台错误/规范偏差/项目偏差；主要依据
4. FB / 结构体视角：分层是否清晰、结构体定位是否正确、是否过度抽象、模板是否匹配当前规范版本
5. 风险与人工复核：必须人工确认/编译验证/现场验证点；哪些结论只是代码层保守推断

## 何时必须提醒人工复核

以下内容必须明确提醒“人工复核后再落地”：

- 状态机
- 安全门 / 急停 / 联锁
- 报警等级与报警锁存
- IO 映射
- 轴控 / 伺服 / 运动控制
- 多工站协同逻辑
- 手自动切换
- 现场接线与极性判断
