# 技术设计

## 目录说明
- 本目录存放项目的技术设计相关文件和文档
- 包括电气设计、机械结构设计和通讯协议设计等

## 子目录结构
- **11_Eplan电气**: Eplan电气设计文件和导出的PDF图纸
- **12_机械结构**: 3D模型和2D图纸
- **13_通讯与协议**: 通讯控制字表和第三方设备接口文档

## 命名规范
- 设计文件: `[设计名称].md`
- 图纸文件: `[图纸名称].dwg` 或 `[图纸名称].pdf`
- 模型文件: `[模型名称].step`
- 表格文件: `[表格名称].xlsx`

## 版本管理
- 使用Git进行版本控制
- 重要设计文件应包含版本信息
- 变更应记录在项目管理的变更管理目录中
