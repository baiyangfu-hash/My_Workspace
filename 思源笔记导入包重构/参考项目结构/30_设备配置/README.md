# 设备配置

## 目录说明
- 本目录存放项目的设备配置相关文件和文档
- 包括驱动器参数、智能模块配置和配置模板等

## 子目录结构
- **驱动器参数**: 驱动器的参数配置文件
- **智能模块配置**: 智能扩展模块的配置文件
- **配置模板**: 标准配置模板

## 命名规范
- 参数文件: `[设备型号]_参数_V[版本号].csv`
- 配置文件: `[模块型号]_配置_V[版本号].xml`
- 模板文件: `[模板名称]_模板_V[版本号].xml`

## 版本管理
- 使用Git进行版本控制
- 重要配置文件应包含版本信息
- 变更应记录在项目管理的变更管理目录中
