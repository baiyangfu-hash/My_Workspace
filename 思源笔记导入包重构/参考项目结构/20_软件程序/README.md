# 软件程序

## 目录说明
- 本目录存放项目的软件程序相关文件和文档
- 包括PLC程序、HMI程序、机器人控制程序和上位机与脚本等

## 子目录结构
- **21_PLC_Work3**: PLC程序源文件和文档
- **22_HMI_ProFace**: HMI程序源文件和文档
- **23_机器人控制**: 机器人控制程序和文档
- **24_上位机与脚本**: 上位机应用和脚本程序

## 命名规范
- 程序文件: `[程序名称].py` 或 `[程序名称].cs`
- 文档文件: `[文档名称].md`
- 配置文件: `[配置名称].json` 或 `[配置名称].xml`

## 版本管理
- 使用Git进行版本控制
- 重要程序文件应包含版本信息
- 变更应记录在项目管理的变更管理目录中
