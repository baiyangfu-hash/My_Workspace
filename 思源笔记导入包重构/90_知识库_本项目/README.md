# 知识库_本项目

## 目录说明
- 本目录存放项目的知识库相关文件和文档
- 这些文件不随项目交付，而是为了记录项目开发过程中的经验和知识

## 子目录结构
- **00_项目索引.md**: 项目索引文件，链接到所有重要文档
- **调试笔记**: 调试过程中的记录和经验
- **避坑指南**: 项目开发中遇到的问题和解决方案
- **最佳实践**: 项目开发中的最佳实践
- **技术选型**: 技术选型的依据和评估
- **外部资源**: 参考资料和学习资源

## 命名规范
- 笔记文件: `[日期]_[笔记标题].md`
- 指南文件: `[指南标题].md`
- 资源文件: `[资源名称].md`

## 版本管理
- 使用Git进行版本控制
- 重要文档应包含版本信息
- 变更应记录在项目管理的变更管理目录中
