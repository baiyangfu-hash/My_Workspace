# 项目管理

## 目录说明
- 本目录存放项目管理相关的文件和文档
- 包括项目立项、需求管理、进度跟踪、会议记录、变更管理和资源管理等

## 子目录结构
- **01_立项与需求**: 项目立项表、技术协议等
- **02_进度与风险**: 进度计划、风险登记册等
- **03_会议与沟通**: 会议记录、沟通文档等
- **04_变更管理**: 变更单、变更台帐等
- **05_资源管理**: 人员分配、设备清单等

## 命名规范
- 文档文件: `[文档名称].md`
- 会议记录: `[日期]_[会议名称].md`
- 变更单: `变更单_00[序号]_[变更内容].md`

## 版本管理
- 使用Git进行版本控制
- 重要文档应包含版本信息
- 变更应记录在变更管理目录中
