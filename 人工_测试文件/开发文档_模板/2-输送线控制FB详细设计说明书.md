## 1. 设计概述

### 1.1 设计目标
- 实现输送线的可靠控制，支持手动和自动两种模式
- 提供速度调节功能，支持停止、慢速、快速三种速度模式
- 实现产品检测和自动运行逻辑
- 提供故障检测和保护机制
- 确保系统稳定运行，避免状态振荡

### 1.2 设计原则
- **高内聚**：将相关功能封装在FB内部，减少外部依赖
- **低耦合**：通过明确的输入输出接口与外部系统交互
- **可靠性**：具备完善的故障检测和保护机制
- **可维护性**：代码结构清晰，文档完整，便于维护和扩展
- **安全性**：确保电机方向切换和运行模式切换的安全限制

### 1.3 系统架构
- **FB_ConveyorControlV4**：主功能块，包含完整控制逻辑
- **初始化模块**：系统初始化，变量重置
- **手动控制模块**：处理手动模式下的控制逻辑
- **自动控制模块**：处理自动模式下的控制逻辑
- **速度控制模块**：处理速度模式切换逻辑
- **故障检测模块**：检测和处理系统故障
- **电机方向控制模块**：处理电机方向控制逻辑
- **计时器模块**：管理系统计时器逻辑
- **状态管理模块**：管理系统运行状态

## 3. 故障处理逻辑

### 3.1 故障检测机制

#### 3.1.1 速度模式冲突检测
- **检测条件**：电机运行状态与速度模式设置不匹配
- **检测逻辑**：`IF tmp_bMotorRunning AND tmp_bSpeedMode = 0 THEN tmp_bMotorFault := TRUE;`
- **故障类型**：速度模式冲突
- **严重程度**：高
- **处理方式**：立即停止电机，设置故障标志

#### 3.1.2 传感器信号异常检测
- **检测条件**：传感器信号持续异常
- **检测逻辑**：通过计时器监测传感器信号持续时间
- **故障类型**：传感器异常
- **严重程度**：中
- **处理方式**：发出报警，保持当前状态

#### 3.1.3 电机方向控制异常检测
- **检测条件**：电机运行时尝试更改方向
- **检测逻辑**：`IF tmp_bMotorRunning THEN tmp_bDirectionChangeAllowed := FALSE;`
- **故障类型**：方向控制异常
- **严重程度**：高
- **处理方式**：忽略方向更改请求，保持当前方向

### 3.3 故障恢复策略

#### 3.3.1 自动恢复
- **适用故障**：轻微故障，如传感器信号短暂异常
- **恢复条件**：故障条件消失后自动恢复
- **恢复流程**：故障条件消失 → 计时器延时 → 自动复位故障标志 → 恢复正常运行

#### 3.3.2 手动恢复
- **适用故障**：严重故障，如速度模式冲突
- **恢复条件**：操作人员确认故障已排除
- **恢复流程**：停止电机 → 排除故障 → 手动复位 → 重新启动

#### 3.3.3 紧急停止
- **适用故障**：严重安全故障
- **恢复条件**：系统检测到严重安全隐患
- **恢复流程**：立即停止所有输出 → 锁定系统 → 人工干预 → 安全检查 → 手动复位

## 5. 维护指南

### 5.1 设计意图说明

#### 5.1.1 关键设计决策
- **模式控制方式**：采用CASE语句处理模式切换，清晰明了
- **速度控制方式**：使用状态变量跟踪速度模式，便于故障检测
- **故障处理方式**：采用条件判断检测故障，及时响应
- **计时器管理**：使用数组变量管理计时器，符合模板规范
- **安全限制**：添加电机方向和运行模式切换的安全限制，确保设备安全

#### 5.1.2 设计约束
- **硬件约束**：无特殊硬件依赖，可在不同PLC系统中使用
- **软件约束**：遵循IEC 61131-3标准，使用SCL语言
- **性能约束**：响应时间要求≤10ms，需要优化代码结构
- **安全约束**：必须确保电机方向和运行模式切换的安全性

### 5.2 维护注意事项

#### 5.2.1 常见问题
| 问题描述 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 电机不运行 | 启动信号未正确输入 | 检查输入信号线路和按钮 |
| 速度异常 | 速度模式设置错误 | 检查速度模式控制逻辑 |
| 故障报警 | 速度模式冲突 | 停止电机后重新启动 |
| 模式切换失败 | 输入信号冲突 | 确保同一时间只有一个模式信号有效 |
| 电机方向不切换 | 电机未停止 | 确保电机停止后再切换方向 |
| 产品到位标志不复位 | 传感器信号异常 | 检查传感器安装和信号线路 |
| 计时器不工作 | 计时器变量未初始化 | 检查计时器数组变量设置 |
