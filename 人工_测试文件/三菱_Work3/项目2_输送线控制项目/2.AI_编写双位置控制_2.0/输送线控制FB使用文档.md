# 输送线控制FB使用文档

## 1. 安装说明

### 1.1 硬件要求

| 设备类型 | 规格要求 | 备注 |
|----------|----------|------|
| PLC | 三菱FX5U系列或Q系列 | 支持GX Works3编程环境 |
| 传感器 | 光电传感器或接近开关 | 用于检测产品位置 |
| 气缸 | 标准气缸及电磁阀 | 用于产品定位和阻挡 |
| 继电器 | 24V直流继电器 | 用于控制电磁阀 |
| 电源 | 24V直流电源 | 为传感器和继电器供电 |

### 1.2 软件要求

| 软件名称 | 版本要求 | 用途 |
|----------|----------|------|
| GX Works3 | V1.0及以上 | PLC编程和调试 |
| 三菱GX Developer | V8.0及以上 | 可选，用于兼容性检查 |

### 1.3 安装步骤

1. **导入FB块**：
   - 打开GX Works3软件
   - 创建或打开现有项目
   - 通过"导入"功能导入 `FB_ConveyorLineControl_work3.st` 文件
   - 导入 `FB_导入PLC变量_输送线控制_work3.csv` 变量表格

2. **配置硬件连接**：
   - 根据变量表格中的地址映射，连接传感器和执行器
   - 确保所有输入输出点正确连接
   - 检查电源和接地是否良好

3. **编译和下载**：
   - 编译FB块，确保无语法错误
   - 下载到PLC中
   - 进行硬件测试和调试

#### 2.1.1 输入变量配置

| i_AutoMode | X2 | 自动模式选择开关，ON为自动模式 |
| i_ManualMode | X3 | 手动模式选择开关，ON为手动模式 |

| i_CylinderRetractCmd | X6 | 手动模式下的气缸缩回按钮 |
| i_AllowIn | M20 | 主控系统允许进料信号 |

| i_Robot_CurrentStation | D101 | 机械手当前工位号 |

| 变量名 | 地址 | 配置说明 |

| q_SysConveyorReady | M201 | 输送线就绪信号（至主控） |

### 2.3 参数调整

1. **气缸动作时间**：
   - 根据实际气缸的动作速度调整定时器设定值
   - 确保气缸有足够的时间完成动作

2. **报警阈值**：
   - 根据系统要求调整报警检测的阈值
   - 平衡灵敏度和误报率

3. **交互时序**：
   - 根据上下游设备的响应速度调整交互时序
   - 确保通信的可靠性

## 3. 操作流程

### 3.1 手动模式操作

1. **进入手动模式**：
   - 将 `i_ManualMode` 开关置为ON
   - 系统自动退出自动模式

2. **气缸控制**：
   - 按下 `i_CylinderExtendCmd` 按钮，气缸伸出
   - 按下 `i_CylinderRetractCmd` 按钮，气缸缩回
   - 两个按钮同时按下时，气缸保持当前状态

3. **状态监控**：
   - 观察 `q_IsReady` 和 `q_HasPart` 指示灯
   - 检查传感器状态是否正确显示

4. **退出手动模式**：
   - 将 `i_ManualMode` 开关置为OFF
   - 系统可进入自动模式或待机状态

### 3.2 自动模式操作

1. **进入自动模式**：
   - 确保系统已复位（`i_Reset` 按钮按下后释放）
   - 将 `i_AutoMode` 开关置为ON
   - 系统自动退出手动模式

2. **系统初始化**：
   - 系统进入初始化状态（`tmp_nState = 0`）
   - 检查传感器状态并进入相应状态
   - `q_SysConveyorReady` 和 `q_ConveyorReady` 置为ON

3. **正常运行**：
   - **等待产品状态**：气缸伸出，允许进料
   - **一号位置有产品**：气缸收回，请求取料
   - **二号位置有产品**：气缸收回，请求取料
   - **两个位置有产品**：气缸收回，禁止进料，请求取料

4. **机械手交互**：
   - 系统发送 `q_RequestPick` 信号请求取料
   - 收到 `i_Robot_TaskAck` 信号后，更新状态
   - 产品离开后，系统更新状态并继续运行

5. **故障处理**：
   - 发生故障时，`q_ErrorActive` 置为ON，`q_ErrorCode` 显示错误代码
   - 按下 `i_Reset` 按钮复位系统
   - 排除故障后，系统可重新进入自动模式

### 3.3 系统复位操作

1. **手动复位**：
   - 按下 `i_Reset` 按钮
   - 系统进入初始化状态，所有输出复位
   - 释放按钮后，系统开始正常运行

2. **系统复位**：
   - 主控系统发送 `i_SysResetRequest` 信号
   - 系统清除错误状态，准备重新运行
   - 复位完成后，`q_ProcessDone` 置为OFF

## 4. 故障排除

### 4.1 常见故障

| 故障现象 | 可能原因 | 排查步骤 | 解决方案 |
|----------|----------|----------|----------|
| 气缸不动作 | 电源故障 | 检查电磁阀电源 | 修复电源连接 |
| | 电磁阀故障 | 检查电磁阀线圈电阻 | 更换电磁阀 |
| | 控制信号异常 | 检查PLC输出点 | 修复输出点或更换模块 |
| 传感器无信号 | 传感器故障 | 检查传感器电源和输出 | 更换传感器 |
| | 信号线路故障 | 检查线路连接 | 修复线路连接 |
| | 产品检测位置不当 | 调整传感器位置 | 重新定位传感器 |
| 状态切换异常 | 传感器信号抖动 | 检查传感器安装稳定性 | 加固传感器安装 |
| | 状态机逻辑错误 | 检查状态机代码 | 修正逻辑错误 |
| 机械手交互失败 | 通信线路故障 | 检查通信线路 | 修复线路连接 |
| | 交互逻辑错误 | 检查交互代码 | 修正交互逻辑 |
| 报警持续触发 | 故障条件持续存在 | 检查故障原因 | 排除故障原因 |
| | 报警逻辑错误 | 检查报警代码 | 修正报警逻辑 |

### 4.2 错误代码解析

| 错误代码 | 错误类型 | 原因 | 解决方案 |
|----------|----------|------|----------|
| 0 | 无错误 | 系统正常运行 | 无需处理 |
| 1001 | 系统急停 | 检测到急停信号 | 检查急停按钮状态，排除故障后复位 |
| 2001 | 上游设备故障 | 上游输送线未就绪 | 检查上游设备状态 |
| 2002 | 下游设备故障 | 机械手未就绪 | 检查机械手状态 |

### 4.3 诊断工具

1. **GX Works3监控**：
   - 使用GX Works3的监控功能实时查看变量状态
   - 观察状态机状态变化，分析故障原因

2. **HMI界面**：
   - 通过HMI界面查看系统状态和错误信息
   - 利用HMI的趋势图功能分析系统运行情况

3. **万用表检查**：
   - 检查传感器输出信号
   - 测量电磁阀线圈电压
   - 检查PLC输入输出点状态

4. **示波器分析**：
   - 分析传感器信号波形，检测信号抖动
   - 测量系统响应时间，优化参数设置

## 5. 维护建议

### 5.1 日常维护

1. **传感器维护**：
   - 定期清洁传感器镜头，避免灰尘积累
   - 检查传感器安装是否牢固，避免振动影响
   - 定期校准传感器灵敏度，确保检测可靠性

2. **气缸维护**：
   - 定期检查气缸气源压力，保持在规定范围内
   - 定期润滑气缸运动部件，延长使用寿命
   - 检查气缸密封件，及时更换磨损的密封件

3. **电气系统维护**：
   - 检查接线端子是否松动，定期紧固
   - 检查电缆绝缘层是否损坏，及时更换
   - 保持电气控制柜清洁，避免灰尘和潮湿

### 5.2 定期维护

1. **月度维护**：
   - 检查所有传感器的工作状态
   - 测试气缸的动作速度和力量
   - 检查PLC的运行温度和状态
   - 备份PLC程序和参数设置

2. **季度维护**：
   - 全面检查电气系统，包括接线、端子、电缆等
   - 测试所有输入输出点的功能
   - 检查系统响应时间和性能指标
   - 更新程序到最新版本（如需要）

3. **年度维护**：
   - 对PLC进行全面检查和测试
   - 检查并更换老化的电气元件
   - 对系统进行全面的功能测试
   - 更新维护记录和系统文档

### 5.3 预防性维护

1. **备件管理**：
   - 储备常用备件，如传感器、电磁阀、继电器等
   - 建立备件库存管理系统，确保备件充足

2. **定期检查**：
   - 建立定期检查计划，提前发现潜在问题
   - 记录系统运行数据，分析趋势变化

3. **培训计划**：
   - 对操作人员进行定期培训，提高操作技能
   - 培训维护人员，掌握系统维护和故障排除技能

4. **更新计划**：
   - 跟踪系统软件和硬件的更新
   - 评估更新的必要性和可行性
   - 制定系统升级计划，保持系统的先进性

输送线控制FB的使用需要遵循正确的安装、配置和操作流程。通过本文档的指导，用户可以：

1. **正确安装和配置**系统，确保硬件连接和软件设置的正确性
2. **熟练操作**手动和自动模式，实现系统的正常运行
3. **快速排除故障**，减少系统 downtime
4. **定期维护**系统，延长设备使用寿命
5. **优化系统性能**，提高生产效率

通过严格遵循本文档的指导，可以确保输送线控制FB的稳定运行，为自动化生产线的高效运行提供有力支持。
