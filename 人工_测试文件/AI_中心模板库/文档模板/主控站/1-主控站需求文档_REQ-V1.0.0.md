## 1. 项目需求

### 1.1 功能需求
实现主控站对各工作站的监控和控制功能，以及与外部系统的通讯对接功能，包括但不限于：

1. **工作站状态监控**：
   - 实时监控各工作站运行状态
   - 收集工作站报警和故障信息
   - 统计工作站生产数据和效率

2. **工作站运行控制**：
   - 启动/停止工作站运行
   - 调整工作站运行参数
   - 协调多工作站工作顺序

3. **外部系统通讯**：
   - 与MES系统数据交互
   - 与ERP系统信息同步
   - 与HMI系统实时通讯

4. **数据管理**：
   - 生产数据采集和存储
   - 历史数据查询和分析
   - 报表生成和导出

### 1.2 非功能需求
1. **符合IEC 61131-3标准**：严格遵循标准规范
2. **模块化设计**：所有功能封装为FB功能块
3. **规范命名**：变量和文件命名遵循项目规范
4. **编码规范**：使用和模板文件相同的编码，确保Autoshop导入无乱码
5. **错误处理**：包含完整的报警和故障处理机制
6. **状态监控**：实时监控所有工作站状态和外部通讯状态
7. **可靠性**：系统稳定运行，支持7×24小时连续工作
8. **可扩展性**：支持工作站数量和类型的灵活扩展

## 2. 程序运行逻辑

### 2.1 FB功能块结构
FB_MainControlStation功能块包含六大模块：

1. **初始化模块**：
   - 初始化所有内部变量
   - 建立与各工作站的连接
   - 设置默认运行参数

2. **工作站监控模块**：
   - 实时采集各工作站状态
   - 处理工作站报警信息
   - 统计工作站生产数据

3. **工作站控制模块**：
   - 发送控制指令到各工作站
   - 协调多工作站工作流程
   - 处理工作站异常情况

4. **外部通讯模块**：
   - 与MES/ERP系统数据交换
   - 与HMI系统实时通讯
   - 处理外部系统请求

5. **报警处理模块**：
   - 集中管理所有报警信息
   - 实现报警分级和优先级
   - 提供报警处理建议

6. **状态机模块**：
   - 实现主控站整体状态管理
   - 确保各工作站按正确顺序运行
   - 处理状态转换逻辑

### 2.2 核心运行逻辑

#### 2.2.1 主控站工作流程
1. **初始化阶段**：
   - 系统启动并初始化
   - 建立与各工作站的连接
   - 连接外部通讯系统
   - 进入待机状态

2. **生产准备阶段**：
   - 接收生产计划
   - 分配生产任务到各工作站
   - 检查各工作站准备状态
   - 准备生产所需资源

3. **生产运行阶段**：
   - 启动各工作站按顺序运行
   - 实时监控生产状态
   - 处理生产过程中的异常
   - 与外部系统同步生产数据

4. **生产完成阶段**：
   - 确认所有工作站任务完成
   - 收集生产数据和报表
   - 清理生产现场状态
   - 准备下一生产任务

#### 2.2.2 工作站控制逻辑
- **启动控制**：按生产计划顺序启动各工作站
- **停止控制**：根据生产完成情况或异常情况停止工作站
- **参数调整**：根据生产需要实时调整工作站参数
- **协调控制**：确保多工作站之间的工作协调一致

#### 2.2.3 外部通讯逻辑
- **数据上传**：定期向MES/ERP系统上传生产数据
- **指令接收**：接收来自外部系统的控制指令
- **状态同步**：保持与外部系统的状态同步
- **异常处理**：处理通讯异常情况

### 2.3 状态字定义
状态字用于反映主控站和各工作站的当前状态，包括运行状态、报警状态、通讯状态等。

### 2.4 错误处理
1. **工作站错误**：各工作站故障时的处理机制
2. **通讯错误**：外部系统通讯故障时的处理机制
3. **系统错误**：主控站自身故障时的处理机制
4. **复位处理**：系统故障后的恢复和复位机制

## 6. 部署与使用

### 6.1 Autoshop导入步骤
1. **导入变量表格**：在Autoshop中导入变量表格文件，确认无乱码和格式错误
2. **导入FB功能块**：在Autoshop中导入FB功能块文件，确认编译通过
3. **实例化FB**：在程序中实例化FB_MainControlStation，连接输入输出变量
4. **配置工作站**：设置各工作站参数和通讯配置
5. **连接外部系统**：配置与MES/ERP/HMI系统的通讯参数

### 6.2 运行监控
1. **HMI监控**：在HMI画面中监控主控站和各工作站状态
2. **远程监控**：通过网络远程监控系统运行状态
3. **调试模式**：使用测试功能块进行功能测试和故障排查

## 7. 故障排查

### 7.1 常见问题
- **变量表乱码**：编码格式不正确，使用和模板文件相同的编码重新导入
- **工作站通讯失败**：检查网络连接和通讯参数设置
- **外部系统连接异常**：检查外部系统状态和通讯配置
- **状态显示异常**：检查工作站状态采集逻辑和数据传输
- **编译错误**：变量未定义或格式错误，检查变量表和FB代码，确保一致

### 7.2 故障处理流程
1. **识别故障**：通过HMI或监控系统识别故障
2. **定位原因**：根据故障现象和报警信息定位原因
3. **执行修复**：按照故障排查指南执行修复
4. **验证修复**：使用测试功能块验证修复效果
5. **记录故障**：记录故障原因和修复方法
