## 1. 功能块概述

### 1.1 功能块简介
FB_Workstation是一个工作站控制功能块，遵循IEC 61131-3标准，采用结构化文本（SCL）语言编写。该功能块具备初始化、手动控制、自动控制、报警处理和状态监控等功能，可广泛应用于各种工作站控制场景。

### 1.2 主要功能
- **初始化功能**：系统启动时初始化内部变量和状态
- **手动控制功能**：响应手动操作指令，实现手动模式下的控制
- **自动控制功能**：执行预设的自动控制流程，实现自动模式下的控制
- **报警处理功能**：检测和响应系统报警信号
- **状态监控功能**：监控系统运行状态，生成状态字反映系统状态
- **主控命令处理功能**：接收和执行来自主控站的命令，包括启动、急停、暂停、初始化
- **运行模式管理功能**：根据主控站设置的运行模式（自动、手动、半自动）执行相应操作
- **状态报告功能**：向主控站报告命令执行状态和工作站运行状态

### 1.3 应用场景
| 应用场景 | 详细说明 | 配置建议 |
|----------|----------|----------|
| 设备控制 | 控制各类工业设备的启动、停止和运行状态 | 标准配置 |
| 流程控制 | 执行预设的生产流程和工艺步骤 | 配置自动控制参数 |
| 状态监控 | 监控设备和系统的运行状态 | 配置状态字参数 |
| 报警管理 | 管理系统报警和故障处理 | 配置报警参数 |
| 主控站集成 | 接收主控站命令并执行，向主控站报告状态 | 配置主控命令和状态报告参数 |

## 2. 安装与配置

### 2.1 安装步骤
1. **准备工作**：确保已安装汇川Autoshop编程软件
2. **导入变量表**：
   - 在Autoshop中打开项目
   - 选择"导入" → "变量表"
   - 选择FB的变量表文件（.csv）
   - 确认导入无错误
3. **导入FB功能块**：
   - 在Autoshop中打开项目
   - 选择"导入" → "功能块"
   - 选择FB的功能块文件（.scl）
   - 确认导入无错误
4. **验证安装**：
   - 检查变量表是否正确导入
   - 检查FB功能块是否正确导入
   - 编译项目，确保无语法错误

### 2.2 配置参数
| 参数名称 | 数据类型 | 默认值 | 范围 | 配置方法 | 详细说明 |
|----------|----------|--------|------|----------|----------|
| 运行超时时间 | INT | 30000 | 1000-3600000 | PLC参数配置 | 设备运行的最大时间，超过此时间将自动停止并报警 |
| 报警延迟时间 | INT | 1000 | 0-10000 | PLC参数配置 | 报警信号触发后，系统响应的延迟时间 |
| 复位延迟时间 | INT | 500 | 0-5000 | PLC参数配置 | 复位信号触发后，系统响应的延迟时间 |

### 2.3 硬件要求
| 硬件组件 | 要求 | 详细说明 |
|----------|------|----------|
| PLC | 汇川Autoshop支持的PLC | 确保PLC型号与Autoshop版本兼容 |
| 输入模块 | 数字输入模块 | 用于接收外部输入信号 |
| 输出模块 | 数字输出模块 | 用于输出控制信号 |
| 通信模块 | 可选 | 用于与外部设备通信 |

|------|------|------|------|----------|

| 4-7 | 保留 | 保留位，用于未来扩展 | 0 | 保留给未来功能使用 |

## 4. 使用方法

### 4.1 功能块实例化
```scl
// 在主程序中实例化FB功能块
PROGRAM Main
VAR
    // 输入变量
    i_StartButton : BOOL;         // 启动按钮
    i_StopButton : BOOL;          // 停止按钮
    i_AutoMode : BOOL;            // 自动模式选择
    i_AutoStop : BOOL;            // 自动停止信号
    i_SystemAlarm : BOOL;         // 系统报警信号
    i_ResetButton : BOOL;         // 复位按钮
    
    // 主控命令输入
    i_MasterStart : BOOL;         // 主控启动命令
    i_MasterEStop : BOOL;         // 主控急停命令
    i_MasterPause : BOOL;         // 主控暂停命令
    i_MasterInit : BOOL;          // 主控初始化命令
    i_MasterMode : INT;           // 主控运行模式参数
    
    // 输出变量
    q_ControlOutput : BOOL;       // 控制输出
    q_AlarmStatus : BOOL;         // 报警状态
    q_SystemStatus : INT;         // 系统状态
    q_CmdStatus : INT;            // 命令执行状态
    q_WorkstationStatus : INT;     // 工作站状态
    
    // FB实例
    FB_WorkstationInstance : FB_Workstation;
END_VAR

// 主程序逻辑
FB_WorkstationInstance(
    i_ManualStart := i_StartButton,
    i_ManualStop := i_StopButton,
    i_AutoStart := i_AutoMode,
    i_AutoStop := i_AutoStop,
    i_Alarm := i_SystemAlarm,
    i_Reset := i_ResetButton,
    i_MasterCmd_Start := i_MasterStart,
    i_MasterCmd_EStop := i_MasterEStop,
    i_MasterCmd_Pause := i_MasterPause,
    i_MasterCmd_Init := i_MasterInit,
    i_MasterParam_Mode := i_MasterMode
);

// 读取输出
q_ControlOutput := FB_WorkstationInstance.q_Output;
q_AlarmStatus := FB_WorkstationInstance.q_AlarmStatus;
q_SystemStatus := FB_WorkstationInstance.q_StatusWord;
q_CmdStatus := FB_WorkstationInstance.q_CmdStatus;
q_WorkstationStatus := FB_WorkstationInstance.q_WorkstationStatus;
END_PROGRAM
```

### 4.2 手动模式操作
1. **启动手动模式**：
   - 确保系统处于待机状态
   - 按下启动按钮（i_ManualStart = TRUE）
   - 系统进入手动运行状态，输出信号（q_Output）变为TRUE
2. **停止手动模式**：
   - 按下停止按钮（i_ManualStop = TRUE）
   - 系统退出手动运行状态，输出信号（q_Output）变为FALSE

### 4.3 自动模式操作
1. **启动自动模式**：
   - 确保系统处于待机状态
   - 激活自动模式信号（i_AutoStart = TRUE）
   - 系统进入自动运行状态，输出信号（q_Output）变为TRUE
2. **停止自动模式**：
   - 激活自动停止信号（i_AutoStop = TRUE）
   - 系统退出自动运行状态，输出信号（q_Output）变为FALSE

### 4.4 报警处理
1. **触发报警**：
   - 当报警信号（i_Alarm）变为TRUE时
   - 系统进入报警状态，输出信号（q_Output）变为FALSE
   - 报警状态输出（q_AlarmStatus）变为TRUE
   - 状态字的位3变为1
2. **复位报警**：
   - 确保报警条件已消除
   - 按下复位按钮（i_Reset = TRUE）
   - 系统退出报警状态，报警状态输出（q_AlarmStatus）变为FALSE
   - 状态字的位3变为0

### 4.5 主控命令操作
1. **初始化命令**：
   - 激活主控初始化命令（i_MasterCmd_Init = TRUE）
   - 系统执行初始化操作，内部变量和状态被重置
   - 命令执行状态（q_CmdStatus）变为1（执行完成）
   - 工作站状态（q_WorkstationStatus）变为0（待料中）

2. **启动命令**：
   - 设置运行模式参数（i_MasterParam_Mode）：0-手动，1-自动，2-半自动
   - 激活主控启动命令（i_MasterCmd_Start = TRUE）
   - 系统根据运行模式执行相应操作
   - 命令执行状态（q_CmdStatus）变为1（执行完成）
   - 工作站状态（q_WorkstationStatus）变为2（工作中）

3. **暂停命令**：
   - 激活主控暂停命令（i_MasterCmd_Pause = TRUE）
   - 系统暂停当前操作，输出信号关闭
   - 命令执行状态（q_CmdStatus）变为1（执行完成）
   - 工作站状态保持不变

4. **急停命令**：
   - 激活主控急停命令（i_MasterCmd_EStop = TRUE）
   - 系统立即停止所有操作，输出信号关闭
   - 命令执行状态（q_CmdStatus）变为1（执行完成）
   - 工作站状态（q_WorkstationStatus）变为0（待料中）

### 4.6 运行模式配置
1. **手动模式（i_MasterParam_Mode = 0）**：
   - 系统进入手动控制模式
   - 响应手动操作指令
   - 适合需要人工干预的场景

2. **自动模式（i_MasterParam_Mode = 1）**：
   - 系统进入自动控制模式
   - 执行预设的自动控制流程
   - 适合标准化的生产流程

3. **半自动模式（i_MasterParam_Mode = 2）**：
   - 系统进入半自动控制模式
   - 结合自动和手动控制的特点
   - 适合需要部分人工干预的场景

## 5. 操作指南

### 5.1 基本操作流程
| 步骤 | 操作 | 预期结果 | 详细说明 |
|----------|----------|----------|----------|
| 1 | 系统启动 | 系统进入初始化状态 | 系统启动后自动执行初始化 |
| 2 | 选择控制模式 | 系统进入对应模式 | 选择手动或自动模式，或通过主控站设置运行模式 |
| 3 | 启动控制 | 系统开始运行，输出信号激活 | 手动模式下按启动按钮，自动模式下激活自动启动信号，或通过主控站发送启动命令 |
| 4 | 监控运行状态 | 状态字和工作站状态反映系统状态 | 通过状态字和工作站状态监控系统运行状态 |
| 5 | 停止控制 | 系统停止运行，输出信号关闭 | 手动模式下按停止按钮，自动模式下激活自动停止信号，或通过主控站发送暂停/急停命令 |
| 6 | 处理报警 | 系统进入报警状态并响应 | 当发生报警时，系统自动处理并等待复位，工作站状态变为报警中 |
| 7 | 复位系统 | 系统恢复正常状态 | 按下复位按钮，或通过主控站发送初始化命令，系统恢复正常 |
| 8 | 主控命令操作 | 系统执行对应命令 | 通过主控站发送启动、急停、暂停、初始化命令，系统执行并报告状态 |

### 5.2 常见操作
| 操作名称 | 操作步骤 | 注意事项 |
|----------|----------|----------|
| 切换控制模式 | 先停止当前模式，再选择新模式 | 确保在停止状态下切换模式，或通过主控站设置运行模式 |
| 紧急停止 | 激活报警信号或停止信号，或通过主控站发送急停命令 | 紧急情况下可直接激活报警信号或发送急停命令 |
| 状态查询 | 读取状态字和工作站状态的值 | 了解系统当前状态，工作站状态提供更详细的信息 |
| 系统复位 | 按下复位按钮，或通过主控站发送初始化命令 | 确保报警条件已消除 |
| 主控命令操作 | 通过主控站发送对应命令 | 确保命令发送顺序正确，避免命令冲突 |
| 运行模式配置 | 通过主控站设置运行模式参数 | 根据实际需求选择合适的运行模式 |

### 5.3 操作注意事项
| 注意事项 | 风险后果 | 规避措施 |
|----------|----------|----------|
| 模式切换 | 系统不稳定 | 确保在停止状态下切换模式，或通过主控站设置运行模式 |
| 信号冲突 | 系统误动作 | 避免手动和自动信号同时激活，避免主控命令与本地操作冲突 |
| 运行超时 | 设备损坏 | 合理设置运行超时时间 |
| 报警处理 | 事故扩大 | 及时处理报警和故障，工作站状态会变为报警中 |
| 未初始化 | 系统异常 | 确保系统正常初始化后再操作，或通过主控站发送初始化命令 |
| 主控命令冲突 | 系统误动作 | 确保主控命令发送顺序正确，避免同时发送多个冲突命令 |
| 运行模式参数错误 | 系统运行异常 | 确保设置正确的运行模式参数，0-手动，1-自动，2-半自动 |
| 状态报告异常 | 监控失效 | 定期检查状态报告功能，确保工作站状态正确上报 |

## 6. 故障排除

### 6.1 常见故障
| 故障现象 | 可能原因 | 排查方法 | 解决方案 |
|----------|----------|----------|----------|
| 输入信号不响应 | 信号类型不匹配 | 检查信号类型和连接 | 修正信号类型和连接 |
| 输出信号异常 | 输出参数配置错误 | 检查输出参数配置 | 修正输出参数配置 |
| 状态字更新异常 | 内部状态管理错误 | 检查状态机逻辑 | 修正状态机逻辑 |
| 通信连接失败 | 通信参数配置错误 | 检查通信参数配置 | 修正通信参数配置 |
| 系统初始化失败 | 初始化条件不满足 | 检查初始化条件 | 确保初始化条件满足 |
| 运行超时 | 运行时间设置过短 | 检查运行时间设置 | 调整运行时间设置 |
| 报警无法复位 | 报警条件未消除 | 检查报警条件 | 消除报警条件后复位 |

### 6.2 故障代码
| 错误代码 | 错误名称 | 错误描述 | 处理方式 |
|----------|----------|----------|----------|
| 1 | 输入信号冲突 | 手动和自动信号同时激活 | 优先处理手动信号，检查信号源 |
| 2 | 输出异常 | 输出信号与预期状态不符 | 触发报警，检查输出电路 |
| 3 | 运行超时 | 运行时间超过设定值 | 自动停止并报警，检查运行时间设置 |
| 4 | 初始化失败 | 系统初始化未完成 | 保持初始状态，检查初始化条件 |
| 5 | 通信错误 | 与外部设备通信失败 | 重试机制，检查通信连接 |

### 6.3 故障处理流程
1. **识别故障**：通过状态字、报警信号或系统行为识别故障
2. **定位原因**：根据故障现象和错误代码定位故障原因
3. **执行修复**：按照故障排查指南执行修复措施
4. **验证修复**：验证故障是否已修复
5. **记录故障**：记录故障原因和修复方法

IF bAlarm THEN
    // 处理报警
ELSIF bManualMode THEN
    // 处理手动模式
ELSIF bAutoMode THEN
    // 处理自动模式

    // 处理待机状态
END_IF;
END_PROGRAM
