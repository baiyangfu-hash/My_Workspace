## 1. 项目需求

### 1.1 功能需求
实现工作站的控制功能，包括但不限于：

1. **主控命令执行功能**：
   - 接收并执行主控命令：启动、急停、暂停、初始化
   - 确保命令执行的优先级和正确性

2. **控制参数处理功能**：
   - 接收并处理主控发送的控制参数
   - 支持运行模式设置：自动运行、手动运行、半自动运行
   - 实时更新参数并应用到工作站控制

3. **状态报告功能**：
   - 向主控报告命令执行状态：执行中、执行完成、不予执行
   - 向主控报告工作站状态：待料中、堵料中、工作中、报警中等
   - 确保状态报告的实时性和准确性

4. **报警处理功能**：
   - 处理报警信号
   - 报警时暂停所有操作并向主控报告

5. **状态监控功能**：
   - 实时监控工作站运行状态
   - 生成状态字反映系统状态
   - 提供详细的状态信息供主控查询

### 1.2 非功能需求
1. **符合IEC 61131-3标准**：严格遵循标准规范
2. **模块化设计**：所有功能封装为FB功能块
3. **规范命名**：变量和文件命名遵循项目规范
4. **编码规范**：使用和模板文件相同的编码，确保Autoshop导入无乱码
5. **错误处理**：包含完整的报警和故障处理机制
6. **状态监控**：实时监控所有运行状态

## 2. 程序运行逻辑

### 2.1 FB功能块结构
FB_Workstation功能块包含七大模块：

1. **初始化模块**：
   - 初始化所有内部变量
   - 设置默认准备好状态

2. **主控命令处理模块**：
   - 接收并解析主控命令
   - 执行相应的操作：启动、急停、暂停、初始化

3. **参数处理模块**：
   - 接收并处理主控发送的控制参数
   - 应用运行模式设置：自动运行、手动运行、半自动运行

4. **状态报告模块**：
   - 生成命令执行状态：执行中、执行完成、不予执行
   - 生成工作站状态：待料中、堵料中、工作中、报警中
   - 向主控报告状态信息

5. **手动控制模块**：
   - 处理手动启动信号
   - 处理手动停止信号

6. **自动控制模块**：
   - 处理自动启动信号
   - 执行预设的自动控制流程

7. **报警处理模块**：
   - 处理报警信号
   - 报警时暂停所有操作并向主控报告

### 2.2 核心运行逻辑

#### 2.2.1 控制流程
1. **初始化阶段**：
   - 系统默认设置为准备好状态
   - 初始化所有内部变量
   - 向主控报告初始化完成状态

2. **主控命令处理阶段**：
   - 接收主控命令：启动、急停、暂停、初始化
   - 解析命令并执行相应操作
   - 向主控报告命令执行状态

3. **参数处理阶段**：
   - 接收主控发送的控制参数
   - 更新运行模式：自动运行、手动运行、半自动运行
   - 应用新参数到工作站控制

4. **状态监控与报告阶段**：
   - 实时监控工作站运行状态
   - 检测并更新工作站状态：待料中、堵料中、工作中、报警中
   - 向主控报告最新状态

5. **报警处理阶段**：
   - 收到报警信号，暂停所有操作
   - 向主控报告报警状态
   - 收到复位信号，清除报警状态并恢复运行

#### 2.2.2 信号处理逻辑
- **主控命令信号**：上升沿触发，执行相应命令
- **控制参数信号**：实时更新，应用新参数
- **手动启动信号**：上升沿触发，启动工作站（手动模式）
- **手动停止信号**：上升沿触发，停止工作站（手动模式）
- **自动启动信号**：上升沿触发，启动工作站（自动模式）
- **自动停止信号**：上升沿触发，停止工作站（自动模式）
- **报警信号**：高电平触发，暂停所有操作并向主控报告
- **复位信号**：上升沿触发，清除报警状态并向主控报告

### 2.3 状态字定义
状态字用于反映系统的当前状态，包括运行状态、报警状态、命令执行状态和工作站状态等。

#### 2.3.1 命令执行状态
| 状态值 | 状态名称 | 描述 |
|--------|----------|------|
| 0 | 空闲 | 无命令执行 |
| 1 | 执行中 | 命令正在执行 |
| 2 | 执行完成 | 命令执行完成 |
| 3 | 不予执行 | 命令无法执行（如条件不满足） |

#### 2.3.2 工作站状态
| 状态值 | 状态名称 | 描述 |
|--------|----------|------|
| 0 | 待料中 | 工作站等待物料 |
| 1 | 堵料中 | 工作站物料堵塞 |
| 2 | 工作中 | 工作站正常工作 |
| 3 | 报警中 | 工作站处于报警状态 |

#### 2.3.3 运行模式
| 模式值 | 模式名称 | 描述 |
|--------|----------|------|
| 0 | 自动运行 | 工作站按照预设程序自动运行 |
| 1 | 手动运行 | 工作站由操作员手动控制 |
| 2 | 半自动运行 | 工作站部分自动、部分手动控制 |

### 2.4 错误处理
1. **报警处理**：收到报警信号时暂停所有操作，设置错误状态
2. **复位处理**：收到复位信号时清除所有错误状态，复位所有内部变量

## 6. 部署与使用

### 6.1 Autoshop导入步骤
1. **导入变量表格**：在Autoshop中导入变量表格文件，确认无乱码和格式错误
2. **导入FB功能块**：在Autoshop中导入FB功能块文件，确认编译通过

## 7. 故障排查

### 7.1 常见问题
- **变量表乱码**：编码格式不正确，使用和模板文件相同的编码重新导入
- **信号不响应**：信号未正确连接，检查物理连接和信号顺序
- **状态字异常**：内部状态错误，检查FB内部逻辑，使用复位信号
- **编译错误**：变量未定义或格式错误，检查变量表和FB代码，确保一致

### 7.2 故障处理流程
1. **识别故障**：通过HMI或状态字识别故障
2. **定位原因**：根据故障现象定位原因
3. **执行修复**：按照故障排查指南执行修复
4. **验证修复**：使用测试功能块验证修复效果
5. **记录故障**：记录故障原因和修复方法
