# 单线圈气缸控制FB接口文档

## 1. 接口概述

### 1.1 接口目的

本接口文档描述单线圈气缸控制功能块（FB）的输入输出接口、内部接口和接口时序，为用户提供完整的接口使用指南。

### 1.2 适用范围

本接口文档适用于汇川Autoshop PLC编程环境下的单线圈气缸控制FB，包括硬件集成、软件集成和调试。

### 1.3 接口分类

接口分为外部接口和内部接口：
- **外部接口**：包括输入接口（传感器信号、控制指令）和输出接口（气缸控制信号、状态指示、报警信号）
- **内部接口**：FB内部模块之间的接口

## 2. 输入接口

### 2.1 输入接口列表

| 接口名称 | 类型 | 描述 | 连接方式 |
|---------|------|------|----------|
| 动点传感器 | BOOL | 检测气缸动点位置 | 直接连接PLC输入端子 |
| 原点传感器 | BOOL | 检测气缸原点位置 | 直接连接PLC输入端子 |
| 气缸_S1 | BOOL | 气缸开始到动点指令 | 直接连接PLC输入端子或内部逻辑 |
| 气缸_S0 | BOOL | 气缸开始到原点指令 | 直接连接PLC输入端子或内部逻辑 |
| 屏蔽动点 | BOOL | 屏蔽动点检测指令 | 直接连接PLC输入端子或内部逻辑 |
| 屏蔽原点 | BOOL | 屏蔽原点检测指令 | 直接连接PLC输入端子或内部逻辑 |
| 复位 | BOOL | 系统复位指令 | 直接连接PLC输入端子或内部逻辑 |
| 动点原点工作取反 | BOOL | 动点原点工作取反 | 直接连接PLC输入端子或内部逻辑 |

### 2.2 输入接口详细说明

#### 2.2.1 动点传感器

- **类型**：BOOL
- **功能**：检测气缸是否到达动点位置
- **信号特性**：
  - 正常状态：OFF（未到位），ON（到位）
  - 信号电压：24V DC
  - 信号电流：≤10mA
- **连接方式**：直接连接PLC输入端子
- **使用注意事项**：
  - 确保传感器安装位置准确，避免误检测
  - 定期检查传感器的灵敏度和可靠性

#### 2.2.2 原点传感器

- **类型**：BOOL
- **功能**：检测气缸是否到达原点位置
- **信号特性**：
  - 正常状态：OFF（未到位），ON（到位）
  - 信号电压：24V DC
  - 信号电流：≤10mA
- **连接方式**：直接连接PLC输入端子
- **使用注意事项**：
  - 确保传感器安装位置准确，避免误检测
  - 定期检查传感器的灵敏度和可靠性

#### 2.2.3 气缸_S1

- **类型**：BOOL
- **功能**：控制气缸开始运动到动点位置
- **信号特性**：
  - 正常状态：OFF（停止），ON（开始运动）
  - 信号电压：24V DC（外部输入）或PLC内部逻辑
- **连接方式**：直接连接PLC输入端子或内部逻辑
- **使用注意事项**：
  - 确保与气缸_S0信号互斥，避免同时触发
  - 建议添加外部按钮或内部逻辑进行确认

#### 2.2.4 气缸_S0

- **类型**：BOOL
- **功能**：控制气缸开始运动到原点位置
- **信号特性**：
  - 正常状态：OFF（停止），ON（开始运动）
  - 信号电压：24V DC（外部输入）或PLC内部逻辑
- **连接方式**：直接连接PLC输入端子或内部逻辑
- **使用注意事项**：
  - 确保与气缸_S1信号互斥，避免同时触发
  - 建议添加外部按钮或内部逻辑进行确认

## 5. 接口时序

### 5.1 正常工作时序

1. **原点到动点时序**：
   - 0ms：i_气缸_S1变为ON
   - ≤100ms：q_气缸动点动作变为ON
   - t1：气缸到达动点位置，i_动点传感器变为ON
   - t1+10ms：q_气缸动点到位变为ON
   - t1+10ms：状态机切换到动点状态（n_State=2）

2. **动点到原点时序**：
   - 0ms：i_气缸_S0变为ON
   - ≤100ms：q_气缸动点动作变为OFF
   - t2：气缸到达原点位置，i_原点传感器变为ON
   - t2+10ms：q_气缸原点到位变为ON
   - t2+10ms：状态机切换到原点状态（n_State=1）

### 5.2 异常处理时序

1. **动点异常时序**：
   - 0ms：i_气缸_S1变为ON
   - ≤100ms：q_气缸动点动作变为ON
   - 3000ms：未检测到i_动点传感器信号
   - 3000ms+100ms：q_动点异常变为ON
   - 3000ms+100ms：状态机切换到报警状态（n_State=3）
   - t3：i_复位变为ON
   - t3+≤100ms：q_动点异常变为OFF
   - t3+≤100ms：状态机切换到初始化状态（n_State=0）

2. **原点异常时序**：
   - 0ms：i_气缸_S0变为ON
   - ≤100ms：q_气缸动点动作变为OFF
   - 3000ms：未检测到i_原点传感器信号
   - 3000ms+100ms：q_原点异常变为ON
   - 3000ms+100ms：状态机切换到报警状态（n_State=3）
   - t4：i_复位变为ON
   - t4+≤100ms：q_原点异常变为OFF
   - t4+≤100ms：状态机切换到初始化状态（n_State=0）

## 7. 接口集成指南

### 7.1 硬件集成

#### 7.1.1 接线说明

1. **传感器接线**：
   - 动点传感器：连接到PLC输入端子，COM端连接24V DC负极
   - 原点传感器：连接到PLC输入端子，COM端连接24V DC负极

2. **控制指令接线**：
   - 气缸_S1：连接到PLC输入端子或内部逻辑
   - 气缸_S0：连接到PLC输入端子或内部逻辑
   - 屏蔽动点：连接到PLC输入端子或内部逻辑
   - 屏蔽原点：连接到PLC输入端子或内部逻辑
   - 复位：连接到PLC输入端子或内部逻辑

3. **输出接线**：
   - 气缸动点动作：连接到PLC输出端子，驱动电磁阀
   - 气缸动点到位：连接到PLC输出端子，驱动指示灯
   - 气缸原点到位：连接到PLC输出端子，驱动指示灯
   - 动点异常：连接到PLC输出端子，驱动报警灯
   - 原点异常：连接到PLC输出端子，驱动报警灯

#### 7.1.2 电源要求

- PLC电源：24V DC
- 传感器电源：24V DC
- 输出负载电源：24V DC

#### 7.1.3 接地要求

- 所有设备的接地端子必须可靠连接
- 接地电阻≤1Ω

|------|---------|----------|
| 气缸不运动 | 控制指令未触发 | 检查i_气缸_S1/i_气缸_S0信号 |
| 到位信号不触发 | 传感器未检测到 | 检查传感器安装位置和灵敏度 |
| 异常信号误触发 | 报警延时过短 | 调整报警延时参数 |
| 复位无效 | 复位信号未正确连接 | 检查复位信号的连接和逻辑 |

### 9.2 常见问题与解决方案
