# 单线圈气缸控制FB详细设计说明书

## 1. 设计概述

### 1.1 设计目标

- 实现单线圈气缸的完整控制逻辑，包括运动控制、位置检测、故障诊断和状态管理
- 采用结构化设计，便于维护和扩展
- 符合IEC 61131-3标准，兼容汇川Autoshop编程环境
- 实现可靠的故障检测和报警机制
- 支持24/7连续运行，响应时间≤100ms

### 1.2 设计原则

- **模块化设计**：将功能划分为独立模块，便于维护和扩展
- **结构化编程**：采用SCL语言，符合IEC 61131-3标准
- **可维护性**：清晰的变量命名、完整的注释和文档
- **可靠性**：冗余设计、故障检测和自动恢复机制
- **可测试性**：模块化结构便于单元测试和集成测试

## 2. 系统架构

### 2.1 整体架构

单线圈气缸控制FB采用模块化设计，主要包括以下几个核心模块：

1. **输入处理模块**：接收外部控制信号和传感器信号
2. **运动控制模块**：控制气缸的运动和原位
3. **位置检测模块**：检测气缸的位置状态
4. **故障诊断模块**：检测和报警气缸故障
5. **状态机模块**：管理系统的整体状态

数据流向：输入信号 → 输入处理 → 运动控制 → 位置检测 → 故障诊断 → 状态机 → 输出信号

## 3. 详细设计

### 3.1 运动控制模块设计

**功能描述**：控制气缸的运动和原位动作，接收外部控制信号，输出气缸控制信号。

**算法设计**：
- 当接收到运动信号（i_气缸_S1）时，设置气缸动点动作信号（q_气缸动点动作）为TRUE
- 当接收到原位信号（i_气缸_S0）时，设置气缸动点动作信号为FALSE
- 实现控制信号的互斥保护，避免冲突

**流程设计**：
1. 接收外部控制信号
2. 执行控制逻辑
3. 输出气缸控制信号
4. 监控控制信号状态

**接口设计**：
- 输入：i_气缸_S1, i_气缸_S0
- 输出：q_气缸动点动作

### 3.2 位置检测模块设计

**功能描述**：检测气缸的位置状态，包括动点到位和原点到位。

**算法设计**：
- 使用定时器实现到位延时确认
- 支持正常检测和屏蔽检测两种模式
- 实现到位状态的互斥逻辑

**流程设计**：
1. 接收传感器信号
2. 执行到位延时逻辑
3. 确定到位状态
4. 输出到位信号

**接口设计**：
- 输入：i_动点传感器, i_原点传感器, i_屏蔽动点, i_屏蔽原点
- 输出：q_气缸动点到位, q_气缸原点到位
- 内部变量：T_0, M_0, MW_0

### 3.3 故障诊断模块设计

**功能描述**：检测和报警气缸故障，包括动点异常和原点异常。

**算法设计**：
- 使用定时器实现故障延时检测
- 支持自动恢复机制
- 实现故障状态的保持和复位

**流程设计**：
1. 监控传感器和控制信号
2. 执行故障检测逻辑
3. 输出故障报警信号
4. 支持手动复位

**接口设计**：
- 输入：i_复位, i_动点传感器, i_原点传感器, i_屏蔽动点, i_屏蔽原点, q_气缸动点动作
- 输出：q_动点异常, q_原点异常
- 内部变量：T_0, M_0, MW_0

### 3.4 状态机模块设计

**功能描述**：管理系统的整体状态，包括初始化、原点状态、动点状态和报警状态。

**算法设计**：
- 采用状态机设计，包含4个状态
- 实现状态之间的平滑切换
- 支持状态的复位和恢复

**状态定义**：
- 0：初始化状态
- 1：原点状态
- 2：动点状态
- 3：报警状态

**流程设计**：
1. 初始化状态：检查初始位置
2. 原点状态：等待运动信号
3. 动点状态：等待返回信号
4. 报警状态：处理故障，等待恢复

**接口设计**：
- 输入：i_复位, q_气缸动点到位, q_气缸原点到位, q_动点异常, q_原点异常
- 内部变量：n_State

## 6. 时序设计

### 6.1 正常工作时序

1. **初始化阶段**：
   - 系统上电，进入初始化状态（n_State = 0）
   - 检查初始位置，切换到相应状态

2. **原点到动点时序**：
   - 接收到i_气缸_S1信号
   - q_气缸动点动作变为TRUE
   - 气缸开始运动
   - 检测到i_动点传感器信号
   - 经过动点到位延时（10ms）
   - q_气缸动点到位变为TRUE
   - 状态切换到动点状态（n_State = 2）

3. **动点到原点时序**：
   - 接收到i_气缸_S0信号
   - q_气缸动点动作变为FALSE
   - 气缸开始返回
   - 检测到i_原点传感器信号
   - 经过原点到位延时（10ms）
   - q_气缸原点到位变为TRUE
   - 状态切换到原点状态（n_State = 1）

### 6.2 异常处理时序

1. **动点异常时序**：
   - q_气缸动点动作变为TRUE
   - 超过报警延时（3000ms）未检测到i_动点传感器信号
   - q_动点异常变为TRUE
   - 状态切换到报警状态（n_State = 3）
   - 等待i_复位信号
   - 接收到i_复位信号，q_动点异常变为FALSE
   - 状态切换到相应状态

2. **原点异常时序**：
   - q_气缸动点动作变为FALSE
   - 超过报警延时（3000ms）未检测到i_原点传感器信号
   - q_原点异常变为TRUE
   - 状态切换到报警状态（n_State = 3）
   - 等待i_复位信号
   - 接收到i_复位信号，q_原点异常变为FALSE
   - 状态切换到相应状态
