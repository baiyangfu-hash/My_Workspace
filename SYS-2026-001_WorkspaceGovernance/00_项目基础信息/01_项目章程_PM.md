# SYS-2026-001 工作区治理项目章程

## 1. 基础信息

| 字段 | 内容 |
|------|------|
| 项目编号 | SYS-2026-001 |
| 项目名称 | WorkspaceGovernance |
| 项目定位 | 工作空间系统级治理项目 |
| 项目范围 | 覆盖 `c:\Users\fubai\Documents\My_Workspace` 的入口治理、职责边界、文档收编、风险控制 |
| 项目负责人 | fubai |

## 2. 立项目标

- 建立整个工作空间的统一治理入口。
- 将根目录长期治理事项从散装计划升级为 PM_SESSION 驱动。
- 降低未来维护时的入口混乱、状态漂移和重复规划成本。

## 3. 项目收益

- 未来所有“跨 PLC / 上位机 / 规范库 / 工具链”的长期事项都有固定归口。
- 根目录 `README.md` 与 `.trae/documents/README.md` 形成稳定入口。
- 历史治理计划可被逐步映射和收编，而不是继续横向堆积。

## 4. 范围定义

### In Scope

- 工作空间根入口治理
- `.trae/documents/` 职责边界治理
- 历史长期治理计划映射与收编
- 工作区级风险台账与变更准入规则

### Out of Scope

- 直接重构 PLC 项目目录结构
- 直接重构软件项目代码结构
- 首轮批量移动历史文档
- 新开发治理工具或 GUI

## 5. 成功标准

- 存在唯一的工作区治理项目入口 `SYS-2026-001_WorkspaceGovernance`
- 存在 `PM_SESSION_SYS-2026-001.md` 并持续维护
- 根目录长期治理事项不再以零散计划为主入口
- 至少 3 份历史长期计划被映射进治理项目文档

## 6. 约束与原则

- 项目编号遵循 `DEV-001`，本项目采用 `SYS-` 前缀，不使用 `SW-`
- 会话载体遵循 `PM-004`，所有当前结论回写 `PM_SESSION`
- 以渐进治理代替一次性大迁移
- 优先建立映射，后续再按节奏做归档和清理
