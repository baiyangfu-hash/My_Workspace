## 1. 问题陈述

### 1.1 现象

PLC项目管理工具（SW-2026-005 V1.0.0-alpha）在执行「打开项目」操作时，选择 `0100_PLC自动化` 目录后弹出错误：

```
打开项目失败
所选目录中未找到项目配置文件:
C:/Users/fubai/Desktop/My_Workspace/0100_PLC自动化
支持以下配置文件: project.json, .plc_project.json, .plc.json
提示: 可通过「新建项目」功能创建新项目。
```

### 1.2 影响

| 能力 | 当前状态 | 用户需求 |
|------|---------|---------|
| 打开单个DJ项目 | ✅ 可用 | — |
| 以树状结构浏览整个PLC项目库 | ❌ 不支持 | **核心需求** |
| 管理共享库(SysLib) | ❌ 不支持 | 需要查看22个FB/FC |
| 跨项目规范检查 | ❌ 不支持 | 需要全库范围检查 |
| 项目间依赖关系可视化 | ❌ 不支持 | DJ-2026-005 → SysLib |

### 1.3 根因

工具的架构只有**单项目**概念，缺少**工作空间(Workspace)/项目库(Project Library)**层级。具体检测链路：

```
on_project_opened(path)
  ├─ 检查根目录配置文件 (project.json / .plc_project.json / .plc.json)
  │   └─ 0100_PLC自动化/ 根目录无任何配置文件 → 失败
  └─ detect_project_type(path)
      └─ DJ_ROOT_MARKERS = ["00_项目管理", "02_PLC程序", "03_HMI设计"]
          └─ 0100_PLC自动化/ 下无此三目录组合 → 返回 GENERIC → 失败
```

### 3.2 改动1: artifact_registry_service.py

**目的**: 新增 `PLC_WORKSPACE` 和 `PLC_LIBRARY` 类型自动检测。

**位置**: [artifact_registry_service.py:26-39](file:///c:/Users/fubai/Desktop/My_Workspace/01_Project自动化项目管理/Python自动化项目总库/02_在研项目/SW-2026-005_PLC项目管理工具/03_主程序/01_主程序核心代码/src/services/artifact_registry_service.py#L26-L39)

**改动内容**:

```python
class ArtifactRegistryService:
    # ===== 现有 =====
    DJ_ROOT_MARKERS = [
        "00_项目管理",
        "02_PLC程序",
        "03_HMI设计",
    ]

    # ===== 新增 =====
    WORKSPACE_MARKERS = [
        "workspace.json",              # 显式声明（优先）
    ]

    # PLC项目库隐式特征：包含多种子项目类型
    LIBRARY_MARKERS = [
        ".plc.json",
    ]

    @classmethod
    def detect_project_type(cls, project_path: str) -> ProjectType:
        """根据目录结构判断项目类型"""
        root = Path(project_path)

        # 优先检查显式workspace声明
        if any((root / m).exists() for m in cls.WORKSPACE_MARKERS):
            return ProjectType.PLC_WORKSPACE

        # 现有：DJ单机项目检测
        markers = [root / marker for marker in cls.DJ_ROOT_MARKERS]
        if all(path.exists() for path in markers):
            return ProjectType.DJ_SINGLE_MACHINE

        # 新增：检测是否为PLC共享库（根目录有.plc.json且含FB/FC子目录）
        if (root / ".plc.json").exists():
            has_fb_dirs = any(
                (root / d).is_dir()
                for d in ["actuator", "timer", "counter", "edge", "convert"]
                if (root / d).exists()
            )
            if has_fb_dirs:
                return ProjectType.PLC_LIBRARY

        # 新增：检测是否为PLC工作空间（含多个可识别子项目）
        sub_projects = 0
        for child in root.iterdir():
            if not child.is_dir():
                continue
            child_type = cls.detect_project_type(str(child))
            if child_type in (ProjectType.DJ_SINGLE_MACHINE,
                              ProjectType.PLC_LIBRARY,
                              ProjectType.GENERIC):
                # GENERIC子目录如果有.plc.json也算
                if child_type == ProjectType.GENERIC:
                    if (child / ".plc.json").exists():
                        sub_projects += 1
                else:
                    sub_projects += 1

        if sub_projects >= 2:
            return ProjectType.PLC_WORKSPACE

        return ProjectType.GENERIC
```

**检测优先级**:
1. `workspace.json` 存在 → `PLC_WORKSPACE`（最高优先，显式声明）
2. DJ三标记齐全 → `DJ_SINGLE_MACHINE`
3. `.plc.json` + FB子目录 → `PLC_LIBRARY`
4. ≥2个可识别子项目 → `PLC_WORKSPACE`（隐式推断）
5. 其他 → `GENERIC`

### 3.3 改动2: project_service.py

**目的**: 新增 `load_workspace_from_path()` 方法，扫描并加载工作空间内所有子项目。

**位置**: [project_service.py](file:///c:/Users/fubai/Desktop/My_Workspace/01_Project自动化项目管理/Python自动化项目总库/02_在研项目/SW-2026-005_PLC项目管理工具/03_主程序核心代码/src/services/project_service.py)

**改动内容**:

```python
@classmethod
def load_workspace_from_path(
    cls, workspace_path: str
) -> Tuple[Optional[List[Project]], Optional[str]]:
    """
    从路径加载PLC工作空间（项目库）

    扫描工作空间目录下的所有可识别子项目：
    - DJ单机项目 (detect_project_type == DJ_SINGLE_MACHINE)
    - 共享库 (.plc.json + FB子目录)
    - 有.plc.json的普通目录

    Args:
        workspace_path: 工作空间根目录路径

    Returns:
        Tuple[List[Project] | None, str | None]: (子项目列表, 错误信息)
    """
    try:
        root = Path(workspace_path)
        if not root.exists() or not root.is_dir():
            return None, f"工作空间目录不存在: {workspace_path}"

        from src.services.artifact_registry_service import ArtifactRegistryService
        from src.core.constants import ProjectType

        projects = []
        ignored_dirs = {".trae", ".git", "__pycache__",
                        "_archive", "node_modules", ".venvs"}

        for item in sorted(root.iterdir()):
            if not item.is_dir() or item.name.startswith(".") or item.name in ignored_dirs:
                continue

            child_type = ArtifactRegistryService.detect_project_type(str(item))

            # 加载DJ单机项目或带.plc.json的项目
            if child_type == ProjectType.DJ_SINGLE_MACHINE:
                project, error = cls.load_project_from_path(str(item))
                if project:
                    project.extra["_workspace_child"] = True
                    projects.append(project)

            elif child_type == ProjectType.PLC_LIBRARY:
                project, error = cls.load_project_from_path(str(item))
                if project:
                    project.project_type = ProjectType.PLC_LIBRARY
                    project.extra["_workspace_child"] = True
                    projects.append(project)
                else:
                    # 库没有project.json时手动构造
                    project = Project(
                        name=item.name,
                        code=item.name,
                        description=f"PLC共享库: {item.name}",
                        business_line=BusinessLine.LIBRARY,
                        path=str(item),
                        project_type=ProjectType.PLC_LIBRARY,
                        workflow_stage=WorkflowStage.STABLE,
                    )
                    cls._enrich_project_metadata(project)
                    project.extra["_workspace_child"] = True
                    cls._projects[project.project_id] = project
                    projects.append(project)

            elif (item / ".plc_json").exists() or (item / ".plc.json").exists():
                project, error = cls.load_project_from_path(str(item))
                if project:
                    project.extra["_workspace_child"] = True
                    projects.append(project)

        logger.info(
            f"工作空间加载完成: {root.name}, 发现 {len(projects)} 个子项目"
        )
        return projects if projects else None, None

    except Exception as e:
        logger.exception(f"加载工作空间失败: {e}")
        return None, f"加载工作空间失败: {e}"
```

## 6. 风险与注意事项

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 向后兼容性 | 低 | 新增类型不影响现有DJ单机项目的检测和加载逻辑 |
| 性能（大目录扫描） | 中 | `load_workspace`只扫一层子目录，不做深层递归；`rglob`仅对选中项目触发 |
| 隐式检测误判 | 低 | 显式`workspace.json`优先；隐式要求≥2个子项目才判定为工作空间 |
| 项目树UI性能 | 中 | 子项目懒加载——先显示节点，点击时再加载详情 |
