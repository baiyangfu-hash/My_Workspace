# ST程序注释格式错误修订计划

## 问题概述

### 发现的问题
在 `FB_1001_Conveyor4Layer_BufferFraming_V4.1.0.st` 中发现 **4处严重的注释格式错误**：

```st
(*------------------------------------------------------------------------------
  3.x 功能描述
 ------------------------------------------------------------------------------)    ❌ 错误：-- 结尾
```

**正确的格式应该是：**
```st
(*------------------------------------------------------------------------------
  3.x 功能描述
 -----------------------------------------------------------------------------*)   ✅ 正确：* 结尾
```

### 影响范围
- **IEC 61131-3 ST语言规则**：`(* *)` 必须成对出现
- **后果**：`--)` 不是有效的注释结束符，会导致从该行开始到下一个 `*)` 之间的**所有代码被意外注释掉**
- **影响文件**：目前确认仅 FB_1001 有此问题（4处），其他5个ST文件已检查无误

**建议新增内容**:

#### 2.2.4 Region 标记注释格式规范 (DEV-V1.0.4 新增)

**1. Region 标记基本语法**:
```st
//#region 编号_功能描述
    // ... 代码块 ...
//#endregion 编号_功能描述
```

**2. Region 内部注释格式要求**:

| 注释类型 | 正确格式 | 错误格式 | 说明 |
|----------|----------|----------|------|
| 段落分隔符 | `(* ============ *)` | `(* ============ --)` | `*` 必须成对 |
| 子段落标题 | `(*--- 标题 ---*)` | `(*--- 标题 ---)` | 禁止单独使用 `--` 结尾 |
| 多行说明 | `(* 说明内容 *)` | `(* 说明内容 --)` | 必须以 `*)` 结束 |

**3. 编号体系规范**:

| 前缀编号 | 功能类别 | 示例 |
|----------|----------|------|
| 1xx | VAR_INPUT 输入变量 | 110_系统控制信号, 120_手动操作信号 |
| 2xx | VAR_OUTPUT 输出变量 | 210_执行器请求, 220_下游信号 |
| 3xx | VAR 内部变量 | 310_状态机核心, 320_定时器 |
| 4xx | VAR CONSTANT 常量 | 410_步序常量, 420_报警码常量 |
| 5xx | 主程序逻辑 | 500_使能处理, 510_初始化流程 |
| 6xx | 自动模式状态机 | 600_入口, 610~710_各步骤 |
| 7xx | 手动模式控制 | 700_入口, 710_伺服点动, 720~760_气缸控制 |
| 8xx | 输入分发/预处理 | 810_公共信号, 820_手动信号 |
| 9xx | 输出收集/后处理 | 910_执行器输出, 920_下游信号 |
