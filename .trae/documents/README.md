# `.trae/documents` 使用说明

## 目录定位

`c:\Users\fubai\Desktop\My_Workspace\.trae\documents\` 是工作空间级临时文档缓冲区。

它用于:
- 一次性分析
- 短期计划
- 调研草稿
- 执行前的临时方案记录

它不再用于:
- 长期工作区治理主入口
- 替代 `SYS-2026-001_WorkspaceGovernance/PM_SESSION_SYS-2026-001.md`
- 长期跨项目事项的单一真源

## 长期事项归口规则

满足以下任一条件的事项，应进入 `SYS-2026-001_WorkspaceGovernance/`:
- 跨多个项目
- 跨多个阶段
- 预计持续超过 2 周
- 影响根目录入口、模板、全局规则或工作区结构

- 在建立映射前，不要直接删除历史计划文件
