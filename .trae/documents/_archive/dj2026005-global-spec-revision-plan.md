
**差异点**：
| 检查项 | 当前状态 | 目标状态 |
|--------|----------|----------|
| 注释符号 | `//` 行注释 | `(* *)` 块注释 |
| 功能块名称行 | 无（仅标题描述） | ✅ 必须有 `功能块名称：xxx` |
| 版本号位置 | 嵌入标题行 | ✅ 独立 `版本号：Vx.x.x` 行 |
| 编制人/审核人 | 缺失 | ✅ 必须有（可填[待填写]） |
| 遵循规范 | 引用旧版 V1.0.0/V1.0.1 | ✅ 更新为 V1.0.5 / V1.0.3 |
| 变更记录 | 无或嵌入说明文字 | ✅ 标准五列表格格式 |

#### ❌ 问题2：注释风格不统一

**现状**：所有文件混用 `//` 和 `(* *)`
- 文件头：`// ======` 分隔符
- VAR区域：`(* ====` 分隔符 + `//` 行内注释
- 逻辑段：`// ---` 分隔符

**目标**（按810规范§2.2.3 SCL子规范）：
- 文件头：必须 `(* *)`
- 段落分隔：`(* ==== 段落名 ==== *)`
- 变量声明后：`(* 注释 *)` 或 `// 注释`（保持一致）
- 行内逻辑：推荐 `//`（SCL简洁性）

#### ❌ 问题3：FB_单层输送机 名称违规（仅#6文件）

**当前**：`FUNCTION_BLOCK FB_单层输送机_V4.0.1`
**问题**：
- 使用中文标识符（违反801规范§3.1 FB名称格式要求）
- 版本号嵌入名称（不规范，应在文件头管理）
- 下划线后跟版本号（非标准做法）

**目标**：`FUNCTION_BLOCK FB_1002_SingleLayerConveyor_BufferFraming`

#### ❌ 问题4：计时器变量命名未优化

**当前（#6文件 V4.0.1）**：使用三菱GX Works3风格的中间变量
```pascal
MM : ARRAY [0..7] OF BOOL;    (* 中间变量 - 计时器控制 *)
TT0 : ARRAY [0..7] OF INT;     (* 计时器预设值 *)
TT1 : ARRAY [0..7] OF INT;     (* 计时器当前值 *)
```

**目标（801规范§4.3.3 V1.0.5简化版）**：
```pascal
tIn : ARRAY [0..7] OF BOOL;    (* 定时器输入 *)
tQ  : ARRAY [0..7] OF BOOL;    (* 定时器输出 *)
tR  : ARRAY [0..7] OF BOOL;    (* 定时器复位 *)
tPt : ARRAY [0..7] OF DINT;    (* 预设值 ms *)
tEt : ARRAY [0..7] OF DINT;    (* 当前值 ms *)
```

> 注意：#6文件使用了特殊的"中间变量+TON分离调用"模式（模仿三菱TIMER_FB），这与标准的 TONR 数组方式不同。需要评估是否完全重构为标准模式，还是保留三菱模式但优化命名。

#### ❌ 问题5：其他文件中的潜在问题（待逐文件详细检查）
