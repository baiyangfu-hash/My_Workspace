## 一、执行摘要

### 1.1 核心问题诊断

通过深度分析 `0100_项目` 实际开发项目和全局仓库现状，发现以下关键问题：

| 问题类别 | 严重程度 | 具体表现 | 影响 |
|----------|----------|----------|------|
| **权威来源不明** | 🔴 高 | PLC规范在801/810/903-905多处定义，版本混乱 | 开发者不知遵循哪个版本 |
| **版本滞后** | 🔴 高 | 全局仓库缺少906/907两份关键实战规范 | 错误预防规则未入库 |
| **技术路线过时** | 🟡 中 | 903仍为Go-Gen纯逻辑方案，已切换到FB_TON共享库 | 定时器实现方式矛盾 |
| **命名规范冲突** | 🟡 中 | 801用下划线分隔(如`i_bStartButton`)，905用小驼峰(`i_bStart`) | 代码风格不统一 |
| **注释标准不一** | 🟢 低 | 810允许中文标点，904强制英文半角 | LSP兼容性问题 |

### 1.2 解决方案核心原则

根据用户明确指示：
1. ✅ **权威基准**: 以 `0100_项目/00_通用规范` 为最终权威来源
2. ✅ **LSP导向**: 01_Siemens_LSP编程规范 = PLC编程规范（唯一保留版本）
3. ✅ **去重合并**: 用SCL规范替换补充原PLC规范，最终只保留一套
4. ✅ **经验融合**: 将906/907实战规范纳入全局仓库
5. ✅ **流程导向**: 技术开发域按开发工作流组织（非按编号堆砌）

### 2.2 关键内容冲突详解

#### 冲突1: 变量命名风格（801 vs 905）

```scl
// 801规范 (旧): 下划线分隔，冗长
i_bStartButton : BOOL;        // 启动按钮信号
q_iMotorRunSpeed : INT;       // 电机运行速度输出

// 905规范 (新/LSP推荐): 小驼峰，简洁
i_bStart : BOOL;              // 启动信号
o_iStatus : INT;              // 状态码输出
```

**决策**: 采用 **905小驼峰风格**
- 理由1: Siemens LSP插件生态主流风格
- 理由2: 已在DJ-2026-005项目验证可行
- 理由3: SW-2026-005工具的naming_checker.py已实现此规则

#### 冲突2: 定时器实现路线（903旧版 vs 903新版）

| 维度 | 旧版(Go-Gen) | 新版(FB_TON共享库) |
|------|---------------|-------------------|
| **实现方式** | 纯SCL计数器模拟 | 调用SysLib库FB_TON功能块 |
| **PT参数类型** | INT (扫描周期数) | DINT (毫秒值) |
| **ET参数类型** | TIME (禁止使用) | DINT (必须使用) |
| **Q参数处理** | 手动布尔变量 | 必须指定接收变量 |
| **配置依赖** | 无需.plc.json特殊配置 | **必须配置libraryDirectories** |
| **适用场景** | 无外部库环境 | 标准Siemens LSP项目 |

**决策**: 采用 **新版FB_TON共享库方案**
- 理由1: DJ-2026-005项目已成功应用
- 理由2: 907规范提供了标准配置模板
- 理由3: SW-2026-005工具的timer_checker.py已适配此规则

#### 冲突3: 注释标点符号（810 vs 904）

| 规则点 | 810 (旧) | 904 (新) |
|--------|----------|----------|
| 中文标点 | ⚠️ 未明确禁止 | ❌ **严格禁止** |
| 嵌套注释 | ⚠️ 未提及 | ❌ **明确禁止** |
| 文件头格式 | `(* *)` 块注释 | `(* *)` 块注释 (一致) |
| 行内注释 | 中文说明 | 中文说明 (一致) |

**决策**: 采用 **904严格版**
- 理由: Siemens LSP编译器对中文标点报错(LX003)

### 3.1 结构设计理念

**与V1.0的关键改进**:

1. **PLC技术栈改为"工作流驱动"**:
   - 不再按文件类型分组（基础/LSP专用/接口）
   - 改为按实际开发顺序：初始化 → 编码 → 错误预防 → 文档
   - 符合工程师日常使用习惯："新建项目先看907，写代码查905，出bug查906"

2. **明确权威层级**:
   ```
   LSP-905 (主规范) ← 包含命名+语法+METHOD的完整定义
     ├─→ LSP-904 (引用) 注释细节
     ├─→ LSP-903 (引用) 定时器细节
     └─→ LSP-906 (引用) 错误预防清单
   ```

3. **废弃文件处理**:
   - 801 → 标记为`_deprecated`，内容归档到905
   - 810 → 拆分有价值章节，其余废弃
