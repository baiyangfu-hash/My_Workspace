## 关于打包技术的说明

用户提到"新的打包技术"，这里澄清：

- **V2.2.0 ~ V2.4.4**: 使用 PyInstaller `--onedir` 模式 → 产出 exe + `_internal/` 目录（160 MB）
- **V2.5.0**: 使用 PyInstaller `--onefile` 模式 → 产出单个 exe（58 MB），运行时解压到临时目录

两种模式都是正常的 PyInstaller 打包方式，`--onefile` 模式分发更简洁。如需改回 `--onedir` 模式可在后续调整。
