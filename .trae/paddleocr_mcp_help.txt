usage: paddleocr_mcp [-h] [--pipeline {OCR,PP-StructureV3}]
                     [--ppocr_source {local,aistudio,self_hosted}] [--http]
                     [--host HOST] [--port PORT] [--verbose]
                     [--pipeline_config PIPELINE_CONFIG] [--device DEVICE]
                     [--server_url SERVER_URL]
                     [--aistudio_access_token AISTUDIO_ACCESS_TOKEN]
                     [--timeout TIMEOUT]

PaddleOCR MCP server - Supports local library, AI Studio service, and self-
hosted servers.

options:
  -h, --help            show this help message and exit
  --pipeline {OCR,PP-StructureV3}
                        Pipeline name.
  --ppocr_source {local,aistudio,self_hosted}
                        Source of PaddleOCR functionality: local (local
                        library), aistudio (AI Studio service), self_hosted
                        (self-hosted server).
  --http                Use HTTP transport instead of STDIO (suitable for
                        remote deployment and multiple clients).
  --host HOST           Host address for HTTP mode (default: 127.0.0.1).
  --port PORT           Port for HTTP mode (default: 8000).
  --verbose             Enable verbose logging for debugging.
  --pipeline_config PIPELINE_CONFIG
                        PaddleOCR pipeline configuration file path (for local
                        mode).
  --device DEVICE       Device to run inference on.
  --server_url SERVER_URL
                        Base URL of the underlying server (required in service
                        mode).
  --aistudio_access_token AISTUDIO_ACCESS_TOKEN
                        AI Studio access token (required for AI Studio).
  --timeout TIMEOUT     HTTP read timeout in seconds for API requests to the
                        underlying server.
