# Checklist - 修复跨机器创建项目目录失败

## 路径工具函数增强
- [x] ensure_directory() 函数返回 tuple[bool, str] 格式
- [x] 成功时返回 (True, "")
- [x] 失败时返回 (False, 具体错误原因字符串)
- [x] 区分至少4种失败类型：权限不足/路径不存在/路径过长/其他
- [x] 所有异常都记录完整堆栈到日志

## 项目服务层路径预检
- [x] create_project() 在使用 custom_path 前验证有效性
- [x] 路径无效时调用 _detect_project_base_path() 回退
- [x] 回退路径无效时使用用户主目录兜底
- [x] 所有回退操作都有日志记录
- [x] 实际使用的路径正确保存到项目对象

## 对话框层路径验证
- [x] _update_default_path() 检测 base_path 可写性
- [x] 总库 root_path 不可用时自动切换到可用路径
- [x] 显示给用户的路径是实际可用的路径
- [x] _on_create() 在提交前再次验证路径

## 错误提示增强
- [x] 用户看到的是中文友好错误消息（非技术术语）
- [x] 不同错误原因对应不同的提示文案
- [x] 日志中包含足够的技术细节用于排查

## 兼容性测试通过
- [x] 开发环境正常创建项目（回归测试）
- [x] 模拟 PyInstaller 环境能成功创建项目
- [x] root_path 为空时的处理正确
- [x] root_path 指向不存在路径时的回退成功
- [x] 多级目录创建正常工作
- [x] 中文路径和特殊字符处理正确
