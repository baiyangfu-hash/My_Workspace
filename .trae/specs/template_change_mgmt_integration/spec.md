# 模板功能模块与变更管理集成迭代 Spec (V2.0)

## Why

当前 Python项目管理工具 (SW-2026-004) 的模板功能与 **06_项目模板规范** 存在以下关键差异：

### 🔴 核心问题：变更管理目录结构不一致

**规范要求（来自 06_项目模板规范）**：
```
{project_root}/00_项目管理/04_变更管理/
├── 01_变更单/                    # ← 变更单直接存放在此（无领域子目录）
│   ├── 040_{code}_变更单 001_CHG-V2.0.0.md
│   ├── 040_{code}_变更单 002_CHG-V2.0.0.md
│   └── ...
├── 03_变更管理规范/              # ← 可选（整线/上位机模板有，小型模板无）
│   └── 042_{code}_变更管理流程规范_PM-V2.0.0.md
└── 04_变更记录/                  # ← 台帐存放位置
    └── 041_{code}_版本变更台帐_CHG-V2.1.0.md
```

**当前实现（change_service.py）**：
```python
# 当前代码使用领域子目录（错误！）
output_path = os.path.join(
    project.path,
    "00_项目管理",
    "04_变更管理",
    "01_变更单",
    f"CHG-{domain_dir}",        # ❌ 不应该有这层目录！
    f"{change.change_id}.md"
)
```

### 📋 其他问题

1. **部分模板 structure 定义不符合规范**：
   - TPL-SINGLE-PLC-001 (对应 TPL-SINGLE-PLC-S001) 的结构过于粗粒度
   - 缺少规范的细粒度路径定义

2. **新建项目时未自动生成初始变更管理文件**：
   - 空白台帐 (`041_{code}_版本变更台帐_CHG-V2.1.0.md`)
   - 可选的变更管理规范说明
   - README 说明文件

3. **文档与版本号需同步更新**

## ADDED Requirements

### REQ-1: 变更管理目录结构标准化

**来源**: 06_项目模板规范/变更管理与模板文件映射文档.md §2.1

系统 SHALL 确保：

1. **所有模板生成的项目** 都包含以下目录结构：
   ```
   {project_path}/00_项目管理/04_变更管理/
   ├── 01_变更单/           # 必须存在
   │   └── (变更单文件直接存放于此)
   ├── 03_变更管理规范/     # 可选（完整版模板）
   │   └── (流程规范文件)
   └── 04_变更记录/         # 必须存在
       └── (台帐文件)
   ```

2. **变更单文件命名规则**：
   - 格式：`040_{project_code}_变更单{序号}_CHG-V2.0.0.md`
   - 示例：`040_SW-2026-001_变更单 001_CHG-V2.0.0.md`
   - 序号：3位数字，从 001 开始递增

3. **台帐文件命名规则**：
   - 格式：`041_{project_code}_版本变更台帐_CHG-V2.1.0.md`
   - 示例：`041_SW-2026-001_版本变更台帐_CHG-V2.1.0.md`

#### Scenario: 验证目录结构合规性
- **WHEN** 使用任意内置模板创建新项目
- **THEN** 项目路径下应存在 `00_项目管理/04_变更管理/` 目录
- **AND** 该目录应包含 `01_变更单/` 和 `04_变更记录/` 子目录
- **AND** 对于完整版模板（FULLLINE, UPPER），还应包含 `03_变更管理规范/` 子目录

### REQ-2: 变更单导出路径修正

**来源**: 变更管理与模板文件映射文档.md §3.2 (工具功能与文件映射表)

系统 SHALL 修改 `change_service.export_change()` 方法：

- **THEN** 变更单文件应出现在 `00_项目管理/04_变更管理/01_变更单/` 目录下
- **AND** 文件名格式为 `040_{code}_变更单XXX_CHG-V2.0.0.md`
- **AND** **不存在** `CHG-PLC/` 或其他领域子目录
