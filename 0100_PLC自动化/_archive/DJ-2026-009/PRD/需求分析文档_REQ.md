# 需求分析文档 (REQ) - DJ-2026-009 长边框堆垛机

## 1. 项目基础信息与工艺背景

### 1.1 业务背景
本项目为 **光伏长边框自动化码垛与隔纸包装系统**（项目编号：`DJ-2026-009`）。设备位于光伏铝边框加工产线末端，接收前道打胶冲孔后的铝边框工件，自动完成双路入料、智能分对、门式机械手移载、隔纸自动裁切与平铺铺设、长短边双向气动纠偏拍齐，以及指定层数塑钢带穿带打捆，最终形成规整的成品垛。

### 1.2 设备核心控制指标
- **设计工作节拍 (CT)**: ≤ 12.0 秒/对 (包含取料、移载、放料与归正)
- **定位精度**: 移载 X/Z 轴定位精度 ±0.1 mm，隔纸架 Z 轴定位精度 ±0.2 mm
- **适用边框长度**: 1800 mm ~ 2600 mm (长边框标准规格)
- **最大叠垛高度**: 1500 mm (整托边框根数由配方参数 `R1508` 设定)
- **主控平台**: 汇川 H5U-1616MTD PLC + EtherCAT 伺服总线 + 威纶通 1280×800 HMI

## 2. 功能需求详细分解 (5 大核心工位)

### 2.1 工位 1：双路入料输送系统 (`FR-1001` / `FB_1001_DualInfeedConveyor`)
- **需求描述**：
  - 支持 1# 进料皮带与 2# 进料皮带独立变频驱动，具备慢速定位与快速输送双段速控制；
  - 进料端配置高精度漫反射光电传感器，实时统计 `输送皮带2入料计数`；
  - 具备来料超限防溢出联锁：当后道移载机械手未取料且入料计数达到 `允许入料数量` 设定值时，自动停止前道输送并发出待料信号。

### 2.2 工位 2：叠垛移载机械手系统 (`FR-1002` / `FB_1002_StackTransferRobot_XZ`)
- **需求描述**：
  - 由 **移载 X 轴**（水平大行程门式伺服）与 **移载 Z 轴**（垂直升降伺服）构成联动移载机构；
  - **示教坐标体系**：
    - X 轴支持：`待机点 (R1000)`、`取料点 (R1002)`、`放料点 (R1004)`、`拉隔纸起点 (R1006)`、`拉隔纸铺设点 (R1008)`；
    - Z 轴支持：`待机高度`、`取料下降减速点`、`取料极限点`、`放料下降减速点`、`层高自适应放料点`；
  - 动态计算当前已抓取边框对数与层已码垛边框对数，放料后依据 `边框层高设定 (R1502)` 自动累加 Z 轴放料坐标。

### 2.3 工位 3：隔纸架与自动裁切系统 (`FR-1003` / `FB_1003_PaperHolder_Z`)
- **需求描述**：
  - 配备独立的 **隔纸架 Z 轴伺服**，实现整卷/整叠瓦楞隔纸的自动升降定位；
  - 坐标预设：`换料点 (R1200)`、`拉隔纸点 (R1202)`、`过道安全点 (R1204)`、`边框阻挡点 (R1206)`；
  - 移载机械手移动至拉纸起点吸附隔纸端头，联动拉出指定长度后，气动切刀执行无级裁切；
  - 具备 `隔纸厚度补偿 (R1506)` 与 `隔纸裁切长度补偿 (R1530)` 动态修正。

### 2.4 工位 4：边框长短边纠偏归正系统 (`FR-1004` / `FB_1004_FrameAlignUnit`)
- **需求描述**：
  - 当机械手将单层边框放置到位后，启动长短边双向拍齐气缸机构；
  - 短边纠偏气缸执行轴向推齐，长边纠偏气缸执行横向拍实；
  - 寄存器支持微调补偿：`短边归正 Z 轴补偿 (R1536)`、`长边归正 X 轴补偿 (R1532)`、`长边归正 Z 轴补偿 (R1534)`。

### 2.5 工位 5：叠垛配方与公共报警系统 (`FR-2001` / `FB_2001_StackRecipeAlarm`)
- **需求描述**：
  - **配方管理**：支持边框截面宽度 (`R1500`)、层高 (`R1502`)、壁厚 (`R1504`)、整托总根数 (`R1508`) 的存储与一键调用；
  - **塑钢带管理**：支持设定 `放塑钢带层数1/2/3 (R1540~R1544)`，叠垛至指定层数时自动暂停并声光提示穿带打捆；
  - **全机报警矩阵**：集成 811 项故障监控点（包含光幕遮挡、伺服跟随误差超限、气缸动作超时、缺纸报警）。

## 3. 安全保护与硬件联锁矩阵

| 联锁事件 | 触发条件 | 保护动作 | 复位条件 |
|:---|:---|:---|:---|
| **安全光幕遮挡** | 码垛区红外光幕信号断开 | 立即切断移载 X/Z 轴与隔纸 Z 轴伺服使能 | 人员离开光幕区，按控制台安全复位按钮 |
| **移载防碰撞干涉** | 隔纸切刀未收回 或 归正气缸伸出 | 移载 Z 轴禁止下行，X 轴禁止移动 | 切刀/归正气缸退回原位磁簧开关接通 |
| **机械手真空异常** | 取料后真空压力表反馈 < -60 kPa | 机械手暂停并报警，禁止 X 轴平移 | 人工确认吸附状态，清除报警后继续 |
| **伺服软件极限超程**| 轴实时坐标超出软限位 | 轴立即减速停止，触发驱动器故障 | 手动点动模式反向回退至有效行程内 |

## 4. 数据与接口需求
- **PLC 变量字典**：共 3,013 个工业点位（详见 `PLC变量定义文档_VAR.md` 与 `io_points.csv`）；
- **HMI 通讯接口**：Modbus-TCP / 寄存器映射，支持 1280×800 工业触控屏实时交互；
- **MES 生产数据**：通过以太网上传当前垛号、完工件数、节拍与故障停机代码。
