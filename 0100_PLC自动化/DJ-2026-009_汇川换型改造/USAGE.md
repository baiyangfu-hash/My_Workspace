# 操作手册 (USAGE)

## 1. 系统概述 (System Overview)
本项目是汇川换型改造项目的核心控制部分，负责实现 IT 与 OT 层的桥接与交互。

## 2. 启动序列 (Startup Sequence)
1. 确认所有急停按钮已旋起，安全门已关闭。
2. 在 HMI 界面点击“复位”按钮，清除历史报警。
3. 点击“伺服使能”，等待所有轴状态变为“Ready”。
4. 点击“自动运行”启动系统。

## 3. 报警处理 (Alarm Handling)
- **FirstUp 报警 (首出报警)**：系统会记录第一个触发的报警信号。根据 HMI 提示排查对应的传感器或伺服驱动器。
- 排查完毕后，必须在手动模式下进行复位，然后重新切入自动模式。

## 4. 安全联锁 (Safety Interlocks)
- **安全门保护**：运行中打开安全门将立即切断伺服动力，系统进入急停状态。
- **气缸防撞**：气缸互锁由 PLC 的 UDT 信号统一校验。
