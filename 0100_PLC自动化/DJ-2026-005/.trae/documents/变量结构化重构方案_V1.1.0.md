### 参考基准: SV_jog 结构体

用户提供的项目实际伺服jog控制结构体:

```pascal
TYPE ST_ServoJog :
STRUCT
    Enable         : BOOL;   // jog执行      (偏移 1)
    Forward        : BOOL;   // jog正转        (偏移 2)
    Backward       : BOOL;   // jog反转        (偏移 3)
    Velocity       : REAL;   // jog目标速度    (偏移 4)
    Deceleration   : REAL;   // jog减速度      (偏移 5)
    Acceleration   : REAL;   // jog加速度      (偏移 6)
    Curvetype      : INT;    // jog曲线类型    (偏移 7)
    Busy           : BOOL;   // jog繁忙        (偏移 8)
    Commandaborted : BOOL;   // jog停止执行    (偏移 9)
    Error          : BOOL;   // jog错误        (偏移 10)
    ErrorID        : INT;    // jog错误代码    (偏移 11)
END_STRUCT
END_TYPE
```

**设计启示**:
- 输入/输出/状态 字段在同一 STRUCT 中（扁平结构，无嵌套）
- BOOL 控制命令在前，REAL/INT 参数居中，BOOL/INT 状态输出在后
- 符合 PLCopen 运动控制 FB 的接口模式
- **本项目所有结构体应遵循此模式：命令输入 → 参数 → 状态输出 三段式**

## 1. 问题诊断：当前变量"散装"现状

### 1.1 散装变量统计

#### 🔴 问题1：伺服轴信号分散在3个位置（最严重）

```pascal
// Z轴信号 - 分散在stPickPlace中
i_bZAxis_HomePos           : BOOL;   // 原点
i_bZAxis_ServoFault        : BOOL;   // 故障
i_bZAxis_FwdLimit          : BOOL;   // 正限位
o_bZAxis_PulseOutput       : BOOL;   // 脉冲输出
o_bZAxis_Enable            : BOOL;   // 伺服使能
o_rZAxisCurrentPos         : REAL;   // 位置反馈

// X2轴信号 - 在stFeeder中又重复一遍，命名还不一致！
i_bX2Axis_Home             : BOOL;    // (少了Pos后缀!)
i_bX2Axis_ForwardLimit     : BOOL;    // (_FwdLimit vs _ForwardLimit)
```

**问题量化**: 3轴 × 10信号 = **30个散装变量**，命名不一致

#### 🔴 问题2：气缸控制信号高度重复

5组气缸 × 4输入+2输出 = 30变量 + stConveyor中2组×4层 = 额外48ARRAY元素 = **78个散装变量**

#### 🟡 问题3：传感器未分类（40+ BOOL）、手动操作扁平化（24 ARRAY元素）

### 2.3 结构体清单（7个通用类型）

#### 📦 **ST_ServoAxis** - 伺服轴完整控制结构体

**参考**: SV_jog 三段式模式  
**适用**: Z轴、X1轴、X2轴及未来扩展轴

```pascal
TYPE ST_ServoAxis :
STRUCT
    // === 命令输入 (BOOL) ===
    Enable          : BOOL := FALSE;   // 轴使能
    HomeRequest     : BOOL := FALSE;   // 回原点请求
    MoveAbsReq      : BOOL := FALSE;   // 绝对定位请求
    JogFwd          : BOOL := FALSE;   // 正向jog
    JogRev          : BOOL := FALSE;   // 反向jog

    // === 参数 (REAL/INT) ===
    TargetPos       : REAL := 0.0;    // 目标位置 (mm)
    Velocity        : REAL := 100.0;  // 速度 (mm/s)
    Acceleration    : REAL := 1000.0; // 加速度
    Deceleration    : REAL := 1000.0; // 减速度

    // === 传感器反馈 (BOOL) ===
    HomePos         : BOOL := FALSE;   // 原点信号
    FwdLimit        : BOOL := FALSE;   // 正限位
    RevLimit        : BOOL := FALSE;   // 反限位
    InPosition      : BOOL := FALSE;   // 到位 (INP)
    ServoFault      : BOOL := FALSE;   // 故障 (ALM)

    // === 状态输出 (BOOL/INT/REAL) ===
    IsHomed         : BOOL := FALSE;   // 已回原点
    IsMoving        : BOOL := FALSE;   // 运动中
    Busy            : BOOL := FALSE;   // 繁忙 (命令执行中)
    CommandAborted  : BOOL := FALSE;   // 命令中止
    Error           : BOOL := FALSE;   // 错误
    ErrorID         : INT := 0;        // 错误代码
    CurrentPos      : REAL := 0.0;    // 位置反馈
END_STRUCT
END_TYPE
```

**使用**: `astServoAxis[Z_AXIS].TargetPos := 100.0;` (2层)

---

#### 📦 **ST_Cylinder** - 双线圈气缸控制结构体

**适用**: 阻挡/分料/升降/夹紧气缸

```pascal
TYPE ST_Cylinder :
STRUCT
    // === 命令输入 ===
    Extend          : BOOL := FALSE;   // 伸出/下降/夹紧命令
    Retract         : BOOL := FALSE;   // 收回/上升/松开命令

    // === 传感器反馈 ===
    ExtendedPos     : BOOL := FALSE;   // 伸出位/下位/工作点
    RetractedPos    : BOOL := FALSE;   // 收回位/上位/原点

    // === 参数 ===
    TimeoutMs       : INT := 5000;     // 超时时间 (ms)

    // === 状态输出 ===
    IsExtended      : BOOL := FALSE;   // 已伸出到位
    IsRetracted     : BOOL := FALSE;   // 已收回到位
    Timeout         : BOOL := FALSE;   // 动作超时
    SensorFault     : BOOL := FALSE;   // 传感器冲突
END_STRUCT
END_TYPE
```

**使用**: `astConveyorLayer[1].stBlockCylinder.Extend := TRUE;` (3层)

---

#### 📦 **ST_ConveyorMotor** - 输送电机控制结构体

**适用**: 变频器驱动的输送带电机

```pascal
TYPE ST_ConveyorMotor :
STRUCT
    // === 命令输入 ===
    FwdCmd          : BOOL := FALSE;   // 正转命令
    RevCmd          : BOOL := FALSE;   // 反转命令
    SlowCmd         : BOOL := FALSE;   // 慢速命令

    // === 安全互锁输入 ===
    SafetyDoorOk    : BOOL := TRUE;    // 安全门OK
    VfdFault        : BOOL := FALSE;   // VFD故障

    // === 参数 ===
    Speed           : REAL := 100.0;   // 速度设定

    // === 实际输出 (经互锁后) ===
    FwdOut          : BOOL := FALSE;   // 正转输出
    RevOut          : BOOL := FALSE;   // 反转输出
    SlowOut         : BOOL := FALSE;   // 慢速输出

    // === 状态输出 ===
    Running         : BOOL := FALSE;   // 运行中
    VfdAlarm        : BOOL := FALSE;   // VFD报警
END_STRUCT
END_TYPE
```

---

#### 📦 **ST_DualSensor** - 双传感器冗余检测结构体

```pascal
TYPE ST_DualSensor :
STRUCT
    // === 传感器输入 ===
    Sensor1         : BOOL := FALSE;   // 主传感器
    Sensor2         : BOOL := FALSE;   // 冗余传感器

    // === 状态输出 ===
    Consistent      : BOOL := TRUE;    // 一致性标志
    ValidSignal     : BOOL := FALSE;   // 有效信号 (一致时 = Sensor1 OR Sensor2)
END_STRUCT
END_TYPE
```

---

#### 📦 **ST_ConveyorLayer** - 单层输送机完整结构体

**适用**: 4层输送机的每一层  
**嵌套**: 内部引用 ST_Cylinder(2个) + ST_ConveyorMotor(1个) + ST_DualSensor(2个)  
**访问深度**: `astConveyorLayer[1].stBlockCylinder.Extend` = 3层 ✅

```pascal
TYPE ST_ConveyorLayer :
STRUCT
    // === 传感器组 (≤2层嵌套) ===
    stPositionDetect : ST_DualSensor;    // 到位检测 (双传感器)

    // === 气缸组 (≤2层嵌套) ===
    stBlockCylinder  : ST_Cylinder;      // 阻挡气缸
    stSeparateCyl    : ST_Cylinder;      // 分料气缸

    // === 电机 (≤2层嵌套) ===
    stMotor          : ST_ConveyorMotor; // 输送电机

    // === 传感器 (散装BOOL，避免额外嵌套) ===
    PreSeparateSensor: BOOL := FALSE;    // 分料前接近开关

    // === 取料确认 ===
    PickupConfirmed  : BOOL := FALSE;    // 取料机构已取走

    // === 手动操作 (6 BOOL, 扁平化) ===
    ManBlockExtend   : BOOL := FALSE;    // 手动: 阻挡下降
    ManBlockRetract  : BOOL := FALSE;    // 手动: 阻挡上升
    ManSeparatePush  : BOOL := FALSE;    // 手动: 分料推出
    ManConveyorFwd   : BOOL := FALSE;    // 手动: 输送正转
    ManConveyorRev   : BOOL := FALSE;    // 手动: 输送反转
    ManConveyorSlow  : BOOL := FALSE;    // 手动: 输送慢速

    // === 状态输出 ===
    Step             : INT := 0;         // 当前步序 0~70
    AlarmCode        : INT := 0;         // 本层报警码
    Running          : BOOL := FALSE;    // 运行中
    Fault            : BOOL := FALSE;    // 故障
    FeedDone         : BOOL := FALSE;    // 放料完成脉冲
END_STRUCT
END_TYPE
```

### 2.4 结构体层次关系图（≤3层约束）

```
SysLib/types/ (跨项目复用)
│
├── 基础类型 (0层嵌套, 无子结构体)
│   ├── ST_ServoAxis         → 22字段, 扁平
│   ├── ST_Cylinder          → 10字段, 扁平
│   ├── ST_ConveyorMotor     → 11字段, 扁平
│   ├── ST_DualSensor        → 4字段, 扁平
│   ├── ST_ProductSensors    → 6字段, 扁平
│   └── ST_ExternalDevice    → 12字段, 扁平
│
└── 组合类型 (1层嵌套, 引用基础类型)
    └── ST_ConveyorLayer     → 引用 ST_Cylinder×2 + ST_ConveyorMotor×1
                               → 全局访问: astConveyorLayer[1].stBlockCylinder (3层) ✅
```

**关键约束**: 不使用 ST_ClampGroup、ST_PickPlaceUnit 等深层嵌套组合体。取放料/送料机构的变量直接在项目级DB中声明，使用基础类型平铺。
