### 4.2 流程需求

#### 4.2.1 系统整体流程

系统采用**三工站流水线架构**，各工站通过放料完成信号串联：

```mermaid
graph LR
    A[四层输送机<br/>FB_1001] -->|L1~L4放料完成| B[取放料机构<br/>FB_1003]
    B -->|放料完成通知| C[打胶机送料机构<br/>FB_1004]
    C -->|X2轴返回待机| A
```

#### 4.2.2 四层输送机自动流程（每层独立9步状态机，Step_S模式）

> **源程序真相**：先输送再分料。Step 0为初始化复位，Step 10/20/30/50/60/70 为不连续编号。

| 步序 | 状态名称 | 动作描述 | 执行器输出 | 传感器条件 |
| ---- | -------- | -------- | ---------- | ---------- |
| 0 | STEP_初始化 | 输送反转复位到初始位 | 输送反转=ON | 限位或超时→跳Step 1 |
| 1 | STEP_等待来料 | 等待分料前感应器检测到边框材料 | 无 | 分料前感应器=ON |
| 2 | STEP_阻挡下降 | 阻挡气缸下降，阻止后续材料进入 | 阻挡电磁阀=ON(下降) | 阻挡气缸下位=ON |
| 10 | STEP_输送正转 | 输送带正向运转，将材料送往取料位置 | 输送带正转=ON | — |
| 20 | STEP_到位检测与阻挡上升 | 双传感器冗余检测到位+阻挡气缸上升释放 | 阻挡电磁阀=OFF(上升) | 到位1 AND 到位2 = ON；阻挡上位=ON |
| 30 | STEP_分料推出 | 分料气缸推出，将边框分离到取料位置 | 分料电磁阀=ON(推出) | 分料气缸下位=ON |
| 50 | STEP_慢速送出 | 输送带慢速精确送出到取料位 | 输送带慢速=ON | — |
| 60 | STEP_请求取料 | 等待取放料机构取走边框 | 所有执行器保持 | 取放料取走确认 |
| 70 | STEP_分料复位 | 分料气缸复位，回到初始状态 | 分料电磁阀=OFF(复位) | 分料气缸上位=ON → 跳Step 0 |

互锁信号：M8(安全门/异常暂停)取反门控正/反转输出；M515(取料机构在安全区)互锁。

#### 4.2.3 取放料机构自动流程（STL S20~S25，6步）

> **源程序真相**：使用三菱 STL 步进梯形图实现。产品检测在S22步内完成，不单独成步。放料完成通知与松开在同一S25步。

| 步序 | 状态名称 | 动作描述 | 关键细节 |
| ---- | -------- | -------- | -------- |
| S20 | 待机等待 | Z轴待机位确认，等待取料请求 | D116=K5(自动运行中) → 跳S21 |
| S21 | 上升到取料高度 | Z轴伺服移动到取片教点(D514) | Z轴伺服定位，到位 → 跳S22 |
| S22 | 夹紧与检测 | 前/后4组夹紧气缸**同时夹紧**，4光电检测边框存在 | 4夹紧确认+4光电全部ON+夹紧确认时间 → 跳S23 |
| S23 | 移动到放料位置 | X1轴移动到放料位置（前放料点D520或后放料点D540） | L1/L3→前放料点，L2/L4→后放料点；X1轴伺服定位 |
| S24 | 下降到放料高度 | Z轴伺服移动到放片教点(D524) | Z轴伺服定位，到位 → 跳S25 |
| S25 | 松开与通知 | 4组夹紧全部松开 + 发送"放料完成"信号给送料机构 | 4松开确认 → 跳回S20 |

#### 4.2.4 打胶机送料机构自动流程（D760步序，4步）

> **源程序真相**：使用 D760 寄存器驱动步序。收到放料完成直接去取料位，不提前等待打胶机允许。

| 步序 | 状态名称 | 动作描述 | 外部交互 |
| ---- | -------- | -------- | -------- |
| D760=0 | 空闲待机 | 等待取放料机构"放料完成"信号 | 接收取放料_放料完成 → D760=1 |
| D760=1 | 移动到取料位 | X2轴移动到取料点(D620) | X2轴伺服定位 → 到位 → D760=2 |
| D760=2 | 移动到打胶机送料 | X2轴移动到放料点(D630)，到达后输出Y47(安全区关闭)；等待打胶机允许(X76)→输出Y44(允许抓料)；等待打胶机取料完成(X102) | 收X76/X102；发Y44/Y47 → D760=3 |
| D760=3 | 返回待机位 | X2轴返回待机位(D610)，输出Y47(安全区开放) | X2轴伺服定位 → 到位 → D760=0 |

**架构特点**：
- **纯协调层主控**：主控程序不包含任何业务逻辑，仅做IO映射和工站调度
- **纯逻辑块工站**：所有工站FB无物理地址依赖，完全通过接口变量与主控交换数据
- **集中式IO映射**：所有X/Y地址映射集中在主控程序的Step1(输入)和Step8(输出)
- **严格执行顺序**：输入映射→HMI读取→外部信号→工站调用(4→5→6→7)→输出映射→HMI回写→D区回写
- **运动控制抽象**：工站以轴抽象接口下发启停/目标/速度等语义，底层脉冲/总线/驱动API由平台适配层实现

## 8. 数据需求

### 8.1 数据存储

| 数据类型 | 存储位置 | 容量 | 用途 |
| ---- | ------ | ---- | ------- |
| 工艺参数 | D100-D107 | 4个REAL(8字) | 输送速度/伺服速度/取料速度/放料速度 |
| 时间参数 | D108-D113 | 3个INT(6字) | 分料时间/夹紧确认时间/升降超时时间 |
| 状态显示 | D120-D127 | 4个INT(8字) | 全局报警码/取料层数/取料步序/备用 |
| 报警数据 | D400-D425 | 1WORD+21INT(43字) | 全局报警字/当前报警码/MES计数/MES队列(10条) |
| HMI控制 | M0-M49 | 50个BOOL | 模式选择/操作按钮/手动操作/状态反馈 |
| 报警记录 | MES队列 | 10条(去重后) | 最近10条报警历史，供MES上传 |

### 8.2 数据安全

- 重要参数设置需要密码保护（HMI权限分级）
- 报警记录不可修改（只读D区）
- 安全相关信号（急停/安全门）采用硬件常闭触点，软件仅读取状态
- D区报警数据固定分配，不随程序修改而变动
