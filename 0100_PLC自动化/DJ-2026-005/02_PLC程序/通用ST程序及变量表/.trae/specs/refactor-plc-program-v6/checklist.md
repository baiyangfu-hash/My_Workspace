# Checklist - PLC程序全面重构 V6.0.0 验证清单

## ⚠️ 核心验证原则

### ✅ 必须替换：变量名（Variable Names）
所有**变量名**必须使用英文，符合801命名规范：
```scl
// ❌ 错误
i_b使能 : BOOL;
s_i步序 : INT;

// ✅ 正确（变量名英文 + 注释中文）
i_bEnable : BOOL;              // 总使能信号(主控系统就绪后置位)
s_iCurrentStep : INT;          // 当前状态机步序(0~10)
```

### ✅ 必须保留：注释（Comments）
所有**代码注释**必须保留中文，便于国内工程师理解：
```scl
(* ============================================================================
 功能块名称: FB_1003_PickPlace_BufferFraming
 功能描述: 边框缓存机 - 取放料机构纯逻辑功能块
 核心工艺: 一次取两根边框(前后夹紧同时动作), 4层循环取2次
 ============================================================================ *)

i_bEnable : BOOL;              // 总使能信号(主控系统就绪后置位)
i_bZAxis_JogUp : BOOL;        // 手动-Z轴向上点动
```

### 📋 Grep验证命令
```bash
# 搜索变量名中的中文（应返回0结果，或仅匹配注释行）
grep -P '[\x{4e00}-\x{9fff}]' *.scl | grep -v '^\s*//' | grep -v '^\s*\*' | grep -v '^\s*\('

# 预期输出: 0 matches (或仅有注释行的中文文字)
```

## 验证方法说明

### 工具辅助验证
1. **VS Code Grep搜索**:
   - 正则表达式: `[\x{4e00}-\x{9fff}]`
   - 排除: 注释行（// 或 * 开头）、字符串字面量
   - 目标文件: 3个重构的FB源文件

2. **TIA Portal 编译器**:
   - 执行"编译所有"操作
   - 检查输出窗口的错误和警告列表
   - 重点确认无 TC001（未声明符号）和 TC002（类型不匹配）

3. **Diff对比工具**:
   - 使用 Beyond Compare / VS Code Diff
   - 对比重构前后版本的每个FB
   - 仅允许差异: 变量名（Chinese → English）
   - 不允许差异: 逻辑结构、运算符、条件判断

### 人工审查重点
1. **状态机转换图**: 绘制重构后的状态转换图，与原版对比确保一致
2. **接口交叉引用**: 从OB1出发，逐个追踪每个参数到FB定义再到GlobalVars
3. **边界条件**: 检查使能失效、故障触发、停止命令等关键路径的逻辑正确性
