# Tasks - PLC程序全面重构 V6.0.0

## ⚠️ 核心执行原则（必须遵守）

### ✅ 变量名英文化 + 注释中文化
**这是本次重构的最重要原则，所有任务都必须遵循：**

1. **必须替换**：所有**变量名**（Variable Names）
   - VAR_INPUT, VAR_OUTPUT, VAR, VAR_CONSTANT 中的标识符
   - 代码逻辑中的变量引用
   - 定时器实例名称（fb_t_xxx）

2. **必须保留**：所有**注释**（Comments）
   - 单行注释 `// 中文说明`
   - 多行注释 `(* 中文说明 *)`
   - 功能块头部注释块
   - #region 标题文字

3. **示例对比**：
```scl
// ❌ 重构前（变量名中文）
VAR_INPUT
    i_b使能 : BOOL;           // 总使能信号
    s_i步序 : INT;            // 当前步序
END_VAR

// ✅ 重构后（变量名英文 + 注释中文保留）
VAR_INPUT
    i_bEnable : BOOL;         // 总使能信号(主控系统就绪后置位)
    s_iCurrentStep : INT;     // 当前状态机步序(0~10)
END_VAR
```
