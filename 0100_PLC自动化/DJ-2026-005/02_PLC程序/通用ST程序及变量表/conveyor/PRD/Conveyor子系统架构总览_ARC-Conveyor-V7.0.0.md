## 1. 架构概览

### 1.1 FB清单

| FB编号 | 名称 | 类型 | 实例数 | 接口 (in+out) | 职责 |
|:------:|------|:----:|:-----:|:-----------:|------|
| **FB_1002** | SingleLayerConveyor | 编排器 | 4 | 22+11=33 | 工艺调度、状态机、报警编码 |
| **FB_1011** | CylinderControl | 执行器 | 8 (4×2) | 5+5=10 | 单气缸伸出/收回+超时+传感器冗余 |
| **FB_1012** | ConveyorMotor | 执行器 | 4 | 6+5=11 | 电机转向+安全门+VFD故障 |

> **FB_1011 / FB_1012 为通用执行器**，存放于共享库 `01_SharedLibraries/SysLib/actuator/`，所有项目可复用。

> **FB_1001 (Conveyor4Layer) 已取消**。其汇总功能由 OB1 的 FOR 循环代替。

### 1.2 层次结构

```
┌────────────────────────────────────────────────────────────────┐
│  L0: OB1 (主循环)                                               │
│      FOR i:=1 TO 4 循环实例化4个 FB_1002                         │
│      运行/故障/报警汇总 (OR/优先级MIN)                           │
├────────────────────────────────────────────────────────────────┤
│  L1: FB_1002 ×4 (编排层)                                        │
│      9步 Step_S 状态机 + 手动模式分发                            │
│      报警码编码 (10x/11x/12x/13x/14x)                           │
├────────────────────────────────────────────────────────────────┤
│  L2: FB_1011 ×8 + FB_1012 ×4 (执行层)                           │
│      气缸: 电磁阀 + 超时 + 传感器冗余                            │
│      电机: 正转/反转/慢速 + 安全门 + VFD                         │
└────────────────────────────────────────────────────────────────┘
```

### 1.3 数据流

```
HMI 按钮 ──────┐
IO 传感器 ──────┤
全局变量 ──────┤
               ├──→ OB1 ──→ fbConveyor[1]: FB_1002
安全信号 ──────┤              ├─ fbBlock: FB_1011 ──→ IO(Y30/Y34/...)
取料确认 ──────┘              ├─ fbSeparate: FB_1011 ──→ IO(Y31/Y35/...)
                              └─ fbMotor: FB_1012 ──→ IO(Y10/Y12/...)
                                                          │
                              ←── q_iAlarmCode ──→ FB_2001 (报警管理)
                              ←── q_bLayerFeedDone ──→ FB_1003 (取放料)
                              ←── q_iCurrentState ──→ HMI
```

## 2. 重构前后对比

### 2.1 接口面

| 指标 | 旧架构 (V6.0.0) | 新架构 (V7.0.0) | 改善 |
|------|:-------------:|:-------------:|:----:|
| FB 数量 | 2 | 3 | +1 (但每个更小) |
| 总接口数 | 126 | 54 (33+10×2+11) | **-57%** |
| FB_1001 接口 | 87 | **0 (取消)** | **-100%** |
| FB_1002 接口 | 39 | 33 | -15% |
| 每FB平均接口 | 63 | 18 | -71% |

### 2.2 内聚性

| 维度 | 旧架构 | 新架构 |
|------|--------|--------|
| 气缸控制 | 混在 FB_1002 状态机中，3处重复 | 独立 FB_1011，复用2次 |
| 电机控制 | 混在 FB_1002 状态机中 | 独立 FB_1012 |
| 传感器冗余 | 手动检测，输出分散 | FB_1011 自动检测，输出集中 |
| 超时逻辑 | 定时器散布状态机各处 | FB_1011 统一管理 |
| 报警编码 | 外部传入层号计算 | FB_1002 自包含编码 |

### 2.3 耦合度

| 耦合点 | 旧架构 | 新架构 |
|--------|--------|--------|
| FB_1001↔FB_1002 | 87个信号全部透传 | **不存在** |
| 气缸↔状态机 | 状态机直接读写传感器+电磁阀 | 通过 Extend/Retract + IsExtended/IsRetracted 协议 |
| 电机↔状态机 | 状态机直接读写方向输出 | 通过 Fwd/Rev/Slow + Running 协议 |
| 报警↔传感器 | 报警码依赖传感器状态 | 报警码来自子FB的 BOOL 汇总 |

## 3. 可扩展性设计

### 3.1 新增一层输送机

只需在 OB1 中增加 `FOR i:=1 TO 5`：

```
(* 从4层扩展到5层 *)
FOR i := 1 TO 5 DO  (* 仅修改循环上限 *)
    fbConveyor[i](...);
END_FOR;
```

### 3.2 新增气缸类型

直接复用 FB_1011，传入不同语义即可：

```
fbClamp : FB_1011_CylinderControl;  (* 新增夹紧气缸 *)
fbClamp.i_bExtend := ...;           (* 语义: 夹紧 *)
fbClamp.i_bRetract := ...;          (* 语义: 松开 *)
```

### 3.3 替换电机驱动类型

只需替换 FB_1012 为新的驱动FB（如伺服），FB_1002 编排器无需修改：

```
(* 变频电机 → 伺服电机 *)
fbMotor : FB_1013_ServoMotor;  (* 接口兼容 *)
```

### 3.4 新增传感器

在 FB_1011 的冗余检查基础上，如需N取M表决，只需升级 FB_1011 内部逻辑：

```
(* V8.0 升级: 3取2表决 *)
bVote := (i_bSensor1 AND i_bSensor2) 
      OR (i_bSensor2 AND i_bSensor3) 
      OR (i_bSensor1 AND i_bSensor3);
```
