# 使用说明 FB_1002_SingleLayerConveyor_BufferFraming

## 1. 功能说明

单层输送机控制块。被 FB_1001 容器块实例化4次(L1~L4)，独立控制每层的物料输送。采用9步 Step_S 状态机，**先输送再分料**。

## 2. 实例化

```
VAR
  fbConvLayer1 : FB_1002_SingleLayerConveyor_BufferFraming;
END_VAR
```

## 3. 输入接线

| 信号类 | 来源 |
|--------|------|
| 模式/启停 | OB1←HMI |
| 手动操作 | OB1←HMI(M10~M45) |
| 传感器 | OB1←IO (X21~X57) |
| 安全互锁 | OB1←External(FB_3001) |
| 工艺参数 | OB1←HMI(D100/D101/D108) |

## 4. 输出接线

| 信号类 | 去向 |
|--------|------|
| 执行器 | OB1→IO (Y10~Y37) |
| 状态/报警 | OB1→HMI + OB1→FB_2001 |
| 放料完成 | OB1→FB_1003 |

## 5. 参数设定（HMI）

| 参数 | D区 | 说明 |
|------|-----|------|
| 输送速度 | D100 | 共用(IEC REAL) |
| 分料超时 | D101 | ms |
| 阻挡等待 | D108 | ms |

## 6. 调试要点

1. Step0 初始反转复位需保证反转限位或超时(3s)到达
2. Step20 到位检测需要1&2双传感器同时ON + 阻挡上升到位
3. 分料推出/复位步均使用同一超时定时器，超时置报警码(100~103)
4. 安全门开(M8取反)时输送正转/反转/慢速被禁止
5. 取料机构在安全区(M515)互锁下不会进入取料请求
