### 4.6 质量保证措施

#### 4.6.1 命名规则遵循度

所有新变量名严格遵循 **801_PLC变量命名与功能块规范_DEV-V1.0.5**：

```
格式: [前缀]_[设备名]_[功能描述]
前缀体系:
  - i_b/i_r/i_i: 输入变量 (BOOL/REAL/INT)
  - o_b/o_r/o_i: 输出变量 (BOOL/REAL/INT)
  - q_b/q_e/q_i: 调试/中间层输出变量
  - s_b/s_i: 内部状态变量 (BOOL/INT)
  - fb_t: 定时器功能块实例 (FB_TON)
  - STP_: 状态机步序常量 (State Step)
  - ALM_: 报警码常量 (Alarm Code)
  - T_DEF_: 默认定时参数 (Time Default)
  - LAYER_/PICK_: 业务逻辑常量
```

#### 4.6.2 注释策略

- ✅ **变量名100%英文**：符合国际PLC编程标准
- ✅ **注释100%中文**：便于国内工程师阅读和理解
- ✅ **混合模式最佳实践**：兼顾标准化和本地化需求

示例：
```pascal
VAR_INPUT
    i_bEnable : BOOL; // 总使能信号(主控系统就绪后置位)
    i_bAutoMode : BOOL; // 自动运行模式选择
END_VAR

VAR_CONSTANT
    STP_Idle : INT := 0; // 空闲待机
    ALM_ZAxisServoFault : INT := 101; // Z轴伺服驱动器故障
END_VAR
```
