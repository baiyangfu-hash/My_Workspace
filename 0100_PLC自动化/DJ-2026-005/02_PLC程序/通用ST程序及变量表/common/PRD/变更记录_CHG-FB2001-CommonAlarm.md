## 3. V5.0.0 版本详细变更说明

### 3.1 变更基本信息

| 属性 | 值 |
|------|-----|
| **变更编号** | CHG-PLC-2026-V500-FB2001 |
| **技术领域** | PLC (程序代码) + 接口重构 |
| **业务性质** | REQ (必需改进) - 系统性变量名标准化 |
| **影响范围** | INTERFACE (接口级) - FB_2001全部16个接口变量 |

### 3.2 变更背景与原因

#### 3.2.1 问题发现
在V5.0.0全面重写过程中，发现FB_2001的接口变量名仍使用中文命名（如`i_i输送机报警`, `o_w全局报警字`），而：
- GlobalVars.db已升级至V3.0.0，使用英文变量名
- OB1.scl已升级至V5.0.0，调用时使用英文变量名
- 导致**编译错误TC001：未声明的符号**

#### 3.2.2 解决方案
将FB_2001的所有16个接口变量名从中文替换为英文，确保三层架构（GlobalVars ↔ OB1 ↔ FB）完全一致。

| 1 | i_i输送机报警 | i_iConveyorAlarm | INT | 四层输送机报警代码 (1~7段) |

### 3.4 命名规则说明

所有新变量名严格遵循 **801_PLC变量命名与功能块规范_DEV-V1.0.5**：

```
格式: [前缀]_[功能描述]
示例: i_iConveyorAlarm (输入-整数-输送机报警)
```

**前缀体系**:
- `i_i`: 整数型输入变量
- `i_b`: 布尔型输入变量
- `o_w`: 字型输出变量
- `o_i`: 整数型输出变量
- `o_b`: 布尔型输出变量
