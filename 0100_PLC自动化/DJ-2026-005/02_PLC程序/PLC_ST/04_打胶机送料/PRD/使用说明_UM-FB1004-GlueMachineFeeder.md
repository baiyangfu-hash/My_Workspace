# 使用说明 FB_1004_GlueMachineFeeder_BufferFraming

## 1. 功能

X2轴横移+打胶机交互。4步D760，收到取放料完成后直接去取料位取边框再送料。

## 2. 安全区信号

- q_bSafetyZoneSignal=TRUE → Y47闭合：打胶机安全保护关闭
- q_bSafetyZoneSignal=FALSE → Y47断开：安全区域恢复

## 3. 打胶机通信

| 信号 | 地址 | 方向 |
|------|------|:--:|
| 允许送料 | X76 | ←打胶机 |
| 取料完成 | X102 | ←打胶机 |
| 允许抓料 | Y44 | →打胶机 |
| 安全区 | Y47 | →打胶机 |

## 4. 调试要点

1. D760=2在到位后同时关Y47并等待X76后才发Y44
2. X102取料完成后立即返回待机并开安全区
3. X2轴区域4传感器用于检测送料平台是否有边框(阻塞回原点逻辑F81)
