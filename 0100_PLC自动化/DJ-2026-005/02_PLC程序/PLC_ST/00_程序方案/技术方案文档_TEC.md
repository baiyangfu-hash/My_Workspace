### 3.2 PLC 型号

- **目标平台**：平台无关ST代码（轴控抽象化，不绑定特定PLC型号）

### 3.3 依赖库

- **SysLib**（共享库路径：`01_SharedLibraries/SysLib`）

  - `FB_1011_CylinderControl`：气缸控制（伸出/收回+超时+传感器冗余）
  - `FB_1012_ConveyorMotor`：电机控制（正转/反转/慢速+安全门+VFD故障）
  - `ST_ServoAxis`：伺服轴结构体（PLCopen MC Part 1 嵌套结构体）

## 4. 控制方案

### 4.1 软件架构（扁平化组件架构）

```
┌─────────────────────────────────────────────────────────────┐
│  OB1 主程序组织块 (调度中心, 不含业务逻辑)                     │
│  ├── Step 1: FB_3001_ExternalInteraction (DJ005实现名: FB_ExternalDeviceInteraction) │
│  ├── Step 2: FB_1002 ×4 (输送机 L1~L4, FOR循环)             │
│  │   └── 汇总: q_bRunning(OR) / q_bFault(OR) / q_iAlarm(MIN)│
│  ├── Step 3: FB_1003 (取放料, VAR_IN_OUT直连伺服轴)          │
│  ├── Step 4: FB_1004 (送料, 工站间信号转发)                  │
│  └── Step 5: FB_2001 (公共报警, 指示灯/蜂鸣器)               │
├─────────────────────────────────────────────────────────────┤
│  GlobalVars 数据块 (I/O映射中心, ~220+变量)                  │
│  ├── stExternal  : STRUCT (安全+外设交互)                    │
│  ├── stConveyor  : STRUCT (4层输送机, 含ARRAY[1..4])         │
│  ├── stPickPlace : STRUCT (取放料+伺服轴)                    │
│  ├── stFeeder    : STRUCT (送料机构)                         │
│  ├── stGlobal    : STRUCT (全局报警+指示灯)                  │
│  └── astServoAxis: ARRAY[1..3] OF ST_ServoAxis              │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 架构特点

- **纯协调层主控**：OB1 不包含业务逻辑，仅做 FB 实例化、调用顺序管理和 I/O 映射
- **纯逻辑块工站**：所有工站 FB 无物理地址依赖，完全通过接口变量交换数据
- **集中式 I/O 映射**：所有 X/Y 地址映射集中在 GlobalVars 数据块
- **严格执行顺序**：输入映射 → 外部信号 → 工站调用(输送→取放→送料) → 输出映射 → 报警
- **运动控制抽象**：FB_1003 通过 VAR_IN_OUT 直连 ST_ServoAxis 结构体，FB内直接操作 PLCopen 接口

### 4.3 状态机方案

| 工站 | 步序类型 | 步数 | 步序编号 | 核心流程 |
|------|----------|------|----------|----------|
| 输送机 | Step_S | 9步 | 0→1→2→10→20→30→50→60→70 | 先输送再分料 |
| 取放料 | STL S20~S25 | 6步 | S20→S21→S22→S23→S24→S25 | 上升→夹紧→横移→下降→松开 |
| 送料 | D760步序 | 4步 | 0→1→2→3 | 取料位→放料位→待机位 |

### 4.4 数据流方案

```
HMI ──→ GlobalVars(M/D区) ──→ OB1 ──→ 各FB(通过stXxx结构体)
                                         ↓
各FB ──→ GlobalVars(q_aXxx输出) ──→ OB1(汇总) ──→ HMI显示
                                         ↓
各FB ──→ FB_2001(报警码) ──→ GlobalVars(D400-D425) ──→ MES
```

## 5. 安全方案

### 5.1 安全检测

- **急停**：X101 常闭检测，触发后全部停止
- **安全门**：X140~X147 共8路互锁，任一打开禁止运行
- **HMI STOP**：X77 独立检测，与急停分开处理
- **全局互锁**：M200 系统使能标志（安全条件满足时置TRUE）

### 5.2 故障安全状态

- 急停触发 → 所有执行器断电（硬件安全继电器优先）
- 安全门打开 → 禁止自动运行，当前步序保持
- 变频器故障 → 对应层输送机停止
- 伺服报警 → 对应轴停止运动，FB输出故障标志

### 5.3 安全等级

- 符合 ISO 13849-1 PLd 要求
- 硬件常闭触点 + 软件双重检测
- 安全相关信号不依赖软件逻辑（硬件安全继电器回路独立于PLC）
