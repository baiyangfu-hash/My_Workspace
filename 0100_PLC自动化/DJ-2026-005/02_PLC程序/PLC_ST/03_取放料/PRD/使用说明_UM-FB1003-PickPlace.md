# 使用说明 FB_1003_PickPlace_BufferFraming

## 1. 功能

边框缓存机取放料机构控制。6 步 S20~S25 状态机，Z 轴升降 + X1 轴横移，4 夹爪独立控制，按层选放料点（L1/L3→D520, L2/L4→D540）。

## 2. 状态机

| 步号 | 名称 | 动作 |
|------|------|------|
| S20 | 待机 | 等待输送机送料完成信号 |
| S21 | Z轴下降 | Z 轴下降至取料高度，使能伺服 |
| S22 | 夹爪取料 | 4 夹爪闭合 + 产品检测（边框有无判断） |
| S23 | Z轴上升 | Z 轴升至安全高度 |
| S24 | X1轴横移 | X1 轴横移至放料点（按层选 D520/D540） |
| S25 | 放料 | 夹爪释放，取放料完成信号 |

## 3. 伺服轴控制

Z 轴和 X1 轴通过 VAR_IN_OUT io_stZAxis/io_stX1Axis (ST_ServoAxis) 直接控制，包含：
- stPower: 使能/状态
- stAbs: 绝对定位
- stStop: 急停
- stSensor: 限位+报警

## 4. 按层选放料点

| 层 | 放料点 | 判断逻辑 |
|----|--------|----------|
| L1, L3 | D520 | i_iPickLayer MOD 2 = 1 |
| L2, L4 | D540 | i_iPickLayer MOD 2 = 0 |

## 5. 调试要点

1. i_iPickLayer 必须从外部输入（不可用 o_iCurrentPickLayer 反馈），否则 S20→S21 转换条件永远 FALSE
2. Z 轴/X1 轴使能前需确认 stPower.Status=TRUE
3. 边框检测在 S22 步内完成，无边框→不夹取→报警
4. 夹爪独立控制，支持单爪调试模式
