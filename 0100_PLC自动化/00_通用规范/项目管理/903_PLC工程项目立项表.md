# PLC 工程项目立项表

> **规范编号**: 903
> **适用领域**: PLC 自动化 / 电气工程
> **版本**: V1.0.0
> **状态**: Active
> **创建日期**: 2026-06-03

## 1. 模板说明

本模板定义 PLC 自动化工程项目的信息模型，用于项目立项、总览展示和工程移交。

**设计原则**：
- 面向电气工程师视角，回答"这是什么项目""在什么平台上跑""经历过哪些变更"
- 区别于通用 PM 立项表（面向软件开发管理），本模板聚焦**PLC 工程本身的技术与业务属性**
- 信息分为五个区块：业务身份 → 技术环境 → 工程规模 → 工程状态 → 变更台账

## 2. 信息模型定义

### 2.1 业务身份（这是什么项目）

| 字段 | 必填 | 说明 | 示例 |
|------|:----:|------|------|
| 项目名称 | 是 | 含版本号 | DJ-2026-005_PLC_边框缓存机_V1.0.0 |
| 业务描述 | 是 | 控制对象 + 功能定位（一句话） | 边框缓存机自动化控制系统，负责输送→定位→取放料→打胶全流程控制 |
| 工艺范围 | 是 | 涉及的工艺段/功能分区 | 输送机、取放料机构、打胶机 |
| 客户/产线 | 否 | 所属产线或客户名称 | XX 车间 3# 产线 |

### 2.2 技术环境（在什么平台上开发）

| 字段 | 必填 | 说明 | 可选值示例 |
|------|:----:|------|-----------|
| 编程平台 | 是 | IDE 开发环境 | 西门子 TIA Portal V17 / 三菱 GX Works3 / Codesys / 贝加莱 Automation Studio |
| PLC 型号 | 否 | 控制器硬件型号 | S7-1217 DC/DC/DC / R04EN / Raspberry Pi CM4 |
| HMI 型号 | 否 | 触摸屏型号（无 HMI 则填"无"） | KTP700 Basic PN / GS2107-WTBD / 无 |

### 2.3 工程规模（项目大概多大）

| 字段 | 数据来源 | 说明 |
|------|---------|------|
| 程序块总数 | 扫描项目文件统计 | OB + FB + FC 的数量汇总 |
| 数据块规模 | 解析 DB 文件 | DB 数量 / 总变量数 |
| 工艺模块数 | 从文件夹结构识别 | 功能分区的数量（如 conveyor、feeder、pickplace） |
| 最后修改时间 | Git 或文件时间戳 | 最近一次代码变更的日期 |

### 2.4 工程状态（当前健康度）

| 字段 | 说明 |
|------|------|
| 规范合规率 | 命名规范 / 注释规范 / 结构规范的检查通过率（百分比） |
| 当前阶段 | 开发中 → 调试验收 → 量产维护 → 已归档 |

**当前阶段枚举值**：

| 阶段 | 说明 |
|------|------|
| `developing` | 开发中：程序编写阶段，变更频繁 |
| `commissioning` | 调试验收：现场联调，问题修复为主 |
| `production` | 量产维护：稳定运行，偶发变更 |
| `archived` | 已归档：项目结项，不再维护 |

### 2.5 变更台账（项目经历了哪些变更）

| 字段 | 说明 |
|------|------|
| 变更总数 | 累计已创建的变更单数量 |
| 待处理变更数 | 处于 `pending_analysis` / `analysis` / `in_review` 阶段的变更单数量 |
| 最近变更记录 | 按时间倒序展示最近 **8 条**变更摘要 |

**变更记录条目格式**：

| 字段 | 说明 | 示例 |
|------|------|------|
| 变更日期 | 变更单创建或最后更新的日期 | 2026-06-02 |
| 变更编号 | 符合 CHG-040 规范的自动编号 | CHG-PLC-2026-012 |
| 变更标题 | 一句话概括变更内容 | 修复输送机急停时序错误 |
| 当前状态 | 变更单所处状态 | completed |

**状态图标参考**：

| 状态 | 图标 | 含义 |
|------|:----:|------|
| pending_analysis | 🔵 | 待分析 |
| analysis | 🟡 | 分析中 |
| in_review | 🟠 | 审核中 |
| approved | ✅ | 已批准 |
| in_progress | 🔧 | 执行中 |
| testing | 🧪 | 测试中 |
| completed | ✅ | 已完成 |
| rejected | ❌ | 已驳回 |
| cancelled | ⛔ | 已取消 |
| archived | 📦 | 已归档 |

## 4. 与其他规范的关系

| 关联规范 | 关系 | 说明 |
|----------|------|------|
| CHG-040 变更管理规范 | 依赖 | 变更台账的编号规则、状态流转遵循 CHG-040 |
| 905 SCL 编程规范 | 引用 | 规范合规率的检查依据来自 905 规则集 |
| 904 命名规范 | 引用 | 命名合规率检查依据 |
| PM-042 全局项目管理规范 | 上位 | 本模板是 PM-042 在 PLC 领域的特化 |

## 5. 数据采集方式

| 信息块 | 采集方式 | 自动化程度 |
|--------|---------|-----------|
| 业务身份 | 手动填写（立项时录入）或从 PRD 提取 | 半自动 |
| 技术环境 | 手动填写（立项时录入）或从项目配置解析 | 半自动 |
| 工程规模 | 扫描项目文件自动统计 | 全自动 |
| 工程状态 | 运行规范检查器自动计算 | 全自动 |
| 变更台账 | 从变更管理系统读取 | 全自动 |
