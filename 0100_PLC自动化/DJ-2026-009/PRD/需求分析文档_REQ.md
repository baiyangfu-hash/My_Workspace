# 需求分析文档 (REQ) - DJ-2026-009 长边框堆垛机

## 1. 真实工艺工况与功能需求

长边框自动码垛机用于自动化生产线末端，接收打胶装框完成的光伏铝边框，按照设定的配方（层数、对数、隔纸厚度、塑钢带层）进行全自动码垛装托。

### 1.1 双路进料与暂存需求
- 支持 1# 输送皮带与 2# 输送皮带双路进料；
- 实时统计 `输送皮带2入料计数`，与 `允许入料数量` 进行互锁控制，防止后道溢出。

### 1.2 叠垛移载与多轴定位需求
- **X轴（水平移载）**：支持 `待机点`、`取料点`、`放料点`、`拉隔纸起点`、`拉隔纸铺设点`；
- **Z轴（垂直升降）**：支持 `取料下降减速点`、`放料下降减速点`、`拉隔纸高度`、`隔纸铺设高度`、`长短边归正高度`；
- 支持动态计算 `移载抓取中边框数量` 与 `层已码垛边框对数`。

### 1.3 隔纸放料架与自动裁切需求
- **隔纸架 Z 轴**：支持 `换料点`、`拉隔纸点`、`过道安全点`、`边框阻挡点`；
- 具备 `隔纸厚度补偿` 与 `隔纸裁切长度补偿设定 (mm)`。

### 1.4 边框双向纠偏归正需求
- 包含 `边框短边归正Z轴位置补偿`、`边框长边归正X轴位置补偿`、`边框长边归正Z轴位置补偿`。

### 1.5 塑钢带与托盘叠垛管理需求
- 支持配方设定：`边框宽度`、`边框层高`、`边框槽壁厚度`、`整托边框根数`；
- 支持设定：`放塑钢带层数设定1/2/3 (层)`，到达设定层数自动执行塑钢带打捆工步。
