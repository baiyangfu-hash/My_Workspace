## 3. 各工站工艺流程

### 3.1 输送机工站 (conveyor)

```
  输送机工艺流程:
  ==================================================
  材料到达 → 阻挡下降 → 输送正转 → 到位检测
         → 阻挡上升 → 分料推出 → 慢速送出 → 放料完成
```

**状态机步骤**:
- Step 0: 待机
- Step 1: 材料到达检测
- Step 2: 阻挡气缸下降
- Step 3: 输送带正转
- Step 4: 到位检测
- Step 5: 阻挡气缸上升
- Step 6: 分料气缸推出
- Step 7: 慢速送出
- Step 8: 放料完成

### 3.2 取放料工站 (pickplace)

```
  取放料工艺流程:
  ==================================================
  等待放料完成 → Z轴下降 → 夹爪夹紧 → 产品检测
             → Z轴上升 → X1轴后移到放料位
             → Z轴下降 → 夹爪松开 → Z轴上升 → 放料完成通知
```

**状态机步骤** (S20~S25):
- S20: 等待放料完成
- S21: Z轴下降 + 夹爪夹紧
- S22: 产品检测确认
- S23: Z轴上升 + X1轴横移
- S24: Z轴下降 + 夹爪松开
- S25: Z轴上升 + 放料完成通知

### 3.3 送料工站 (feeder)

```
  送料工艺流程:
  ==================================================
  等待取放料放料完成 → X2轴前移到取料位
                    → 等待下游设备允许送料
                    → 发送允许抓料 → 等待取料完成
                    → X2轴返回待机位 → 循环
```

**状态机步骤** (D760):
- D760.0: 等待取放料放料完成
- D760.1: X2轴前移到取料位
- D760.2: 等待下游允许送料 + 发送允许抓料
- D760.3: 等待取料完成 + X2轴返回待机位

### 3.4 外部设备交互 (external)

```
  外部设备交互流程:
  ==================================================
  上游设备信号处理 → 下游设备信号处理
                  → 安全联锁判断
                  → 就绪信号生成
                  → 送料请求协调
                  → 外部设备报警汇总
```

### 3.5 公共报警管理 (common)

```
  公共报警管理流程:
  ==================================================
  各工站报警汇聚 → 全局报警字计算 → 最高优先级选取
               → MES 报警队列管理 (去重)
               → 新报警脉冲标志 (MES 上传触发)
```

## 4. 工站间信号传递

| 上游工站 | 下游工站 | 信号名称 | 信号说明 |
|---------|---------|---------|---------|
| conveyor | pickplace | q_bLayerFeedDone | 输送机放料完成 |
| pickplace | feeder | q_bPlaceDoneToFeeder | 取放料放料完成 |
| external | OB1 | q_bSystemSafetyConditionMet | 系统安全条件满足 |
| 各工站 | common | q_iAlarmCode | 各工站报警码 |

## 5. 安全联锁

### 5.1 系统使能条件

系统使能 = TRUE 需同时满足：
1. 急停按钮未按下
2. 安全门已锁定
3. 外部设备无急停/故障

### 5.2 工站间互锁

- 取放料需等待输送机放料完成
- 送料需等待取放料放料完成
- 外部设备交互失败时停止本机
