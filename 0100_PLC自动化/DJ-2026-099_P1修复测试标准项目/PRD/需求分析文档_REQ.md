## 1. 项目概述

### 1.1 项目背景

测试P1-3/P1-7修复

本项目为自动化控制设备，通过 PLC 控制伺服电机、气缸、输送带等执行机构，实现物料的自动分料、输送、取放和送料功能。设备需与上下游设备进行信号交互，并通过 HMI 人机界面实现操作和监控。

### 1.2 项目目标

- 搭建符合 LSP-907 规范的标准 PLC 项目骨架
- 实现各工站核心工艺逻辑（输送/取放/送料/外部交互/公共报警）
- 通过现场调试验收，交付可量产运行的 PLC 程序
- 提供完整的设计文档和操作手册

### 1.3 项目范围

**包含**:
- PLC 程序开发（OB1 + 5个工站 FB + GlobalVars DB）
- HMI 界面设计（自动监控/手动操作/参数设定/报警显示）
- 现场调试支持
- 完整文档交付（REQ/INT/DSN/TEC + 程序文档）

**不包含**:
- 电气原理图设计（由电气工程师负责）
- 机械结构设计（由机械工程师负责）
- 非本项目相关的功能

### 2.3 功能详细描述

#### 2.3.1 自动分料 (F-001)

输送机工站在自动模式下，按 9 步状态机执行分料输送循环：
1. 材料到达检测 → 2. 阻挡气缸下降 → 3. 输送带正转 → 4. 到位检测
→ 5. 阻挡气缸上升 → 6. 分料气缸推出 → 7. 慢速送出 → 8. 放料完成

每步设有超时检测和传感器故障检测，触发报警时停止运行。

#### 2.3.2 取放料循环 (F-003)

取放料工站接收输送机放料完成信号后，按 6 步状态机执行取放料循环：
等待放料完成 → Z轴下降 → 夹爪夹紧 → 产品检测 → Z轴上升 → X1轴横移 → Z轴下降 → 夹爪松开 → Z轴上升 → 放料完成通知

一次取两根边框（长边x2 + 短边x2），4层循环2次完成全部取料。

## 3. 非功能需求

### 3.1 性能需求

- **扫描周期**: PLC 扫描周期 ≤ 10ms，确保实时响应
- **定位精度**: 伺服轴定位精度 ±0.1mm
- **响应时间**: 急停信号响应时间 ≤ 50ms
- **HMI 刷新率**: 状态刷新周期 ≤ 500ms

### 3.2 可靠性需求

- **MTBF**: 平均无故障运行时间 ≥ 8000 小时
- **冗余设计**: 关键传感器采用双传感器冗余（如到位检测）
- **故障恢复**: 报警复位后可快速恢复运行，无需重新上电
- **数据完整性**: GlobalVars 数据块掉电保持

### 3.3 安全性需求

- **急停**: 急停按钮按下后，所有运动立即停止
- **安全门**: 安全门打开时，禁止自动运行
- **安全继电器**: 通过安全继电器回路实现硬接线安全
- **软件互锁**: 各工站间信号互锁，防止误动作
- **限位保护**: 伺服轴正反向限位开关保护
